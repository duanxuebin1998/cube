# CPU3 当前屏幕菜单树

更新日期：2026-07-18

本文件与同目录 `CPU3当前屏幕菜单树.opml` 同口径，用于在 Markdown 中快速查看 CPU3 当前菜单层级。`[只读]` 表示该叶子项仅用于显示或状态确认，不作为用户可写参数入口。AO输出当前实际显示5组16项，其中12项可操作、4项只读；`AO SIL/WHG`、原错误等级槽位和`DAC回读电流`只作隐藏预留，不进入本菜单树。`输出电流`表示最近一次成功下发给AD5421的电流命令值，不是DAC回读或物理环路实测值。AO分组和叶子按当前OLED实际短名列出；规范名到短名的完整映射见 `CPU3参数名称优化确认清单.md`，短名不改变参数或枚举语义。
