# CPU3参数名称优化确认清单

日期：2026-07-15

确认状态：已按“统一一个中文名称；名称过长时另设屏幕短名”重新整理。本文件覆盖CPU3可见菜单名称；AO输入值、输入百分比和输出电流虽然来自运行态，但属于AO菜单只读项，因此在第4节列出。其它状态页运行态字段仍按`CPU3状态页不同状态显示信息确认表.md`维护。

## 1. 使用说明

本文用于确认 CPU3 屏幕菜单参数名称是否需要优化。原则是：**同一个参数只确定一个正式中文名称**，文档和参数清单统一使用该名称；如果正式名称过长，再提供一个“屏幕短名”用于 OLED 菜单显示。

确认方式建议：

- `同意`：按“统一中文名称”修改文档和参数名称；如有屏幕短名，则屏幕菜单显示短名。
- `保留`：继续使用当前参数名称，屏幕短名留空。
- `调整为：xxx`：采用你指定的新正式中文名称。
- `待确认`：需要先确认现场口径或算法含义。

## 2. 命名原则

1. 一个参数只设一个正式中文名称，避免文档内同一变量出现两个中文名。
2. 屏幕短名只服务于 OLED 显示空间，不改变正式中文名称。
3. 单位已经由 `unit` 显示时，正式中文名称里尽量不重复写单位。
4. 同一类参数保持成对命名，例如高/低、上限/下限、起点/终点。
5. 不改 `operanum`、寄存器地址、结构体字段名或协议语义。

当前AO菜单固定为上述5组16项，其中13项可操作、3项只读。12项持久化配置始终可预配置，不受工作模式、电流模式、故障模式或仿真开关状态限制；模式条件只决定配置何时参与输出。`AO输出仿真`作为非持久化运行态动作，仍仅在输出已启用时可操作。`AO输出电流`始终保留在运行状态页，工作模式禁用、CPU2快照无效或尚无成功下发记录时显示`N/A`。`AO SIL/WHG`和`DAC回读电流`只作隐藏预留，不进入当前名称清单和OLED菜单；旧`AO输出使能`、正常起点/终点电流、高低报警液位及其电流、调试电流名称不再代表协议20当前语义，只能在历史版本资料中保留。

现有OLED字库缺少`诊、断、仿、真、百、别、站、普、近、际、告`，当前不新增自制字模。规范名称与当前OLED短名按下表冻结；这些差异只用于小屏显示，不改变文档、协议和算法语义。
