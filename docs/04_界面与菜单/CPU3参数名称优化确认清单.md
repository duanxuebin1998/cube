# CPU3参数名称优化确认清单

日期：2026-06-13

确认状态：已按“统一一个中文名称；名称过长时另设屏幕短名”重新整理。本文件只覆盖 CPU3 菜单参数命名，不覆盖状态页运行态字段。读取部件参数页的 `RSSI`、`X角`、`Y角` 显示口径按 `CPU3状态页不同状态显示信息确认表.md` 维护。

## 1. 使用说明

本文用于确认 CPU3 屏幕菜单参数名称是否需要优化。原则是：**同一个参数只确定一个正式中文名称**，文档和参数清单统一使用该名称；如果正式名称过长，再提供一个“屏幕短名”用于 OLED 菜单显示。

确认方式建议：

- `同意`：按“统一中文名称”修改文档和参数名称；如有屏幕短名，则屏幕菜单显示短名。
- `保留`：继续使用当前参数名称，屏幕短名留空。
- `调整为：xxx`：采用你指定的新正式中文名称。
- `待确认`：需要先确认现场口径或算法含义。

## 2. 命名原则

1. 一个参数只设一个正式中文名称，避免文档内同一变量出现两个中文名。
2. 屏幕短名只服务于 OLED 显示空间，不改变正式中文名称。
3. 单位已经由 `unit` 显示时，正式中文名称里尽量不重复写单位。
4. 同一类参数保持成对命名，例如高/低、上限/下限、起点/终点。
5. 不改 `operanum`、寄存器地址、结构体字段名或协议语义。
