# CPU3参数单位与范围补充清单

日期：2026-06-13

## 1. 结论

本文用于跟踪 CPU3 参数菜单 `param_meta[]` 的单位、范围显示和范围校验后续工作。

当前结论：

- 已完成稳定单位补充：机械、液位、水位、罐高、分布、Wartsila、AO、手输值等已确认单位的参数已经在菜单中显示单位。
- 已完成已有范围显示：`is_check=true` 的参数会在详情页显示范围，未额外打开新的范围校验。
- 已完成继电器动态单位：CPU3 V1.11.1.1 起，R1~R4 报警阈值和报警滞回按本路“报警取值源”动态显示 `mm` 或 `℃`。
- 暂不启用新的静态范围：罐高、盲区、分布上下限、单点位置、电机距离等依赖现场配置或其它参数，不适合直接写死范围。
- 本轮已从源码确认：电机限速为 `0.01m/min`，液位找液/滞后阈值为整数 `Hz` 频率差，运行态角度为 `0.01°`，探底角度阈值为 `°`，水位阈值类电容为 `pF` 且参数原始值 `x1000`，零点电容为 `0.1pF`，磁通量 D/T 本质为密度/温度修正量。
- 已完成密度手输值口径整改：CPU3 V1.11.1.2 起，`密度手输值` 按 `kg/m3 x10` 显示和保存，范围为 `0.0~2000.0 kg/m3`；CPU3 本地手输值字段改为 32 位，避免大于 255 的手输值被截断。
- CPU3 本地参数结构已继续演进，当前 `CPU3_PARAM_VERSION` 为 `0x0004`，并保留 `0x0003` 迁移路径；CPU2 设备参数和共享 `DEVICE_PROTOCOL_VERSION` 仍按协议文档单独维护。
- 已同步读取部件参数状态页口径：X/Y 角按 `debug_data.angle_x/y` 的角度 `x100` 显示，读取参数态不受 `bottom_detect_mode` 限制；蓝牙 RSSI 为运行态字段，单位 `dB`，`rssi_valid == 0` 时显示 `RSSI:N/A`，不属于 `param_meta[]` 可写参数。
- 仍需现场或算法确认：称重类原始量含义、尺带伸缩率单位、是否给液位探头距差启用范围校验，以及“尺带类型”选项与厚度映射。

## 2. 参数元数据规则

CPU3 参数菜单的数据来自 `LTD_DISPLAY_CPU3/Application/system_param/system_parameter.c` 中的 `param_meta[]`。

| 字段 | 作用 |
| --- | --- |
| `unit` | 菜单列表、详情页和输入页的单位显示 |
| `flag_checkvalue` | 是否启用写入前范围检查 |
| `valuemin` / `valuemax` | 写入范围 |
| `point` | 小数位，决定原始整数和显示值之间的倍率 |
| `offset` | 输入/显示偏移，当前主要用于磁通量 D/T |

维护原则：

1. 只补 `unit` 属于显示体验变化，通常只升 CPU3 固件版本，不改变 `DEVICE_PROTOCOL_VERSION`。
2. 启用 `flag_checkvalue` 或改 `valuemin` / `valuemax` 会改变现场可写入行为，必须单独评估版本、CHANGELOG 和测试方案。
3. 源相关参数不写静态单位，例如继电器报警阈值和滞回，必须按“报警取值源”动态显示。
4. 动态范围和组合校验不要混入单位补充提交，应单独设计、单独验证。

## 4. 本轮确认结果

依据 CPU2/CPU3 当前源码确认如下。本节只确认单位和倍率口径，不改变寄存器地址、字段顺序或写入行为。

| 参数/类别 | 确认口径 | 源码依据 | 菜单建议 |
| --- | --- | --- | --- |
| 电机限速 | 原始值单位为 `0.01m/min`；`200` 表示 `2.00m/min` | `max_motor_speed` 注释、运动接口 `speed_x100` 和日志均按 `0.01m/min` | 可显示为 `m/min`，`point=2`，单位 `m/min` |
| 运行态电机速度 | 原始值单位为 `0.01m/min` | `debug_data.motor_speed` 注释和打印口径 | 状态/调试页按 `m/min` 显示时用 `point=2` |
| 运行态 X/Y 角 | 原始值为角度 `x100`；`123` 表示 `1.23°` | 读陀螺仪后写入 `angle_x = ax * 100`，显示侧 `point=2` | 已按 `°`、2 位小数显示，保持 |
| 读取参数态 X/Y 角 | 与运行态 X/Y 角同口径；读取部件参数完成态直接按 `debug_data.angle_x/y` 显示，不依赖 `bottom_detect_mode` | `CMD_ReadPartParams()` 读取陀螺仪后刷新 `debug_data.angle_x/y`，CPU3 状态页读取参数上下文直接使用该快照 | 读取参数页保持 `°`、2 位小数；探底/罐高上下文仍按探底模式控制角度显示 |
| 蓝牙连接 RSSI | 运行态原始值为 dB；`rssi_valid` 表示当前快照是否有效 | CPU2 发布 `wireless_pairing_status.rssi_valid/rssi`，CPU3 通过协议 9 读取 | 状态页只读显示 `RSSI:<value>dB` 或 `RSSI:N/A`；不是 `param_meta[]` 参数 |
| 液位找液阈值 | 原始值为整数 `Hz` 频率差；默认 `15` 表示 `15Hz` | 精找液位中直接比较 `frequency_difference` 与 `oilLevelThreshold` | CPU3 V1.11.1.2 起显示单位 `Hz`，`point=0` |
| 液位滞后阈值 | 原始值为整数 `Hz` 频率差；默认 `20` 表示 `20Hz` | 跟随监测中直接比较 `fabs(frequency_difference)` 与 `oilLevelHysteresisThreshold` | CPU3 V1.11.1.2 起显示单位 `Hz`，`point=0` |
| 探底角度阈值 | 原始值为整度；默认 `12` 表示 `12°` | 默认值注释为“单位(度)/倍率*1”，探底判断中直接转 `float` 比较 | 可补单位 `°`，小数位保持 `0` |
| 水位跟随电容阈值 | 原始值为 `pF x1000`；CPU2 V1.12.1.3 默认 `20000` 表示 `20.000pF` | `WaterCapRawToFloat(raw) = raw / 1000.0f`，跟随目标为 `air_cap + threshold` | 可显示单位 `pF`，`point=3` |
| 水位寻找电容阈值 | 原始值为 `pF x1000`；CPU2 V1.12.1.3 默认 `10000` 表示 `10.000pF` | 与水位跟随阈值同用 `WaterCapRawToFloat()` | 可显示单位 `pF`，`point=3` |
| 水位滞后电容阈值 | 原始值为 `pF x1000`；CPU2 V1.12.1.3 默认 `30000` 表示 `30.000pF` | 稳定监测中用 `WaterCapRawToFloat(water_lag_cap_threshold)` | 可显示单位 `pF`，`point=3` |
| 零点电容 | 原始值为 `0.1pF`；保存时 `zero_cap = 10 * cap` | 读取零点电容后保存 `10*cap`，加载时 `zero_cap / 10.0` | 可显示单位 `pF`，`point=1` |
| 当前电容状态量 | 运行态是 float pF；显示侧乘 10 后按 1 位显示 | `current_capacitance` 来自 `Sensor_ReadWaterCapacitance(float*)`，状态页显示 `cap * 10` 且 `point=1` | 状态页可补显示单位 `pF` |
| 磁通量D/密度修正 | 存储原始值以 `10000` 为零点，实际修正量为 `(raw - 10000) / 10` | CPU2 传感器读数后执行 `density += (densityCorrection - 10000) / 10` | CPU3 V1.11.1.2 起文案改为 `密度修正`，单位 `kg/m3`，`point=1` |
| 磁通量T/温度修正 | 存储原始值以 `1000` 为零点，实际修正量为 `(raw - 1000) / 10` | CPU2 传感器读数后执行 `temp += (temperatureCorrection - 1000) / 10` | CPU3 V1.11.1.2 起文案改为 `温度修正`，单位 `℃`，`point=1` |
| 称重类参数 | 当前源码只能确认是称重传感器/算法内部计数，不是物理 g/kg | UART4 取 `int16_t g_weight`，`current_weight = empty_weight - g_weight`，碰撞阈值直接用该内部值计算 | 暂不补 g/kg；可文案标注“称重值”或“计数” |
| 探底称重阈值 | 与称重内部值同口径 | 探底判断直接比较 `current_weight` 和 `bottom_weight_threshold` | 暂不补 g/kg；可显示为“称重值” |
| 密度手输值 | 原始值按 `kg/m3 x10`；`10000` 表示 `1000.0kg/m3` | 运行态密度显示按 `x10 kg/m3`，CPU3 本地手输值字段已改为 32 位保存 | CPU3 V1.11.1.2 起显示为 `kg/m3`，`point=1`，范围 `0~20000` |

### 第四步：动态范围/组合校验设计

前提：完成现场边界和安全策略确认。

候选规则：

- 液位盲区 `<=` 液位罐高。
- 水位盲区 `<=` 水位罐高。
- 区间测量上限/下限满足方向口径和大小关系。
- 分布点数、点间距、最高点距液面、最低点距罐底组合后不越界。
- 单点位置满足盲区和罐高边界。
- 电机运行距离满足普通/强制运动不同安全边界。

注意：这一步不是简单 `param_meta[]` 范围，建议独立做校验函数和测试方案。
