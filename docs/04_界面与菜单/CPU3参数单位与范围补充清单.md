# CPU3参数单位与范围补充清单

日期：2026-06-09

## 1. 背景

当前 CPU3 参数菜单的数据来自 `LTD_DISPLAY_CPU3/Application/system_param/system_parameter.c` 中的 `param_meta[]`。该表已经支持单位、范围和小数位：

- `unit`：菜单显示和输入时使用的单位。
- `is_check`：是否启用范围检查。
- `valuemin` / `valuemax`：输入范围。
- `point`：小数位，决定原始整数和显示值之间的倍率。

现状中有不少参数名称或结构体注释已经表达了单位，但 `param_meta[]` 里单位为空；也有一些参数已经写了 `valuemin/valuemax`，但 `is_check=false`，实际输入没有按范围拦截。CPU3 V1.11.0.0 已先补齐一批稳定单位和显示范围，本文继续作为后续补充清单。

## 2. 补充原则

1. 单位只在语义稳定时补充。名称含 `mm`、结构体注释写明 `0.1mm/0.001mm` 的参数，可以直接补 `mm`。
2. 范围只在不会误伤现场配置时启用。已有明确枚举、布尔、点数、次数、电流范围的参数可以启用；依赖罐高、液位、机械行程的动态范围不建议直接写死。
3. 源相关参数不加静态单位。继电器报警阈值的单位取决于“报警取值源”，可能是液位、水位、温度或浮子位置，不能在 `param_meta[]` 中统一写死。
4. 补单位一般只影响显示和输入提示；启用范围检查会改变参数写入行为，需要按共享协议语义变化评估版本和文档。

## 5. 可以启用已有范围校验

这些参数的 `valuemin/valuemax` 已经写了非零范围，但当前 `is_check=false`。如果确认现场不会依赖超限写入，建议把范围检查打开。

| 参数 | 当前范围字段 | 建议 |
| --- | --- | --- |
| `液位探头距差` | `-999999~999999`，小数 1 位，`mm` | 可启用范围检查；显示为 `-99999.9~99999.9 mm` |
| `磁通量D` | `-10000~10000`，小数 1 位，offset `-10000` | 需先确认 offset 显示口径；确认后启用 |
| `磁通量T` | `-1000~1000`，小数 1 位，offset `-1000` | 需先确认 offset 显示口径；确认后启用 |

## 6. 建议补范围但需要确认上限

这些参数单位明确，但合理范围依赖罐高、机械行程、传感器能力或现场参数，不建议直接写一个固定上限。可以先在文档中标注单位，后续再决定是否加静态范围或动态范围检查。

| 参数 | 建议单位 | 范围建议 | 不确定点 |
| --- | --- | --- | --- |
| `液位罐高` | `mm` | `0~最大机械行程` | 最大罐高是否有项目固定上限 |
| `液位盲区` | `mm` | `0~液位罐高` | 是否允许等于罐高 |
| `水位罐高` | `mm` | `0~最大机械行程` | 是否必须等于液位罐高 |
| `水位盲区` | `mm` | `0~水位罐高` | 是否允许为 0 |
| `称重忽略区` | `mm` | `0~找零/罐高相关行程` | 当前只知道单位，缺少上限 |
| `零点最大偏差` | `mm` | `0~找零允许偏差上限` | 上限需由机械和编码器精度确认 |
| `找零下行距离` | `mm` | `0~水位最大下行距离` | 与回零流程安全边界相关 |
| `水位最大下行距离` | `mm` | `0~机械最大行程` | 对水位/罐底共用，不能随意收窄 |
| `分布点间距` | `mm` | `>0，且点数*间距不超过区间` | 需要动态组合校验 |
| `最高点距液面` | `mm` | `0~液位/罐高` | 依赖液位结果和分布区间 |
| `最低点距罐底` | `mm` | `0~罐高` | 依赖罐底参考 |
| `区间测量上限` | `mm` | `0~罐高` | 与下限存在大小关系 |
| `区间测量下限` | `mm` | `0~罐高` | 与上限存在大小关系 |
| `最高密度点` | `mm` | `0~罐高` | Wartsila 方向口径需确认 |
| `最低密度点` | `mm` | `0~罐高` | Wartsila 方向口径需确认 |

| `最高点液面距` | `mm` | `0~罐高` | 注释写有“0.1mm 或按定义”，需确认倍率 |

| `单点测量位置` | `mm` | `盲区~罐高` | 动态依赖罐高和盲区 |
| `单点监测位置` | `mm` | `盲区~罐高` | 动态依赖罐高和盲区 |
| `电机运行位置` | `mm` | `0~最大机械行程` | 指令参数，需保留调试弹性 |
| `电机上行/下行距离` | `mm` | `0~最大安全距离` | 强制运动和普通运动边界不同 |

## 7. 需要先确认单位

这些参数目前不能直接补单位，建议先和算法/现场口径确认。

| 参数 | 当前线索 | 待确认 |
| --- | --- | --- |
| `液位找液阈值` | 小数 1 位，液位传感器相关 | 是频率阈值、频率差值，还是其它传感器量 |
| `滞后阈值` | 小数 1 位，液位传感器相关 | 是否与液位找液阈值同单位 |
| `水位跟随电容阈值` | 小数 3 位，结构体注释建议明确倍率 | 是电容物理单位、ADC 值，还是 x1000 后的无量纲值 |
| `水位寻找电容阈值` | 小数 3 位 | 同上 |
| `零点电容` | 小数 1 位 | 与水位电容阈值倍率是否一致 |
| `水位滞后电容阈值` | 小数 3 位，结构体注释为 x1000 | 建议显示为“电容(x1000)”或确认真实单位 |
| `探底角度阈值` | 罐底角度，当前无小数 | 是 `°`、0.01°，还是传感器原始值 |
| `探底称重阈值` | 探底称重 | 是重量原始值、g、kg，还是称重 ADC 值 |
| `空载称重/满载称重及上下限` | 称重参数，当前无单位 | 是称重原始值、g、kg，还是内部重量计数 |
| `电机运行电流` | 范围 `1~31` | 这是 TMC 电流档位，不应误写为 A/mA |
| `电机限速` | 结构体注释为 `0.01m/min` | 建议单位显示 `m/min`，但需确认菜单输入是否按该倍率显示 |
| `尺带伸缩率` | 小数 6 位 | 是否为无量纲系数、ppm，或 1/℃ 系数 |
| `R1~R4高高/高/低/低低值` | IEEE754 float | 单位取决于 `报警取值源`，不能静态写死 |
| `R1~R4滞回` | IEEE754 float | 单位取决于 `报警取值源` |
| `R1~R4阻尼系数` | damping factor | 已统一为“阻尼系数”，不是电阻单位 |

## 9. 推荐落地顺序

1. 已完成：第一批稳定单位补充，覆盖编码轮、尺带、液位/水位罐高、盲区、实测罐高偏差、初始罐高和当前罐高。
2. 已完成：部分已有范围显示，覆盖故障自动恢复重跑次数、水位测量方式、分布测点数、悬停时间、AO 电流、COM 参数、手输值等已经 `is_check=true` 的参数。
3. 后续评估是否打开已有范围检查：`液位探头距差`、`磁通量D`、`磁通量T`。
4. 后续再做动态范围或组合校验：罐高相关距离、分布测量上下限、单点位置、电机运行距离。
5. 已完成：继电器报警阈值和报警滞回不在 `param_meta[]` 写静态单位，CPU3 V1.11.1.1 起根据同一路 `报警取值源` 在菜单列表、详情和输入页动态显示 `mm` 或 `℃`。

## 10. 版本影响

- 只补 `unit`：通常属于显示文案/菜单体验变化，预计只需要升级 CPU3 固件版本，不改变 `DEVICE_PROTOCOL_VERSION`。
- 启用 `is_check` 或改变 `valuemin/valuemax`：会改变参数写入行为，属于参数语义变化；需要评估 CPU2/CPU3 固件版本、CHANGELOG、版本改动与测试方案，必要时补充协议变更记录。
- 如果新增动态校验逻辑，不改变寄存器结构，但会影响现场参数可写范围，也应按用户可见行为变化记录版本。
