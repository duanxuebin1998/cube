# CPU3 继电器输出菜单优化说明

## 优化边界

本次优化 CPU3 屏幕菜单结构和显示名称，并删除旧 DO 报警接口；`RelayAlarmConfig relayAlarm[4]` 字段顺序和 CPU2 继电器方式2执行逻辑不变。

适用版本：

- CPU2 `V1.12.0.0`
- CPU3 `V1.10.0.0`
- `DEVICE_PROTOCOL_VERSION = 7`

## 参考思路

参考 N81 操作手册中“应用 -> 报警”和“输入/输出 -> 数字量 Xx-x”的组织方式，将继电器配置拆成两类：

- 报警配置：定义报警模式、报警取值源、无效值策略、HH/H/L/LL、滞回和阻尼预留。
- 输出通道：定义继电器工作模式、输出报警位、触点类型和清锁存报警。

这样现场配置时先选 R1/R2/R3/R4，再在单路下配置通道和报警参数，避免四路 52 个字段平铺在一个页面。

## 新菜单路径

| 层级 | 菜单项 |
| --- | --- |
| 参数配置 | 输出配置 |
| 输出配置 | 继电器输出 |
| 继电器输出 | R1继电器 / R2继电器 / R3继电器 / R4继电器 |
| Rn继电器 | 通道设置 |
| Rn继电器 | 报警配置 |

`输出配置` 下只保留 `AO输出` 入口，旧 DO 报警入口已删除：

| 菜单项 | 用途 |
| --- | --- |
| `AO输出` | 原 AO 输出参数入口，路径从参数配置首页下沉到输出配置页 |

## 通道设置

每路继电器的 `通道设置` 显示 4 项：

| 显示名 | 操作码字段 | 说明 |
| --- | --- | --- |
| `Rn工作模式` | `operating_mode` | 禁用 / 无源输出 |
| `Rn输出报警位` | `digital_source` | 选择 HH/H/L/LL 或组合报警作为输出位 |
| `Rn接点` | `contact_type` | 常开 / 常闭 |
| `Rn清报警` | `clear_alarm` | 清除已恢复但仍锁存的报警，CPU2 消费后清零 |

## 报警配置

每路继电器的 `报警配置` 显示 9 项：

| 显示名 | 操作码字段 | 说明 |
| --- | --- | --- |
| `Rn报警模式` | `alarm_mode` | 关闭 / 开启 / 锁存 |
| `Rn无效值` | `error_value` | 测量值无效时输出的报警状态 |
| `Rn报警取值源` | `alarm_source` | 储罐液位 / 液相温度 / 水位 / 浮子位置 / 无 |
| `Rn高高值` | `HH_alarm_value` | 高高限，按 IEEE754 float 原始位传输 |
| `Rn高值` | `H_alarm_value` | 高限，按 IEEE754 float 原始位传输 |
| `Rn低值` | `L_alarm_value` | 低限，按 IEEE754 float 原始位传输 |
| `Rn低低值` | `LL_alarm_value` | 低低限，按 IEEE754 float 原始位传输 |
| `Rn滞回` | `alarm_hysteresis` | 防止报警在限值附近反复抖动 |
| `Rn阻值` | `damping_factor` | 阻尼预留值，当前不参与 CPU2 计算 |

## 实现要点

- CPU3 菜单新增 `输出配置`、`继电器输出`、`R1/R2/R3/R4 继电器`、`通道设置`、`报警配置` 页面。
- `ParamGroupOf()` 和枚举文字显示不再直接散落裸范围判断，改由 `RelayParam_ChannelOf()`、`RelayParam_FieldOf()`、`RelayParam_IsConfig()` 集中识别继电器参数。
- 旧 DO 报警字段、操作码和保持寄存器已删除，不再提供菜单入口或兼容同步接口。
- 本次不新增运行状态页；四路运行态仍按协议版本 7 从输入寄存器尾段同步，后续可再做只读状态页。

## 联调检查

| 检查项 | 预期 |
| --- | --- |
| 菜单路径 | 参数配置 -> 输出配置 -> 继电器输出 -> Rn继电器 |
| 单路字段数量 | 通道设置 4 项，报警配置 9 项，合计仍为每路 13 项 |
| 旧 DO 字段 | 已删除，不与 R1/R2/R3/R4 方式2配置混排 |
| 写入通道设置 | CPU3 仍按原操作码写入 CPU2 对应保持寄存器 |
| 写入报警配置 | CPU3 仍按原操作码写入 CPU2 对应保持寄存器 |
| 协议版本 | 不变，仍要求 CPU2/CPU3 均为 `DEVICE_PROTOCOL_VERSION = 7` |
| 字库检查 | `py LTD_DISPLAY_CPU3\font_check.py` 无缺字 |
