## 维护要求

- 新增或修改 CPU3 菜单项时，同步说明菜单路径、中文/英文显示、写权限、范围、操作码和寄存器地址。
- 调整测量命令或调试指令时，同步更新 `CPU3参数菜单优化方案.md` 中的完整菜单树，并确认调试指令仍保留在密码边界内。
- 新增中文显示内容时，运行 `py LTD_DISPLAY_CPU3\font_check.py` 检查字库。
- 涉及 CPU2/CPU3 共享参数语义时，同步更新 `docs/01_协议与寄存器/CPU2_CPU3协议变更记录.md`。
- Word、Excel、PDF 文件作为导出版或确认附件维护；源码口径发生变化时，先更新 Markdown，再在发布归档前重新导出二进制文件。
- 菜单和显示口径发生冲突时，先以源码和 Markdown 说明为准；`CPU3状态页显示参数矩阵.xlsx` 是确认矩阵，不自动代表最新源码状态。
- Office/XLSX 的责任边界见 `../00_构建与版本/附件与源文件清单.md`；`CPU3参数菜单优化方案.docx` 和 `LNG计量仪屏幕菜单.docx` 作为确认稿或导出版保留，长期维护正文仍回到源码依据和 Markdown。
