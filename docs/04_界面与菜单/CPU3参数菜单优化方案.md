# CPU3参数菜单优化方案

更新日期：2026-07-22

本文基于当前CPU3参数菜单、`param_meta[]`参数元数据、屏幕菜单实现和《LNG计量仪屏幕菜单》整理结果，记录已落地的菜单优化方案。本次正式组合为CPU2 V1.31.0.0 / CPU3 V1.31.0.0、共享协议27。协议20完成的AO基础菜单能力随协议21发布，协议23收敛故障动作，协议24进一步定义传感器位置源及初始/过程/保持状态，协议25增加水位滞后时间预留项，协议26增加单一AO电流修正，协议27发布固定功能块地址、维护模式与继电器运行态，并把AO电流修正纳入量程设置。真实面板操作、写失败回滚和掉电保持仍需台架验证。目标是降低现场误操作风险，提高选项型参数可读性，并让出厂默认值、现场设置值和维护信息分层清晰。

## 一、优化目标

1. 降低现场参数查找成本：把测量业务参数、输出配置、通信设置和维护信息分层。
2. 降低误操作风险：危险参数不设置维护权限，改用二次确认、当前值显示、交付文档默认值说明和选择式编辑降低误操作。
3. 提高菜单可读性：屏幕显示使用短名称，文档保留完整名称和字段解释。
4. 保持协议可追踪：共享字段、地址窗口或语义变化时同步协议版本、迁移和兼容说明，不用菜单显示结果掩盖协议不匹配。
5. 便于交付和维护：文档、默认值、菜单选项和源码中的枚举含义保持一致。

## 二、推荐参数配置首页

完整菜单建议按“测量参数、输出配置、通信设置、显示设置、维护设置”五类组织。`param_meta[]` 中的保留项和内部 `设备指令` 寄存器不作为现场菜单项展示，其余可见参数均需要有入口。

| 一级入口 | 二级入口 | 说明 |
| --- | --- | --- |
| 测量参数 | 运行策略、电机与编码、扭力参数、零点参数、液位参数、水位参数、罐底与罐高、密度测量参数、Wartsila参数、SI参数、修正与补偿 | 现场投运、测量策略、外部 profile 和机械测量相关参数；不再单独设置“现场设置”入口。 |
| 输出配置 | 继电器报警输出、AO输出 | 继电器按 K1~K4 展示，每路再分“通道设置”“报警配置”和只读“报警状态”。 |
| 通信设置 | COM1、COM2、COM3 | 外部串口参数集中管理；修改协议时自动套用推荐串口参数。 |
| 显示设置 | 显示基础、数据源与手输值 | CPU3 本机显示、屏幕亮度、语言、小数位、数据来源和手输显示值。 |
| 维护设置 | 设备信息、参数校验 | 只读版本、传感器、协议和参数校验信息。 |

AO输出当前实际显示5组17项：工作模式、电流模式、输出源、电流修正、固定电流、0%/100%对应值、阻尼、故障动作、故障电流、初始电流和模拟电流共12项可见持久化配置，另有上电固定关闭的非持久化输出模拟开关；输出状态、输入值、输入百分比和输出电流为4项只读运行状态。AO输出电流取最近一次成功下发给AD5421的电流命令值，不等同于DAC回读或物理环路实测值。电流修正范围为-1.00～1.00mA，仅在启用态的最终输出阶段叠加一次，物理目标限幅为3.20～24.00mA；禁用态固定3.40mA，不叠加修正。原`AO SIL/WHG`槽位已原位改为电流修正；原错误等级槽位和`DAC回读电流`只保留内部设计位置，当前不显示、不启用，不计入17项菜单。

上表使用规范名称。实际小屏为适配128x64 OLED使用短名：`AO输入百分比→输入比例`、`AO阻尼系数→阻尼系数`；工作模式显示`禁用`、`4-20mA输出`、`HART从站+输出`，电流模式显示NE、US、普通和固定电流，故障动作显示`故障电流`或`保持上次`。运行页第一行直接显示`AO:初始`、`AO:过程`、`AO:保持`、`AO:故障`、`AO:模拟`、`AO:固定`、`AO:禁用`、`AO:驱动故障`或`AO:N/A`。

除两个隐藏预留外，已实现菜单不因模式变化隐藏。12项可见持久化配置始终可预配置，不受工作模式、电流模式、故障动作或输出模拟状态限制；当前模式不使用的配置仅暂不参与输出计算，切换到对应模式后生效。`AO输出模拟`是非持久化运行态动作，仅在输出已启用时可操作；切换到禁用模式时清除模拟，重新启用不恢复旧状态。4项运行状态始终只读；输出电流在禁用、CPU2快照无效或尚无成功下发记录时显示`N/A`。输出源变化必须先显示确认；CPU3确认后只写输出源，CPU2在该事务内装载新源默认量程，CPU3随后补读完整AO配置。取消、写入失败或补读失败均不得把未确认源和量程当作有效镜像。0%和100%对应值必须成对处理，两值禁止相等但允许反向。

调整原则：

## 九、通信协议联动规则

当前程序在屏幕或管理帧写入 COM 协议时，会先用旧参数发送完成应答，再把目标协议及其推荐波特率、数据位、校验和停止位整组应用到该串口；即使请求值与当前协议相同，也会重新归一化为该协议推荐参数。之后单独修改波特率、数据位、校验或停止位时仅执行取值合法化，不会再次套用协议模板，因此仍允许现场按需覆盖推荐参数。现场菜单只显示计量仪、瓦锡兰、LTD、LH、SI 五个有效协议，不显示预留协议项。

| 协议 | 建议自动套用参数 | 说明 |
| --- | --- | --- |
| 计量仪协议/DSM | 4800 8N1 | 对应当前 COM1 出厂默认配置。 |
| 瓦锡兰协议 | COM2: 2400 8E1；COM3: 2400 8E1 | 按现场确认口径，COM2/COM3 均使用 2400 偶校验。 |
| LTD协议 | 4800 8N1 | 对外串口默认值与计量仪协议/DSM一致；不影响CPU2/CPU3板间UART5。 |
| LH协议 | 9600 8N1 | LH现场Modbus协议固定带出该推荐参数，不影响其它外部端口。 |
| SI协议 | 9600 8O1 | 当前程序已有自动收敛逻辑。 |

菜单显示说明：协议项保存后会刷新波特率、数据位、校验、停止位显示值。当前 CPU3 程序已把 DSM、瓦锡兰、LTD、LH、SI 纳入同一套协议联动表。

## 十、水位测量方式含义

从 CPU2 程序调用关系看，`water_level_mode` 的含义不是液位测量方式的同一套枚举，而是水位找点/跟随流程选择：

| 数值 | 程序行为 | 说明 |
| --- | --- | --- |
| 0 | `SearchWaterLevel()` + `FollowWaterLevel()` | 慢速粗找/精找水位点，然后进入普通水位跟随。出厂默认值为 0。 |
| 非0 | `FindWaterLevel_FastByStateFlip_StableExit()` + `FollowWaterLevel_fast()` | 快速状态翻转找初始水位点，然后进入快速水位跟随。 |

因此水位测量方式建议在菜单中显示为：

| 菜单值 | 建议显示 |
| --- | --- |
| 0 | 慢速模式（当前固件屏幕显示为“低速模式”） |
| 1 | 快速模式 |

写入时可继续按 0/非0 兼容 CPU2；显示时把所有非0 值归一显示为“快速模式”，并建议保存时将非0 归一为 1，避免现场出现 2、3 等无额外语义的值。

## 十一、版本和兼容性判断

协议24不改变 `DeviceParameters` 结构、寄存器地址或命令码，但把AO输出源1改为传感器位置、原非跟随电流改为初始电流，并新增运行态保持来源，因此CPU2/CPU3共享协议由23提升到24。

本次正式组合的 `DEVICE_PROTOCOL_VERSION` 为27，固件为CPU2 `V1.31.0.0` / CPU3 `V1.31.0.0`。协议9起追加无线RSSI，协议10至20逐步建立AO能力，协议21追加固定点结果代际和三阶段快照，协议22只重排共享故障编号，协议23收敛AO故障动作，协议24定义初始/过程/保持状态和传感器位置源，协议25增加水位滞后时间预留参数，协议26定义单一AO电流修正，协议27用固定功能块地址替换旧紧凑地址并发布维护模式、继电器运行态和参数完成代次。现场故障编号按CPU2程序版本选表，并确认CPU2/CPU3协议版本严格相等；协议26及更早组合不能与协议27混用，协议23及更早版本不能按协议24解释输出源1、初始电流和保持状态。

CPU3 `V1.20.0.0`进一步收紧本机通信门禁：状态、完整参数和当前连接协议三类快照必须满足对应条件，且共享协议匹配、未锁存CPU2通信故障时，菜单普通命令和参数写才可下发；页面成功状态以合法CPU2 ACK为准。非命令写已发起但未取得合法ACK时，CPU3会立即使参数快照失效并强制全量补读。CPU3 `V1.25.0.0`继续把固定点结果纳入独立已确认快照，并在首次通信失败时关闭全部快照。协议15～17及19的升级来自故障码目录变化，协议18来自SI生命周期扩展，协议20来自AO共享契约，协议21来自固定点代际。

如果后续改动涉及参数默认值、字段语义、寄存器映射、命令码或跨 CPU 状态含义，需要按共享协议规则评估 `DEVICE_PROTOCOL_VERSION`、CPU2/CPU3 固件版本和协议变更记录。
