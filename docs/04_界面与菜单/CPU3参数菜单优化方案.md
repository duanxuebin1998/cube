# CPU3参数菜单优化方案

更新日期：2026-06-15

本文基于当前 CPU3 参数菜单、`param_meta[]` 参数元数据、屏幕菜单实现和《LNG计量仪屏幕菜单》整理结果，记录已落地的菜单优化方案。当前源码口径为 CPU2 V1.16.0.0 / CPU3 V1.15.0.0，共享协议版本为 11。目标是降低现场误操作风险，提高选项型参数可读性，并让出厂默认值、现场设置值和维护信息分层清晰。

## 一、优化目标

1. 降低现场参数查找成本：把测量业务参数、输出配置、通信设置和维护信息分层。
2. 降低误操作风险：危险参数不设置维护权限，改用二次确认、当前值显示、交付文档默认值说明和选择式编辑降低误操作。
3. 提高菜单可读性：屏幕显示使用短名称，文档保留完整名称和字段解释。
4. 保持协议兼容：不改变 CPU2/CPU3 共享寄存器地址、字段顺序和 `DeviceParameters` 结构语义。
5. 便于交付和维护：文档、默认值、菜单选项和源码中的枚举含义保持一致。

## 二、推荐参数配置首页

完整菜单建议按“测量参数、输出配置、通信设置、显示设置、维护设置”五类组织。`param_meta[]` 中的保留项和内部 `设备指令` 寄存器不作为现场菜单项展示，其余可见参数均需要有入口。

| 一级入口 | 二级入口 | 说明 |
| --- | --- | --- |
| 测量参数 | 运行策略、电机与编码、称重参数、零点参数、液位参数、水位参数、罐底与罐高、密度测量参数、Wartsila参数、修正与补偿 | 现场投运、测量策略和机械测量相关参数；不再单独设置“现场设置”入口。 |
| 输出配置 | 继电器报警输出、AO输出 | 继电器按 R1~R4 展示，每路再分“通道设置”“报警配置”和只读“报警状态”。 |
| 通信设置 | COM1、COM2、COM3 | 外部串口参数集中管理；修改协议时自动套用推荐串口参数。 |
| 显示设置 | 显示基础、数据源与手输值 | CPU3 本机显示、屏幕亮度、语言、小数位、数据来源和手输显示值。 |
| 维护设置 | 设备信息、参数校验 | 只读版本、传感器、协议和参数校验信息。 |

调整原则：

1. “读取部件参数”位于测量命令第 6 位，保留普通测量入口属性。
2. “水位单次测量”和“水位跟随”统一放入“水位测量”子菜单。
3. 密度测量拆为“密度单点测量”和“密度分布测量”两个入口，直接位于“测量命令”下。
4. 分布测量、国标分布测量、密度每米测量、区间密度测量、瓦锡兰区间密度统一归入“密度分布测量”。
5. “浮子运行到高度”仍作为普通测量命令；“上行”“下行”“强制上行”“强制下行”“强制提零点”归入“调试指令/浮子运动控制”。
6. 指令输入页、下发确认页、保护确认页按命令所属分组返回对应子菜单，避免返回时跳到错误层级。
7. “获取空载称重”和“获取满载称重”下发后进入独立“获取...称重中”页面，完成后直接返回“调试指令/称重标定”，不退出到状态页。

### 3.7 当前源码入口调整点

当前 `display_tankopera.c` 已按推荐结构调整参数配置首页和指令入口：

1. 将现有“基础信息”拆成“维护设置/设备信息”和“测量参数/运行策略”，避免故障策略混在设备只读信息里。
2. 将原罐高相关入口整理为“罐底与罐高”，与实际参数内容一致。
3. 标定液位值、修正液位值、标定水位值、标定罐高值、单点测量位置、单点监测位置、电机运行位置、电机上行/下行距离不挂入参数配置首页，继续随测量指令或调试指令下发。
4. CPU3 本机参数已挂到“显示设置”和“通信设置”，其中 COM1/COM2/COM3 独立放在通信设置。
5. 参数校验保留在维护设置中，只读参数不混入现场常改参数页。
6. 带参指令菜单项和下发确认页只显示指令名，不在指令名后追加参数值；参数值保留在输入页和参数写入确认页显示。
7. 测量命令已按水位测量、密度单点测量、密度分布测量聚合，读取部件参数调整到测量命令第 6 位。
8. 调试指令已按浮子运动控制、标定修正、称重标定、无线维护、系统维护分组；上行/下行仍保留在调试指令密码边界内。
9. 称重标定下的空载/满载获取指令已改为等待页交互，等待页显示当前称重值，完成后回到称重标定菜单。

## 四、选项型参数优化

选项型参数建议统一走“上下键选择 + 确认”的编辑方式，不再让用户输入裸数字。

| 参数 | 当前风险 | 建议选项显示 |
| --- | --- | --- |
| 上电默认指令 | 数字不直观，误设后上电行为改变 | 0=无；1=回零点；2=寻找液位；3=单点监测；4=水位跟随 |
| 液位测量方式 | 现场难以理解 0/1/2/3 | 0=相对频率；1=定频；2=密度找液位；3=超声 |
| 水位测量方式 | 已改为选项编辑，避免现场输入 2、3 等无额外语义的值 | 0=慢速粗找/精找 + 普通水位跟随；1=快速状态翻转找点 + 快速水位跟随 |
| 分布测模式 | 直接输入数字不直观 | 0=分布测量；1=国标测量；2=每米测量；3=区间测量 |
| 记步模式 | 改错会影响位置来源 | 0=编码器；1=电机 |
| 数据源设置 | 手输值和实测值容易混淆 | 0=设备测量；1=手工输入 |
| COM协议 | 协议选择会影响外部通讯，预留协议不在菜单显示 | 0=计量仪协议；1=瓦锡兰协议；2=LTD协议；5=SI7000协议 |
| 继电器报警配置 | 选项多，裸数字容易误配 | 按字段显示中文选项，如禁用/无源输出、常开/常闭、关/开/锁存。 |
| 尺带类型 | 《LNG计量仪屏幕菜单.docx》提出将“尺带厚度”改为选项，但当前未给出类型名称和厚度映射 | 待确认后再把 `tape_thickness_mm` 做成候选项编辑，避免改变 CPU2/CPU3 共享参数语义 |

## 九、通信协议联动规则

当前程序在写任一串口字段后会执行串口配置归一化，并采用“协议优先”规则：用户修改 COM 协议后，系统自动改写同一串口的波特率、数据位、校验和停止位，不要求用户再逐项匹配。现场菜单只显示计量仪、瓦锡兰、LTD、SI7000 四个有效协议，不显示预留协议项。

| 协议 | 建议自动套用参数 | 说明 |
| --- | --- | --- |
| 计量仪协议/DSM | 4800 8N1 | 对应当前 COM1 出厂默认配置。 |
| 瓦锡兰协议 | COM2: 4800 8N1；COM3: 4800 8N1 | 按现场确认口径，COM2/COM3 均使用 4800 8N1。 |
| LTD协议 | 115200 8N1 | 按 CPU2 串口5（UART5）配置口径。 |
| SI7000协议 | 9600 8O1 | 当前程序已有自动收敛逻辑。 |

菜单显示说明：协议项保存后会刷新波特率、数据位、校验、停止位显示值。当前 CPU3 程序已把 DSM、瓦锡兰、LTD、SI7000 纳入同一套协议联动表。

## 十、水位测量方式含义

从 CPU2 程序调用关系看，`water_level_mode` 的含义不是液位测量方式的同一套枚举，而是水位找点/跟随流程选择：

| 数值 | 程序行为 | 说明 |
| --- | --- | --- |
| 0 | `SearchWaterLevel()` + `FollowWaterLevel()` | 慢速粗找/精找水位点，然后进入普通水位跟随。出厂默认值为 0。 |
| 非0 | `FindWaterLevel_FastByStateFlip_StableExit()` + `FollowWaterLevel_fast()` | 快速状态翻转找初始水位点，然后进入快速水位跟随。 |

因此水位测量方式建议在菜单中显示为：

| 菜单值 | 建议显示 |
| --- | --- |
| 0 | 慢速模式（当前固件屏幕显示为“低速模式”） |
| 1 | 快速模式 |

写入时可继续按 0/非0 兼容 CPU2；显示时把所有非0 值归一显示为“快速模式”，并建议保存时将非0 归一为 1，避免现场出现 2、3 等无额外语义的值。

## 十一、版本和兼容性判断

菜单分组、继电器报警状态只读页、显示文案、选择式编辑、协议联动、二次确认、状态页选源，以及只读版本/校验值显示格式修复本身不改变 `DeviceParameters` 字段含义、寄存器地址、命令码或 CPU2/CPU3 共享协议。

当前源码的 `DEVICE_PROTOCOL_VERSION` 为 10。协议 9 起在读取部件参数调试区追加无线滑环 RSSI 字段；协议 10 起追加 AO 模拟电流输出运行态，并把原 `reserved26` 替换为 `AoOutputEnable`，用于控制 AO 输出默认关闭/启用。现场版本核对时必须同时确认 CPU2/CPU3 协议版本严格相等；不能继续按早期协议 7 或协议 9 判断当前程序兼容性。

如果后续改动涉及参数默认值、字段语义、寄存器映射、命令码或跨 CPU 状态含义，需要按共享协议规则评估 `DEVICE_PROTOCOL_VERSION`、CPU2/CPU3 固件版本和协议变更记录。

## 十二、已确认结论

1. 恢复出厂设置只保留“恢复全部默认值”，不增加“恢复当前页默认值”。
2. 危险参数不需要维护权限，也不新增更高等级密码；如需密码，沿用当前屏幕密码体系。
3. COM 协议选项中文命名需要统一对外口径。
4. LTD 协议串口推荐参数按 CPU2 串口5（UART5）配置：115200 8N1。

## 十三、状态页显示同步

CPU3 状态页已按当前源码同步显示策略：

1. 液位、水位、密度、温度、频率、电容和罐高按设备状态选择数据源，不在待机、运动、维护或故障状态混入旧业务结果。
2. 位置固定取 `debug_data.sensor_position`，称重固定取 `debug_data.current_weight`，正常状态页路径下即使值为 0 也显示。
3. 分布完成态显示分布液位和平均密度/温度；单点测量和单点监测分别取对应结果结构。
4. 读取部件参数完成态显示最新 `debug_data` 快照，包括位置、称重、温度、频率、电容、X/Y 角；读取参数态的 X/Y 角不受 `bottom_detect_mode` 限制。
5. 读取部件参数完成态显示蓝牙 RSSI；`rssi_valid != 0` 时显示 `RSSI:<value>dB`，否则显示 `RSSI:N/A`。
6. AO 输出配置页包含 `AO输出使能`，取值 `0=关闭`、`1=启用`；当前出厂默认关闭，避免未接电流环时上报 AO 故障。
7. 详细逐状态显示项、数据源和现场确认点见 `CPU3状态页不同状态显示信息确认表.md`。
