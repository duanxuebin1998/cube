# SI 官方资料翻译审计输出

本目录保存 SI7000 官方资料中文整理过程中的审计结果和中间索引，用于追踪源 PDF 页码、翻译覆盖情况和可读性检查结果。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `source_pdf_pages.json` | 源 PDF 页码、章节和提取结果索引 |
| `translation_audit_report.md` | 中文整理结果的覆盖性、可读性和风险审计报告 |

## 维护说明

- 本目录只保存审计输出，不作为业务协议唯一来源。
- 正式协议映射和联调口径仍以 `docs/01_协议与寄存器/SI协议适配/` 下的映射表、联调检查表和版本改动记录为准。
