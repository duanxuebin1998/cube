# 官方资料中文整理生成辅助工具

本目录只保存 `../SI7000官方资料包_中文全文翻译_优化排版_无附录.pdf`、`../SI7000官方资料包_中文全文翻译_版式复刻.pdf` 和配套源稿的生成辅助材料，不作为 SI 协议实现口径、项目需求或业务排查入口。

## 文件

| 文件 | 用途 | 维护口径 |
| --- | --- | --- |
| `generate_readable_translation_pdf.py` | 读取本目录已校订中文 Markdown 和图片资产，生成推荐阅读的优化排版 PDF 和源稿 | 后续校对译文时优先维护该脚本和对应章节 Markdown |
| `generate_layout_clone_translation.py` | 读取官方资料包页面与翻译缓存，生成中文全文翻译版式复刻 PDF 和源稿 | 仅在需要重新生成中文全文翻译 PDF 时维护 |
| `translation_cache.json` | 保存页级翻译缓存和人工校对结果，供生成脚本复用 | 作为生成缓存使用，修改后需重新生成并校对输出文件 |

## 使用约束

- 当前工程 SI 协议行为仍以源码、协议映射表和版本记录为准，本目录内容不能替代实现口径。
- 重新生成 PDF 前，应先确认官方原件路径、输出文件名和所选生成脚本，避免覆盖已校对版本。
- 优化排版 PDF 的正文来源是上级目录中的中文 Markdown；版式复刻 PDF 的正文来源是 `translation_cache.json`。
- 生成过程产生的临时页面、采样图片或中间文件应优先放在仓库临时目录；如因追溯需要保留在本目录下，必须补充 README 说明用途和维护边界。
