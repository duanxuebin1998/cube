资料包共 101 页。该 PDF 是多个官方资料合并后的资料包，包含产品概览、认证页、DCS Modbus 接口规范、包装规格、外形和接线图、安装与调试手册、操作手册、维修手册和保修信息。

## 整理目标

把官方英文资料分批整理为中文 Markdown，便于后续协议适配、联调、维护和需求确认使用。整理稿要求：

- 尽量完整翻译正文、表格、注意事项、步骤和限制。
- 保留必要英文术语，例如 SI-7000、LTD、DCS、Modbus、RS485、TGIM、Profile、Auto、Cal、Manual、Interlock。
- 地址、功能码、位号、寄存器号、单位、缩放值保持原始数值。
- 对图片、图纸、证书和照片类页面，保留原图引用，并在图下补中文解释。
- 对官方资料内部疑似矛盾、过时或与当前项目实现不同的内容，只做整理备注，不在译稿中擅自改成工程实现口径。

## 图片和图纸处理规则

Markdown 文件本身只保存文字，不直接内嵌图片二进制。后续遇到图片类内容时，按以下方式处理：

1. 在本目录创建 `assets/` 子目录。
2. 从 PDF 按页渲染或提取图片，命名建议为 `p026_general_arrangement_sheet1.png`、`p030_field_wiring_tgim.png`。
3. 在 Markdown 中使用相对路径引用，例如：

   ```md
   ![SI-7000 总体布置图 Sheet 1](assets/p026_general_arrangement_sheet1.png)
   ```

4. 图片下方写中文图注和关键标注翻译。
5. 对尺寸图、接线图、安装步骤照片，不用纯文字替代原图；文字只补充检索和理解。
6. 如需中文重绘图，应同时保留原始图片引用，方便和官方资料对照。

## 当前已知整理备注

- 资料包目录页显示 DCS Modbus Interface Specification 从第 10 页开始；目录下另有独立文件 `../00_原始资料/SI7000_modbus_官方.pdf`，内容与资料包第 10-24 页对应，便于单独抽取文字。
- DCS Modbus 规范的 Profile 数据地址表列到 Point 199，即 30021-30620；同一节文字又说最大点数为 500，即 0-499。中文稿保留这两个原始说法，并标出待复核。
- 资料包中的部分图纸页和认证页文字抽取不完整，中文稿已以页面渲染图片作为主要官方依据。
- IECEx 证书页已按页面图片保留；资料包未包含证书 Annex，涉及认证限制条件时应进一步查阅 Annex 和最新认证文件。
- 产品规格页的设备重量 180 kg 与包装规格页净重 178 kg 接近但不完全一致，现场吊装和运输应以项目图纸、装箱单和实物为准。
- 现场接线图提到 Dwg. No. 050-701 connection detail，但当前资料包第 26-31 页未包含该连接细节图。
- 安装与调试手册明确完整上电、系统测试和校准只能由 Scientific Instruments 人员执行或在其陪同下执行；中文稿不作为现场操作授权。
- 资料包第 52-85 页实际包含操作手册 Part A 和 Part B，不只是 Part A；中文稿已按实际分卷整理。
- 维修手册强调所有维修必须由合格人员执行，维修期间必须执行上锁挂牌（Lock-out Tag-out）；中文稿仅作资料理解和需求核对，不作为现场操作授权。
- 保修政策页为扫描件，已按页面图像整理关键条款；如用于合同或质保判断，应以官方原件和正式商务文件为准。
