## 图片处理口径

Markdown 正文以可检索文字和表格为主。对结构图、接线图、证书、包装图、安装步骤照片等版式或图像信息，后续从 PDF 渲染或提取为 PNG，放入本目录下的 `assets/` 子目录，再在正文中用相对路径引用。图片中的关键英文标注会在图片下方补充中文说明，必要时另做中文重绘版。

当前已生成的图片资产保存在 `assets/`，包括资料包封面和总目录、产品概览页、规格页、IECEx 证书页、DCS Modbus 规范页面、包装规格页、机械布置图、现场接线图、安装步骤图、调试/附录页、操作手册 LCD 界面页、维修手册页面和保修政策扫描页。

## PDF 全文翻译版本

推荐使用 `SI7000官方资料包_中文全文翻译_优化排版_无附录.pdf`。该版本以本目录人工整理的中文译稿为正文来源，按资料包章节重新排版，不强制对应原 PDF 页数；原图、图纸、照片和扫描页仅在正文需要对照的位置保留，便于阅读。

优化排版 PDF 生成脚本为 `tools/generate_readable_translation_pdf.py`，源稿为 `SI7000官方资料包_中文全文翻译_优化排版源稿.md`。如后续继续校对译文，应优先修改对应章节 Markdown，再重新生成该 PDF。

`SI7000官方资料包_中文全文翻译_版式复刻.pdf` 是历史页级对照版本，采用“原 PDF 页面图像作为底图 + 中文翻译覆盖层”的方式生成，目标是尽量保持原资料包页面尺寸、图纸、图片、表格线、页眉页脚和页码位置不变。

生成脚本为 `tools/generate_layout_clone_translation.py`，翻译缓存为 `tools/translation_cache.json`。如后续需要人工校对某一页译文，可修改缓存或脚本中的扫描页手工翻译后重新生成 PDF。

`tools/` 仅作为全文翻译 PDF 的生成辅助目录，不作为 SI 协议实现口径、项目需求或业务排查入口。

## 维护提醒

- 不改写 `../00_原始资料/` 内的官方原件。
- 原文中的专业术语、协议名、功能码、地址、单位和部件英文名按需保留。
- 遇到官方资料内部不一致时，中文稿保留原文口径并加“整理备注”，不自行改写为当前项目实现口径。
