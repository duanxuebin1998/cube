1. 目标和边界

本页记录 2026-07-01 SI协议进一步兼容的实际落地结果：当前已把 SI 基础协议兼容版推进到按 Scientific Instruments SI profile 行为独立执行的版本。核心原则是：CPU3 承担 SI协议和参数外观，CPU2 承担真实测量、电机动作和必要状态。

CPU2 不保存 SI Modbus 地址号、线圈、功能码、异常码和缩放规则，但保存 SI profile 执行参数。CPU3 负责把外部寄存器读写桥接到 CPU2 参数或 CPU3 本机参数，并下发 profile 启动命令。
范围 本次处理 不做或后续处理
SI profile 流程 新增独立命令、独立流程、Point0、探底频次、200 点上限。 不再复用普通分布密度测量流程。
SI 参数 40001~40003 存入 CPU2 profile 执行参数，40010~40023 存入 CPU3 SI 参数。 CPU2 仍不处理 SI Modbus 地址和功能码。
状态和报警 CPU3 负责 SI 状态语义合成和报警限值判断。 只有必须依赖 CPU2 原始过程数据时，才新增最小共享结果。

2. 改动点总览

改动点 归属 实施方案 影响
新增 SI profile 命令 共享协议 新增 CMD_SI_PROFILE，CPU3 的 00004 Profile 不再桥接 CMD_MEASURE_DISTRIBUTED。 影响 DEVICE_PROTOCOL_VERSION。
新增 CPU2 profile 参数 CPU2 新增 si_profile_first_point、si_profile_increment、si_profile_dwell_time 和 si_profile_bottom_detect_interval，复用原预留参数槽并掉电保存。 影响共享协议版本；CPU2 DEVICE_PARAM_VERSION 保持 3。
解耦 40001~40003 CPU2/CPU3 CPU3 对外仍暴露 SI 保持寄存器和菜单项，但底层桥接 CPU2 profile 参数，不再写普通分布测量参数。 避免影响普通分布测量。
独立 profile 测量流程 CPU2 新增独立入口，执行时读取 CPU2 保存的 profile 参数，完成探底、到底、Point0、逐点采样和点阵写入。 影响 CPU2 测量流程和流程图。
自动 profile 调度 CPU3 基于 40010~40013 和 CPU3 RTC，从起始时间开始按周期跨天触发；到点后直接覆盖当前命令。 影响 CPU3 调度流程。
状态合成 CPU3 10010=0 固定可信；10002/10003 按液位跟随稳定状态合成；10001 保持现有逻辑。 影响 SI FC02 输出。
报警限值 CPU3 40014~40023 不复用现有限值，CPU3 独立保存并合成 10017~10026、10029~10032。 影响报警寄存器和测试用例。
Profile Timestamp CPU3 30007~30010 改为 CPU3 收到 SI 00004 Profile、屏幕 SI profile 或自动触发 profile 时的时间。 不依赖 CPU2 start 事件。

3. CPU2 / CPU3 详细职责

CPU2 真实测量和状态来源

  • 新增 CMD_SI_PROFILE 独立执行入口。
  • 持久保存 SI profile 执行参数，不保存 SI Modbus 地址号。
  • 维护底部位置有效性、按 SI profile 入口触发次数推进的探底计数、Point0 采集和 profile 点阵。
  • 保留 probe_at_liquid_level、liquid_stable、profile_complete_latched、profile_complete_counter 等真实状态。
  • 提供测量失败、阻挡、完成锁存和点阵数据给 CPU3 映射。

CPU3 协议外观和参数合成

  • 维护 SI Modbus RTU 从站、地址表、缩放和异常响应。
  • 将 40001~40003 和菜单 profile 参数桥接到 CPU2 参数。
  • 持久化 40010~40023 自动调度和报警限值。
  • 将 00004 Profile 转为 CMD_SI_PROFILE 启动命令。
  • 负责自动 profile 调度、时间戳锁存、状态位和报警位合成。
  • 复用 SlaveAddress 作为 Tank ID，保持当前密度缩放和钳位。

4. 参数存储和状态回传

层级 字段 存放/传递 说明
CPU2 profile 执行参数 profile_first_point、profile_increment、profile_dwell_time、bottom_detect_frequency CPU2 掉电保存 与 40001~40003 和探底频次对应，执行时直接读取。
CPU3 SI 参数 auto_profile_interval、auto_profile_enable、auto_profile_hour、auto_profile_minute、alarm_limit_* CPU3 掉电保存 与 40010~40023 对应，负责调度和报警合成。
状态回传 profile lifecycle、Point0 captured、complete latch/counter、点阵、液位跟随稳定状态、失败/阻挡状态 CPU2 产生，CPU3 读取 CPU3 再映射为 100xx、300xx 和报警状态。

5. Profile 测量流程

1. 触发CPU3 收到 SI 00004 Profile、屏幕 SI profile 或自动调度触发，锁存开始时间。
2. 启动CPU3 下发 CMD_SI_PROFILE，不携带 profile 参数上下文。
3. 参数CPU2 读取本机 SI profile 参数，并按进入 SI profile 入口的触发次数判断探底频次。
4. Point0运行到底部位置采集 Point0；无旧底部且探底失败时使用当前位置，但不刷新底部参考。
5. 点阵按 first point、increment、dwell time 生成候选点并逐点采样，最多 200 点；到点判定为液面以上时停止且不写入该点。
  1. 探底频次默认 1；1 表示每次 profile 前探底，更大值表示每 N 次触发探底一次；计数按进入 CPU2 SI profile 入口推进，不按成功完成次数推进。
  2. 不探底时也必须运行到上次探底保存的底部位置读取 Point0。
  3. 停止条件包括当前候选点被判定为液面以上、达到上限位置或达到 200 点上限；液面以上点不写入有效点阵。
  4. profile 完成后保持完成态，不自动回液位跟随。

7. 实施结果

  1. 共享协议升到 DEVICE_PROTOCOL_VERSION = 14，新增 CMD_SI_PROFILE = 20，并通过 profile_source 隔离 SI profile 结果。
  2. CPU2 复用预留槽新增 SI profile 执行参数，覆盖 40001~40003 及探底频次；DEVICE_PARAM_VERSION 保持 3。
  3. CPU3 菜单和 SI Modbus 将 40001~40003 桥接到 CPU2 参数，不再桥接普通分布参数。
  4. CPU2 新增 SI profile 独立测量入口，执行时读取本机 profile 参数。
  5. CPU3 将 00004 Profile 改为锁存开始时间并下发 CMD_SI_PROFILE。
  6. CPU3 落地自动 profile 调度、状态合成、报警合成和 timestamp 锁存；CPU3 本机参数 FRAM 版本升至 0x0006。
  7. 同步映射表、PLC 联调表、CPU2/CPU3 协议变更记录和 golden frame/契约检查脚本。

CPU3 菜单更新

菜单页 菜单项 存储归属 实现要求
SI Profile SI首点、SI步距、SI停留、SI探底 CPU2 参数 新增 CPU2 参数操作号和参数同步；菜单写入后 CPU2 掉电保存，不能改普通分布参数。
自动 Profile SI自动、SI周期、SI时、SI分 CPU3 本机参数 写入后保存 FRAM 并重算下一次触发；周期禁止为 0，关闭使用使能项。
SI 报警 低/高密度、低/高温、LL/HH 液位、低/高液位、温差、密差 CPU3 本机参数 与 40014~40023 同源，菜单、PLC 写入和报警合成使用同一套限值。
SI 状态 下次时间、触发源、完成计数 只读运行态 可作为第二阶段诊断页；不作为 SI协议必需项。
  • display_tankopera.c 在参数配置下新增 SI参数 入口，拆分 Profile、自动 Profile、报警三个配置页。
  • display_tankopera.h 同步新增 CPU2 参数操作号和 CPU3 本机操作号，避免把 CPU2-backed 菜单项误放入 CPU3 本机参数区。
  • cpu3_comm_display_params.c 只保存 40010~40023；40001~40003 通过内部主板参数同步写 CPU2。
  • 菜单显示已收敛为 128x64 OLED 可容纳的短名：SI首点、SI步距、SI停留、SI探底、SI周期、SI自动、SI时、SI分；修改后需重新运行菜单宽度和字库检查。

8. 版本、兼容和风险

事项 影响 处理
新增 CMD_SI_PROFILE CPU2/CPU3 共享协议变化。 升级 DEVICE_PROTOCOL_VERSION，更新协议变更记录。
新增 CPU2 SI profile 参数 CPU2 参数存储变化。 CPU2 复用原预留槽，DEVICE_PARAM_VERSION 保持 3；通过协议版本迁移补默认值并同步 CPU3 参数镜像。
CPU3 SI协议调度和报警参数持久化 CPU3 本机参数存储变化。 CPU3 本机参数版本升至 0x0006，补 V3/V4/V5 迁移、默认值和恢复默认行为。
自动 profile 直接覆盖当前命令 可能影响当前测量状态清理。 增加状态机和中止残留回归测试。
密度 16 位上限 0.01 kg/m3 下 16 位最大表达 655.35 kg/m3。 已确认接受当前缩放和钳位口径。
