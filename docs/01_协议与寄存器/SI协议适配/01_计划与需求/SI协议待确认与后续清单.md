## 2. 当前仍需复核

截至 2026-07-01，本轮 SI协议进一步兼容需求的实现前关键口径已基本确认。后续重点不再是需求口径确认，而是把最新确认项同步到代码实现和联调验证：报警阈值 `0` 不再禁用、负温度阈值写入、温度无效值 `-200.00°C`、密度无效值 `0`、以及探底频次按触发次数计数。

本地 `00_原始资料` 能确认串口参数、地址窗口、保留地址、缩放单位、`40011` 启停语义、`40010=1440` 日周期建议、DCS 200 点点阵窗口和有效点外返回 0；没有找到完整的 `40001~40023` 出厂默认值和非法值总表。因此当前代码默认值统一按 CUBE 工程默认记录，不写成 SI 官方出厂默认。

### 2.1 资料已回答的问题

| 项目 | 结论 | 对后续工作的约束 |
| --- | --- | --- |
| 串口默认/固定参数 | `9600 8O1 RTU` | CPU3 SI协议模式必须强制该串口格式 |
| 地址窗口 | `00001~00016`、`10001~10032`、`40001~40023`、`30001~30620` | 越界访问返回 Modbus 异常，不能扩表误兼容 |
| 保留地址 | `00005~00008`、`00016`、`10007`、`10011`、`10014~10016`、`10027~10028`、`40004~40009`、`30005`、`30014~30020` | 保留输出为 0，保留写入拒绝 |
| Profile DCS 点数 | Point 0~199，共 200 点 | 当前 PLC 联调上限固定为 200 点 |
| 有效点外数据 | 超过有效点数的 profile 寄存器为 0 | 完成前和点数外不得输出旧点残留 |
| 自动 profile | `40011=0` 禁用、`40011=1` 启用；每天一次建议 `40010=1440` | 关闭自动 profile 使用 `40011=0`，`40010=1440` 仅作为建议配置 |
| 缩放 | Level 1mm/count，Temperature 0.01°C/count，Density 0.01kg/m3/count | 文档、PLC 和脚本必须按该倍率验收 |
| 时间戳 | 当前按 CPU3 下发或自动触发 profile 指令时刻锁存 | 不新增首点采集事件 |
| 无效值 | 温度无效对外 `-200.00°C`；密度无效对外 `0` | 仅在 CPU3 SI协议转换层做映射，不污染 CPU2 原始测量数据 |

### 2.2 资料未回答或仍有冲突的问题

| 项目 | 当前口径 | 需要确认的点 |
| --- | --- | --- |
| `40001~40023` 出厂默认值 | 当前使用 CUBE 工程默认 | 是否有现场 SI 参数备份或供应商默认表 |
| `40001~40023` 完整非法值范围 | 仅已实现 0、小时、分钟、使能等基础边界 | 是否需要按官方设备拒绝其它边界值 |
| 报警启用方式 | 阈值 `0` 已确认是有效值，不能再禁用 | 是否新增独立 enable 位，或改为始终启用全部阈值报警 |
| 设备内部 500 点 | 当前 DCS 表只支持 200 点，直接扩到 500 会影响共享结构、同步寄存器、脚本和内存 | 若 PLC 明确要求超过 200 点，需要另定扩展地址或分页机制 |
| `40003` 秒/毫秒差异 | Modbus DCS 按秒 | 是否存在本机菜单或非 DCS 主机按毫秒配置的现场需求 |

## 4. 已完成的开发动作

2026-07-01 本轮已完成以下开发动作：

1. 把确认结论同步到 `SI协议需求与实施总览.md`、`../02_协议映射/SI协议兼容映射表.md` 和 `../04_联调测试/SI协议_PLC联调检查表.md`。
2. 扩展 `tools/check_si_modbus_frames.py` 和 `tools/check_si_protocol_contract.py`，覆盖自动 profile 默认帧、协议版本、命令号、CPU2/CPU3 参数和状态口径。
3. 新增 `CMD_SI_PROFILE = 20`，同步 CPU2/CPU3 命令枚举、协议版本和协议变更记录。
4. CPU2 新增 SI profile 执行参数和独立测量入口，完成探底频次、Point0、独立参数和 profile 点阵。
5. CPU3 修正状态位、时间戳、自动 profile 调度和 SI 保持寄存器映射；`40001~40003` 桥接 CPU2 参数，`40010~40023` 使用 CPU3 本机参数。
6. CPU3 新增 `SI参数` 菜单入口，拆分 `Profile参数`、`自动Profile`、`报警限值` 三个子页。
