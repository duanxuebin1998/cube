一页结论

当前实现已经达到“SI DCS 地址表可通信、关键状态可读、Profile 可独立执行、参数可从 PLC 和屏幕配置”的阶段。2026-07-02 按官方全文复核后，确认仍存在 Manual、Auto、Cal、Profile 生命周期和测量可信性偏差；这些偏差需要在联调前决定是改代码、作为受控偏差接受，还是由 PLC/现场规程规避。

FC01~FC06 已支持读线圈、读离散输入、读保持寄存器、读输入寄存器、写单线圈、写单寄存器。
200 点 当前 DCS 地址表覆盖 Point 0~199，输入寄存器窗口为 30021~30620。
独立 Profile 00004 Profile、屏幕入口和自动调度均下发 CMD_SI_PROFILE。
CPU2 参数 40001~40003 存入 CPU2 SI profile 执行参数，不污染普通分布测量参数。
CPU3 参数 40010~40023 存入 CPU3 SI 本机参数，用于自动调度和报警合成。
9600 8O1 选择 SI 协议后，CPU3 外部串口按官方 Modbus 口径配置。
9 项偏差 R-01~R-09 已纳入待确认清单；SI Profile 成功后已回 Auto，剩余重点是 Manual 抑制、自动 Profile、Cal、Probe Uncal 和报警默认值。
P0 决策 Manual 报警/自动 Profile、Cal 回 Auto、10010 可信性和 40014~40023 默认值需要优先确认。
联调门控 PLC 读取液位必须结合 10013；不能只凭 30004 或 10010=0 判断当前液位可信。
关键口径：SI 分布测量不先找液位。CPU2 以底部采样目标作为 Point0 的实际运动位置，但 Point0 对外位置字段固定写 0；Point1 按 40001 绝对位置运行和输出，后续按 40002 递增。运行中遇到液面以上点即停止，并且不把该空气点写入 profile 点阵。
关键风险：当前 10010 Probe Un-calibrated 固定为 0，Manual 下 SI 报警未完全按官方语义清零，自动 Profile 可能在 Manual 下触发，Cal 仍不是完整 Level Calibration。SI Profile 成功后已排队 CMD_FIND_OIL 回液位跟随，PLC 联调必须验证 10013 恢复。

职责边界

当前架构把协议外观留在 CPU3，把真实运动和采样闭环放在 CPU2。这样 CPU2 不需要理解 SI 地址、功能码和异常码，但仍能保存和执行 SI profile 需要的参数。

PLC / DCS

按 SI Modbus RTU 访问线圈、离散输入、保持寄存器和输入寄存器。

CPU3 SI 层

处理地址、功能码、CRC、异常响应、缩放和状态合成。

CPU3 参数/调度

保存 40010~40023，根据 RTC 触发自动 profile。

CPU2 命令/参数

接收 CMD_SI_PROFILE，保存 40001~40003 对应执行参数。

CPU2 测量闭环

探底、运动、停稳等待、采样、空气判定、点阵锁存。

层级 当前职责 明确不承担
CPU3 SI Modbus RTU 从站、地址表、异常码、缩放、状态合成、自动调度、报警合成、时间戳锁存、屏幕菜单入口。 不执行真实电机闭环，不把 SI 地址号下沉给 CPU2。
CPU2 保存 SI profile 执行参数，执行探底、Point0、逐点运动、密度/温度采样和结果锁存。 不处理 SI Modbus 帧、功能码、CRC、异常响应。
CPU2 <-> CPU3 通过共享协议传递命令、参数、状态、profile 点阵和测量结果。 不承载 PLC 专用的地址编号语义。

SI Profile 流程

当前 SI profile 是独立测量流程，不再映射到普通分布密度测量。关键目标是满足 SI 点阵语义：Point0 在底部采样但对外位置字段固定为 0，后续可编程点从 40001 绝对位置开始按步距采样。

触发

00004、屏幕 SI Profile 或自动调度触发，CPU3 锁存开始时间。

探底判断

上电首次、无底部参考、频次命中或频次为 1 时执行真实探底。

底部选择

探底成功用当前底部；失败时有旧底部用旧底部，没有旧底部用当前位置。

生成点位

Point0 对外位置 = 0；Point1 = first 绝对位置；Point2 = first + increment。

逐点采样

移动、等待稳定窗口、采样温度密度；遇到空气点停止且不写入。

Profile 细节 当前口径
是否先找液位 不先找液位。运行到候选点后通过密度和频率判断是否已经到液面以上。
Point0 实际运动/采样目标优先来自本轮探底结果；没有本轮有效底部时按 fallback 逻辑选择。写入 SI 点阵时位置字段固定为 0。
40001 表示 Point1 的绝对位置，不覆盖 Point0；即使实际底部高于 40001，也不跳过 Point1。
40003 单位为秒，当前作为停稳后的稳定等待窗口使用。
停止条件 空气点、达到 200 点、达到罐高/上限、命令切换或测量错误。
完成态 至少 Point0 有效才认为本轮成功；成功后锁存 PROFILE_SOURCE_SI 并递增完成计数。

官方语义偏差和待确认需求

本节同步自 2026-07-02 的官方全文复核结论。它不是新增实现清单，而是当前 SI 兼容层与 SI 原设备语义之间需要进一步确认或受控接受的差异。若现场要求严格等同 SI 原机，应优先处理 P0 项。

编号 官方语义 当前 CUBE 口径 影响 处理建议
R-01 / P0 Manual mode 下不报告任何报警，液位读数也不更新。 CPU2 本机继电器报警会使用 manual_alarm_inhibit；CPU3 SI 报警位仍按 40014~40023 合成。 PLC 可能在维护或强制移动期间看到 SI 报警，并误用旧液位。 确认是否在 CPU3 SI 层按 Manual 清除 10017~10026/10029~10032；PLC 必须以 10013=1 门控当前液位。
R-02 / P0 自动 Profile 到点时，如果系统处于 Manual，Profile run 不会开始。 si_modbus_periodic_task() 到点后直接调用 SI profile 启动入口。 维护人员将设备置于 Manual 后，仍可能被自动 Profile 打断。 确认是否增加 Manual/维护状态跳过条件和跳过计数；如不改代码，现场需禁用自动 Profile。
R-03 / P0 Profile run 和 Cal run 完成后返回 Auto，探头回液位界面继续跟踪。 SI profile 成功后先进入 STATE_SPREADPOINTOVER 并排队 CMD_FIND_OIL；00002 Calibrate 当前仍桥接 CMD_CALIBRATE_ZERO。 Profile 后需等待自动找液位完成；找液位完成前 10013 仍可能为 0，30004 不能当当前液位。 验证 Profile 成功后是否自动进入 CMD_FIND_OIL 并恢复 10013=1；Cal 完整回 Auto 语义仍待确认。
R-04 / P0 Probe Un-calibrated 表示当前位置/液位是否可信。 10010 固定输出 0；探底失败且无旧底时可用当前位置继续 profile。 外部 SI 主机看不到位置不可信风险，Point0 可能被误认为真实罐底样本。 确认 10001/10010/Profile Complete 在无底部参考和探底失败时的最终对外策略。
R-05 / P1 上下 level sensor 是 SI 原机判断液/气界面的核心硬件状态。 10002/10003 由 CPU3 根据液位跟随稳定状态合成。 PLC 若当作真实传感器开关，会误判液面、气相或异常状态。 确认 PLC 是否接受合成状态；如不接受，需要硬件或映射来源扩展。
R-06 / P1 Interlock 是高限互锁；Reel Alarm 是卷盘或物理驱动故障。 10004 和 10009 当前由错误码或阻塞状态概括合成。 无法区分高限互锁、卷盘故障、普通测量错误和工况阻止。 若 PLC 用于安全联锁或维护派工，应细分错误来源或新增诊断位。
R-07 / P1 30007~30010 更接近首个 profile 点采集时间。 当前在 CPU3 收到或触发 CMD_SI_PROFILE 时锁存。 不能用于严格计算 Point0 或每点采样时间。 接受为“profile 命令启动时间”，或新增 CPU2 Point0 采集事件。
R-08 / P1 缺少 bottom reference 时应通过 Cal/Profile 重新建立可信基准。 探底失败且无旧底时可用当前位置继续 profile，Point0 对外仍为 0。 数据可用但底部坐标和全部点位可能偏移。 确认是继续输出低可信数据，还是改为 profile 失败并置位未校准/互锁状态。
R-09 / P0 报警阈值是实际设定点，官方资料未给独立 enable 位。 40014~40023 默认 0，且 0 是有效阈值。 默认参数下可能一有有效数据就报警。 现场必须下发合理默认阈值，或确认新增独立报警 enable/disable 方案。
当前最需要现场确认的需求：Manual 是否严格按官方语义做；Cal 是否实现完整 Level Calibration 并回 Auto；10010 是否还能固定为 0；报警默认值和启用方式如何定义；探底失败且无旧底时是否允许继续输出 profile。

差异与风险

P0 Manual 抑制未贯通

Manual 下官方要求不报告报警、不更新液位、自动 Profile 不启动；当前 CPU3 SI 报警和自动调度尚未完全按该语义门控。

P0 Cal 完整语义未落地

SI Profile 成功后已排队找液位并回 Auto；Cal 仍只桥接零点标定，不是官方完整 Level Calibration。

P0 Probe Uncal 固定可信

10010 固定 0 会隐藏底部参考、零点或探头位置不可信风险；尤其在探底失败且无旧底时必须专项确认。

P0 报警阈值默认 0

40014~40023 的 0 是有效阈值，不是禁用值；默认 0 可能导致首次有效数据后立即报警。

P1 传感器和报警来源合成

10002/10003 不是真实双 level sensor；10004/10009 也未区分高限、卷盘、电机和普通错误。

问题优先级排序

优先级 差异/风险 为什么重要 当前建议
P0 Manual 报警、液位和自动 Profile 官方 Manual 下报警不报告、液位不更新、自动 Profile 不启动；当前 SI 层未完全做到。 先决定是否按官方语义改 CPU3 SI 层；若保留偏差，PLC 侧必须禁用或规避。
P0 Cal 完整语义和回 Auto SI Profile 已自动排队找液位；Cal 仍不是官方触底建立 bottom reference 后回液位的流程。 确认是否重做 00002 Calibrate 语义；Profile 联调需验证自动找液位和 10013=1。
P0 10010 和探底失败可信性 10010=0 不能再直接解释为物理校准可靠；无旧底探底失败继续 profile 会降低数据可信性。 确认 10001/10010/10005 在探底失败场景下的最终对外策略。

进一步兼容实施方案

旧版报告提出的分阶段方案仍有参考价值，但当前已有多项能力落地。下一步不应继续扩大地址表，而应先完成官方语义偏差决策：哪些必须改成 SI 原机行为，哪些作为受控偏差交给 PLC 和现场规程处理。

阶段 0：锁定当前协议基线

确认 PLC 使用官方清单内的 FC01~FC06；确认接受 200 点 DCS 表、密度 16 位钳位、Profile Timestamp 为触发下发时间、速度档不区分。

下一步：保持官方地址表和功能码边界；不要在 P0 偏差未决前继续扩展协议面。

阶段 1：决策 Manual 语义

明确 Manual 下 SI 报警是否全部清零、自动 Profile 是否跳过、液位是否只作为旧值保留。

下一步：若按官方语义，修改 CPU3 SI 报警合成和自动调度门控；若接受偏差，联调表记录 PLC 规避规则。

阶段 2：验证回 Auto 生命周期

SI Profile 成功后已由 CPU2 排队 CMD_FIND_OIL；Cal 是否也要做完整 Level Calibration 并回 Auto 仍需决策。

下一步：联调验证 Profile 完成后 00003 Auto 和 10013 恢复；再决定是否重做 00002 Calibrate。

阶段 3：决策可信性状态

明确 10010 Probe Un-calibrated 是否继续固定为 0，以及无底部参考、探底失败、维护后应如何对外表达。

下一步：若需要真实可信性，重新定义 10001/10010/10005 的组合语义。

阶段 4：决策报警默认值

明确 40014~40023 出厂/现场默认值，或者新增独立报警 enable/disable 方案。

下一步：不能再用阈值 0 表示禁用；需要现场默认阈值表或协议扩展。

阶段 5：P1 状态源和诊断增强

按 PLC 真实依赖决定是否细化真实 level sensor、Interlock、Reel Alarm、通信诊断计数和超过 200 点扩展。

下一步：每次改变 SI 可见行为时，同步映射表、联调检查表、协议契约脚本和本 HTML。

推荐落地顺序

顺序 改动包 涉及方向 下一步/处理原则
1 冻结当前 FC01~FC06 和地址窗口 CPU3 SI Modbus、联调脚本、PLC 工具 保持官方功能码和 200 点 DCS 表，先不扩展 FC15/FC16 或 500 点读取。
2 处理 P0 官方语义偏差 Manual、自动 Profile、Profile/Cal 回 Auto、Probe Uncal、报警默认值 逐项决定改代码或接受受控偏差，并同步联调判据。
3 处理 P1 状态源差异 真实 level sensor、Interlock、Reel Alarm、Point0 时间戳 根据 PLC 是否依赖这些位决定是否新增状态源或诊断位。
4 后续扩展能力 超过 200 点、通信诊断、菜单诊断页 只在现场明确需要后做扩展；新增行为必须有独立版本和联调记录。
