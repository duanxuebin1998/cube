协议18兼容实现已经落地到 CPU2 和 CPU3：SI Profile 使用独立生命周期；Point0 前保留上一轮完整 SI 结果，Point0 有效样本建立新周期并把点数置为1，随后只按有效液体点递增；活动期对外点阵保持全0；返回液位稳定并完成 CPU3 分块拉取和代际复核后，才一次同代发布 Complete、最终点数、点阵和六项 Profile 报警。原 C-01~C-09 抓包差异均已在协议18关闭或冻结为明确兼容口径。

协议18 CPU2/CPU3 共享契约同步升级；旧协议组合继续由严格版本门禁拦截。

SI Profile 生命周期与对外可见值

CPU2负责真实运动、采样和权威生命周期；CPU3负责外部SI寄存器投影、时间语义、候选拉取和不可变发布快照。两端通过协议18共享字段协作。

PREPARING

接受 CMD_SI_PROFILE，探底或选取回退底部；对外继续保留完整旧SI。

MEASURING

Point0有效样本建代；N从1开始增长，活动点阵始终隐藏。

RETURNING_LEVEL

采点停止后排队找液位；候选结果尚未对外发布。

COMPLETE

液位和电机门禁满足，CPU3分块复核后同代发布最终快照。

FC06事务写与FRAM迁移

40004~40009 本地原始槽

站2抓包值已作为默认值：0、50、1000、0、5、1。字段保持原始16位，不猜测业务含义，也不参与测量控制。

FC06成功必须完成合法性检查、运行态候选更新、FRAM写入和写后读回，随后才更新holding镜像。

40010~40023 事务写

每次FC06按完整CPU3 SI参数结构执行事务。CPU2离线不阻塞本地参数写，但FRAM写入或读回失败会对外返回设备忙 0x06。

失败时恢复整份写前运行态，不更新holding；同时尽力把旧结构修复写回FRAM。

FRAM V6 → V7

CPU3本地参数存储版本提升到V7，显式识别V6布局并迁移。V6已有SI自动Profile、报警参数和合法三路串口配置必须原值保留；V6迁移和V7重载不再把合法Wartsila 4800 8N1/8N2猜成历史默认值后改写。

新增加的 40004~40009 只补协议18默认值，不用恢复出厂覆盖旧参数。

仍保留的受控偏差与未发布边界

下列项目不属于C-01~C-09生命周期兼容包的未完成项；它们是SI原机语义、当前硬件来源或发布验证上的独立边界。没有新增现场决定前，不应把它们写成协议18已经完全复刻SI原机。

Manual与自动调度

仍需按PLC实际依赖验证Manual下报警、液位保持和自动Profile抑制是否符合现场要求。

Cal完整语义

00002 Calibrate 与SI原机完整触底建基准、回Auto流程不是本次生命周期兼容包的验收结论。

硬件状态来源

10002/10003是合成液位传感器状态；Interlock和Reel Alarm也可能是错误状态归纳，不等同SI原机独立硬件触点。

底部可信性

无可信旧底且探底失败时使用当前位置继续是已确认兼容策略，但该Point0位置不能作为物理罐底校准证明。

地址与功能边界

维持官方DCS 200点窗口和FC01~FC06；FC15/FC16及超过200点不是当前支持范围。

发布边界

协议18代码已实现但尚未形成正式发布组合；CPU2和CPU3必须成对使用，协议17/18混搭应被版本门禁拦截。
