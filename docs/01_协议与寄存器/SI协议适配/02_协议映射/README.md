# SI协议映射索引

更新日期：2026-08-17

本目录保存 SI协议地址表与当前 CUBE 变量、命令、状态、限制和兼容策略的映射关系。

## 维护原则

- `SI协议兼容映射表.md` 是本目录当前正式维护源；协议地址、缩放、命令、状态和限制以该文件为准。
- `SI协议当前兼容情况总览.html` 是与正式Markdown同步的评审阅读件；其它旧HTML和Word导出件不再作为维护对象，需要对外传阅时从Markdown重新导出。
- 最新正式组合为 `DEVICE_PROTOCOL_VERSION = 34`、CPU2 `V1.40.0.0` / CPU3 `V1.40.0.0`。SI映射和生命周期仍以协议18为功能基线，协议34不改变SI外部地址、功能码或字段语义；CPU2/CPU3仍必须按共享协议严格配套。
- 2026-07-13 两轮站 2 完整 Profile 和专项查询确认的私有行为已经进入兼容实现：`30014~30016` 镜像 FC01/FC02，`30017~30020` 保持0；`40004~40009` 作为 CPU3 本地原始兼容槽，默认 `0、50、1000、0、5、1`，支持 FC03/FC06 和掉电保存；`40004~40023`均使用FRAM事务写和失败整份回滚；Point0建立周期、点数递增、活动点阵清零、回液位后的最终同代发布以及已发布SI快照与后续非SI分布隔离均已落地。抓包章节仍保留“当时 CUBE”的原始差异，只通过现状后记说明已经关闭的差异。
- CPU3 本机参数存储由 `V6` 升至 `V7`，V6 迁移保留原 SI 参数和三路串口配置，只为六个兼容槽补默认值。
- 协议18首个正式匹配组合为CPU2 `V1.26.0.0` / CPU3 `V1.24.0.0`；协议17及更早版本不得混搭。提交前审查遗留见`../01_计划与需求/SI协议待确认与后续清单.md`第7节。
