# SI PLC联调检查表

日期：2026-05-16
更新：2026-07-01

本文用于 SI协议兼容实现的 PLC、主机侧或 CPU3 屏幕联调。2026-07-01 后，SI profile 已从普通分布测量解耦：`00004 Profile` 和屏幕 `SI Profile` 均下发 `CMD_SI_PROFILE`，`40001~40003` 桥接 CPU2 SI profile 参数，`40010~40023` 由 CPU3 持久化并用于自动调度和报警合成。官方协议口径以 `../00_原始资料/SI7000_modbus_官方.pdf` 的 `020-701 Rev B` 为准。

## 1. 联调前置条件

| 项目 | 要求 |
| --- | --- |
| 官方依据 | SI-7000 DCS Modbus Interface Specification `020-701 Rev B` |
| 串口参数 | RS485、Modbus RTU、`9600 8O1` |
| 站号 | 当前复用 `SlaveAddress` 作为 SI Tank ID；不新增独立 SI Tank ID 参数 |
| 功能码 | `FC01`、`FC02`、`FC03`、`FC04`、`FC05`、`FC06` |
| 点数 | DCS 地址表按 200 个 profile 点联调 |
| 本轮不覆盖 | 不测试超过 200 点扩展；不测试 Slow/Medium/Fast 三档真实速度差异；不测试独立 Tank ID |

资料来源口径：

- 串口参数、地址窗口、保留地址、缩放单位、`40011` 启停语义、`40010=1440` 日周期建议、200 点 DCS 表来自官方资料。
- `40001~40023` 逐项出厂默认值未在本地原始资料中找到；当前默认值按 CUBE 工程默认验收。
- 温度无效值统一按 `-200.00°C` 验收，寄存器值为 `-20000`，补码 `0xB1E0`；密度无效值按 `0` 验收。

## 2. 主机侧参考帧

参考帧由 `tools/check_si_modbus_frames.py --dump` 生成。默认站号按 `0x01` 示例，现场如果站号不同，需要替换首字节并重算 CRC。

| 场景 | 请求帧 | 期望响应 |
| --- | --- | --- |
| 读全部线圈 `00001~00016` | `01 01 00 00 00 10 3D C6` | 默认安全态示例：`01 01 02 01 01 79 AC` |
| 读全部离散输入 `10001~10032` | `01 02 00 00 00 20 79 D2` | 默认公制示例：`01 02 04 20 00 00 00 F0 22` |
| 读 `40010~40013` | `01 03 00 09 00 04 94 0B` | 默认参数示例：`01 03 08 00 3C 00 00 00 00 00 00 69 D4`，表示周期 60min、默认关闭、起始 00:00 |
| 读 `30001~30013` | `01 04 00 00 00 0D 31 CF` | 零快照示例：`01 04 1A 00 00 B1 E0 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 77 4B`，真实时间字段可非零 |
| 写 `00004 Profile ON` | `01 05 00 03 FF 00 7C 3A` | `01 05 00 03 FF 00 7C 3A` |
| 写 `40012=23` | `01 06 00 0B 00 17 B8 06` | `01 06 00 0B 00 17 B8 06` |
| 写 `40016=-20.00°C` | `01 06 00 0F F8 30 FA 1D` | `01 06 00 0F F8 30 FA 1D` |
| 读非法保持寄存器 `40024` | `01 03 00 17 00 01 34 0E` | `01 83 02 C0 F1` |
| 写非法 `40011=2` | `01 06 00 0A 00 02 28 09` | `01 86 03 02 61` |
| 官方未列功能码示例 `FC16` | `01 10 00 00 00 01 02 00 00 A6 50` | `01 90 01 8D C0` |

## 3. FC01 线圈检查

| 地址 | 名称 | 当前验收口径 |
| --- | --- | --- |
| `00001` | Manual | 非 Auto/Cal/Profile 状态下可置位；写入 ON 桥接维护模式 |
| `00002` | Calibrate | 写入 ON 后桥接现有校准/探底入口 |
| `00003` | Auto | 写入 ON 后桥接找液位/自动液位入口 |
| `00004` | Profile | 写入 ON 后锁存 profile 开始时间，并下发 `CMD_SI_PROFILE` 独立 profile 命令 |
| `00005~00008` | 保留 | 读取为 0；写入应返回非法地址 |
| `00009` | Stop | 写入 ON 后桥接维护/停止语义 |
| `00010~00012` | Up Slow/Medium/Fast | 当前三档统一桥接强制上行；真实速度差异待确认 |
| `00013~00015` | Down Slow/Medium/Fast | 当前三档统一桥接强制下行；真实速度差异待确认 |
| `00016` | 保留 | 读取为 0；写入应返回非法地址 |

## 4. FC02 离散输入检查

| 地址 | 名称 | 当前验收口径 |
| --- | --- | --- |
| `10001` | Bottom Reference | 来自 CPU2 通用罐底参考状态 |
| `10002` | Lower Level Sensor | 液位跟随稳定时返回 `1`；其它状态也返回 `1`，按“在液体中”显示 |
| `10003` | Upper Level Sensor | 液位跟随稳定时返回 `0`，表示在空气中；其它状态返回 `1`，按“在液体中”显示 |
| `10004` | Interlock | 当前第一版按错误/过程阻塞合成，精确互锁语义待确认 |
| `10005` | Profile Complete | 仅 SI profile 完成锁存后置位；普通分布和 Wärtsilä 分布不置 SI 完成态 |
| `10006` | Unit Is Metric | 固定为 1 |
| `10009` | Reel Alarm | 当前按设备错误简化合成，不再细分卷尺、电机、校准等来源 |
| `10010` | Probe Un-calibrated | 固定返回 `0`，SI协议对外始终显示探针位置可信 |
| `10012` | Interval Timer | `40011=1` 且 `40010>0` 时置位，表示自动 profile 调度有效 |
| `10013` | Probe At Liquid Level | 来自 CPU2 通用液位到达状态 |
| `10017~10024` | 当前值报警 | 由当前值与 CPU3 SI协议 `40014~40021` 阈值合成，阈值 `0` 是有效值 |
| `10025~10026` | Profile 偏差报警 | CPU3 扫描 profile 相邻点温度差/密度差，与 `40022/40023` 比较合成；温度差按 int16 温度值计算 |
| `10029~10032` | Profile 上下限报警 | profile 完成后按点阵和阈值合成 |

## 5. FC03/FC06 保持寄存器检查

| 地址 | 名称 | 当前验收口径 |
| --- | --- | --- |
| `40001` | Profile First Point | 桥接 CPU2 `si_profile_first_point`，表示 Point1 绝对位置，协议单位 mm |
| `40002` | Profile Increment | 桥接 CPU2 `si_profile_increment`，表示从 `40001` 开始逐点递增的步距，协议单位 mm |
| `40003` | Profile Dwell Time | 桥接 CPU2 `si_profile_dwell_time`，表示每点停稳后的等待时间，单位秒 |
| `40004~40009` | 保留 | 写入返回非法地址 |
| `40010` | Automatic Profile Interval | CPU3 SI 本机参数，单位分钟；禁止写入 0，默认 60 |
| `40011` | Automatic Profile Enable | CPU3 SI 本机参数，只接受 `0/1`；为 1 时调度生效 |
| `40012` | Automatic Profile Hour | 只接受 `0~23` |
| `40013` | Automatic Profile Minute | 只接受 `0~59` |
| `40014~40023` | 报警和偏差阈值 | CPU3 SI 本机参数，掉电保存并用于 `10017~10026/10029~10032` 报警合成 |

## 6. FC04 输入寄存器检查

| 地址 | 名称 | 当前验收口径 |
| --- | --- | --- |
| `30001` | Current Probe Position | 当前探头位置，单位 mm |
| `30002` | Current Temperature | 有符号 `0.01°C` |
| `30003` | Current Density | `0.01 kg/m3`；超过 16 位范围时钳位 |
| `30004` | Liquid Level | 最近一次液位读数；官方建议结合 `10013` 判断是否为当前液位 |
| `30006` | Number of Points | 官方采集过程中可递增；当前仅 SI profile 完成锁存后输出有效点数 |
| `30007~30010` | Profile Timestamp | 官方语义为首个 profile 点采集时间；当前为 CPU3 收到 SI `00004 Profile`、屏幕 SI profile 或自动 profile 触发时锁存的开始时间 |
| `30011~30013` | Current Time | CPU3 RTC 当前时分秒，应持续变化；可作为通信活性检查 |
| `30021~30620` | Profile 点阵 | 官方 DCS 地址表覆盖 200 点；超出有效点数返回 0，超过 200 点需扩展方案 |

官方 profile 读取建议：profile 开始触底后旧点阵和 `10005 Profile Complete` 会清除，完成后 `10005=1` 且点阵可采集。当前实现更保守，完成锁存前 `30006` 和点阵保持无效，PLC 应以 `10005=1` 后读取点阵作为验收口径。

## 7. 边界和异常检查

| 场景 | 期望 |
| --- | --- |
| CRC 错误 | 不生成正常响应 |
| 地址不匹配 | 不生成正常响应 |
| 未支持功能码 | 返回 `Illegal Function` |
| 读数量为 0 | 返回 `Illegal Data Value` |
| 读超过表范围 | 返回 `Illegal Data Address` |
| 写保留线圈或寄存器 | 返回 `Illegal Data Address` |
| 写 `40011 > 1` | 返回 `Illegal Data Value` |
| 写 `40010 = 0` | 返回 `Illegal Data Value`，关闭自动 profile 使用 `40011=0` |
| 写 `40012 > 23` | 返回 `Illegal Data Value` |
| 写 `40013 > 59` | 返回 `Illegal Data Value` |

### 7.1 保留地址检查

| 区域 | 保留地址 | 联调期望 |
| --- | --- | --- |
| 线圈 | `00005~00008`、`00016` | 读取为 0；写 ON/OFF 返回 `Illegal Data Address` |
| 离散输入 | `10007`、`10011`、`10014~10016`、`10027~10028` | 读取为 0 |
| 保持寄存器 | `40004~40009` | 读取为 0；写入返回 `Illegal Data Address` |
| 输入寄存器 | `30005`、`30014~30020` | 读取为 0 |

### 7.2 缩放和上限检查

| 项目 | 联调期望 |
| --- | --- |
| 位置/液位 | 协议单位为 mm；内部 0.1mm 数据输出时向协议 mm 转换，负位置按 0 输出 |
| 温度 | 协议单位为有符号 `0.01°C`；负温度应按 16 位补码由 PLC 解释 |
| 密度 | 协议单位为 `0.01 kg/m3`；超过 `655.35 kg/m3` 时当前实现钳位到 `65535` |
| Profile 有效点外 | `30006` 指定有效点数之外的 `30021~30620` 点阵寄存器保持 0 |
| 200 点边界 | Point 199 对应最后一组三元组；Point 200 不在当前 DCS 地址表内 |

### 7.3 无效值检查

| 项目 | 联调期望 |
| --- | --- |
| 当前温度无效 | `30002` 输出 `-200.00°C`，寄存器值 `0xB1E0` |
| profile 点温度无效 | 对应温度寄存器输出 `-200.00°C`，寄存器值 `0xB1E0` |
| 当前密度无效 | `30003` 输出 `0` |
| profile 点密度无效 | 对应密度寄存器输出 `0` |
| 液位/位置无效 | 继续输出 `0` |
| 无效值报警过滤 | 无效温度和无效密度不参与上下限或偏差报警判断 |
| 负温度偏差 | 构造相邻点跨 0°C 温度，例如 `-1.00°C` 和 `1.00°C`，`10025` 应按 `200` 个 `0.01°C` 计差 |

## 8. SI Profile 流程检查

| 场景 | 验收口径 |
| --- | --- |
| 上电后首次 profile | 必须先真实探底，再采集 Point0；Point0 对外位置字段固定为 `0` |
| 探底频次为 `1` | 每次 profile 前都真实探底 |
| 探底频次为 `N` | 上电首次必须探底；后续按进入 CPU2 SI profile 入口的触发次数计数，前 `N-1` 次可复用旧底部位置，第 `N` 次重新真实探底；不按成功完成次数计数 |
| 不探底 profile | 仍需运行到上次探底保存的底部位置采集 Point0；Point0 对外位置字段固定为 `0` |
| 探底失败且有旧底部位置 | 使用旧底部位置继续本轮 profile |
| 探底失败且无旧底部位置 | 使用当前位置作为底部采样目标并继续，但不刷新底部参考、不标记底部可信、不清首次探底状态；Point0 对外位置字段仍为 `0` |
| 点阵位置字段 | `30021` 对应 Point0 位置，必须为 `0`；Point1 位置必须等于 `40001`；Point2 位置必须等于 `40001+40002`；即使实际底部高于 `40001`，也不跳过 Point1 |
| 不预找液位 | `00004 Profile` 触发后，CPU2 不应先执行 `SearchOilLevel()`；`30004 Liquid Level` 不要求在 profile 前刷新 |
| 液面停止条件 | 候选点逐点运行，到点采样判定为液面以上时停止，不写入该液面以上 profile 点；达到罐高或 200 点上限也停止 |
| 屏幕 Profile 下发 | CPU3 屏幕进入“密度分布测量 -> SI Profile”并确认后，应锁存 `30007~30010` 并下发 `CMD_SI_PROFILE`；确认页返回密度分布测量菜单 |
| CPU3 菜单短名 | Profile 页显示 `SI首点/SI步距/SI停留/SI探底`，自动页显示 `SI周期/SI自动/SI时/SI分`，不得越过 128x64 OLED 列宽 |
| 普通分布隔离 | 普通分布、国标、每米、间隔和 Wärtsilä 分布运行和完成后，SI `00004/10005/30006/点阵` 不应被置为有效 |

## 9. 本轮仍需现场实测或不覆盖的需求

| 需求 | 原因 |
| --- | --- |
| 独立 SI Tank ID 参数 | 当前已确认复用 `SlaveAddress`；只有现场明确要求单独配置时再扩展 |
| 三档手动速度差异 | 现场是否需要真实速度未确认 |
| 超过 200 点 profile 扩展 | 当前不做；如 PLC 后续要求，需要扩展地址或分页机制 |
| SI协议官方手册逐项默认值复核 | 当前代码采用保守默认值：CPU2 首点 100mm、步距 1000mm、停留 10s、探底频次 1；CPU3 自动周期 60min、默认关闭。报警阈值 `0` 是有效值 |
| 报警启用方式 | `0` 已确认是有效阈值，不能再用于禁用；如需禁用报警，需要另定 enable 方案 |
