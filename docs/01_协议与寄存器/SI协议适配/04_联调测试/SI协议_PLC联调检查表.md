# SI PLC联调检查表

日期：2026-05-16
更新：2026-07-20

本文用于 SI协议兼容实现的 PLC、主机侧或 CPU3 屏幕联调。2026-07-01 后，SI profile 已从普通分布测量解耦：`00004 Profile` 和屏幕 `SI Profile` 均下发 `CMD_SI_PROFILE`，`40001~40003` 桥接 CPU2 SI profile 参数，`40010~40023` 由 CPU3 持久化并用于自动调度和报警合成。官方协议口径以 `../00_原始资料/SI7000_modbus_官方.pdf` 的 `020-701 Rev B` 为准。

2026-07-02 根据官方全文译稿复核后，本检查表新增 Manual、自动 Profile、Profile/Cal 完成后回 Auto、Probe Un-calibrated、双液位传感器合成和探底失败 fallback 等偏差检查。当前 SI Profile 成功后已自动排队找液位，Cal 完整回 Auto 语义仍待确认；未改代码的偏差项应按“已知偏差”记录。

2026-07-10 补充 CPU2 通信门禁和写失败反馈：`FC05=ON`、`FC06 40001~40003` 依赖 CPU2 ACK，失败返回设备忙 `0x06` 且不提交影子；`40010~40023` 是 CPU3 本机持久化参数，不依赖 CPU2 在线状态。

2026-07-13 现场抓包确认真实 SI 的 `30014~30016` 是 FC01/FC02 私有镜像，空闲态和 Profile 下行动态态均已直接对齐；`40004~40009` 部分非零，Point0 输出实际底部位置，点数和时间戳从 Point0 开始发布。

2026-07-14已按确认方案落地协议18：`30014~30016`镜像FC01/FC02，Point0输出本轮实际采用底部，Point0建立新周期并从 `N=1`递增，回液位稳定且完成点阵代际复核后再发布最终组合；`40004~40009`按站2默认值提供原样读写和FRAM保存。本文以下“当前验收口径”仍指协议18建立的SI功能基线。当前整机开发及最新正式组合为协议25、CPU2 V1.30.0.0 / CPU3 V1.29.0.0；协议19故障码、协议20 AO、协议21固定点代际、协议22故障码重排、协议23/24 AO语义和协议25水位预留参数均不改变本表SI地址、生命周期、参数或通过标准；历史差异只用于现场对照。

## 1. 联调前置条件

| 项目 | 要求 |
| --- | --- |
| 官方依据 | SI-7000 DCS Modbus Interface Specification `020-701 Rev B` |
| 串口参数 | RS485、Modbus RTU、`9600 8O1` |
| 站号 | 当前复用 `SlaveAddress` 作为 SI Tank ID；不新增独立 SI Tank ID 参数 |
| 功能码 | `FC01`、`FC02`、`FC03`、`FC04`、`FC05`、`FC06` |
| 点数 | DCS 地址表按 200 个 profile 点联调 |
| 本轮不覆盖 | 不测试超过 200 点扩展；不测试 Slow/Medium/Fast 三档真实速度差异；不测试独立 Tank ID |

资料来源口径：

- 串口参数、地址窗口、保留地址、缩放单位、`40011` 启停语义、`40010=1440` 日周期建议、200 点 DCS 表来自官方资料。
- `40001~40023` 逐项出厂默认值未在本地原始资料中找到；当前默认值按 CUBE 工程默认验收。
- 温度无效值统一按 `-200.00°C` 验收，寄存器值为 `-20000`，补码 `0xB1E0`；密度无效值按 `0` 验收。

## 6. FC04 输入寄存器检查

| 地址 | 名称 | 当前验收口径 |
| --- | --- | --- |
| `30001` | Current Probe Position | 当前探头位置，单位 mm |
| `30002` | Current Temperature | 有符号 `0.01°C` |
| `30003` | Current Density | `0.01 kg/m3`；超过 16 位范围时钳位 |
| `30004` | Liquid Level | 最近一次液位读数；官方建议结合 `10013` 判断是否为当前液位 |
| `30006` | Number of Points | Point0前保留上一轮最终点数；Point0建立新周期后从1按有效液体点递增，最终点数事先未知 |
| `30007~30010` | Profile Timestamp | Point0建立新周期时由CPU3锁存RTC；CPU3重启/重连无法恢复时允许为0，不伪造旧时间 |
| `30011~30013` | Current Time | CPU3 RTC 当前时分秒，应持续变化；可作为通信活性检查 |
| `30014` | 官方 Reserved/站2 FC01 镜像 | 按Modbus低位优先镜像 `00001~00016`，必须与FC01同一位图来源一致 |
| `30015` | 官方 Reserved/站2 FC02 前半镜像 | 按Modbus低位优先镜像 `10001~10016` |
| `30016` | 官方 Reserved/站2 FC02 后半镜像 | 按Modbus低位优先镜像 `10017~10032` |
| `30017~30020` | Reserved | 两个不重叠时段共 6265 个站 2 合法样本均为 0；当前 CUBE 也固定 0 |
| `30021~30620` | Profile 点阵 | 官方 DCS 地址表覆盖 200 点；超出有效点数返回 0，超过 200 点需扩展方案 |

协议18复刻站2的完成门禁边沿：命令后到Point0前保留上一轮`10005 Profile Complete=1`和旧点数；Point0建立新周期后Complete清0、点数变1并递增；活动期点阵窗口保持全0；最终回液位并完成点阵代际复核后，Complete、最终N、点阵和Profile报警才作为同一发布快照开放。PLC不能在发命令后只等待`10005=1`，必须先确认进入Profile或Complete出现清零，再等待最终组合重新成立。

## 7. 边界和异常检查

| 场景 | 期望 |
| --- | --- |
| CRC 错误 | 不生成正常响应 |
| 地址不匹配 | 不生成正常响应 |
| 未支持功能码 | 返回 `Illegal Function` |
| 读数量为 0 | 返回 `Illegal Data Value` |
| 读超过表范围 | 返回 `Illegal Data Address` |
| 写保留线圈或未兼容保留寄存器 | 返回 `Illegal Data Address`；`40004~40009`是协议18明确支持的例外 |
| 写 `40011 > 1` | 返回 `Illegal Data Value` |
| 写 `40010 = 0` | 返回 `Illegal Data Value`，关闭自动 profile 使用 `40011=0` |
| 写 `40012 > 23` | 返回 `Illegal Data Value` |
| 写 `40013 > 59` | 返回 `Illegal Data Value` |
| 状态/参数/当前连接协议快照未完成、共享协议不兼容、参数刷新中或 CPU2 通信故障锁存时写 `FC05=ON` | 返回 Slave Device Busy `0x06`，对应线圈影子不置位 |
| CPU2 ACK 成功时写 `40001~40003` | FC06原帧回显；参数快照立即失效并主动补读四组，补读完成前读取范围与`40001~40003`相交的FC03及后续CPU2参数写返回Slave Device Busy `0x06`；`40004~40023`仍可离线读写 |
| CPU2 ACK 失败、超时或响应非法时写 `40001~40003` | 返回 Slave Device Busy `0x06`，`g_deviceParams` 和 SI 保持寄存器影子保持原值；参数快照立即失效并主动补读四组，同轮其它普通命令被阻止 |
| CPU2 离线时写 `40004~40023` 合法值 | 正常回显并写入CPU3本机参数，不得因CPU2离线误返回`0x06` |
| `40004~40023`首次FRAM写入或写后读回校验失败 | 恢复整份写前运行态，尽力写回完整旧FRAM镜像，FC06返回设备故障`0x06`且holding快照不提交；相同值重试也必须执行持久化修复 |
| 收到 `0x06` 后恢复完整 CPU2 `0x04` 状态快照并重试 | 重试成功，FC01/FC03 回读与目标值一致 |
| 自动 Profile 到点但 CPU2 不可用 | 首次下发失败；5 s 内不重复同步请求，达到 5 s 后重试；同一分钟内 CPU2 恢复后能够成功触发，成功后本分钟不再重复 |

## 8. SI Profile 流程检查

| 场景 | 验收口径 |
| --- | --- |
| 上电后首次 profile | 必须先真实探底，再采集Point0；最终Point0位置输出本轮实际采用的底部参考 |
| 探底频次为 `1` | 每次 profile 前都真实探底 |
| 探底频次为 `N` | 上电首次必须探底；后续按进入 CPU2 SI profile 入口的触发次数计数，前 `N-1` 次可复用旧底部位置，第 `N` 次重新真实探底；不按成功完成次数计数 |
| 不探底 profile | 仍需运行到上次探底保存的底部位置采集Point0；最终Point0位置输出该旧底部位置 |
| 探底失败且有旧底部位置 | 使用旧底部位置继续本轮 profile |
| 探底失败且无旧底部位置 | 使用当前位置作为底部采样目标并继续，不刷新底部参考、不标记底部可信、不清首次探底状态，也不置本轮失败或Interlock；最终Point0输出该当前位置 |
| 点阵位置字段 | `30021`对应Point0，最终必须等于本轮实际采用底部位置；Point1等于`40001`，Point2等于`40001+40002`；即使实际底部高于`40001`也不跳过Point1 |
| 不预找液位 | `00004 Profile` 触发后，CPU2 不应先执行 `SearchOilLevel()`；`30004 Liquid Level` 不要求在 profile 前刷新 |
| 液面停止条件 | 候选点逐点运行，到点采样判定为液面以上时停止，不写入该液面以上 profile 点；达到罐高或 200 点上限也停止 |
| 屏幕 Profile 下发 | CPU3屏幕进入“密度分布测量 -> SI Profile”并确认后下发`CMD_SI_PROFILE`；`30007~30010`等CPU2 Point0周期边沿到达时锁存；确认页返回密度分布测量菜单 |
| CPU3 菜单短名 | Profile 页显示 `SI首点/SI步距/SI停留/SI探底`，自动页显示 `SI周期/SI自动/SI时/SI分`，不得越过 128x64 OLED 列宽 |
| 普通分布隔离 | 已发布SI的Complete、N、时间、点阵和Profile报警不被普通分布、国标、每米、间隔或Wärtsilä结果覆盖；当前非SI动作状态也不得被旧SI终态遮挡 |

### 8.1 真实 SI 完成门禁对照

| 阶段 | 真实 SI 抓包特征 | CUBE 联调重点 |
| --- | --- | --- |
| 命令前/旧结果 | `30014 Auto=1`，`30015 Complete=1`，`30006` 为上一轮最终点数 | 记录命令前基线，禁止把旧 Complete 当成本轮完成 |
| 已进入 Profile、Point0 前 | `30014 Profile=1`；Complete 仍可能短暂为 1；旧点数和旧时间保留 | 确认模式进入，不只等待 Complete=1 |
| Point0 完成 | Complete 由1清0，`30006=1`，时间戳更新 | 协议18应出现相同边沿；点阵仍全0，后续每个有效液体点只递增N |
| 仪器处理/最终生成 | 第二轮到液位后继续 20.439 s 才发布最终结果；时长接近 `40003=20 s` | 不把该窗口误写成纯 CPU 运算；同步记录液位点停留、最终采样、报警计算和发布顺序 |
| 最终完成 | `30014 Profile=0/Auto=1`，`30015 Complete=1/AtLevel=1`，第二轮 `30016=0x0200`，随后读取点阵 | 协议18必须等回液位Stable、电机停止、Interlock=0和分块代际复核完成后，再同一发布快照开放最终模式、Complete、N、点阵和Profile报警 |

空闲态和 Profile 下行态的 FC01/FC02/FC04 已直接对齐；下一轮完整对照应补齐 Point0、逐点上行、液位稳定和最终完成阶段，并在 Point0 前后、中段和最终完成后抽读 `30021~30032`。第二轮点阵已证明相邻密差超过 `40023` 时 `30016=0x0200`，应在该报警非零稳态直接读取 FC02。专项请求必须暂停原上位机或进入同一调度队列，禁止两个无仲裁主站同时发送。

## 9. 官方语义偏差专项检查

以下检查用于确认当前 CUBE 行为与官方 SI 原机语义之间的差异。若现场决定接受偏差，需要在联调记录中写清 PLC 规避方式；若决定追求官方一致，应先修改 CPU2/CPU3 实现再验收。

| 场景 | 官方期望 | 当前 CUBE 预期或需观察项 | 判定 |
| --- | --- | --- | --- |
| Manual 报警抑制 | Manual mode 下所有报警不报告 | 写 `00001 Manual` 或 `00009 Stop` 后构造当前值/profile 报警条件，观察 `10017~10026/10029~10032`；当前 CPU3 SI 层可能仍按阈值置位 | 若仍置位，记录为已知偏差 R-01 |
| Manual 液位有效性 | Manual 下液位读数不更新，且必须返回 Auto 后才恢复 | Manual 或强制上下行期间连续读 `30004` 和 `10013`；PLC 不得在 `10013=0` 时把 `30004` 当当前液位 | `10013=0` 时只能按旧值或未知处理 |
| Manual 下自动 Profile | 到点时若处于 Manual，自动 Profile 不应启动 | 启用 `40011=1`，设置即将到点的 `40010/40012/40013`，设备保持 Manual，观察是否下发 `CMD_SI_PROFILE` 或进入 `00004 Profile` | 当前若启动，记录为已知偏差 R-02 |
| Profile 完成后回 Auto | Profile 完成后应返回 Auto 并跟踪液位 | 采点结束后观察 `RETURNING_LEVEL`、`00004 Profile=1`、`10005 Complete=0`；CPU2自动排队 `CMD_FIND_OIL`，回到稳定液位且电机停止后再观察 `00003 Auto=1`、`10013 Probe At Liquid Level=1`、`10005 Complete=1` 同代发布 | 回液位前不得提前Complete；最终 `10013=1` 后才把 `30004` 当当前液位；若未自动回 Auto或组合分帧发布，记录为异常 |
| Cal 完整语义 | `00002 Calibrate` 应触底建立 bottom reference，然后返回液位并 Auto | 写 `00002 Calibrate` 后观察是否只是零点标定，是否自动找液位并回 Auto | 当前桥接 `CMD_CALIBRATE_ZERO`，完整 Level Calibration 待确认 |
| Probe Un-calibrated | 无底部参考、断电/维护后或位置不可信时应置位 | 构造底部参考无效、探底失败或维护后状态，读取 `10010` | 当前固定 `0`；只能作为兼容固定值，不作为物理可信证明 |
| Lower/Upper Level Sensor | 应反映真实上下液位传感器是否在液体中 | 在非液位跟随、profile、手动和故障状态读取 `10002/10003` | 当前为合成状态，不能用于真实传感器联锁 |
| Interlock/Reel Alarm | `10004` 表示高限互锁，`10009` 表示卷盘/物理驱动报警 | 分别构造普通错误、profile 阻塞和电机/位置异常，观察 `10004/10009` 是否可区分 | 当前为概括合成；如 PLC 要区分故障源需扩展 |
| Profile Timestamp | 应接近首个profile点采集时间 | 记录写`00004`时刻、CPU2 Point0周期边沿、CPU3轮询和`30007~30010` | 协议18在观察到Point0边沿时锁存，允许存在一个内部轮询周期偏差；不能用于推算每点精确采样时间 |
| 无旧底且探底失败 | 严格SI语义下应重新建立底部参考或失败 | 清空/模拟无旧底部位置并构造探底失败，观察`10001`、Interlock、N和`30021~30023` | 按确认口径使用当前位置继续、不置失败/Interlock，Point0输出当前位置；数据仍属低可信受控偏差 |
| 报警阈值默认 0 | 阈值 0 是设定点，不是禁用 | 恢复默认 `40014~40023=0` 后构造有效测量值，观察报警位 | 默认阈值可能立即触发报警；现场需下发合理阈值或定义 enable |

## 10. 本轮仍需现场实测或不覆盖的需求

| 需求 | 原因 |
| --- | --- |
| 站2真实RS485连续两轮 | 验证旧结果→Point0→递增N→回液位→最终同代组合的完整时序 |
| 协议17/18混搭拦截 | 共享字段已扩展，必须证明严格版本门禁生效 |
| 协议18/21/24与25混搭拦截 | 当前协议25包含故障码、AO、固定点代际和水位预留参数等后续共享扩展，必须证明严格版本门禁生效，不能返回伪兼容SI快照 |
| CPU3 V6真实FRAM镜像迁移 | 静态布局检查不能替代真实旧镜像的参数和三路串口配置保留验证 |
| `40004~40023`掉电保存和FRAM故障注入 | 验证正常重启保持、失败`0x06`、整份运行态回滚和旧FRAM镜像修复 |
| Point0前后取消/失败 | 验证Point0前保留旧快照、Point0后清空本轮且不恢复旧Complete |
| CPU3各阶段重启/重连 | 验证Point0前恢复、Point0后禁止旧结果恢复，以及时间无法恢复时输出0 |
| CPU2通信中断和分块重试 | 验证候选头/块/头代际复核不会发布混代点阵 |
| 1/30/200点边界 | 验证N递增、200点封顶和有效点外全0 |
| 普通分布与SI快照隔离 | 验证其它分布测量不覆盖已发布SI快照，旧SI终态不遮挡实时非SI动作 |
