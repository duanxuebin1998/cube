# SI 对外 PLC 协议

本目录保存可直接提供给 PLC、HMI 或上位机开发人员的 SI 对外通信资料。

| 文件 | 用途 |
| --- | --- |
| `CUBE_SI_Modbus_RTU_PLC对接协议V1.0.md` | CUBE 设备 SI Modbus RTU 外部通信、Profile 生命周期、数据归档和历史查询对接基线 |

维护规则：

- 本目录只描述外部可见契约，不写 CPU2/CPU3 内部变量、源码路径和历史实施过程。
- 地址、缩放、功能码、异常响应或 Profile 生命周期发生外部可见变化时，先更新内部兼容映射和实现验证，再同步更新本目录协议版本。
- Markdown 是维护源。只有明确需要对外提供 PDF 时，才从最终 Markdown 生成并完成版式检查。
- 当前协议适用基线为 CPU2 `V1.42.8.0`、CPU3 `V1.40.1.0`、CPU2/CPU3 共享协议 `35`。
