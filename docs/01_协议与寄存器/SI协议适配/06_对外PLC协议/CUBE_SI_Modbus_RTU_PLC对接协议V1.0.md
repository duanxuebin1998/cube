# CUBE SI Modbus RTU PLC 对接协议 V1.0

文档日期：2026-09-01\
适用对象：PLC、HMI、工控机及上位机软件开发人员\
适用固件：CPU2 `V1.42.8.0`、CPU3 `V1.40.1.0`\
设备内部配套协议：CPU2/CPU3 共享协议 `35`\
文档状态：PLC 对接基线

## 1. 文档目的和适用范围

本文定义 CUBE 设备以 SI 兼容模式对外提供的 Modbus RTU 通信接口，包括：

- RS485 和 Modbus RTU 通信参数；
- 支持的功能码、地址、数据类型、缩放和异常响应；
- 模式、状态、报警、参数和 Profile 点阵的读取与写入；
- Profile 由 PLC、设备屏幕或设备自动调度发起时的统一识别方法；
- Profile 完成后的单次读取、记录、查询和导出要求。

本文不描述设备内部处理器通信、内部变量、程序模块或源码实现。PLC 只依赖本文定义的外部状态和寄存器，不应依赖设备内部实现细节。

## 2. 对接结论

PLC 作为 Modbus RTU 唯一主站，CUBE 设备作为从站。PLC 建议周期读取以下三组数据：

1. `FC01` 读取 `00001~00016`：模式和运动状态；
2. `FC02` 读取 `10001~10032`：设备状态和报警；
3. `FC04` 读取 `30001~30020`：实时值、Profile 点数、时间和状态镜像。

Profile 可以由 PLC、设备屏幕或设备自动调度发起。PLC 不区分发起来源，只根据状态变化建立一次测量会话：

1. 在线观察到 `Profile` 从 0 进入 1；
2. 再观察到 `Profile=1、Complete=0、N>=1`，确认本轮已经开始采点；
3. 最后观察到 `Profile=0、Complete=1、AtLevel=1、N=1~200`；
4. 此时读取前 N 个完整测点并保存一条记录；
5. 当前会话保存后立即关闭，只有下一次新的 `Profile 0->1` 才能建立新记录。

PLC 启动、重启或重新连接时不补录设备中已经存在的旧 Profile 结果。

## 3. 物理层和串口参数

| 项目 | 要求 |
| --- | --- |
| 物理接口 | RS485，两线半双工 |
| 主从关系 | PLC/HMI/工控机为主站，CUBE 设备为从站 |
| 总线主站数量 | 同一总线只允许一个主站；禁止两个无仲裁主站同时发送 |
| 传输模式 | Modbus RTU |
| 波特率 | 9600 baud |
| 数据位 | 8 |
| 校验 | Odd，奇校验 |
| 停止位 | 1 |
| 简写 | `9600 8O1` |
| 从站地址 | `1~247`，使用设备当前 Modbus 站号 |
| 广播地址 0 | 不支持；设备只处理与本机站号一致的请求 |
| 建议轮询周期 | 约 1 s；多设备时按站号顺序轮询 |

实际端子名称和 A/B 极性以设备接线图为准。不同厂家的 A/B 标注可能相反，首次联调应以能够稳定收发且无持续 CRC 错误为准确认极性。

## 4. Modbus RTU 帧规则

### 4.1 字节顺序和 CRC

- 16 位寄存器数据按 Modbus 标准使用大端字节序，高字节在前。
- RTU 帧尾 CRC16 使用 Modbus CRC，多项式 `0xA001`，CRC 低字节先发送。
- 位数据响应按低位优先打包，请求的第一个地址对应数据区第一个字节的 bit0。
- 温度按有符号 Int16 二进制补码解释；其它未特别说明的寄存器按 UInt16 解释。

### 4.2 地址表示

本文使用便于 PLC 阅读的参考地址。Modbus 报文中的 PDU 起始地址从 0 开始：

| 数据区 | 本文参考地址 | 报文 PDU 起始地址示例 |
| --- | --- | --- |
| 线圈 | `00001~00016` | `00001 -> 0x0000`，`00004 -> 0x0003` |
| 离散输入 | `10001~10032` | `10001 -> 0x0000`，`10013 -> 0x000C` |
| 输入寄存器 | `30001~30620` | `30001 -> 0x0000`，`30021 -> 0x0014` |
| 保持寄存器 | `40001~40023` | `40001 -> 0x0000`，`40010 -> 0x0009` |

PLC 软件若使用 0 基地址，直接填写 PDU 偏移；若使用 1 基参考号，填写本文地址。首次联调必须用参考帧确认软件地址规则，避免整体偏移 1。

### 4.3 请求、响应和异常帧

读请求：

```text
[站号][功能码][起始地址Hi][起始地址Lo][数量Hi][数量Lo][CRC Lo][CRC Hi]
```

读响应：

```text
[站号][功能码][数据字节数][数据...][CRC Lo][CRC Hi]
```

`FC05`、`FC06` 写成功响应与请求的站号、功能码、地址和值相同，并重新计算 CRC。异常响应格式为：

```text
[站号][功能码 | 0x80][异常码][CRC Lo][CRC Hi]
```

## 5. 支持的功能码

| 功能码 | 名称 | 支持范围 | 单次数量限制 |
| --- | --- | --- | --- |
| `0x01` / FC01 | Read Coils | `00001~00016` | 受地址窗口限制，建议一次读 16 位 |
| `0x02` / FC02 | Read Discrete Inputs | `10001~10032` | 受地址窗口限制，建议一次读 32 位 |
| `0x03` / FC03 | Read Holding Registers | `40001~40023` | 最大 125，实际窗口 23 个 |
| `0x04` / FC04 | Read Input Registers | `30001~30620` | 每次最大 125 个寄存器 |
| `0x05` / FC05 | Write Single Coil | 可写线圈 | ON=`0xFF00`，OFF=`0x0000` |
| `0x06` / FC06 | Write Single Register | `40001~40023` | 每次写 1 个寄存器 |

不支持 `FC15`、`FC16` 及其它未列功能码。特别注意：批量写保持寄存器的 `FC16/0x10` 不支持，参数必须使用 `FC06` 逐项写入。

## 6. 数据类型、单位和无效值

| 数据 | 类型 | 分辨率/单位 | 无效值或边界 |
| --- | --- | --- | --- |
| 位置、液位 | UInt16 | 1 count = 1 mm | 无效或负位置输出 0；超过 UInt16 时饱和 |
| 温度 | Int16 | 1 count = 0.01 degC | `-20000`，寄存器 `0xB1E0` 表示无效温度 |
| 密度 | UInt16 | 1 count = 0.01 kg/m3 | 0 表示无效密度；超过 655.35 kg/m3 时输出 65535 |
| 时间 | UInt16 | 月、日、时、分、秒分别占 1 个寄存器 | 时间无法建立时为 0 |
| Profile 点数 | UInt16 | 点 | `0~200`，完整结果必须为 `1~200` |
| 报警阈值 | UInt16 或 Int16 | 跟随对应工程量 | 阈值 0 是有效值，不表示禁用 |

温度和密度无效值不参与报警比较。PLC 保存历史数据时应同时保存寄存器原始值、换算后的工程值和有效性标志。

## 7. 线圈表：FC01 / FC05

### 7.1 地址定义

| 地址 | PDU偏移 | 名称 | FC05写ON行为 | FC01读回含义 |
| --- | ---: | --- | --- | --- |
| `00001` | `0x0000` | Manual | 进入手动/维护控制状态 | 当前为手动或非自动状态 |
| `00002` | `0x0001` | Calibrate | 启动零点标定 | 当前处于标定流程 |
| `00003` | `0x0002` | Auto | 启动寻找并跟踪液位 | 当前处于自动液位跟随 |
| `00004` | `0x0003` | Profile | 请求启动一轮 SI Profile | 当前处于 SI Profile 活动流程 |
| `00005~00008` | `0x0004~0x0007` | Reserved | 拒绝写入，异常码 `0x02` | 固定 0 |
| `00009` | `0x0008` | Stop | 取消当前测量或运动 | 当前电机停止 |
| `00010` | `0x0009` | Up Slow | 强制上行 | 当前上行时由中速位代表实际方向 |
| `00011` | `0x000A` | Up Medium | 强制上行 | 当前上行时置 1 |
| `00012` | `0x000B` | Up Fast | 强制上行 | 当前上行时由中速位代表实际方向 |
| `00013` | `0x000C` | Down Slow | 强制下行 | 当前下行时由中速位代表实际方向 |
| `00014` | `0x000D` | Down Medium | 强制下行 | 当前下行时置 1 |
| `00015` | `0x000E` | Down Fast | 强制下行 | 当前下行时由中速位代表实际方向 |
| `00016` | `0x000F` | Reserved | 拒绝写入，异常码 `0x02` | 固定 0 |

### 7.2 写线圈规则

- `FC05=ON` 是动作请求。正常回显表示设备已经接受请求，不表示动作已经完成；PLC仍须轮询实际状态。
- `FC05=OFF` 只清对应协议影子，不下发停止动作。需要停止时必须向 `00009 Stop` 写 ON。
- `00001~00004` 模式位互斥；`00009~00015` 停止和方向位互斥。
- Slow、Medium、Fast 三档当前执行相同的上行或下行动作，不提供真实三档速度差异。
- 线圈读回以设备实际状态为准，不是最后一次写入值的永久锁存。

### 9.2 Profile 点阵

Profile 点阵范围为 `30021~30620`，最多 200 点，每点占 3 个连续寄存器。对点号 `n=0~199`：

| 字段 | 参考地址公式 | PDU偏移公式 | 类型/单位 |
| --- | --- | --- | --- |
| 位置 | `30021 + 3n` | `20 + 3n` | UInt16，mm |
| 温度 | `30022 + 3n` | `21 + 3n` | Int16，0.01 degC |
| 密度 | `30023 + 3n` | `22 + 3n` | UInt16，0.01 kg/m3 |

其中：

- Point0 是本轮实际采用的罐底参考点；
- Point1 的位置等于 `40001`；
- Point2 的位置等于 `40001 + 40002`；
- PointN 的位置等于 `40001 + (N-1) * 40002`；
- `30006` 指定前 N 个有效点，N 之外的寄存器为 0；
- 新一轮 Point0 建立后到最终完成前，整个点阵窗口保持 0；
- 只有 `10005 Complete=1` 且最终门禁成立后，完整点阵才一次性开放读取。

参数写入规则：

- 参数必须使用 `FC06` 单寄存器写入，不能使用 `FC16` 批量写入。
- 写成功后设备返回标准 FC06 回显。PLC应再使用 FC03 回读并确认最终值。
- `40001~40003` 写入依赖设备测量控制链路可用；暂时不可用时返回异常 `0x06`。
- `40004~40023` 为设备本机保存参数；只有保存成功才正常回显，保存失败返回异常 `0x06`并保留原值。
- `40004~40009` 仅用于兼容，PLC不得为其赋予业务含义。
- 自动 Profile 首次按 `40012:40013` 指定时刻运行，之后按 `40010` 分钟间隔连续调度；`40011=0`关闭自动 Profile。

## 11. Profile 生命周期

### 11.1 对外状态时序

| 阶段 | Profile `00004` | Complete `10005` | AtLevel `10013` | N `30006` | 点阵 `30021...` | PLC处理 |
| --- | ---: | ---: | ---: | ---: | --- | --- |
| 空闲/旧结果 | 0 | 可能为0或1 | 视当前状态 | 可能保留旧N | 可能保留旧结果 | 只建立基线，不补录 |
| 已接受启动、Point0前 | 1 | 可能短时保留旧值 | 0 | 可能短时保留旧N | 旧结果可能短时保留 | 建立临时会话，不读取结果 |
| Point0已建立 | 1 | 0 | 0 | 从1开始 | 全部为0 | 确认本轮开始采点 |
| 逐点测量 | 1 | 0 | 0 | 按有效液体点递增 | 全部为0 | 持续监视 |
| 返回液位 | 1 | 0 | 最终变为1 | 冻结 | 全部为0 | 等待最终发布 |
| 完整结束 | 0 | 1 | 1 | 最终 `1~200` | 前N点完整开放 | 读取并保存一次 |
| 取消或失败 | 0 | 0或未形成新完成 | 视现场状态 | 新周期结果无效 | 不提供新完整点阵 | 丢弃本轮会话 |

不能在写入 Profile 命令后立即读取点阵，也不能只看到 `Complete=1` 就认定新结果完成。Point0前可能短时保留上一轮 Complete、N和时间，必须先观察到本轮开始采点的组合。

### 11.2 PLC发起 Profile

PLC向 `00004` 写 ON：

```text
FC05，PDU地址 0x0003，写值 0xFF00
```

设备正常回显只表示启动请求被接受。PLC随后仍按统一状态机等待 `Profile=1`、本轮采点开始和最终完成。PLC不需要写 `00004=OFF`结束 Profile。

### 11.3 设备发起 Profile

设备屏幕或自动调度发起 Profile 时，外部状态与 PLC 发起完全一致。PLC不得把“本程序没有下发启动命令”作为忽略条件，只要在线观察到新的 `Profile 0->1`，就应建立本轮临时会话。

协议不提供发起来源字段，历史记录不区分 PLC、设备屏幕或自动调度来源。

## 12. PLC Profile记录状态机

### 12.1 建议状态

| PLC状态 | 进入条件 | 处理 | 退出条件 |
| --- | --- | --- | --- |
| `WAIT_BASELINE` | PLC启动、重连或通信恢复 | 连续取得有效状态；不补录已有结果 | 至少观察到一次 `Profile=0` |
| `WAIT_START` | 已建立空闲基线 | 等待新的 `Profile 0->1` | 检测到 `Profile=1`，创建未保存会话 |
| `WAIT_POINT0` | 已看到本轮启动 | 不使用旧Complete、旧N或旧时间 | `Profile=1、Complete=0、N>=1` |
| `WAIT_COMPLETE` | 已确认本轮开始采点 | 等待返回液位和最终发布 | `Profile=0、Complete=1、AtLevel=1、N=1~200` |
| `READ_RESULT` | 完整结束组合成立 | 锁存头部、分块读取N点、复核头部、事务保存 | 保存成功或本次读取被放弃 |

任何状态发生通信断开，均放弃尚未保存的会话并返回 `WAIT_BASELINE`。重连后不补录断线期间完成的结果。

### 12.2 完成后读取一次

识别到完整结束后：

1. 读取并锁存 `30001~30020`，记录最终 N、时间、模式、状态和报警；
2. 从 PDU偏移20开始读取 `3*N` 个点阵寄存器；
3. FC04每次最多读取125个寄存器，建议每块读取120个，即40个完整测点；
4. 最多需要5块即可读完200点，最后一块读取剩余完整点；
5. 点阵读完后再次读取 `30001~30020`，确认仍为 `Profile=0、Complete=1、AtLevel=1`，并且N和Profile时间未变化；
6. 主记录和N个测点作为一个事务一次性保存；任何一块失败都不得保存半条记录；
7. 保存成功后关闭当前会话，回到 `WAIT_START`。

推荐分块公式：

```text
blockStart = 20 + 120 * blockIndex
remaining  = 3 * N - 120 * blockIndex
blockQty   = min(120, remaining)
```

`blockQty`必须为3的整数倍，避免把一个测点拆到两个请求中。

### 12.3 防止重复记录

不需要对点阵计算指纹，也不需要反复读取同一结果：

- 每次新的 `Profile 0->1`只创建一个会话；
- 一个会话只允许从 `WAIT_COMPLETE`进入一次 `READ_RESULT`；
- 保存成功后立即设置本会话已保存并关闭会话；
- 即使 `Complete=1`保持多个PLC扫描周期，也不得再次读取或保存；
- 只有下一次新的 `Profile 0->1`才能创建下一条记录。

## 13. Profile历史记录和查询要求

### 13.1 保存内容

每条Profile主记录至少保存：

- 记录编号；
- 设备名称、设备编号和Modbus站号；
- PLC识别到的开始时间和完成时间；
- 设备Profile时间 `30007~30010`；
- 最终有效点数N；
- 完成时 `30001~30020` 原始值；
- 完成时模式、Complete、AtLevel、Interlock及全部报警；
- 前N个测点的位置、温度和密度原始值、工程值及有效性。

主记录和N个测点必须作为一个整体保存。取消、失败、通信中断、点阵未读全或存储失败时，不生成成功记录。

### 13.2 查询和显示

历史功能至少支持：

- 按完成日期范围查询；
- 按设备或Modbus站号查询；
- 按是否存在报警查询；
- 按点数范围和记录编号查询；
- 历史列表分页并按完成时间倒序显示；
- 查看单条记录的概要、全部点位、位置-温度曲线和位置-密度曲线；
- 导出单条记录的概要和全部点位，至少支持CSV。

历史记录一直保存，不按时间或条数自动删除。存储空间不足时必须明确报警或提示，不得静默覆盖旧记录。若PLC本体不适合长期保存，应使用配套HMI、工控机或现有历史数据库保存。

## 14. 异常响应和主站处理

| 异常码 | Modbus名称 | 本协议含义 | PLC处理建议 |
| --- | --- | --- | --- |
| `0x01` | Illegal Function | 功能码不支持 | 停止使用该功能码，改用FC01~FC06支持项 |
| `0x02` | Illegal Data Address | 地址越界或保留地址不可写 | 检查参考号和0/1基地址换算 |
| `0x03` | Illegal Data Value | 数量、帧字段或写值非法 | 检查数量、FC05写值和参数范围 |
| `0x06` | Slave Device Busy | 设备当前无法完成命令/参数操作，或内部数据快照暂不可用 | 保持原目标值，延时后重试，并通过读回确认 |

以下情况设备不返回正常响应：

- 从站地址不匹配；
- CRC错误；
- 帧长度不足，无法形成有效请求。

主站应区分“收到Modbus异常响应”和“完全超时”。收到 `0x06`不能视为命令或参数已成功执行。

## 15. 站号1参考帧

以下帧仅适用于站号 `1`。站号改变后必须替换首字节并重新计算 CRC。

| 操作 | 请求帧 | 期望响应类型 |
| --- | --- | --- |
| 读全部线圈 `00001~00016` | `01 01 00 00 00 10 3D C6` | FC01位数据响应 |
| 读全部离散输入 `10001~10032` | `01 02 00 00 00 20 79 D2` | FC02位数据响应 |
| 读全部保持寄存器 `40001~40023` | `01 03 00 00 00 17 05 C4` | FC03，46字节数据 |
| 读头部输入寄存器 `30001~30020` | `01 04 00 00 00 14 F0 05` | FC04，40字节数据 |
| 启动 Profile，`00004=ON` | `01 05 00 03 FF 00 7C 3A` | 成功时标准FC05原值回显 |
| Stop，`00009=ON` | `01 05 00 08 FF 00 0D F8` | 成功时标准FC05原值回显 |
| 写 `40001=500 mm` | `01 06 00 00 01 F4 89 DD` | 成功时标准FC06原值回显 |
| 从Point0起读40点、120寄存器 | `01 04 00 14 00 78 B0 2C` | FC04，240字节数据 |
| 不支持的FC16示例 | `01 10 00 00 00 01 02 00 00 A6 50` | `01 90 01 8D C0` |

## 17. 当前兼容边界

- Profile点阵对外最多200点；不支持Point200及以上地址。
- Slow、Medium、Fast当前只表示方向命令，不产生三档真实速度差异。
- `00002 Calibrate`当前执行零点标定，不代表完整液位标定流程。
- `10002/10003`是兼容合成状态，不是真实双液位传感器输入。
- `10004 Interlock`和`10009 Reel Alarm`是当前设备故障/阻挡的综合状态，未细分全部硬件故障源。
- `40004~40009`是兼容保留槽，允许读写但没有公开业务含义。
- 温度时间戳在本轮Point0事件建立时锁存；PLC或设备通信重连后不能重建的历史时间为0。
- 密度使用UInt16和0.01 kg/m3分辨率，超过655.35 kg/m3时饱和为65535。
- 本文定义软件和报文契约；最终项目仍需在真实PLC、RS485总线、目标板和实际存储介质上完成验收。
