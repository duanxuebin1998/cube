# SI协议适配文档索引

日期：2026-07-01

本目录集中保存 SI协议适配相关资料，避免散落在 `docs` 根目录。后续新增 SI协议文档优先放在本目录下，并按用途归入对应子目录。

口径说明：`SI` 是 SI 公司设备型号，不代表协议只适配这一款设备。后续正文统一使用“SI协议”描述同族设备协议；维护目录、正文和用户可见协议说明统一写“SI协议”；代码符号、脚本名和短标签保留“SI”；`00_原始资料` 内原始附件保留官方/现场原文件名。

## 目录结构

| 目录 | 用途 | 主要文件 |
| --- | --- | --- |
| `00_原始资料` | 外部或原始输入资料，只作为依据，不直接记录执行状态 | `SI7000协议.docx`、`SI7000_PLC协议及软件需求说明.docx`、官方 PDF |
| `01_计划与需求` | 需求总览、实施方案、待确认问题和后续清单 | `SI协议需求与实施总览.md`、`SI协议待确认与后续清单.md` |
| `02_协议映射` | SI协议地址表与当前设备变量、命令、限制的对应关系 | `SI协议兼容映射表.md` 为当前唯一维护源 |
| `03_改动记录` | 本轮实际改动、验证记录和阶段性总结 | `SI协议适配改动整理.md/.pdf`、`CPU2暂存区改动整理.md/.pdf` |
| `04_联调测试` | PLC/主机侧联调检查表和参考帧 | `SI协议_PLC联调检查表.md` |

## 建议阅读顺序

1. `01_计划与需求/SI协议需求与实施总览.md`
2. `01_计划与需求/SI协议待确认与后续清单.md`
3. `02_协议映射/SI协议兼容映射表.md`
4. `04_联调测试/SI协议_PLC联调检查表.md`
5. `03_改动记录/SI协议适配改动整理.md`
6. `03_改动记录/CPU2暂存区改动整理.md`

如果只想看当前进一步兼容已经怎么落地，直接看 `01_计划与需求/SI协议需求与实施总览.md`。
如果只想看后续还需要现场或资料复核什么，直接看 `01_计划与需求/SI协议待确认与后续清单.md`。
如果只想看当前地址映射和已实现状态，直接看 `02_协议映射/SI协议兼容映射表.md`。

## 维护规则

- 原始资料不要改名或改内容，避免和现场或官方文件对不上。
- 同名 PDF、HTML 或 Word 文件仅作为历史导出件或外发阅读件；`01_计划与需求`、`02_协议映射`、`03_改动记录` 和 `04_联调测试` 中的 Markdown 才是后续维护正文。
- 新增需求先放到 `01_计划与需求/SI协议待确认与后续清单.md`，确认后再进入 `01_计划与需求/SI协议需求与实施总览.md`。
- 改 SI 地址、缩放、状态位或命令映射时，同步更新 `02_协议映射/SI协议兼容映射表.md`。
- 实际完成代码或文档改动后，同步更新 `03_改动记录/SI协议适配改动整理.md`；如果改动涉及 CPU2 暂存区，还要同步更新 `03_改动记录/CPU2暂存区改动整理.md`。
- 如果改动 CPU2/CPU3 共享协议，还要同步更新 `../CPU2_CPU3协议变更记录.md`。
