# CPU2 串口助手命令面板

本目录维护 CPU2 USART1 调试命令的串口助手导入配置及生成说明。配置由协议卷和生成工具共同约束，修改命令名称、参数格式或分组后必须重新生成并执行一致性检查。

## 文件说明

- [CPU2 串口助手命令面板配置](CPU2串口助手命令面板配置.json)：可导入串口助手的 10 组、67 个命令按钮配置。
- [CPU2 串口助手命令面板生成与维护说明](CPU2串口助手命令面板生成与维护说明.md)：生成入口、配置结构、维护步骤和检查方法。
- [CPU2 串口调试命令协议卷](../CPU2串口调试命令协议卷.md)：命令语法、ACK/ERR、参数范围和安全约束的正式依据。

## 提交前检查

```powershell
py -X utf8 tools\generate_cpu2_serial_command_panel.py --check
```

通过标准：输出 10 组、67 个按钮且退出码为 0；协议卷、生成器和 JSON 配置不存在命令名称或参数格式漂移。
