# 无线滑环匹配资料索引

更新日期：2026-06-06

本目录保存 CPU2 传感器无线滑环链路的匹配流程、设备端匹配方案和后续联调记录。

| 文件 | 用途 |
| --- | --- |
| `无线滑环匹配过程.docx` | 现有人工匹配流程记录，包含串口参数、从机 MAC 查询和主机默认连接 MAC 配置指令。 |
| `无线滑环设备端匹配方案.md` | 设备端直接匹配的固件和联调方案。 |
| `无线滑环设备端匹配开发计划与执行记录.md` | CPU2 设备端匹配实现记录，包含 `SPS`、`SPR`、`SPN=<name>`、`SPC` 调试入口和最终合并版本口径。 |

CH9141K 原厂资料归档在 `../../../07_硬件原理图/00_原始资料/CPU2芯片手册/CH9141K/`。第三方资料保留原始文件名，便于和供应商文档对应。

## 维护口径

- `无线滑环匹配过程.docx` 是旧人工流程原始记录，除勘误外不直接作为后续实现正文维护。
- 设备端匹配、命令入口、调试步骤、版本归档和现场验证结论应写入同目录 Markdown。
- 如果 DOCX 中的串口参数或 MAC 配置流程被新实现替代，优先更新 `无线滑环设备端匹配方案.md` 和执行记录，再在总附件清单中保留 DOCX 的历史定位。
