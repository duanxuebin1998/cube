# SI7000协议适配文档索引

日期：2026-05-16

本目录集中保存 SI7000 协议适配相关资料，避免散落在 `docs` 根目录。后续新增 SI7000 文档优先放在本目录下，并按用途归入对应子目录。

## 目录结构

| 目录 | 用途 | 主要文件 |
| --- | --- | --- |
| `00_原始资料` | 外部或原始输入资料，只作为依据，不直接记录执行状态 | `SI7000协议.docx`、`SI7000_PLC协议及软件需求说明.docx`、官方 PDF |
| `01_计划与需求` | 需求拆解、官方资料整理、下一步计划和待确认项 | `SI7000下一轮需求确认表.md`、`SI7000说明书需求确认清单.md`、`SI7000下一步工作计划.md`、`SI7000后续需求记录.md`、`SI7000协议适配执行计划.md` |
| `02_协议映射` | SI7000 地址表与当前设备变量、命令、限制的对应关系 | `SI7000兼容映射表.md` |
| `03_改动记录` | 本轮实际改动、验证记录和阶段性总结 | `SI7000协议适配改动整理.md/.pdf`、`CPU2暂存区改动整理.md/.pdf` |
| `04_联调测试` | PLC/主机侧联调检查表和参考帧 | `SI7000_PLC联调检查表.md` |

## 建议阅读顺序

1. `01_计划与需求/SI7000官方资料整理与兼容计划.md`
2. `01_计划与需求/SI7000下一轮需求确认表.md`
3. `01_计划与需求/SI7000说明书需求确认清单.md`
4. `01_计划与需求/SI7000下一步工作计划.md`
5. `02_协议映射/SI7000兼容映射表.md`
6. `03_改动记录/SI7000协议适配改动整理.md`
7. `03_改动记录/CPU2暂存区改动整理.md`
8. `04_联调测试/SI7000_PLC联调检查表.md`
9. `01_计划与需求/SI7000后续需求记录.md`

如果只想填写下一轮需要确认的需求，直接看 `01_计划与需求/SI7000下一轮需求确认表.md`。
如果只想看完整需求依据，直接看 `01_计划与需求/SI7000说明书需求确认清单.md`。
如果只想看下一步怎么做，直接看 `01_计划与需求/SI7000下一步工作计划.md`。

## 维护规则

- 原始资料不要改名或改内容，避免和现场或官方文件对不上。
- 新增需求先放到 `01_计划与需求/SI7000后续需求记录.md`，确认后再进入工作计划。
- 改 SI7000 地址、缩放、状态位或命令映射时，同步更新 `02_协议映射/SI7000兼容映射表.md`。
- 实际完成代码或文档改动后，同步更新 `03_改动记录/SI7000协议适配改动整理.md`；如果改动涉及 CPU2 暂存区，还要同步更新 `03_改动记录/CPU2暂存区改动整理.md`。
- 如果改动 CPU2/CPU3 共享协议，还要同步更新 `../CPU2_CPU3协议变更记录.md`。
