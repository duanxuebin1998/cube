SI7000 进一步兼容需求与实施方案

日期：2026-07-01 ｜ 范围：需求整理、当前兼容基线、进一步兼容方案、验证计划；本文不修改固件代码。

1. 需求结论

本轮目标：SI7000 兼容从“地址表和基础读写兼容”升级为“按 Scientific Instruments SI7000 profile 行为做独立测量流程兼容”。
Profile 独立化 需实施

00004 Profile 需要触发新的 SI7000 专用 CPU2 命令，不再复用普通分布测量 CMD_MEASURE_DISTRIBUTED。

科学仪器测量过程 需实施

profile 前按探底频次决定是否真实探底；不探底时也必须运行到底部位置，采集 Point 0 密度。

状态输出口径固定 已明确

10001 Bottom Reference 始终为未到底；10010 Probe Un-calibrated 始终为可信。

上下液位传感器 已明确

液位跟随时下传感器为液体、上传感器为空气；其它状态两个传感器均显示在液体。

自动 Profile 调度 需实施

40010~40013 需要作为独立保持寄存器驱动真实自动 profile 调度。

报警限值和时间戳 需实施

兼容全部报警限值和状态；30007~30010 Profile Timestamp 改为 profile 测量开始时间。

2. 当前兼容基线

profile 测量流程 复用普通分布测量流程，profile 点阵来自现有分布测量结果。 新增独立流程，按底部点 Point 0 加后续停点生成点阵。

Profile Timestamp 当前按完成计数变化锁存完成时刻。 改为 profile 测量开始时间。

3. 设计原则

  • CPU3 继续负责 SI7000 Modbus RTU 地址、功能码、异常响应、缩放、保持寄存器和自动调度。
  • CPU2 只新增真实测量所需的通用命令、流程和必要状态，不在 CPU2 中引入 SI7000 地址号或 Modbus 细节。
  • SI7000 profile 与普通分布测量、Wärtsilä 密度测量互相隔离，避免改 SI7000 时影响其它业务。
  • 40001~40003、40010~40013 必须按 SI7000 独立保持寄存器处理。
  • 报警限值优先复用现有比较逻辑和运行态能力；只有单位、方向、阈值含义、持久化语义完全一致时才复用现有参数。
  • 对外协议状态以本轮确认口径为准，10001 和 10010 不再等同内部真实探底或校准状态。

4. SI7000 Profile 独立测量流程

4.1 新增命令

建议命令 建议编号 用途 影响
CMD_SI7000_PROFILE 建议使用普通命令预留区，例如 20~22 中一个空位 执行 SI7000 专用 profile 测量 新增 CPU2/CPU3 共享命令，需要升级共享协议版本并更新契约检查。

CPU3 si7000_apply_coil_write() 中 SI7000_COIL_PROFILE 不再发送 CMD_MEASURE_DISTRIBUTED，改为发送 CMD_SI7000_PROFILE。

4.2 测量步骤

  1. CPU2 收到 CMD_SI7000_PROFILE。
  2. 进入 SI7000 profile 运行状态，清除上一轮完成锁存、点阵和 profile 报警状态。
  3. 锁存 profile 测量开始事件，供 CPU3 输出 30007~30010。
  4. 根据 SI7000 探底频次计数判断本轮是否真实探底。
  5. 达到探底频次时先执行真实探底，成功后刷新内部底部参考；探底失败则本轮 profile 失败。
  6. 未达到探底频次时不真实探底，但必须按已有底部参考、罐高、盲区或专用底部位置参数运行到底部测量位置。
  7. 在底部测量位置等待稳定，采集 Point 0 的位置、温度、密度。
  8. 按 40001 Profile First Point、40002 Profile Increment、40003 Profile Dwell Time 生成后续停点。
  9. 逐点运行、等待、采集温度和密度，直到达到点数上限、液位边界或其它停止条件。
  10. 扫描 profile 点阵生成报警状态，写入分布测量共享数据，置位完成锁存并递增完成计数。
  11. 进入 SI7000 profile 完成状态，并按策略回到自动液位跟随或单点监测。

4.3 探底频次

参数 含义 范围建议 默认值建议
si7000_profile_bottom_detect_interval SI7000 profile 探底频次；0 表示不自动探底，N 表示每 N 次 SI7000 profile 前探底一次。 0~100 0 或按现场要求确认
不建议复用 Wärtsilä 探底频次：Wärtsilä 参数已经有专用业务语义，SI7000 profile 的点阵、底部点和调度行为不同，复用参数会导致现场配置互相影响。

4.4 底部点和真实探底分离

动作 含义 是否刷新底部参考
真实探底 用扭力、角度或现有底部检测方式确认罐底。 是，内部可刷新底部参考。
运行到底部测量位置 按已有底部参考或配置位置运行到 Point 0 采样位置。 否，不改变内部探底可信状态。

5. 状态位输出方案

5.1 Lower/Upper Level Sensor

设备状态 10002 Lower Level Sensor 10003 Upper Level Sensor 对外含义
液位跟随状态 1 0 下传感器在液体，上传感器在空气。
其它状态 1 1 两个传感器均显示在液体。

第一版建议由 CPU3 根据 CPU2 当前状态合成：STATE_FLOWOIL 或后续明确的液位跟随状态按“下液体、上空气”输出，其它状态按“两者均在液体”输出。

5.2 固定状态

地址 名称 输出口径 内部状态处理
10001 Bottom Reference 固定返回 0，一直显示未到底。 内部真实探底状态继续维护，用于测量流程、底部位置和故障判断。
10010 Probe Un-calibrated 固定返回 0，一直显示可信。 内部零点、编码器可信状态和探底失败仍用于本机保护和测量错误处理。

6. 独立保持寄存器方案

地址 名称 独立参数含义 单位/范围建议
40001 Profile First Point 底部点 Point 0 之后的首个停点。 mm，0~65535
40002 Profile Increment 后续 profile 每点步距。 mm，1~65535
40003 Profile Dwell Time 每点停留时间。 秒，建议 1~3600
40010 Automatic Profile Interval 自动 profile 周期。 分钟，建议 0~1440 或按现场确认
40011 Automatic Profile Enable 自动 profile 使能。 0/1
40012 Automatic Profile Hour 自动 profile 起始小时。 0~23
40013 Automatic Profile Minute 自动 profile 起始分钟。 0~59
存储建议：40010~40013 由 CPU3 持久化最自然，因为自动调度依赖 CPU3 RTC；40001~40003 影响 CPU2 测量动作，推荐正式加入 CPU2 可见的 SI7000 专用参数，或在 CPU3 触发 profile 前同步给 CPU2。若写入 CPU2 DeviceParameters，需要升级参数版本并处理升级默认值。

7. 自动 Profile 调度

建议自动 profile 调度放在 CPU3：CPU3 持有 SI7000 外部协议、独立保持寄存器和 RTC，到点后向 CPU2 下发 CMD_SI7000_PROFILE，CPU2 只负责执行真实测量。

规则 建议口径
使能 40011 = 0 时不自动触发；40011 = 1 时启用。
首次触发 第一次触发时间为 40012:40013。
周期触发 后续按 40010 分钟周期触发；40010 = 0 的语义需联调前确认。
忙碌处理 设备忙、手动动作、关键故障或当前 profile 运行中时不强行触发，记录跳过或延后原因。
10012 Interval Timer 建议表示自动 profile 使能且调度器有效，而不是简单等于 40011。

8. 报警限值和状态兼容

限值地址 状态地址 含义 建议处理
40014 10017、10031 Low Density / Profile Low Density 当前值和 profile 点阵分别比较，阈值为 0 时建议视为未启用。
40015 10018、10032 High Density / Profile High Density 复用密度比较逻辑，参数保持 SI7000 独立。
40016 10019、10029 Low Temperature / Profile Low Temperature 按当前温度和 profile 点阵温度比较。
40017 10020、10030 High Temperature / Profile High Temperature 按当前温度和 profile 点阵温度比较。
40018~40021 10021~10024 LL、HH、Low、High Level Alarm 可复用液位比较逻辑，不建议直接复用 AO 或继电器报警参数。
40022 10025 Profile Temp Deviation Alarm profile 完成后按相邻点温度差扫描生成。
40023 10026 Profile Density Deviation Alarm profile 完成后按相邻点密度差扫描生成。
复用边界：“尽量复用”优先复用计算函数、状态字段和比较口径；除非确认完全同义，不建议让 PLC 写 SI7000 限值时同时改变 AO、继电器、Wärtsilä 或普通分布测量参数。

地址 新含义

10. 版本和兼容影响

改动项 共享协议影响 参数存储影响 说明
新增 CMD_SI7000_PROFILE 是 否 新增 CPU2/CPU3 共享命令，必须升级 DEVICE_PROTOCOL_VERSION。
00004 改下发新命令 是 否 命令语义变化，需要更新映射表、联调表和 golden frame/契约检查。
10001/10010 固定输出 否 否 只影响 CPU3 SI7000 映射行为。
40001~40013 独立保持寄存器 视同步方式而定 可能 若 CPU2 持久化 profile 参数，需要升级 CPU2 参数版本；若 CPU3 持久化调度参数，需要处理 CPU3 本机参数。
自动 profile 调度 否 可能 CPU3 调度本身不改共享协议，但调度参数掉电保存会影响参数存储。
报警限值全部兼容 视算法位置而定 可能 当前值报警可在 CPU3 计算；profile 偏差若放 CPU2 生成，可能影响共享字段。

建议实施阶段

  1. 先完成 CPU3 映射和独立参数阶段：10001/10010/10002/10003、40010~40013、时间戳和当前值报警。
  2. 再完成 CPU2 独立 SI7000 profile 阶段：新增命令、独立流程、Point 0、探底频次、profile 点阵和偏差报警。

11. 验证计划

类别 验证点
静态检查 运行 py tools\check_si7000_modbus_frames.py、py tools\check_si7000_protocol_contract.py；新增命令或共享字段后扩展脚本覆盖命令号和协议版本。
状态位 10001 任意状态为 0；10010 任意状态为 0；液位跟随时 10002=1,10003=0，其它状态 10002=1,10003=1。
保持寄存器 40001~40003 写入后可回读且不改变普通分布测量参数；40010~40013 合法值可写可回读，非法小时、分钟、使能值返回异常。
自动调度 到点后下发 SI7000 profile；设备忙、故障、手动状态时不误触发；10012 与调度有效状态一致。
测量流程 探底频次为 0 时不真实探底但采集 Point 0；频次为 1 时每次探底；频次为 N 时第 N 次探底。
点阵语义 Point 0 必须写入第一组三元组；40001 是 Point 0 之后首个停点，不能覆盖底部点。
报警和时间戳 当前值报警、profile 上下限报警、profile 偏差报警均按限值置位和恢复；30007~30010 显示 profile 开始时间。

12. 实施前确认项

  1. SI7000 探底频次默认值使用 0 还是 1。
  2. 不探底时“底部位置”使用已有底部参考、罐高/盲区，还是新增 SI7000 底部偏移参数。
  3. 40010 = 0 时，自动 profile 是禁用周期只按每日时刻触发，还是完全不触发。
  4. 40014~40023 是否必须掉电保存。
  5. 报警限值参数是否允许只在 CPU3 存储，还是必须让 CPU2 侧也可见。
  6. 自动 profile 到点但设备忙时，是跳过本次、延后到空闲立即执行，还是等待下一个周期。
  7. profile 完成后是否自动回到液位跟随。
