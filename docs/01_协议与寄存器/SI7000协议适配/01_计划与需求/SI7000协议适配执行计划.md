## 协议依据

协议文件：`docs/01_协议与寄存器/SI7000协议适配/00_原始资料/SI7000协议.docx`

官方补充资料：

- `docs/01_协议与寄存器/SI7000协议适配/00_原始资料/SI7000官方操作手册.pdf`
- `docs/01_协议与寄存器/SI7000协议适配/00_原始资料/SI7000官方资料包_含Modbus规范.pdf`
- 整理文档：`docs/01_协议与寄存器/SI7000协议适配/01_计划与需求/SI7000官方资料整理与兼容计划.md`

关键要求：

- PLC 为 Modbus RTU 主站，SI7000 为从站。
- 物理层为 RS-485。
- 串口参数：9600 bps，8 数据位，奇校验，1 停止位，即 8O1。
- 从站地址：`Device ID = Tank ID`，同一总线唯一。
- 建议主站最小请求间隔不小于 1 秒。
- 支持功能码：FC01、FC02、FC03、FC04、FC05、FC06。
- 线圈区：00001-00016，用于模式切换和手动方向/速度控制。
- 离散输入区：10001-10032，用于状态、限位、报警和 profile 完成状态。
- 保持寄存器区：40001-40023，用于 profile 参数、自动 profile 参数和报警设定点。
- 输入寄存器区：30001-30620，用于实时测量值、当前时间和 profile 点阵。
- 时间字段：30011-30013 为当前时/分/秒，30007-30010 为 profile 时间戳月/日/时/分。
- 缩放规则：液位/位置按 mm，温度按 0.01 摄氏度有符号，密度按 0.01 kg/m3，时间为整数寄存器。

### 4. SI7000 外部 Modbus 从站适配

在 CPU3 中完善 `Communication/external/si7000_modbus`：

1. 新增 `COM_PROTO_SI7000` 并接入 `COM_DispatchProtocol()`。
2. 将 SI7000 协议加入 CPU3 本机 COM 参数菜单可选项。
3. 支持串口配置为 9600 8O1。
4. 从站地址从设备参数读取，优先复用现有传感器编号/设备编号字段；若现有字段语义不合适，再新增 CPU3 本机从站地址参数。
5. FC01/FC02 读位时按 Modbus 起始地址转换到 0 基数组。
6. FC03/FC04 读寄存器时按协议范围限制。
7. FC05 写线圈：
   - Manual、Calibrate、Auto、Profile 模式互斥。
   - Stop、Up Slow/Medium/Fast、Down Slow/Medium/Fast 速度/动作位互斥。
   - 写入手动方向/速度位时，应中断当前 profile 或自动液位跟踪，并切到 Manual 语义。
8. FC06 写保持寄存器：
   - 可直接映射到现有 CPU2 参数的字段立即写 CPU2。
   - 暂无内部参数对应的报警设定点先保留影子值，但需要文档说明。
9. 异常响应按 Modbus 标准返回非法功能、非法地址、非法值。

### 5. SI7000 数据映射

离散输入重点映射：

- 10001 Bottom Reference：来自 `既有测量子结构状态字段.bottom_reference_valid` 或罐底/零点可信状态。
- 10002 Lower Level Sensor：下液位传感器是否在液体中，优先根据现有液位状态能力映射。
- 10003 Upper Level Sensor：上液位传感器是否在液体中，若无独立硬件状态先置 0 并记录限制。
- 10004 Interlock：达到最大允许探头位置或上行禁止状态。
- 10005 Profile Complete：来自 `density_distribution.profile_complete_latched` 和分布完成状态。
- 10006 Unit Is Metric：当前固定为公制时置 1。
- 10009 Reel Alarm：设备错误码或电机/卷筒相关错误。
- 10010 Probe Un-calibrated：零点/位置未校准。
- 10012 Interval Timer：由 `40011 Automatic Profile Enable` 影子值合成。
- 10013 Probe At Liquid Level：来自 `oil_measurement.probe_at_liquid_level`。
- 10017-10024：当前密度、温度、液位与 `40014-40021` 影子阈值比较合成；阈值为 0 时视为未启用。
- 10029-10032：profile 完成锁存后，任一点温度/密度与 `40016/40017/40014/40015` 比较合成；10028 保留为 0。

输入寄存器重点映射：

- 30001 Current Probe Position：当前探头位置，单位 mm。
- 30002 Current Temperature：当前温度，单位 0.01 摄氏度，有符号。
- 30003 Current Density：当前密度，单位 0.01 kg/m3。
- 30004 Liquid Level：最近一次液位，profile 期间不更新，回到液面后更新。
- 30006 Number of Points：profile 点数。
- 30007-30010 Profile Timestamp：profile 完成时锁存月/日/时/分。
- 30011-30013 Current Time：CPU3 当前时/分/秒。
- 30021+3n：profile 第 n 点位置、温度、密度，n 为 0-199。

### 6. CPU3 时钟适配

1. CPU3 当前 HAL 驱动包未包含 `stm32f4xx_hal_rtc.c/.h`，不直接启用 `HAL_RTC_MODULE_ENABLED`，避免引入缺失头文件导致构建失败。
2. 增加项目本地 `cpu3_clock.c/.h`，通过 CMSIS RTC 寄存器和现有 `HAL_RCCEx_PeriphCLKConfig()` 管理 RTC 时钟。
3. 在 `App_Init()` 初始化时钟模块。
4. 时钟源策略：
   - 若后续硬件确认已接 LSE，可切换为 LSE。
   - 当前先使用 `SystemClock_Config()` 已启用的 LSI，记录精度风险。
5. 提供统一接口：
   - `Cpu3Clock_Init()`
   - `Cpu3Clock_GetDateTime()`
   - `Cpu3Clock_SetDateTime()`
   - SI7000 层在 `profile_complete_counter` 变化时锁存 profile 时间戳。
6. SI7000 读 30011-30013 时调用当前时间接口。
7. profile 完成时锁存时间戳到 30007-30010。
8. 评估是否需要通过 CPU3 本机参数菜单增加时间设置项；如果新增中文菜单文案，需要同步检查 CPU3 字库。

## 风险与约束

- CPU3 工程没有现成 HAL RTC 源文件，本次已采用项目本地 CMSIS RTC 寄存器封装，避免额外引入缺失 HAL 模块。
- 当前 RTC 使用 LSI 时钟源，能满足 SI7000 当前时间显示和 profile 时间戳锁存；长期精度仍取决于硬件是否具备 LSE。
- SI7000 协议文档中的 Lower/Upper Level Sensor 当前仍无内部可靠来源，本次固定为 0，并已在映射文档中明确。
- SI7000 文档标注密度为 `0.01 kg/m3`，本次已按示例输出并在超过 16 位时钳位，需和 PLC 侧确认实际密度范围是否接受该限制。
- 官方资料复核后，profile 第 0 点应为罐底点，`40001` 是罐底之后的第一编程停点；当前 `40001 -> spreadTopLimit` 仍需现场和现有分布测量方向确认。
- 官方资料复核后，profile 时间戳更适合锁存在首点采集时刻；当前按完成时刻锁存属于第一版兼容实现，后续需由 CPU2 提供 profile 首点事件后再修正。
- 所有 CPU2/CPU3 源码中的中文注释要保持原编码，不做整文件编码转换。
