# SI7000 PLC联调检查表

日期：2026-05-16

本文用于 SI7000 第一版兼容实现的 PLC 或主机侧联调。本文只覆盖当前已经落地且不依赖未确认需求的内容；上下液位传感器、独立 Tank ID、自动 profile 调度、报警阈值落盘、三档真实速度、首点时间戳等需求仍以 `docs/01_协议与寄存器/SI7000协议适配/01_计划与需求/SI7000说明书需求确认清单.md` 为准，确认前不作为本轮验收失败项。

## 1. 联调前置条件

| 项目 | 要求 |
| --- | --- |
| 串口参数 | RS485、Modbus RTU、`9600 8O1` |
| 站号 | 默认复用当前 `SlaveAddress`；独立 Tank ID 未确认前不新增配置 |
| 功能码 | `FC01`、`FC02`、`FC03`、`FC04`、`FC05`、`FC06` |
| 点数 | DCS 地址表按 200 个 profile 点联调 |
| 未确认项 | 不测试超过 200 点扩展、不测试自动 profile 真实调度、不测试报警阈值掉电保存 |

## 2. 主机侧参考帧

参考帧由 `tools/check_si7000_modbus_frames.py --dump` 生成。默认站号按 `0x01` 示例，现场如果站号不同，需要替换首字节并重算 CRC。

| 场景 | 请求帧 | 期望响应 |
| --- | --- | --- |
| 读全部线圈 `00001~00016` | `01 01 00 00 00 10 3D C6` | 默认安全态示例：`01 01 02 01 01 79 AC` |
| 读全部离散输入 `10001~10032` | `01 02 00 00 00 20 79 D2` | 默认公制示例：`01 02 04 20 00 00 00 F0 22` |
| 读 `40010~40013` | `01 03 00 09 00 04 94 0B` | 未写入前示例：`01 03 08 00 00 00 00 00 00 00 00 95 D7` |
| 读 `30001~30013` | `01 04 00 00 00 0D 31 CF` | 零快照示例：`01 04 1A ... DF 82`，真实时间字段可非零 |
| 写 `00004 Profile ON` | `01 05 00 03 FF 00 7C 3A` | `01 05 00 03 FF 00 7C 3A` |
| 写 `40012=23` | `01 06 00 0B 00 17 B8 06` | `01 06 00 0B 00 17 B8 06` |
| 读非法保持寄存器 `40024` | `01 03 00 17 00 01 34 0E` | `01 83 02 C0 F1` |
| 写非法 `40011=2` | `01 06 00 0A 00 02 28 09` | `01 86 03 02 61` |
| 非法功能码 `FC16` | `01 10 00 00 00 01 02 00 00 A6 50` | `01 90 01 8D C0` |

## 3. FC01 线圈检查

| 地址 | 名称 | 当前验收口径 |
| --- | --- | --- |
| `00001` | Manual | 非 Auto/Cal/Profile 状态下可置位；写入 ON 桥接维护模式 |
| `00002` | Calibrate | 写入 ON 后桥接现有校准/探底入口 |
| `00003` | Auto | 写入 ON 后桥接找液位/自动液位入口 |
| `00004` | Profile | 写入 ON 后桥接分布测量入口 |
| `00005~00008` | 保留 | 读取为 0；写入应返回非法地址 |
| `00009` | Stop | 写入 ON 后桥接维护/停止语义 |
| `00010~00012` | Up Slow/Medium/Fast | 当前三档统一桥接强制上行；真实速度差异待确认 |
| `00013~00015` | Down Slow/Medium/Fast | 当前三档统一桥接强制下行；真实速度差异待确认 |
| `00016` | 保留 | 读取为 0；写入应返回非法地址 |

## 4. FC02 离散输入检查

| 地址 | 名称 | 当前验收口径 |
| --- | --- | --- |
| `10001` | Bottom Reference | 来自 CPU2 通用罐底参考状态 |
| `10002` | Lower Level Sensor | 未确认硬件来源前返回 0，不作为本轮失败项 |
| `10003` | Upper Level Sensor | 未确认硬件来源前返回 0，不作为本轮失败项 |
| `10004` | Interlock | 当前第一版按错误/过程阻塞合成，精确互锁语义待确认 |
| `10005` | Profile Complete | profile 完成锁存后置位 |
| `10006` | Unit Is Metric | 固定为 1 |
| `10009` | Reel Alarm | 当前第一版按设备错误简化合成，错误分类待确认 |
| `10010` | Probe Un-calibrated | 当前按零点状态简化合成，位置基准口径待确认 |
| `10012` | Interval Timer | 当前由 `40011` 影子使能合成 |
| `10013` | Probe At Liquid Level | 来自 CPU2 通用液位到达状态 |
| `10017~10024` | 当前值报警 | 由当前值与 `40014~40021` 影子阈值合成，阈值为 0 时不启用 |
| `10025~10026` | Profile 偏差报警 | 来自 CPU2 通用偏差字段；具体算法待确认 |
| `10029~10032` | Profile 上下限报警 | profile 完成后按点阵和阈值合成 |

## 5. FC03/FC06 保持寄存器检查

| 地址 | 名称 | 当前验收口径 |
| --- | --- | --- |
| `40001` | Profile First Point | 当前桥接 `spreadTopLimit`；方向和边界待确认 |
| `40002` | Profile Increment | 当前桥接 `spreadMeasurementDistance` |
| `40003` | Profile Dwell Time | 当前桥接 `spreadPointHoverTime` |
| `40004~40009` | 保留 | 写入返回非法地址 |
| `40010` | Automatic Profile Interval | 影子回读，不触发真实调度 |
| `40011` | Automatic Profile Enable | 只接受 `0/1`，影子回读并影响 `10012` |
| `40012` | Automatic Profile Hour | 只接受 `0~23` |
| `40013` | Automatic Profile Minute | 只接受 `0~59` |
| `40014~40023` | 报警和偏差阈值 | 运行期影子寄存器，掉电保存待确认 |

## 6. FC04 输入寄存器检查

| 地址 | 名称 | 当前验收口径 |
| --- | --- | --- |
| `30001` | Current Probe Position | 当前探头位置，单位 mm |
| `30002` | Current Temperature | 有符号 `0.01°C` |
| `30003` | Current Density | `0.01 kg/m3`；超过 16 位范围时钳位 |
| `30004` | Liquid Level | 当前 CPU2 最近液位；Manual/profile 期间保持策略待确认 |
| `30006` | Number of Points | profile 完成锁存后输出有效点数 |
| `30007~30010` | Profile Timestamp | 当前按完成时刻锁存；首点时间戳待确认 |
| `30011~30013` | Current Time | CPU3 RTC 当前时分秒，应持续变化 |
| `30021~30620` | Profile 点阵 | 按 200 点 DCS 地址表输出；超出有效点数返回 0 |

## 7. 边界和异常检查

| 场景 | 期望 |
| --- | --- |
| CRC 错误 | 不生成正常响应 |
| 地址不匹配 | 不生成正常响应 |
| 未支持功能码 | 返回 `Illegal Function` |
| 读数量为 0 | 返回 `Illegal Data Value` |
| 读超过表范围 | 返回 `Illegal Data Address` |
| 写保留线圈或寄存器 | 返回 `Illegal Data Address` |
| 写 `40011 > 1` | 返回 `Illegal Data Value` |
| 写 `40012 > 23` | 返回 `Illegal Data Value` |
| 写 `40013 > 59` | 返回 `Illegal Data Value` |

## 8. 本轮暂不验收的需求

| 需求 | 原因 |
| --- | --- |
| 独立 SI7000 Tank ID 参数 | 用户/PLC 侧未确认 |
| Lower/Upper 液位传感器真实映射 | 硬件或 CPU2 等价状态未确认 |
| Profile 第 0 点强制罐底 | 当前 CPU2 点阵语义仍需确认 |
| Profile 时间戳改为首点采集时间 | 需要 CPU2 生命周期事件，需求未确认 |
| `40010~40013` 真实自动 profile 调度 | 调度责任边界未确认 |
| `40014~40023` 掉电保存 | 参数持久化需求未确认 |
| 三档手动速度差异 | 现场是否需要真实速度未确认 |
| 超过 200 点 profile 扩展 | PLC 是否读取扩展点未确认 |
