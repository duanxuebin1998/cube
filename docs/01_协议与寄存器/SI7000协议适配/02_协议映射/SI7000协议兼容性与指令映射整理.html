SI7000 协议兼容性与指令映射整理

基于当前工作区源码、SI7000 映射文档和协议检查脚本整理。当前结论是：第一版 SI7000 PLC 兼容层已能覆盖主要 Modbus 读写和核心测量数据，但还不是 SI7000 原机行为的完全等价实现。

整理日期 2026-06-03
兼容层位置 CPU3 外部串口协议转换层
通信格式 Modbus RTU，9600，8O1
验证脚本 SI7000 地址表和共享协议契约均通过

1. 兼容性总览

已可联调 支持 FC01/FC02/FC03/FC04/FC05/FC06，并接入 CPU3 主分发和兼容分发路径。
核心数据已映射 位置、温度、密度、液位、profile 点阵、profile 完成状态、当前时间和完成时间戳已有输出。
部分功能是影子兼容 40010~40023 可写可回读，可参与报警合成，但未落盘，也不触发真实自动 profile 调度。
仍有现场确认项 Tank ID、上下液位传感器、真实三档速度、密度缩放范围和首点时间戳仍需确认。
当前适配策略是让 CPU3 对外模拟 SI7000 Modbus 从站，CPU2 只提供通用测量数据、通用状态和通用命令。这样不会把 SI7000 地址、线圈、功能码等外部协议语义下沉到 CPU2 测量内核。
项目 当前兼容状态 说明
功能码 已支持 FC01 读线圈、FC02 读离散输入、FC03 读保持寄存器、FC04 读输入寄存器、FC05 写单线圈、FC06 写单保持寄存器。其它功能码返回 Illegal Function。
地址窗口 已保护 线圈 16 位、离散输入 32 位、保持寄存器 23 个、输入寄存器 620 个。越界读取或写保留区返回 Modbus 异常。
串口配置 已接入 选择 COM_PROTO_SI7000 后，CPU3 参数加载和写入会收敛到 SI7000 要求的 9600 8O1。
从站地址 部分兼容 优先使用现有 SlaveAddress，合法范围 1~247；SI7000 独立 Tank ID 尚未做专用参数。
异常响应 已支持 非法功能、非法地址、非法值均生成标准异常帧；CRC 错、站号不匹配或帧长过短不生成正常响应。
工程量转换 已支持 位置/液位从内部 0.1mm 转协议 mm；温度转有符号 0.01°C；密度转协议 0.01 kg/m3 并做 16 位钳位。
profile 数据 已支持 完成锁存后输出点数和点阵；未完成时点阵保持 0，避免 PLC 读到上一轮残留。
自动 profile 影子兼容 40010~40013 可写可回读，40011 影响 10012，但不触发真实定时调度。
报警阈值 影子兼容 40014~40023 运行期保存，可合成离散输入报警位；掉电保存、偏差算法和报警细分仍待确认。

2. Modbus 功能码和地址窗口

功能码 SI7000 地址区 当前行为 边界处理
FC01 00001~00016 线圈 读取模式线圈、停止/方向线圈和保留位。 读数量为 0 或超过 2000 返回 Illegal Data Value；越界返回 Illegal Data Address。
FC02 10001~10032 离散输入 读取罐底参考、联锁、profile 完成、公制单位、报警和 profile 报警等状态。 同 FC01 位读取边界。
FC03 40001~40023 保持寄存器 读取 profile 参数、自动 profile 影子参数和报警阈值影子参数。 读数量为 0 或超过 125 返回 Illegal Data Value；越界返回 Illegal Data Address。
FC04 30001~30620 输入寄存器 读取实时位置、温度、密度、液位、时间、profile 时间戳和最多 200 个 profile 点。 同 FC03 寄存器读取边界。
FC05 00001~00016 单线圈写 仅允许已实现的动作线圈；合法 ON 写入桥接到 CPU2 通用命令。 只接受 0xFF00 或 0x0000；写保留线圈返回 Illegal Data Address。
FC06 40001~40023 单寄存器写 40001~40003 下发 CPU2 参数；40010~40023 保存在 CPU3 影子寄存器。 40011 仅允许 0/1，40012 仅允许 0~23，40013 仅允许 0~59。

3. FC05 线圈到 CPU2 指令映射

线圈写入只作为外部指令入口。写入 ON 后，CPU3 通过 CPU2 既有命令保持寄存器下发 CommandType；下一次读回仍以 CPU2 实际状态为准。

SI7000 地址 线圈含义 当前 CPU2 指令 兼容状态 说明
00001 Manual CMD_MAINTENANCE_MODE 近似映射 当前系统里最接近 Manual 的入口是维护模式，也用于退出自动/动作状态。
00002 Calibrate CMD_CALIBRATE_ZERO 保守映射 先映射到零点标定；SI7000 是否需要细分零点、液位、水位或罐高校准仍待确认。
00003 Auto CMD_FIND_OIL 已桥接 作为液位自动跟随/找液位入口。
00004 Profile CMD_MEASURE_DISTRIBUTED 已桥接 作为分布/区间密度 profile 测量入口。
00005~00008 保留 无 拒绝写入 FC05 写入返回 Illegal Data Address，读取保持 0。
00009 Stop CMD_MAINTENANCE_MODE 近似映射 承担“打断当前动作并进入手动态”的保守停止语义。
00010 Up Slow CMD_FORCE_MOVE_UP 合并映射 慢/中/快三档当前没有真实速度差异。
00011 Up Medium CMD_FORCE_MOVE_UP 合并映射 与 Up Slow 相同。
00012 Up Fast CMD_FORCE_MOVE_UP 合并映射 与 Up Slow 相同。
00013 Down Slow CMD_FORCE_MOVE_DOWN 合并映射 慢/中/快三档当前没有真实速度差异。
00014 Down Medium CMD_FORCE_MOVE_DOWN 合并映射 与 Down Slow 相同。
00015 Down Fast CMD_FORCE_MOVE_DOWN 合并映射 与 Down Slow 相同。
00016 保留 无 拒绝写入 FC05 写入返回 Illegal Data Address，读取保持 0。
互斥规则：00001~00004 模式线圈在 CPU3 影子区互斥；00009~00015 停止和手动方向/速度线圈在影子区互斥。影子区只用于写后立即回读和协议表现，最终状态仍由 CPU2 运行状态刷新。

6. 当前不兼容和待确认点

优先级 问题点 当前行为 兼容风险 建议下一步
P0 密度缩放范围 按 0.01 kg/m3 输出，超过 16 位钳位。 16 位最高只表达 655.35 kg/m3，常规油品密度可能被钳位。 与 PLC 确认倍率；必要时定义兼容倍率或扩展寄存器。
P0 从站地址/Tank ID 复用 SlaveAddress。 如果现场 Tank ID 与 Modbus 站号不是同一口径，会出现地址配置不一致。 确认是否需要 SI7000 专用 Tank ID 参数。
P0 40001~40003 profile 参数语义 桥接现有分布测量参数。 SI7000 First Point 是罐底之后首个停点，当前 spreadTopLimit 方向和边界可能不完全一致。 复核官方资料和现场 PLC 参数定义，必要时新增专用转换。
P0 Lower/Upper Level Sensor 10002/10003 固定 0。 官方资料把上下液位传感器作为液/气界面核心状态，长期固定 0 只能算第一版兼容。 确认硬件来源或 CPU2 等价通用状态。
P0 profile 时间戳 按完成时刻锁存。 官方语义更接近首点采集时间，PLC 若按首点时间判断会有偏差。 后续补 CPU2 profile 生命周期事件后修正。
P1 40010~40023 掉电保存 只保存在 CPU3 运行期影子寄存器。 掉电后自动 profile 和报警设定丢失。 确认是否需要 CPU3 本机参数或 CPU2 专用参数持久化。
P1 自动 profile 真实调度 40010~40013 不触发调度。 PLC 以为已经开启自动 profile，但设备不会按时间自动执行。 明确调度责任边界后再实现。
P1 三档手动速度 Slow/Medium/Fast 合并到上行或下行命令。 PLC 若依赖速度档位，现场动作与 SI7000 原机不一致。 确认是否需要 CPU2 新增通用速度参数或命令。
P1 报警语义细分 Reel Alarm、Probe Un-calibrated、profile 偏差报警为简化或通用字段映射。 PLC 可能无法区分卷尺、电机、校准和偏差算法来源。 确认报警分类和阈值算法。
P2 协议诊断计数 当前只返回异常帧，不记录诊断统计。 联调时不易定位 CRC 错、站号错、非法地址等问题频率。 后续增加 CPU3 本地诊断计数和最后一次错误摘要。
