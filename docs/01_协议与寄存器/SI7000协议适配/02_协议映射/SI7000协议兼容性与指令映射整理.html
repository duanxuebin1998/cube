SI7000 协议兼容情况整理

本文面向 PLC 联调、项目评审和后续需求确认，按当前工程源码与既有 SI7000 文档整理第一版兼容状态。结论只覆盖当前已经落地或明确固定返回的行为，未确认的现场需求单独列为限制和后续确认项。

整理日期2026-06-13
兼容层位置CPU3 外部串口侧
外部协议SI7000 Modbus RTU 从站
协议版本依据DEVICE_PROTOCOL_VERSION = 8

1. 总体结论

可联调基础 Modbus 功能 已支持 FC01、FC02、FC03、FC04、FC05、FC06，带标准 CRC、站号、长度、地址和值域检查。
已映射测量和 profile 输出 实时位置、温度、密度、液位、profile 点数、点阵和时间寄存器已经接入 CPU2/CPU3 共享数据。
部分兼容命令和保持寄存器 模式/动作线圈已桥接 CPU2 通用命令；40001~40003 写入真实参数，其余 SI7000 专用设定先保持影子回读。
待确认现场语义 Tank ID、上下液位传感器、自动 profile 调度、报警阈值落盘、三档速度和 profile 首点时间戳仍需现场或 PLC 侧确认。
当前定位是“第一版可联调兼容”：CPU3 对外模拟 SI7000 地址、功能码、缩放和异常响应；CPU2 只提供真实测量、通用状态和通用命令，不下沉 SI7000 专用地址或 PLC 语义。

2. 通信兼容

项目 当前兼容情况 说明
串口参数 已支持9600 8O1 选择 COM_PROTO_SI7000 后，CPU3 保存和加载 COM 参数时自动收敛到 SI7000 官方要求的 9600、8 数据位、奇校验、1 停止位。
站号 / Tank ID 复用现有地址 优先使用现有 SlaveAddress，有效范围 1~247；无效时使用 SI7000 层默认地址。独立 SI7000 Tank ID 尚未确认。
请求频率 从站正常响应 当前不主动限制合法请求频率；联调建议 PLC 轮询周期不小于 1 秒，后续可增加诊断计数。
异常响应 已支持 非法功能返回 01，非法地址返回 02，非法值返回 03；CRC 错误、地址不匹配和长度过短不生成正常响应。

3. 功能码覆盖

功能码 用途 当前状态 边界
FC01 读线圈 00001~00016 已支持 16 位窗口；越界返回非法地址；响应位按 Modbus 低位优先打包。
FC02 读离散输入 10001~10032 已支持 32 位窗口；上下液位传感器无可靠来源，当前固定为 0。
FC03 读保持寄存器 40001~40023 已支持 23 个寄存器窗口；单帧最多 125 个寄存器。
FC04 读输入寄存器 30001~30620 已支持 620 个寄存器窗口；profile 点阵只在完成锁存后输出，范围外保持 0。
FC05 写单线圈 已桥接 只接受 0xFF00 / 0x0000；保留线圈拒绝写入；ON 写入桥接 CPU2 通用命令。
FC06 写单保持寄存器 部分真实写入 40001~40003 写 CPU2 分布测量参数；40010~40023 当前为 CPU3 影子回读。

5. 已完成的工程对接

CPU3 外部协议层

  • 新增 SI7000 独立 Modbus RTU 从站模块。
  • 接入 CPU3 主分发路径和兼容分发路径。
  • 按 SI7000 地址表维护线圈、离散输入、保持寄存器和输入寄存器快照。
  • 实现 CRC、站号、长度、地址窗口和值域检查。
  • 对 COM_PROTO_SI7000 自动收敛串口参数到 9600 8O1。

CPU2/CPU3 共享状态

  • 协议版本当前为 DEVICE_PROTOCOL_VERSION = 8，两端严格一致。
  • 补充并同步 bottom_reference_valid、probe_at_liquid_level、profile_complete_latched 等 SI7000 所需中性状态。
  • CPU2 写共享输入寄存器，CPU3 读取后再转换成 SI7000 状态位。
  • 已有契约脚本检查字段顺序、寄存器偏移和协议版本一致性。

6. 保留限制和风险

限制项 当前处理 兼容影响
独立 Tank ID 复用现有 SlaveAddress 如果 PLC 要求 SI7000 Tank ID 独立于其它协议地址，需要新增 CPU3 本机参数和配置入口。
上下液位传感器 10002/10003 固定 0 官方 SI7000 用这两个状态判断液/气界面，长期兼容需要硬件或 CPU2 等价状态确认。
Profile First Point 40001 先桥接 spreadTopLimit SI7000 语义是“罐底之后第一个编程停点”，需确认与现有分布测量参数方向和边界完全一致。
Profile 时间戳 按 profile 完成时刻锁存 官方语义更接近首点采集时间；如 PLC 严格依赖采集开始时间，需要 CPU2 增加生命周期事件。
自动 profile 调度 40010~40013 影子回读 当前不会到点自动触发 profile；若现场需要，应设计 CPU3 调度、互斥条件和参数落盘。
报警阈值落盘 40014~40023 运行期影子值 掉电后不保留；如果 PLC 写入后必须持久化，需要新增 SI7000 专用参数，不建议复用其它协议阈值。
手动三档速度 Slow/Medium/Fast 统一桥接方向命令 PLC 如果要求三档真实速度，需要 CPU2 新增通用速度命令或速度参数。
密度 16 位范围 按 0.01 kg/m3 输出，超 16 位钳位到 65535 16 位最高只表达 655.35 kg/m3，常规高密度值可能被钳位，必须与 PLC 侧确认倍率或扩展方案。
上述限制不是当前联调失败项，但会影响“完全替代 SI7000”的长期兼容度。后续新增外部可见行为时，应同步更新映射表、PLC 联调检查表和 golden frame/协议契约脚本。

7. 联调验收建议

检查项 建议验收口径
基础通信 PLC 使用 9600 8O1、正确站号和 Modbus RTU CRC 后，能读取四类地址区并收到合法响应。
异常响应 非法功能码、越界地址、保留线圈/寄存器写入、40011/40012/40013 非法值均返回对应异常码。
命令桥接 写 00001~00004、00009~00015 时应收到标准 echo；设备状态变化以 CPU2 实际状态为准。
实时测量值 30001~30004 的位置、温度、密度和液位应符合当前 CPU2 数据与单位转换口径。
Profile 输出 未完成 profile 时 30006 和点阵为 0；完成锁存后输出有效点数、时间戳和 200 点窗口内的点阵数据。
影子寄存器 40010~40023 写入后运行期可回读，并能参与 10012 或报警位合成；掉电保存不纳入本轮验收。
