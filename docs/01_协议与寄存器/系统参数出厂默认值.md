# 系统参数出厂默认值

更新日期：2026-07-18

本文整理 CPU2 `RestoreFactoryParamsConfig()` 写入的系统参数出厂默认值。CPU2 是参数 FRAM 的最终持久化端；CPU3 参数菜单名称和小数位来自 `param_meta[]`，用于辅助阅读。未在恢复出厂函数中显式赋值的 `reserved*` 字段由 `memset()` 清零。

## 数据来源

| 来源 | 用途 |
| --- | --- |
| `LTD_MAIN_CPU2/Services/ParamStorage/system_parameter.c` | 恢复出厂默认值的实际赋值入口 |
| `LTD_MAIN_CPU2/Services/ParamStorage/system_parameter.h` | `DeviceParameters` 字段、枚举、常量 |
| `LTD_DISPLAY_CPU3/Application/system_param/system_parameter.c` | CPU3 参数菜单中文名、单位、小数位 |
| `LTD_MAIN_CPU2/Application/Inc/app_version.h` | CPU2 固件版本编码 |

## 注意事项

- 恢复出厂会先清零整个`DeviceParameters`，再写入上述AO默认值。0%和100%对应值有效范围为0到所选源上限，两值禁止相等但允许反向；用户写入非法组合时严格拒绝并保留原有效配置，不使用恢复默认掩盖写入错误。
- 普通、NE和US模式中，储罐液位与水位只在匹配跟随状态且样本有效时更新过程电流；传感器位置在当前记步源就绪后不受命令门禁限制并持续跟随。首次有效过程目标成功写入AD5421前输出初始电流；已有成功过程目标后，命令切换、重新搜索或样本暂时无效进入保持状态，不回退初始电流。
- 真实设备故障严格定义为`device_state == STATE_ERROR`且错误码既不是`NO_ERROR`也不是`STATE_SWITCH`，优先级高于仿真。故障动作只允许输出配置的故障电流或保持上次有效过程电流；上次有效值仅在正常过程目标成功写入AD5421后更新，同时缓存该轮输入值和比例。禁用、输出源、电流模式或量程端点变化时清除缓存；传感器位置源的罐高或记步方式变化也清除缓存。
- 保持期间冻结一阶阻尼状态，恢复有效过程输入后从保持值继续计算。缓存只存在于CPU2 RAM，不跨掉电；AD5421写失败不得更新缓存。
- `softwareVersion`和`protocolVersion`取决于当前编译源码。当前开发及最新正式组合为CPU2 `V1.30.0.0` / CPU3 `V1.29.0.0`、共享协议25。
- 2026-07-06 当前源码为协议版本 14，新增 SI Profile 参数默认值并通过旧协议标记或运行期归一化补齐；`DEVICE_PARAM_VERSION` 和 `DeviceParameters` 结构大小保持不变。
- 2026-07-08 CPU2 `V1.21.3.0` 保持协议版本 14 和参数存储版本 3；`oilLevelHysteresisTime` 仅作为方法 0/1 跟随变化确认时间，速度闭环稳定等待改为固定 1000 ms。
- 2026-07-11 CPU2 已更新到 `V1.22.0.0`；共享协议仍为 14，`DEVICE_PARAM_VERSION` 仍为 3，恢复出厂默认值和 `DeviceParameters` 布局未因 V1.21.4.0～V1.22.0.0 改变。
