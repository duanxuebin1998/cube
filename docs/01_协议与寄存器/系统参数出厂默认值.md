# 系统参数出厂默认值

更新日期：2026-06-09

本文整理 CPU2 `RestoreFactoryParamsConfig()` 写入的系统参数出厂默认值。CPU2 是参数 FRAM 的最终持久化端；CPU3 参数菜单名称和小数位来自 `param_meta[]`，用于辅助阅读。未在恢复出厂函数中显式赋值的 `reserved*` 字段由 `memset()` 清零。

## 数据来源

| 来源 | 用途 |
| --- | --- |
| `LTD_MAIN_CPU2/Services/ParamStorage/system_parameter.c` | 恢复出厂默认值的实际赋值入口 |
| `LTD_MAIN_CPU2/Services/ParamStorage/system_parameter.h` | `DeviceParameters` 字段、枚举、常量 |
| `LTD_DISPLAY_CPU3/Application/system_param/system_parameter.c` | CPU3 参数菜单中文名、单位、小数位 |
| `LTD_MAIN_CPU2/Application/Inc/app_version.h` | CPU2 固件版本编码 |

| `param_version` | `DEVICE_PARAM_VERSION` | 当前源码为 3 |
| `struct_size` | `sizeof(DeviceParameters)` | 运行时写入结构体大小 |
| `magic` | `DEVICE_PARAM_MAGIC` | `0x4C54444D`，即 `LTDM` |
| `crc` | 保存时计算 | 恢复出厂函数先置 0，`save_device_params()` 再更新 CRC |

## 注意事项

- 恢复出厂会先清零整个 `DeviceParameters`，因此所有 `reserved*` 字段默认值均为 0。
- `softwareVersion` 和 `protocolVersion` 取决于当前编译源码；本文记录的是 2026-06-09 当前源码值。
- CPU2 源码是出厂默认值的权威来源；CPU3 参数表只用于菜单展示、单位和小数位说明。
