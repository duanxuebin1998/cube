# 传感器安全协议 SIL 资料索引

更新日期：2026-08-03

本目录集中维护 CPU2 与安全相关传感器之间的通信协议正文、实施方案、验证记录和残余风险论证。当前 Markdown 是权威维护源；同名 PDF 是阅读导出件，内容必须与对应 Markdown 同步，但不替代 Markdown。

## 当前状态

- 已冻结并已实现的基线仍是点对点安全通信协议 V1，线上 `protocol_version=0x01`。
- CPU2 设备侧 V1 协议栈、会话、UART6 传输、完整参数分页和主机级测试已有静态/构建证据。
- 传感器端实现、真实短线和 200 米 RS485、故障注入、FTTI、诊断覆盖率和 SIL 定量论证仍未关闭。
- “CPU2 同时连接两个不同功能传感器”当前处于文档设计阶段，尚未修改固件、机器契约或正式 V1 帧语义。

## 维护规则

1. V1 冻结正文与双端点设计提案分开维护；未通过评审、实现和验证前，不得把提案写成当前行为。
2. 若只改变 CPU2 内部总线调度和端点数量、线上帧字节不变，应记录为系统拓扑 Profile 变化；若改变冻结字段、负载、命令、能力位或地址契约，则提升相应协议/负载版本。
3. 两个传感器的身份、会话、配置摘要、数据年龄、采样计数、故障和恢复证据必须分别记录；共享总线故障单独作为公共原因处理。
4. 代码实现、golden frame、主机测试和构建通过不等于完成 SIL 认证；真实长线、故障注入和端到端 FTTI 证据必须单列。
5. 修改带同名 PDF 的 Markdown 后，同步生成 PDF，并进行内容一致性和页面渲染检查。
