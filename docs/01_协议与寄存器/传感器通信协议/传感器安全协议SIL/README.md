# 传感器安全协议 SIL 资料索引

更新日期：2026-08-07

本目录是 CPU2 与安全相关传感器通信协议的正式 Markdown 维护入口。资料按“现行协议、候选协议、实施与验证、安全论证、历史方案”分层，避免把已实现基线、未来设计和历史方案混在一起。

## 当前结论

- 当前已冻结并具有 CPU2 设备侧实现证据的是安全通信协议 V1，线上 `protocol_version=0x01`。
- V1 的传感器端实现、真实短线和 200 米 RS485、故障注入、FTTI、诊断覆盖率及 SIL 定量论证尚未关闭。
- V2 是待评审的新协议，线上候选 `protocol_version=0x02`，采用单活动端点互斥和安全运行期纯单向主动上报。
- V2 支持后续增加电导率、含水率等不同传感器 Profile，但任一时刻最多只有一个传感器主动发送。
- 旧“双端点同总线轮询”方案已被 V2 单活动端点方案替代，仅保留为历史资料。

## 维护规则

1. V1 和 V2 分开维护，V2 未评审、实现和验证前不得写成当前固件行为。
2. 新传感器通过 V2 Runtime Profile 扩展；改变公共信封、命令或状态机时必须评估提升安全协议版本。
3. 实施证据必须注明协议版本、CPU2/传感器端范围以及真实硬件是否执行。
4. 历史方案不得重新成为实施输入；需要恢复时必须重新评审并形成新版本。
5. 代码、golden frame、主机测试或构建通过均不等于完成 SIL2/SC3 认证。
