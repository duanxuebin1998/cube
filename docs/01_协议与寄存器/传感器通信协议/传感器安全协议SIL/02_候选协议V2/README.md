V2 精简候选版的核心：

- 支持不同功能传感器的受控 Runtime Profile。
- 任一时刻最多一个传感器主动发送。
- 配置和切换阶段双向；安全运行阶段纯单向。
- 控制面只有 `HELLO`、`START_STREAM` 和 `STOP_STREAM` 三条命令。
- 运行时序和字段契约静态注册，不在连接时动态协商。
- 单个 64 位 `session_id` 同时绑定 CPU2 与传感器的新鲜因子。
- 删除同步帧、双时隙、数据 ACK、运行期轮询和重复会话标识。
- DM4 运行帧固定 92 字节：44 字节公共头、44 字节 Profile 和 4 字节 CRC32C。
- 旧端点未停止并确认静默前，禁止启动新端点。

精简仅删除重复机制和中间状态；会话、序号、数据年龄、配置摘要、状态、诊断、有效字段和 CRC32C 等安全门禁仍保留。

DM4 业务参数语义来源：《多参数传感器通信协议 V4.0》。

当前现行协议为《传感器安全通信协议 V1》。
