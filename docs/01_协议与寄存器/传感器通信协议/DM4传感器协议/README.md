## 当前边界

- 参数0～25可读，参数65～159可读写；参数26～64为不可访问保留区。
- 密度单位统一为`kg/m³`，动力黏度为`cP`，运动黏度为`cSt`。
- 协议只有密度和液位两种测量模式：`D`进入密度模式，`S`进入液位模式；`L`和`M`不是测量模式，分别控制密度模式下测水和磁零点功能的使能/关闭，且二者互斥。
- 主动发送帧已确定为64字节：`55 AA 01 A1`开头，携带参数0～12、16位小端序号和CRC16/MODBUS。
- CRC覆盖字节0～61；主动发送周期为500 ms，抖动上限未知。
- 链路为RS485半双工；主动帧结束后等待20 ms再发送关闭主动上报的命令，主动上报到期时传感器优先上报，CPU2收到有效8字节应答后才能进入交互通信。
- 参数65会持久化，CPU2应直接消费主动数据，只在必要的模式切换或配置阶段集中停流交互，避免频繁写0/1。
- 参数0～12不是同一次采样结果，而是组帧时各参数的最新值；完整帧可以原子发布，但不能当作同一测量时刻的数据。
- 同一RS485总线允许多台设备，但同时只能有一台主动上报；地址0也会主动上报。
- 周期抖动、命令最大应答时间、恢复后的首帧延时和序号规则仍待台架确认。
- 参数4为随模式变化的当前测量频率：液位模式返回液位频率，密度模式返回密度谐振频率；CPU2必须结合状态字解释。
- 当前没有DM4真实串口抓包和整机台架验证，不能把静态整理写成硬件验证结论。
