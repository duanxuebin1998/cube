## 边界

- CUBE CPU2自`V1.36.0.0`起在UART4按19200 8N1被动接收精确22字节的`CC 03 83`帧，校验前21字节异或BCC后更新重量和扭力模块温度；CPU3通过协议31共享槽显示温度。该实现不包含`0x81/0x82`接收、下行查询或完整Newhall协议栈。
- 协议卷依据 Newhall 当前源码静态整理；真实串口、电气接口、称重标定和整机行为仍需台架验证。
- Newhall 源目录当前没有 Git 元数据，协议卷使用逐文件 SHA-256 锁定来源快照。
- 本次周度校正只同步已发布状态，不修改 CUBE 或 Newhall 固件行为，不升级固件版本和 CUBE 共享协议版本。
