## 使用边界

- 本目录中的NMS81原始资料和OPML只用于外部产品配置参考；CUBE参数、寄存器、菜单和运行行为以当前协议24源码及上述项目正式文档为准。
- NMS81 的接线方式、Ex-d/Ex-ia 输出能力、HART 和 SIL/WHG 功能依赖其订货选型与硬件模块，不能直接等同于 CUBE 硬件能力。
- 协议24没有移动AO地址或改变结构尺寸，但重新解释输出源1、初始电流和运行态来源；CPU2/CPU3必须严格使用同一协议版本。物理电流精度、断环恢复和HART叠加仍需台架验证，不得用DAC预留字段替代电流表证据。
