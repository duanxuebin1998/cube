## 使用边界

- 本目录中的NMS81原始资料和OPML只用于外部产品配置参考；CUBE参数、寄存器、菜单和运行行为以当前协议34源码及上述项目正式文档为准，其中AO倍率和迁移规则源自协议33。
- NMS81 的接线方式、Ex-d/Ex-ia 输出能力、HART 和 SIL/WHG 功能依赖其订货选型与硬件模块，不能直接等同于 CUBE 硬件能力。
- 协议33保持第4个AO槽、LTD/LH地址、结构尺寸、CRC和`DEVICE_PARAM_VERSION=3`不变；协议26～32旧修正值乘10迁移，协议25及更早或未知版本归零。协议34不再改变AO字段。CPU2/CPU3必须严格使用同一协议版本，上位机协议32/33/34参数快照不得混用。自动检查和构建不证明真实电流环0.001mA精度、边界饱和、断环恢复或HART叠加，必须使用电流表台架验证。
