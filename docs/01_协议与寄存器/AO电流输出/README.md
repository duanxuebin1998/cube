## 使用边界

- 本目录中的NMS81原始资料和OPML只用于外部产品配置参考；CUBE参数、寄存器、菜单和运行行为以当前协议27开发源码及上述项目正式文档为准。
- NMS81 的接线方式、Ex-d/Ex-ia 输出能力、HART 和 SIL/WHG 功能依赖其订货选型与硬件模块，不能直接等同于 CUBE 硬件能力。
- 协议26把第4个AO槽解释为有符号电流修正值；协议27固定AO地址块但保持参数结构尺寸和存储版本不变。CPU2/CPU3必须严格使用同一协议版本。物理电流精度、修正后的边界饱和、断环恢复和HART叠加仍需台架验证，不得用DAC预留字段替代电流表证据。
