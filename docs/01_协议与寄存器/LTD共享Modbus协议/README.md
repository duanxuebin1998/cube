本目录维护 CPU2 与 CPU3 共用的 LTD Modbus RTU 对外协议。LTD 菜单协议和 CPU2/CPU3 板间共享寄存器不再作为两套协议分别管理。

## 当前结论

- 当前开发及最新发布源码为 `DEVICE_PROTOCOL_VERSION = 24`；正式组合为CPU2 `V1.29.0.0` / CPU3 `V1.27.0.0`。
- 协议24沿用协议22重排、协议23正式发布的129项共享故障编号和协议21固定点代际，定义AO传感器位置源、初始/过程/保持状态。CPU3另有本机故障。现场解释共享故障时按CPU2程序版本选表，不用共享协议版本替代。
- CPU3 的 LTD 外部端口使用与 CPU2 相同的保持寄存器、输入寄存器和命令码。
- CPU3 读请求由最近一次 CPU2 缓存快照独立响应；写请求转发给 CPU2，只有 CPU2 返回合法 ACK 才向外返回成功。
- AO当前实际菜单为5组16项：11项可见持久化配置、1项非持久化仿真开关和4项只读运行状态；AO输出电流复用`last_sent_mA_x100`，表示最近成功下发命令而非物理回读。SIL/WHG、原错误等级槽位和DAC回读均隐藏预留；仿真开关位于CRC之后且不持久化，DAC回读有效标志当前固定为0。
- CPU3对两组固定点结果采用代际前读、24个寄存器私有读取和代际后读；前后代际一致才原子提交公开快照，失败或变化时丢弃候选并重试。
- 设备状态、无线链路和 AO 运行态中的32位故障码按当前统一故障码表解释；旧编号只能用于对应CPU2历史版本，不能直接套用。
