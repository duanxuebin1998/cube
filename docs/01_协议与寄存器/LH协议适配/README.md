# LH 协议适配文档索引

更新日期：2026-07-22

本目录维护二代计量仪 LH Modbus RTU 对外协议、CUBE 映射边界和联调口径。LH 是 CPU3 外部 COM 协议，不等同于 CPU2/CPU3 板间共享 Modbus。

## 当前实现口径

- CPU3 的 `COM_PROTO_LH=3` 使用默认 `9600 8N1`，同协议切换请求也重新应用 LH 默认串口参数；随后仍可由屏幕手动覆盖串口字段。
- 支持 FC01、FC03、FC04、FC05、FC10；FC01 兼容读线圈请求并将合法范围内的线圈位统一返回 0，命令只有在 CPU2 返回合法 ACK 后才成功，参数还必须等待 FRAM 完成代次并回读目标字段一致后才成功。
- 17 个线圈、28 个输入寄存器和 `0x0000～0x005C` 保持寄存器以 Word 手册为当前外部查表资料；源码维护入口为 `LTD_DISPLAY_CPU3/Communication/external/lh_modbus/`。
- 维护进入、维护退出和清除全部锁存报警通过 CPU2 命令切换通道执行；若测量或运动正在进行，当前流程可能先受控退出。
- K1～K3 阻尼字段可写保存但当前业务未消费；传感器幅值当前没有正常硬件更新路径；二者不得作为控制或验收依据。
- 自动检查和双端构建不能替代真实 RS485、FRAM 掉电、命令时序、继电器 NO/NC 和 AO 电流环台架验证。
