# 协议与寄存器文档索引

更新日期：2026-08-03

本目录用于保存 CPU2/CPU3 共享协议、外部 Modbus/DSM/SI协议适配、寄存器表、协议版本和兼容性记录。凡是会影响通信地址、字段语义、命令、状态、缩放、补码解释或协议兼容性的资料，优先归入本目录。

## 维护规则

- 修改 CPU2/CPU3 共享协议、共享参数语义、寄存器长度、命令码或跨 CPU 状态含义时，同步更新 `CPU2_CPU3协议变更记录.md`。
- 修改 LTD 外部功能码、寄存器窗口、快照/写确认或异常码行为时，同步更新 `LTD共享Modbus协议/` 和 `tools/check_ltd_modbus_contract.py`。
- 修改 SI协议对外可见行为时，同步更新 `SI协议适配/02_协议映射/`、`03_改动记录/` 和 `04_联调测试/`。
- 修改 Wartsila 外部可见行为时，同步更新 `Wartsila协议适配/2026-01-27_莆田现场Wartsila抓包协议整理.md`、`Wartsila协议适配/当前兼容情况与协议栈.md`、`../05_测试记录/协议台架验收/` 的工具 catalog/派生矩阵和对应专项契约；原始抓包继续归档在 `Wartsila协议适配/00_原始资料/`。
- 外部供应商原始资料优先放入对应适配目录的 `00_原始资料/`，不要直接覆盖原始文件。
- DSM CPU1 传感器传统 UART 协议归入 `传感器通信协议/DSM传感器协议/`；协议正文以 DSM 固件仓库为唯一真源，通过同步脚本更新 CUBE 副本，并在本地 README 单独维护 CUBE 消费范围和差异。
- DSM 原始协议表归档到 `DSM协议适配/00_原始资料/`；项目内解释、兼容性结论或代码变更依据写入 `DSM协议适配/02_协议映射/` 并回链源表。
- `DSM寄存器说明V1.225.xlsx` 保留为历史外部寄存器表；如与 V1.228 源表或当前源码冲突，以 V1.228 源表、DSM 兼容 Markdown、源码和版本记录共同确认当前口径。
- 协议名、标准名、供应商资料名可保留英文；项目解释和执行计划优先使用中文文件名。
- 本目录中 Markdown 是项目解释和兼容性结论的维护正文；Excel 表是寄存器或外部协议源表，修改前必须确认对应代码、协议版本和 README 口径。
- 非 Markdown 附件的责任边界见 `../00_构建与版本/附件与源文件清单.md`；DSM、SI、无线滑环相关附件只作为源表或原始资料，项目实现口径必须回到本目录 Markdown 和源码依据。
