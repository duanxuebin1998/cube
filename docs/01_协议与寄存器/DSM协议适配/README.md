# DSM 协议适配文档索引

更新日期：2026-07-10

本目录集中保存 DSM/一代计量仪对外 Modbus 协议资料、二代计量仪兼容边界和项目内解释。原始 Excel 只作为协议输入资料，当前工程实现口径以源码、版本记录和本目录 Markdown 结论为准。

## 目录结构

| 目录 | 用途 | 主要文件 |
| --- | --- | --- |

## 建议阅读顺序

1. `02_协议映射/DSM_V1.228一代协议卷整理.md`：当前项目内 DSM V1.228 兼容结论，包含源表提取、二代扩展、设备忙 `0x06` 和多字段非原子边界。
2. `../../02_需求与计划/已实现/二代计量仪同步支持DSM_V1.228协议需求方案.md`：追溯二代兼容需求确认项。
3. `../../00_构建与版本/版本改动与测试/2026-06-02_CPU3_V1.8.0.0_DSM_V1.228外部协议兼容_改动与测试方案.md`：追溯 CPU3 V1.8.0.0 已落地范围和验证口径。
4. `00_原始资料/在线一体机对外Modbus协议V1.228.xlsx`：查全量寄存器行、字段范围和原始备注。
5. `02_协议映射/二代计量仪modbus使用手册（2026版）.docx`：只作为历史二代手册和 Word 版式参考，不作为当前固件实现权威源。

## 维护口径

- V1.228 Excel 是一代计量仪协议源表；不要直接在工程内改写原始表。
- 二代计量仪通过 CPU3 外部 DSM Modbus 适配层兼容该协议，不把一代协议源表直接等同于 CPU2/CPU3 内部共享协议。
- 如果一代源表和二代实现有差异，先在 `02_协议映射/` 写清差异、兼容策略和依据，再视改动范围同步版本方案、协议记录或测试脚本。
- 修改 DSM 外部可见地址、缩放、状态、线圈命令或异常码时，同步检查 `LTD_DISPLAY_CPU3/Communication/external/DSM_modbus/`、相关版本方案和本目录 Markdown。
- 当前目录没有名为 `DSM_V1.228对外Modbus正式协议卷.md/.docx` 的正式文件，不再在索引中引用不存在的文件；后续确需生成外发正式卷时，应在内容评审通过后单独建立并同步索引。
- `../DSM寄存器说明V1.225.xlsx` 保留为历史寄存器核对表，不作为本次 V1.228 一代源表的替代品。
