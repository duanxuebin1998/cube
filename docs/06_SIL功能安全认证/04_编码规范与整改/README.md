# SIL 编码规范与整改

更新日期：2026-07-31

## 目录用途

本目录用于维护 CPU2 安全相关代码的编码规范、规则偏离、整改检查和静态分析预筛资料。

## 文件索引

| 文件 | 内容 |
| --- | --- |
| `CPU2编码规范.md` | CPU2 编码规范、强制规则、门禁和验证要求 |
| `CPU2编码规范偏离记录模板.md` | MISRA、CERT 和项目规则偏离的记录与审批模板 |
| `CPU2编码规范整改检查表.md` | 编码规范整改任务、模块跟踪和静态搜索预筛项 |
| `MISRA_C2012预筛整改重点.html` | MISRA C:2012 方向预筛结果和优先整改项 |

## 维护原则

- 规则、偏离、整改状态和验证证据应保持可追踪。
- 预筛结果只作为正式静态分析前的输入，不代替合格工具的正式报告。
- 涉及安全相关模块范围时，同步核对 `../02_软件架构/CPU2安全相关模块清单.md`。
