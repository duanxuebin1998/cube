## 使用规则

1. 首先打开验收包中的《CPU2软件详细设计中期验收说明》，再按编号顺序检查总册和各分册。
2. 验收意见使用“文件名 + 物理页码 + 设计编号或问题描述”定位。
3. 验收包中的 Word 为冻结副本；后续修改回到 [`06_分卷编制`](../06_分卷编制/) 正式维护源。
4. 新一轮源文档变更不得覆盖既有验收包，应建立新的日期或版本目录并重新生成完整哈希清单。
5. 中期验收不等于需求批准、硬件验证、台架验证、现场验证或 SIL 认证通过。
