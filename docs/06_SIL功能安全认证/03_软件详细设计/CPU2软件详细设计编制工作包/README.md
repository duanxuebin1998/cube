# CPU2 软件详细设计编制工作包

## 用途

本目录位于 CUBE Git 仓库的正式文档区，集中保存 CPU2 软件详细设计的参考文档、撰写标准、当前框架、流程图版式基准和后续撰写计划。

后续启动完整文档撰写时：

- 内容组织、说明深度、表格形式和版式优先参考一代《FX01.软件详细设计V1.1》。
- 每轮同时对照最近已验收的同类分册，核查参考版式在当前生成链中的实际落地；自动门禁通过不能替代全本逐页视觉复核。
- CPU2 实际行为、模块、接口、参数、故障处理和版本信息以启动撰写时的当前源码和批准资料为准。
- 流程图按 V0.4 已确认的黑白线框、原生判断框和箭头留白标准绘制。
- 无法确认的内容保留“待确认”或“待验证”，不得从一代文档直接推定为当前 CPU2 已实现行为。

## 资料使用顺序

1. 用户对本次编制的最新要求。
2. 启动撰写时的 CPU2 当前源码、接口、参数、故障码和批准资料。
3. 一代参考文档的章节结构、内容表达和版式。
4. 本工作包中的撰写与排版要求。
5. V0.4 流程图版式基准。

一代参考文档是内容和格式模板，不是当前 CPU2 行为的事实来源。
