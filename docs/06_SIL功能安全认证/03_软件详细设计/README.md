## 维护原则

- Word 正文和流程图版式以工作包内的参考文档及撰写标准为准。
- 框架、参考件和正式编制稿必须通过文件名与版本号明确区分。
- 设计描述应能追踪到需求、模块、接口、异常处理和验证证据，不把待验证内容写成已完成结论。
