## 入库边界

- 已有授权或用户已提供的标准 PDF，可放入本目录或其子目录，并在本文记录来源、版本、用途和授权状态。
- 官方公开发布的资料，可保留原始文件并记录官方下载页面；下载后必须确认文件头为 PDF 或原始资料格式，不能把网页登录页、预览页或 404 页面当作标准原文入库。
- IEC、ISO、MISRA、NDA 资料、认证机构模板和供应商受控包，如果官方入口未提供完整原文下载，只登记官方获取路径、建议文件名和授权状态；拿到授权文件或用户提供文件后再补入库。
- 项目自有理解、摘要、适用矩阵和评审结论写入 Markdown；不得把受版权保护的标准原文改写成“全文整理版”。

## 授权文件入库命名规则

| 类型 | 命名建议 |
| --- | --- |
| IEC 标准 | `IEC_<标准号>_<年份>[_AMD<序号>_<年份>][_CSV].pdf` |
| ISO 标准 | `ISO_<标准号>-<部分号>_<年份>.pdf` |
| GB/T 标准 | `GB_T_<标准号>.<部分号>-<年份>_<中文简称>.pdf` |
| 厂商 Safety Manual | `<厂商>_<器件或软件包>_Safety_Manual_<版本>.pdf` |
| FMEDA/FMEA | `<厂商>_<器件>_FMEDA_<版本>.pdf` 或 `<厂商>_<器件>_FMEA_<版本>.pdf` |
