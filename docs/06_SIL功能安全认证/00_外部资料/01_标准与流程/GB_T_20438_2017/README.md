# GB/T 20438-2017 标准资料

更新日期：2026-06-27

## 资料用途

本目录归档用户提供的 `GB20438 (1).zip` 中的 GB/T 20438-2017 七个分册 PDF。GB/T 20438 等同采用 IEC 61508:2010，是电气、电子、可编程电子安全相关系统功能安全的基础标准体系。

这套资料在 CUBE 项目中主要用于 SIL 准备和软件工程过程对齐：

- 明确功能安全管理、安全生命周期、确认和验证活动边界。
- 对齐 E/E/PE 安全相关系统要求，以及 CPU2/CPU3 与外部安全链路的职责边界。
- 重点支撑软件安全生命周期、软件安全需求、架构设计、编码、验证、确认、配置管理和变更控制。
- 为 SIL 等级确定、技术措施选择、措施充分性复核和认证沟通提供标准依据。
