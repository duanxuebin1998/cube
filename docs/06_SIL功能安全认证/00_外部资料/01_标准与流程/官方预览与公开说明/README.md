# 官方预览与公开说明

更新日期：2026-07-03

本目录用于归档 IEC、ISO、国家标准公开页面、官方预览页、标准获取入口和公开说明材料。

维护口径：

- 只保存官方允许公开获取或项目已授权归档的资料。
- 不保存未授权的 IEC、ISO 或其它受版权保护标准全文。
- 标准正式引用以官方完整原文、公司受控文本和认证机构确认版本为准。
- 子目录按来源或资料类型建立 README，说明资料来源和使用边界。
