## 维护要求

- 只从国家标准全文公开系统页面记录公开状态。
- 若后续官方页面开放全文下载，下载后先确认文件头和内容，再按 `../../待获取标准原文/` 的建议路径入库。
- 不从第三方转载站点补入国家标准或等同采用 ISO/IEC 的标准全文。
