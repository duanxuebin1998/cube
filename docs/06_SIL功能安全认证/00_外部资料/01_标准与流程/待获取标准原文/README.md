# 待获取标准原文

更新日期：2026-07-03

本目录用于记录需要通过官方公开下载、授权、用户提供、NDA 或公司受控渠道获取的标准原文。当前只保存获取说明和建议归档结构，不保存未授权的 IEC、ISO、MISRA、认证机构或供应商受控资料。

## 使用方式

1. 获取或授权前，先看上级目录 `标准原文归档清单.md` 的优先级、官方入口和公开下载核查结论。
2. 获取正式文件后，按清单建议路径和命名规则放入对应子目录。
3. 在本 README 或对应子目录 README 中补充标准版本、来源、授权范围、入库日期、文件校验和使用边界。
4. 如果资料来自 NDA 或供应商受控包，不要直接提交到公开仓库；只登记公司文控编号和责任人。
5. 如果官方入口返回的是网页登录页、预览页或 404 页面，不得改名为 PDF 入库；必须确认文件头和内容确实为完整标准原文。
