# 案例参考资料

更新日期：2026-06-06

## 目录用途

本目录用于归档外部已认证或已发布安全手册的产品案例，帮助 CUBE SIL 准备时学习资料结构、证据边界、生命周期要求和安全架构表达方式。

案例资料只用于工程参考，不能作为 CUBE 已满足 SIL 的证明。正式认证仍应以 CUBE 自身 SRS、设计、代码、测试、计算、工具确认、认证机构意见和公司质量体系为准。

## 维护规则

- 只归档用户提供、供应商公开发布或可追溯来源的案例资料。
- 不把第三方产品证书结论直接写成 CUBE 认证结论。
- 每个案例应至少说明资料来源、可借鉴内容、不能直接套用的边界。
