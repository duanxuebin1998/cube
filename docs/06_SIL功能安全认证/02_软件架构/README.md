## 维护原则

- 双版本资料应明确区分安全核心、安全支撑、现场辅助和开发调试代码。
- 涉及构建变体、源码清单或安全输出权限的改动，应同步检查 CPU2 构建配置和安全代码范围矩阵。
- 文档说明不代表已经完成 SIL 认证，实际认证结论以需求、设计、实现、测试和评审证据闭环为准。
