- V0.2 遵循[处理器与传感器架构确认基线](../02_编制依据与差异分析/处理器与传感器架构确认基线.md)：不存在 CPU0；CPU1 在 DSM、LTD、DM4 中三选一；SIL 配置仅 `CPU1（DM4 安全协议）↔ CPU2` 为安全通信；CPUW（扭力）每台必装且非安全相关；CPU4 仅保留 `外部实时温度计→CPU4→CPU3→上位机` 的未来非安全路径；AO/HART、继电器和电机归 CPU2，所有外部数字协议归 CPU3；无线主从只作为蓝牙透明传输载体。
