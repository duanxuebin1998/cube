# ER02 软件架构设计编制工作包

更新日期：2026-08-05

## 用途

本工作包用于参考一代《ER02.软件架构设计V1.1》，编制当前二代计量仪软件架构设计。参考文档只作为章节、表格、页眉页脚、目录和 Visio 风格基线；二代处理器职责、接口、状态和调度关系以当前源码、现行协议、系统架构资料及批准材料为准。

## 当前状态

- 软件架构设计已启动，当前交付版本为 `V0.1` 中期评审稿。
- 当前 Word 为 23 个物理页（正文 19 页）、3 个分节、34 张表，包含 9 个 `Visio.Drawing.15` OLE、9 个 EMF 预览和 9 份独立 VSDX；编制侧 72/72 项结构门禁及 23/23 页最终渲染检查已通过。
- F09 的异常路径已采用三段虚线和 0.35 in 垂直末段接框，消除沿框顶骑线；cycle7 全本渲染已重新检查。
- CPU2/CPU3 事务语义已区分：普通参数写以合法 ACK 作为该次写成功门禁；恢复出厂等长事务的 ACK 仅表示受理，最终完成还需依据 CPU2 后续状态/结果及重新同步。
- CPU2 软件详细设计保持冻结，等待本工作包中的 ER02 架构基线完成并形成评审结论后再恢复。
- 本轮不修改固件、不升版、不暂存、不提交、不推送。
- CPU1/DM4 传感器端未提供完整固件源码，正文仅描述协议合同、硬件能力和目标职责，不声明传感器端已经实现。
- CPU4 仅有 `WirelessHost_V4.1_init` 局部源码，正文按当前源码证据描述，并把版本、接线归属和故障恢复缺口列为待确认项。

## Word 与 Visio 门禁

- 每次实质修改后更新目录、整本重排，并从物理第 1 页检查到末页。
- 流程图以一代 ER02 的白底细黑线为主，仅对明确安全边界和目标合同边界使用克制语义色；节点不重叠，连线不穿框，文字不压线，箭头转折和箭头端保留明显净空。
- Word 中的正式图为 `Visio.Drawing.15` 可编辑 OLE；每个对象保留独立 VSDX。
- 不生成正式 PDF；PDF 和 PNG 只作为 `tmp/` 下的临时渲染检查产物。
- 文档结论区分源码已核对、文档合同、目标设计、待确认和未验证，不把静态或渲染检查表述为目标板、台架、现场、故障注入或 SIL 认证证据。
