## 图形规则

- 延续一代 ER02 的白底、细黑线、紧凑标题栏和统一字体，不另建一套视觉系统。
- 安全红色只用于 SIL 配置下 `CPU1（DM4 安全协议）↔ CPU2` 的安全通信边界；普通协议、CPUW、CPU3、CPU4 和蓝牙链路不得误标为安全链路。
- 未来目标或尚未闭环的路径使用克制虚线/注释表达，不把待设计内容画成当前已实现模块。
- 节点不得重叠，连线不得穿框，标签不得压线；箭头转折、箭头端和相邻框之间保留明显净空。
- F05 的“安全故障→安全受控维护”和“安全受控维护→安全故障”必须使用两条独立单向箭头，不使用视觉含糊的共线双向箭头；当前两线水平净距为 0.38 英寸。
