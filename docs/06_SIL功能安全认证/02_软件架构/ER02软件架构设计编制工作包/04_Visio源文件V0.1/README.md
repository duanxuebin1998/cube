# ER02 V0.1 Visio 源文件

本目录保存 `ER02.二代计量仪软件架构设计V0.1.docx` 中可编辑 `Visio.Drawing.15` OLE 对象对应的独立 VSDX。V0.1 已通过历史版式检查，但用户内容评审未通过；这些 VSDX 当前不是批准架构图。

图号、Word OLE 和 VSDX 必须一一对应。图形以一代 ER02 的白底细黑线为主；安全红色只允许用于 SIL 配置下 DM4 安全协议的 `CPU1（DM4）↔ CPU2` 端到端边界，目标合同边界使用克制蓝色，待补路径使用黑色虚线。禁止节点重叠、连线穿框、标签压线、箭头端贴框、不必要的交叉或页面裁切。

后续重编应遵循 `../02_编制依据与差异分析/处理器与传感器架构确认基线.md`：F01 至 F03 画明 CPU1 的 DSM/LTD/DM4 三选一、原始数据和计算结果上传、DM4 安全/非安全协议，以及 SIL 配置唯一的 CPU1（DM4）↔CPU2 安全通信链路；F04 固定 AO/HART、继电器和电机归 CPU2，F06/F07 固定所有外部数字协议归 CPU3；F08 改为 CPUW（扭力）模块、自诊断责任和独立诊断码缺口，F09 改为 CPUW→CPU2 非安全数据流、1000 ms 超时、统一错误处理、电机驱动有效时调用慢停流程及 CPU3 轮询同步。CPU4 只在总体图中保留 `外部实时温度计→CPU4→CPU3→上位机` 的未来非安全路径。无线主机和无线从机只画成蓝牙透明传输链路，不画独立 CPU 或安全处理端点。
