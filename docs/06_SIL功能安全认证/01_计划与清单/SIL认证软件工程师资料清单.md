# SIL 认证软件工程师资料清单

更新日期：2026-06-30

## 目标

本文件用于说明团队软件工程师在 CPU2/CPU3 后续 SIL 认证准备中，需要阅读、维护、提交或向外部获取的资料。这里的清单面向工程落地，不替代认证机构或公司质量体系的正式要求。

## 使用顺序

| 阶段 | 软件工程师要做的事 | 主要输入资料 | 主要输出资料 |
| --- | --- | --- | --- |
| 认证范围确认 | 明确哪些功能、模块、接口属于安全相关软件 | IEC 61508 概览、系统安全需求、CPU2 安全相关模块清单 | 软件安全范围说明、安全相关模块边界 |
| 软件安全需求 | 把系统级安全需求拆成可验证的软件需求 | IEC 61508-3、HSG238、系统需求、故障分析 | 软件安全需求规格、需求追踪矩阵 |
| 架构与详细设计 | 明确安全机制、诊断、降级、故障记录、接口隔离 | IEC 61508-3、ST Safety Manual、CPU2/CPU3 协议资料 | 软件架构设计、详细设计、接口说明 |
| 编码实现 | 按 MISRA C:2012/CERT C 子集实现，记录偏离项 | CPU2 编码规范、MISRA Compliance、MISRA C Amendment 4、CERT C | 源码、编码检查报告、deviation record |
| 静态分析 | 配置规则集、处理告警、保留工具版本和配置 | 静态分析工具手册、MISRA/CERT 规则映射 | 静态分析报告、未关闭告警说明 |
| 单元与集成测试 | 覆盖安全需求、边界、错误路径、诊断功能 | 软件需求、设计、测试策略、覆盖率规则 | 单元测试、集成测试、覆盖率报告 |
| 工具与库确认 | 确认编译器、静态分析器、测试工具、HAL/STL 的适用性 | 工具手册、工具资质包、ST X-CUBE-STL 资料 | 工具确认记录、第三方软件适用性说明 |
| 评审与审计 | 提供可追溯证据，准备认证机构问题回复 | 所有规格、设计、代码、测试、偏离记录 | 评审记录、问题整改闭环、认证证据包 |

## 编码检查资料组合

最低可执行组合：

- `../04_编码规范与整改/CPU2编码规范.md`
- `../04_编码规范与整改/CPU2编码规范偏离记录模板.md`
- `MISRA_Compliance_2020.pdf`
- `MISRA_C_2012_Amendment_4.pdf`
- SEI CERT C 在线规则库
- 静态分析工具的 MISRA/CERT 规则映射表
- 编译器告警配置和构建日志

认证更完整组合：

- MISRA C:2012 主规则或公司批准的后续 MISRA C 版本
- 静态分析工具 qualification kit 或工具确认资料
- 单元测试工具 qualification kit 或工具确认资料
- 编译器安全手册、已知问题列表、版本锁定记录
- 所有 deviation record 的审批证据

## 获取原则

- 可以公开下载的资料放入 `../00_外部资料/`，并在 README 中保留来源链接。
- 付费标准、受版权限制资料、NDA 资料不放非官方副本，只记录官方获取路径和申请责任人。
- 每次更新外部资料时记录资料版本、下载日期和来源 URL。
- 认证证据包中不要混用第三方镜像来源，避免版权和可追溯性问题。
