## 目录用途

本目录用于维护 CUBE 功能安全认证的阶段计划、资料清单、交付物清单和缺口跟踪入口。

## 文件索引

| 文件 | 内容 |
| --- | --- |
| `CUBE功能安全认证详细工作计划.md` | SIL 准备阶段、P0/P1/P2 工作、测试验证和证据包路线 |
| `SIL认证软件工程师资料清单.md` | 软件工程师需要使用、采购、申请、维护和产出的资料清单 |

## 维护原则

- 计划状态应区分已具备、待补充、待评审和待认证机构确认。
- 计划中的资料路径应指向本目录或相邻分类目录中的正式维护源。
- 文档和代码检查结果不能表述为已经完成 SIL 认证。
