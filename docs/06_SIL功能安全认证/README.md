# SIL 功能安全认证资料

更新日期：2026-06-30

## 目录用途

本目录用于集中存放 CPU2/CPU3 功能安全、SIL 认证准备、编码规范、偏离记录、模块分级和整改检查相关资料。

当前资料主要服务于 CPU2 后续 SIL2 准备工作，目标路线参考 NMS8x/NMS81 单通道 HFT=0 时可用于最高 SIL 2 应用的做法。这里的文档是认证准备和工程治理资料，不代表已经完成 SIL2 认证。

## 维护原则

- 新增 SIL、功能安全、编码规范和安全模块分级资料优先放入本目录。
- 外部标准、厂商资料和认证机构资料只归档官方公开版本；付费、版权受限或 NDA 资料只记录官方获取路径。
- Markdown 文档默认只保留 `.md`，不自动生成 PDF。
- 如果文档内容涉及实际固件行为、构建配置或测试代码隔离变化，再按项目版本规则评估是否需要升级固件版本。
- 外部 PDF、厂商包和案例资料只作为证据输入；CUBE 自身认证路线、偏离记录、模块分级和整改清单以 Markdown 为维护正文。
