# 流程模板索引

更新日期：2026-06-27

本目录用于保存 Codex 协作时反复使用的轻量流程模板，目标是减少每次重新说明背景、重新追 CPU2/CPU3 链路和重新设计验证步骤的时间。

## 模板清单

| 模板 | 适用场景 |
| --- | --- |
| `CUBE影响面检查表.md` | 参数、协议、菜单、显示、错误码、默认值、单位和版本影响类任务 |
| `故障改动前后对比包.md` | 编码器校验失败、蓝牙通信失败、AO 干扰、样机异常等排故任务 |
| `只读分析方案模板.md` | 用户明确要求“先不改代码”“先出方案”“检查是否存在问题”的任务 |
| `工作日志模板.md` | 每个 Codex 线程结束后记录背景、关键文件、结论和后续动作 |

## 使用规则

- 先判断任务类型，再复制对应模板到本次任务文档或工作日志中填写。
- 只读分析任务不要提前改代码，先填 `只读分析方案模板.md`。
- 故障排查任务优先补齐 `故障改动前后对比包.md`，再判断是否需要改代码。
- 涉及 CPU2/CPU3 共享语义时，同时使用 `CUBE影响面检查表.md`。
- 模板只用于收敛流程，不替代源码、构建、样机和文档证据。
