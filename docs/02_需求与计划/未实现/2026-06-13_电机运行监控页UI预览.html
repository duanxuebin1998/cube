电机运行监控页 UI 预览

优化版：弱化网页装饰，按 CPU3 128x64 小屏的 4 行信息节奏重新排版。

推荐小屏样式

向下运行中 RUN
位置 1250.5 mm
扭力 18.6 kg
返回 停止运动
返回状态页
上无动作
下无动作
确认停止运动

这个版本把页面重心放在 4 行屏幕内容上：状态、位置、扭力、软键动作。网页里的彩色只用于沟通层级，实际 OLED 仍按单色文本落地。

优化原则

位置 推荐显示 原因
第 1 行 直接显示设备状态第一行，例如“向下运行中” 不再额外加标题，避免小屏浪费空间，也和状态页口径一致。
第 2 行 位置 + 右侧数值 + 单位 用固定标签宽度和右对齐数值，读数变化时不显得跳。
第 3 行 扭力 + 右侧数值 + 单位 和位置行形成相同节奏，现场扫一眼就能比较趋势。
第 4 行 返回 / 停止运动，确认页改为返回 / 确认停止 底行只放软键语义，不再混入状态说明。

我建议采用的改法

  • 运行监控页保留当前 4 行结构，但让位置、扭力的数值列固定，减少“乱”的感觉。
  • 停止确认页不要只显示一句话，继续显示位置和扭力，用户确认时还能看见电机当前状态。
  • 底部右侧统一用动作词：运行页“停止运动”，确认页“确认停止”，停止中“停止中”。
  • 完成态可以短暂停留 1 到 2 秒显示“运行完成”，再自动返回状态页。

固件同步点

当前优化版已同步到 CPU3 固件：display_tankopera.c 已将运行页和停止确认页统一为状态、位置、扭力、软键四行节奏，并让位置和扭力数值从固定列开始显示。

适用命令

仍只针对 CMD_RUN_TO_POSITION、CMD_MOVE_UP、CMD_MOVE_DOWN、CMD_FORCE_MOVE_UP、CMD_FORCE_MOVE_DOWN。找油、找水、找底、单点、分布、密度区间、瓦锡兰密度流程等业务命令不进入本页。

边界

这里的停止仍是受控慢停，不应标成“急停”。真正急停需要独立的硬件断能、驱动禁用、恢复流程和故障记录策略。
