电机运行类指令一键停止方案

日期：2026-06-13 | 状态：CPU3 已落地初版，待硬件联调 | 范围：CPU3 UI、CPU2 已有取消命令复用、电机停止语义、外部协议口径

结论

推荐保持现有电机运行指令入口不变：用户仍在原有命令页下发纯电机指令，包括运行到指定位置、上行、下行、强制上行、强制下行。上述指令下发成功后不返回状态页，而是自动进入新的电机运行监控页。

运行监控页实时显示电机运行位置和扭力值，并提供“一键停止当前运动”。纯电机指令自然完成、停止完成或取消完成后，CPU3 再自动切回状态页。

“一键停止”仍定义为“停止当前动作”的受控停止功能，底层复用现有 CMD_CANCEL_MEASUREMENT = 16 语义，由 CPU2 统一取消当前命令、停止电机并回到待机。UI 上不使用“急停”字样，避免把受控慢停误认为安全急停。

页面沟通原型见同目录 2026-06-13_电机运行监控页UI预览.html，用于确认小屏布局、按键提示和运行/停止/完成状态文案。

落地状态

CPU3 已实现 已在 LTD_DISPLAY_CPU3/Application/display/display_tankopera.c 增加电机运行监控页，指令下发成功后按命令类型决定是否进入该页。

入口不变 电机运行指令仍在原有命令页下发，不新增“电机控制”单独页面。

范围收敛 仅 CMD_RUN_TO_POSITION、CMD_MOVE_UP、CMD_MOVE_DOWN、CMD_FORCE_MOVE_UP、CMD_FORCE_MOVE_DOWN 进入监控页，其它测量或业务命令保持原退出策略。

停止复用 监控页“停止运动”确认后仍下发 CMD_CANCEL_MEASUREMENT，CPU2 复用既有取消当前命令与慢停逻辑。

待硬件联调 本地已通过 CPU3 构建验证；仍需台架确认运行态刷新、自然完成返回状态页、停止后不继续跑到原目标。

设计目标

操作目标

现场人员沿用原有命令页下发纯电机运行或强制运动指令，随后自动进入运行监控页；监控页持续显示设备状态第一行、位置和扭力，并提供停止运动入口。

安全目标

停止动作必须由 CPU2 主循环统一执行，CPU3 只下发命令，不直接改 CPU2 状态机或 TMC5130 寄存器。

兼容目标

优先复用既有保持寄存器中的 command 字段和 CMD_CANCEL_MEASUREMENT，避免新增 CPU2/CPU3 共享协议。

推荐方案

层级 方案 说明
CPU3 UI 沿用原有命令页，新增“电机运行监控页” 运行到指定位置、上行、下行、强制上行、强制下行仍在原有命令页下发；CPU3 下发这些纯电机指令成功后自动进入运行监控页，监控页显示设备状态第一行、运行位置、扭力值和停止运动入口。
CPU2 命令 复用 CMD_CancelMeasurement() 取消自动恢复、清当前命令、清错误码、调用 MotorCtrl_SlowStop()，最后切到待机。
电机动作 使用受控慢停 MotorCtrl_SlowStop() 下发停止并等待 RAMPSTAT.VZERO，不是直接断能。
外部协议 后续统一 STOP 语义 SI7000 当前 STOP 线圈映射到维护模式，建议后续评估是否改为同样下发取消当前动作，或区分 Manual 与 Stop。

UI 交互设计

入口
不新增单独电机控制菜单；运行到指定位置、上行、下行、强制上行、强制下行仍从原有命令页下发。
命令下发后
用户在原有命令页确认下发上述纯电机指令后，CPU3 写入对应命令并立即切到运行监控页，不先返回状态页。
运行监控页
第一行直接复用设备状态页第一行，例如“向下运行中”“运行到指定位置中”；下面显示当前位置、扭力值和停止运动入口。
一键停止
运行监控页底部确认项使用“停止运动”，避免“停止”二字含义不清。触发确认页时文案为“停止当前运动?”，确认后下发 CMD_CANCEL_MEASUREMENT。
自动返回
监控页轮询 CPU2 当前命令和设备状态。运动自然完成、停止完成或取消完成后，显示“已完成”或“已停止”，短暂停留后自动切回状态页。

界面文案建议

  • 入口：沿用原有电机运行和强制运动指令页面
  • 监控页标题：电机运行中
  • 第 1 行：复用设备状态页第一行
  • 监控数据显示：位置、扭力
  • 监控页操作：停止运动
  • 确认页标题：停止当前运动?
  • 确认键提示：确认停止
  • 返回键提示：返回
  • 执行中提示：正在停止...
  • 完成提示：已停止

控制对象

电机运行命令仍按原有命令页权限和状态判断下发。运行监控页只跟踪本次纯电机控制指令，停止运动入口只在“当前运动可停止”时可用。

类别 处理方式 理由
运行类指令 进入运行监控页：CMD_RUN_TO_POSITION、CMD_MOVE_UP、CMD_MOVE_DOWN 这是本需求重点，用户应能直接停止当前电机运动。
强制运动 进入运行监控页：CMD_FORCE_MOVE_UP、CMD_FORCE_MOVE_DOWN 强制动作风险更高，停止入口应更容易触达，但仍需要确认。
普通测量/业务流程 不进入运行监控页：找油、找水、找底、单点、分布、密度区间、瓦锡兰密度流程等 这些流程可能内部触发电机动作，但它们不是用户直接下发的纯电机指令，仍按原业务状态页、测量流程和取消策略处理。
维护/手动 暂不纳入：CMD_MAINTENANCE_MODE 或手动运行态 维护模式是否退出、是否停止当前动作需要单独定义，避免和本次纯电机运行监控页混在一起。

实现拆分

步骤 改动点 验收口径
1 CPU3 保持原有电机运行指令入口，仅纯电机指令下发成功后跳转到运行监控页。 不新增单独电机控制菜单；CMD_RUN_TO_POSITION、CMD_MOVE_UP、CMD_MOVE_DOWN、CMD_FORCE_MOVE_UP、CMD_FORCE_MOVE_DOWN 能正常下发并进入监控页。
2 运行监控页第一行复用设备状态页第一行，下方显示当前位置和扭力值。 监控页第一行和状态页一致，例如“向下运行中”“运行到指定位置中”。
3 运行监控页底部确认项从“停止”优化为“停止运动”。 用户能明确知道确认键会停止当前电机运动，而不是退出页面。
4 停止操作复用确认页和 Display_RequestCancelMeasurement()，确认后写 CPU2 命令寄存器。 从运行监控页下发的停止命令仍为 CMD_CANCEL_MEASUREMENT。
5 运行监控页检测纯电机指令完成、停止完成或取消完成后自动切回状态页。 自然完成和用户停止都能从监控页收敛回状态页，不需要用户手动返回。
6 CPU2 检查所有运行类循环是否持续调用命令切换检查。 运行到位置、点动、强制运动过程中收到 CMD_CANCEL_MEASUREMENT 能及时退出并慢停。
7 补充调试日志和测试方案，区分用户停止与故障停机。 用户主动停止不进入最终报错，不把取消动作记成故障。

协议与版本影响

推荐方案 不新增保持寄存器、不新增命令枚举、不改变 DeviceParameters 布局时，通常不需要升级 DEVICE_PROTOCOL_VERSION。

需要评估 如果后续把外部协议 STOP 线圈从维护模式改为取消当前动作，属于外部协议行为变化，应同步更新 SI7000 映射文档、联调检查表和版本测试方案。

固件版本 本次初版仅改变 CPU3 UI 行为并复用 CPU2 已有取消命令，未新增 CPU2 协议或寄存器；合入版本时需要评估 CPU3 固件版本，CPU2 无新增改动则不单独升版。

风险与边界

不能把本功能称为急停

当前推荐路径是 MotorCtrl_SlowStop()，属于受控停止。真正急停需要独立设计硬件断能、驱动禁用、恢复流程和故障记录策略。

风险 规避方式
CPU3 只改 UI，CPU2 运行循环没有响应命令切换 实现时逐个检查运行到位置、点动、强制运动和调试路径的 HasEffectiveCommandSwitchRequest() 或停机封装调用。
用户停止被当成故障记录 取消命令返回值按用户动作处理，不进入最终报错；停止失败才记录告警或故障。
SI7000 STOP 与本机 UI STOP 语义不一致 短期文档说明差异；后续按外部协议需求统一 Manual 与 Stop 的映射。
停止后位置源或目标残留影响下一次运动 沿用电机停止后的目标对齐、状态刷新和速度恢复逻辑；必要时补充台架验证。

验证建议

  • 在原有电机运行指令页选择运行到指定位置、上行、下行、强制上行、强制下行，不新增单独电机控制页。
  • 上述纯电机指令下发成功后，CPU3 不返回状态页，而是自动进入电机运行监控页。
  • 找油、找水、找底、单点、分布、密度区间、瓦锡兰密度流程等业务命令不进入运行监控页。
  • 运行监控页第一行复用设备状态页第一行，并持续刷新当前位置和扭力值。
  • 在运行监控页选择停止并确认后，CPU2 收到 CMD_CANCEL_MEASUREMENT，电机慢停并回待机。
  • 纯电机指令自然完成后，运行监控页自动切换到状态页。
  • CMD_RUN_TO_POSITION 运行过程中停止，确认不会继续跑到原目标。
  • CMD_MOVE_UP、CMD_MOVE_DOWN、强制上/下行过程中停止，确认停止后速度恢复为参数速度。
  • 停止过程中连续按键不会重复下发导致状态错乱。
  • 停止不是故障：CPU2 不应留下最终错误码，CPU3 状态页不显示故障原因。
  • 电机停止失败或通信异常时，有清晰的提示和日志，不静默失败。

当前代码依据

LTD_MAIN_CPU2/Services/ParamStorage/system_parameter.h：已有 CMD_CANCEL_MEASUREMENT = 16。

LTD_MAIN_CPU2/Application/Src/measure.c：已有 CMD_CancelMeasurement()，会取消自动恢复、清命令/错误码、调用 MotorCtrl_SlowStop() 并回待机。

LTD_DISPLAY_CPU3/Application/display/display.c：现有长按返回取消页可作为确认页和绘制逻辑参考，但本方案不再把状态页作为主要控制入口。

LTD_DISPLAY_CPU3/Application/display/display_tankopera.c：已有菜单框架和 Display_RequestCancelMeasurement()，可复用其下发 CMD_CANCEL_MEASUREMENT 的能力。

LTD_DISPLAY_CPU3/Communication/external/si7000_modbus/si7000_modbus_slave.c：SI7000 STOP 当前映射到 CMD_MAINTENANCE_MODE，后续需要单独评估是否统一。
