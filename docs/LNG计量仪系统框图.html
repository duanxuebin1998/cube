阅读口径

本图按“现场能接线、开发能定位、联调能追数据”的口径整理。CPU3 是显示和外部通讯入口，CPU2 是测量控制和底层硬件控制入口；两板之间用内部 Modbus RTU 同步参数、命令、状态和测量结果。

CPU3 显示通讯板 CPU2 主控测量板 外部主站或现场设备 安全、恢复、维护链路

整机系统框图

CPU3 是入口层

外部主站和现场人员主要接触 CPU3。CPU3 负责协议选择、串口参数归一化、屏幕显示、菜单参数写入，并通过内部链路把命令和参数同步到 CPU2。

CPU2 是执行层

CPU2 承担测量流程、电机控制、传感器读取、参数 FRAM 持久化、故障自动恢复和运行态结果发布，是所有实际动作的最终执行端。

共享协议是边界

固件版本只用于显示和追踪；CPU2/CPU3 是否兼容以 DeviceParameters.protocolVersion 严格相等为准，当前为协议版本 12。

硬件框图

两块板卡主控均为 STM32F429ZGTx。CPU3 侧负责显示、按键、外部 COM 口和到 CPU2 的内部 485；CPU2 侧负责电机驱动、编码器、传感器链路、HART/4-20mA、FRAM、继电器和电源检测。

板卡 硬件模块 MCU 接口/主要引脚 用途
CPU3 OLED 显示 SPI1：PA4/PA5/PA6/PA7；控制脚 PA2 OLED_D/C、PF5 OLED_NREST 状态页、菜单、故障页和维护操作显示。
CPU3 按键和拨码 PF1/PF2/PF3/PF4 为 DOWN/SURE/BACK/UP；ADDRESS0~7、MODE0~3 为 GPIO 输入 现场菜单操作、地址配置和模式选择。
CPU3 外部 COM 口 COM1 = USART6 PC6/PC7 + PB9；COM2 = USART2 PD5/PD6 + PB8；COM3 = USART3 PD8/PD9 + PB12 外部 DSM、Wärtsilä、LTD、SI7000 等协议入口。
CPU3 CPU2 内部 485 UART5 PC12/PD2 + PG5 MAIN_BOARD_485_SEL CPU3 作为主站轮询 CPU2，读输入寄存器、写保持寄存器。
CPU3 本机 FRAM SPI4 PE11/PE12/PE13/PE14 保存 COM 配置、显示配置和本机参数缓存。
CPU2 CPU3 内部 485 UART5 PC12/PD2 + PC13 CPU2_485_SEL CPU2 作为内部 Modbus 从站，发布参数、状态和测量结果。
CPU2 电机驱动 SPI2 PB12/PB13/PB14/PB15 连接 TMC5130；PD10 DRV_ENN；PA4 MOTOR_IREF 控制电机运动、速度和电流；启动阶段通过禁用驱动和早期停机清除旧目标。
CPU2 编码器 SPI5 PF6/PF7/PF8 连接 AS5145，RX only；TIM1 周期采样 读取编码轮角度，维护尺带位置和运动门控。
CPU2 传感器/无线滑环链路 USART6 PC6/PC7，默认 9600；PG8 SENSOR_ENN 连接探头传感器和 CH9141K 无线滑环透传链路，维护命令可执行最近匹配。
CPU2 4-20mA 与 HART AD5421：SPI3 PB3/PB4/PB5 + PB6 CS + PB8 FAULT；HART：USART2 PD5/PD6，PB7 RTS 模拟电流输出、故障电流和 HART 通信。
CPU2 电源检测和继电器 PC2/PC3 为 24V/12V ADC；PG9~PG12 为 RELAY1~4 输出；NC/NO 反馈为 GPIO 输入 监测供电和继电器状态，支持现场输出和安全诊断。
CPU2 本机 FRAM SPI4 PE11/PE12/PE13/PE14 保存设备参数、CRC、协议版本迁移后的默认值和持久化运行参数。

CPU2/CPU3 数据闭环

数据对象 主要方向 用途 维护重点
DeviceParameters CPU3 写入，CPU2 保存和执行；CPU2 也发布当前参数 设备参数、算法参数、输出参数、协议版本和共享命令字段 参数单位、signedness、范围、默认值或语义变化时，需要同时检查 CPU2/CPU3 结构、寄存器映射、菜单元数据和协议版本。
MeasurementResult CPU2 生成，CPU3 读取 设备状态、错误码、当前命令、液位/水位/密度/探底结果、无线滑环匹配结果等运行态数据 字段新增或顺序变化会影响输入寄存器布局；CPU2/CPU3 两端字段顺序必须一致。
command CPU3 或外部协议写入 CPU2 触发回零、找液位、单点测量、分布测量、标定、无线滑环匹配等动作 新增共享命令属于协议可见变化，需评估并更新 DEVICE_PROTOCOL_VERSION。
protocolVersion CPU2 发布，CPU3 判断 判断 CPU2/CPU3 共享协议是否兼容 当前协议版本为 7；固件版本号不参与兼容判断。

外部接口与协议适配

协议/接口 所在层 整理后的定位 注意事项
DSM V1.228 CPU3 外部 Modbus 面向 PLC/上位机的外部协议兼容层，读取状态、结果、参数并通过线圈触发命令。 内部状态不能简单等同 DSM 状态，必要时由 CPU3 做状态码翻译。
SI7000 CPU3 外部协议层 将 SI7000 所需地址、状态位、线圈、缩放和异常响应映射到 CUBE 内部模型。 串口配置选择 SI7000 后自动收敛到 9600 8O1，避免菜单组合出 PLC 不兼容配置。
Wärtsilä CPU3 外部协议层 面向瓦锡兰密度梯度、分布测量和测后探底场景。 外部流程依赖 CPU2 内部测量状态和密度分布结果。
内部 Modbus RTU CPU3 与 CPU2 之间 CPU3 读写 CPU2 的共享保持/输入寄存器，是两板唯一稳定数据边界。 使用协议版本判断兼容性；共享字段变化必须两端同步。

测量执行链路

命令类别 典型命令 执行模块 结果发布
基础测量 回零、找液位、找水位、找罐底、单点测量、综合测量 CPU2 测量状态机、电机控制、传感器采样 设备状态、错误码、液位/水位/实高/密度等结果写入输入寄存器。
密度分布 普通分布、国标分布、每米密度、区间密度、瓦锡兰密度区间 CPU2 分布测量流程，CPU3 外部协议按需重排或缩放 支持最多 200 个内部密度点；外部协议按自身地址表发布。
维护和调试 强制上行、强制下行、标定、匹配无线滑环；命令 115 保留 CPU2 调试/维护分支，命令 115 不再提供菜单入口或执行电机动作 状态页显示维护、调试、匹配中/完成；失败时保持故障页错误码。

启动安全与故障恢复链路

安全链路关注的是“先确定硬件不会继续旧运动，再允许软件业务命令”。如果机械结构不能自锁，禁用驱动会取消保持电流，台架和现场需要单独确认负载不会产生危险位移。
