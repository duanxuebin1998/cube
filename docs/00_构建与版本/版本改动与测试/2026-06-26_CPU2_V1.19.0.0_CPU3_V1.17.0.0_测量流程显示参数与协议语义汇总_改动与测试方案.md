# CPU2 V1.19.0.0 / CPU3 V1.17.0.0 测量流程、显示参数与协议语义汇总改动与测试方案

日期：2026-06-26

## 版本变化

- CPU2：`V1.18.1.1 -> V1.19.0.0`。
- CPU3：`V1.16.1.1 -> V1.17.0.0`。

## 协议版本/兼容性

- `DEVICE_PROTOCOL_VERSION`: `11 -> 12`。
- 共享命令 `115` 从原强制提零点执行命令改为 `CMD_RESERVED_CMD7`。
- 设备状态 `0x002F`、`0x802F` 改为保留状态，不再作为强制提零点运行/完成状态发布或显示。
- 不新增、不移动 CPU2/CPU3 共享寄存器地址；本次协议升级原因是跨 CPU 共享命令和状态语义发生变化。
- CPU2/CPU3 必须同为协议版本 12；协议版本 11 的 CPU2/CPU3 可能仍存在命令 115 强制提零点语义或菜单入口，不建议混用。

## 参数存储兼容性

- CPU2 `DEVICE_PARAM_VERSION`: `3 -> 3`。
- `DeviceParameters` 结构大小：不变。
- 升级是否清参数：否。
- CPU3 本机显示/通信参数存储版本保持 `0x0004`，结构大小不变。
- Wartsila 旧默认串口参数在 CPU3 加载本机参数时迁移：旧默认 `4800 8N1/8N2` 迁移为新默认 `2400 8E1`；用户手动修改过的非默认参数不强制覆盖。
- 现场动作：正常升级即可；如 FRAM A/B 分区本身 CRC、magic、版本或结构大小校验失败，仍按既有异常流程恢复出厂参数。

## 本次改动点

- CPU2 删除 `CMD_ForceLiftZero()` 执行入口，收到命令 115 时按保留/未知指令处理，不启动电机。
- CPU3 删除强制提零点菜单项、无参命令映射、电机运行监控归类和状态页文案。
- 新增 `tools/check_reserved_cmd7_contract.py`，检查 CPU2/CPU3 命令 115 和状态 `0x002F/0x802F` 均保持保留语义。
- 修复修正液位和水罐高度标定的 `0.1mm` 固定偏差，不再在标定反算中追加固定 `+1`。
- CPU3 Wartsila 默认串口参数调整为 2400 8E1，并同步 CubeMX `.ioc` 和 UART 初始化默认值。
- 读取部件参数增加当前蓝牙连接 MAC 显示；CPU2 发布连接 MAC 快照，CPU3 参数页显示 `MAC:AABBCCDDEEFF` 或 `MAC N/A`。
- CPU3 增加电机电流 IRUN 档位选择和 RMS 电流显示，支持 1..31 档位配置。
- 中文业务口径统一为“液位”“扭力”，保留 `oilLevel`、`weight`、寄存器名等协议和代码标识符；CPU3 字库补充“扭”字。
- 梳理浮子运动和停机流程，删除电机运行监控中特定“停止当前运动?”二次确认分支，保留通用取消测量入口。
- 同步程序流程文档、协议记录、参数菜单文档、说明书资料、README 索引和相关契约脚本。

## 影响范围

- 影响 CPU2 共享命令分发、强制动作状态定义、液位/水位标定计算和读取部件参数快照。
- 影响 CPU3 参数菜单、状态页文案、Wartsila 默认串口参数、读取部件参数显示、电机电流档位显示和字库。
- 影响协议版本 12 的跨 CPU 兼容判断，旧版本 CPU2/CPU3 不应与本版本混用。
- 不影响 CPU2 参数存储结构、CPU3 本机参数存储结构、保持寄存器地址和输入寄存器长度。

## 重点测试点

| 测试项 | 前置条件 | 步骤 | 预期结果 | 通过标准 |
| --- | --- | --- | --- | --- |
| 命令 115 保留 | CPU2/CPU3 均为协议 12 | 通过调试或异常路径尝试下发命令 115 | CPU2 不启动电机，只按保留/未知命令处理 | 无电机动作，无强制提零点状态 |
| CPU3 菜单无强制提零点 | CPU3 正常显示 | 遍历操作菜单和状态页 | 无强制提零点入口和运行/完成文案 | 菜单不能下发命令 115 |
| 取消测量停机 | CPU2 正在测量或电机运行 | 长按返回触发取消测量 | CPU2 停止电机并回到待机或取消状态 | 通用取消入口不受删除强制提零点影响 |
| 修正液位无固定偏差 | 已知缆长和标定真值 | 执行修正液位，读取反算罐高或结果 | 不再额外增加 `0.1mm` | 结果与 `current_cable_length + calibrateOilLevel` 一致 |
| 水位标定无固定偏差 | 已知缆长和水位标定真值 | 执行水位标定，读取 `water_tank_height` | 不再额外增加 `0.1mm` | 结果与 `current_cable_length + calibrateWaterLevel` 一致 |
| Wartsila 新默认参数 | CPU3 恢复默认或旧默认 FRAM 参数 | 加载本机参数并检查 COM 配置 | Wartsila 默认通信为 2400 8E1 | 默认值和 UART 初始化一致 |
| Wartsila 手动参数保留 | CPU3 已保存非默认通信参数 | 升级后加载本机参数 | 非默认手动参数不被强制覆盖 | 现场手动配置保持 |
| 读取部件 MAC 显示 | CPU2 已连接蓝牙从机 | 执行读取部件参数并进入 CPU3 参数页 | 显示 `MAC:AABBCCDDEEFF` | MAC 与 CPU2 当前连接一致 |
| 读取部件无连接显示 | CPU2 无有效蓝牙连接 | 执行读取部件参数并进入 CPU3 参数页 | 显示 `MAC N/A` | 不显示残留旧 MAC |
| 电机电流档位 | CPU3 参数菜单可编辑 | 选择 IRUN 1、16、31 并保存 | RMS 电流显示和档位匹配 | 写入、显示和读回一致 |
| 中文口径和字库 | CPU3 正常显示 | 浏览参数页、状态页和扭力相关页面 | “扭力”“液位”显示完整 | 无缺字、越界和旧误导文案 |
