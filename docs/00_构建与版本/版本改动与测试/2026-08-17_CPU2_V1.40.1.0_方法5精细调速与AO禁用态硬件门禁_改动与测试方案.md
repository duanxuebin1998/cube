# CPU2 V1.40.1.0 方法5精细调速与AO禁用态硬件门禁改动与测试方案

## 1. 文档目的和适用版本

本文记录CPU2 `V1.40.0.0 -> V1.40.1.0`的两项问题修复：方法5在液面附近的精细连续调速，以及AO禁用态对AD5421硬件访问的完整门禁。本文用于代码复核、台架测试和提交范围核对，不把静态检查或构建结果表述为目标板验证。

适用组合：CPU2 `V1.40.1.0`、CPU3 `V1.40.0.0`、共享协议34。

## 4. 详细改动

### 4.1 方法5在首次换向后进入精细调速

- 源码位置：`measure_oilLevel.c`的`FrequencyLevel_RunClosedLoopConfigured()`和`FrequencyLevel_ComputeFineSpeedMMin()`。
- 改前问题：方法5接近目标频率后仍受常规`0.01 m/min`速度分辨率限制；液面反馈约4秒一轮时，最小步幅偏大，容易在死区两侧反复越过。
- 具体改法：首次搜索记录初始方向，第一次跨越目标并换向后锁存精细模式；持续跟随从入口即使用精细模式。死区外速度按`0.0007 + (0.1000 - 0.0007) * ratio^2`计算，`ratio=(|频差|-死区)/450`并限制到`0~1`。
- 必查边界：死区内返回0并慢停；死区外最小速度不低于`0.0007 m/min`；频差达到死区外450 Hz后不超过`0.10 m/min`；首次搜索在尚未换向时仍保留常规速度。
- 通过标准：曲线单调、边界限幅正确；16 Hz死区示例中55 Hz绝对频差对应约`0.001446 m/min`，4秒理论位移小于`0.1 mm`。

### 4.2 精细速度运动入口保持原安全前置条件

- 源码位置：`motor_ctrl.h`和`motor_ctrl_motion_api.c`的`MotorCtrl_StartFineVelocity()`。
- 改前问题：既有速度接口使用`m/min x100`整数，无法表达液面附近所需的千分之一米每分钟以下速度。
- 具体改法：新增浮点线速度入口，校验方向、正速度和设备最大速度，随后依次执行命令切换、驱动就绪、驱动健康、位置同步、线速度换算和JOG启动；运动显示状态仍由原统一接口发布。
- 必查边界：非法方向、速度0、负速度、超过最大速度、位置未就绪、驱动故障、速度换算为0和命令切换。
- 通过标准：合法精细速度能转换为非零驱动速度并启动；任一前置门禁失败时不启动运动并返回原错误码。

### 4.3 低速失步门限按适用范围启用

- 源码位置：`measure_oilLevel.c`的`FrequencyLevel_CheckMotionGuards()`和`FrequencyLevel_ReadCurrentWithGuards()`。
- 改前问题：现有失步检测以`0.5 mm/s`为最小速度门限；精细速度低于`0.03 m/min`时，实际期望速度低于该门限，继续套用会形成确定性误报。
- 具体改法：精细速度低于`0.03 m/min`时只跳过`MotorCtrl_CheckLostStepAutoTiming()`；位置刷新、罐高/盲区、称重通信、满载/罐底、碰撞、传感器读取和命令切换仍执行。速度达到阈值或处于常规速度模式时恢复失步检测。
- 必查边界：`0.0299`和`0.0300 m/min`两侧；跳过失步检测时的碰撞、位置越界和称重故障；精细模式退出后的门禁恢复。
- 通过标准：低于阈值不因旧速度门限误报失步，其他安全出口仍能停止并传播原错误；达到阈值后失步检测重新执行。

### 4.4 AO禁用态不访问AD5421

- 源码位置：`ao_output.c`的`AoOutput_EnterDisabledState()`、`AoOutput_Init()`和`AoOutput_UpdateInternal()`。
- 改前问题：AO工作模式为禁用时仍可能初始化AD5421、轮询诊断或写入名义禁用电流；在未安装、断环或故障硬件上会产生无意义SPI访问和故障副作用。
- 具体改法：上电即禁用或运行中切到禁用时，先清驱动就绪/重试、诊断节拍、恢复状态、写入尝试和仿真状态，再在临界区清待处理诊断事件；运行态发布`AO_OUTPUT_SOURCE_DISABLED`、名义目标、最近实发0、无驱动故障、无有效回读，并直接返回。
- 必查边界：上电禁用、启用后切禁用、禁用期间周期刷新、禁用期间电流修正非0、禁用后重新启用、AD5421开路和故障状态残留。
- 通过标准：禁用期间SPI上没有AD5421初始化、诊断或写入帧；最近实发为0、回读无效、故障状态清除；重新启用后按原驱动初始化和恢复路径工作。

## 5. 数据流和异常闭环

方法5链路为：目标频率/死区配置 -> 当前频率 -> 方向与精细速度计算 -> 电机就绪/健康/位置同步 -> 连续运动 -> 位置/称重/碰撞/适用范围内失步检查 -> 死区稳定或错误出口。换向前先慢停，任何启动、停止或保护错误都由`FrequencyLevel_StopAndReturn()`停止并返回。

AO链路为：AO配置快照 -> 工作模式判断。禁用分支只更新CPU2运行态并返回；启用分支才进入AD5421就绪、诊断、恢复、目标选择、修正、写入和结果发布。该分支顺序保证禁用时不会先产生硬件访问再退出。

## 9. 风险与未验证项

- 尚未验证真实机械系统在`0.0007 m/min`附近能否克服静摩擦，或驱动换算后的最小非零速度是否产生爬行；需要电机、卷筒和实际缆带负载台架。
- 低于`0.03 m/min`时有意跳过旧失步判据；位置、称重和碰撞保护仍在，但极低速真实失步需要后续建立适用的独立判据。
- 尚未用逻辑分析仪证明禁用态SPI绝对静默，也未验证从禁用重新启用时AD5421电气状态和4-20mA环路恢复。
- 未执行目标板、FRAM掉电、RS485、长期运行、现场或SIL验证。静态检查和构建只证明代码形状与可编译链接。
