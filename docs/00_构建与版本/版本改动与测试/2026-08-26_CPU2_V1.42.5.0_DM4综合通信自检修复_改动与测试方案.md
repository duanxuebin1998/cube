## 4. 逐项改动清单

### 4.1 SC先监听V4主动帧再按需查询蓝牙

- 源码位置：`service_debug_command.c`的`SensorWireless_CommTest()`；调用链为串口`SC` -> `SensorService_Detect()` -> V4主动监听 -> 必要时蓝牙AT查询 -> 透传恢复后再次监听 -> 交互协议识别。
- 改前问题：`SC`在调用统一识别流程前额外执行一次`WirelessPairing_CheckBluetoothLink()`。V4主动DMA已经占用UART6时，蓝牙AT查询无法取得链路所有权并返回`0x000D0021`，随后统一识别却能通过主动帧识别成功，形成同一轮测试先报蓝牙异常再报传感器正常的矛盾结果。
- 具体改法：删除`SC`入口的重复蓝牙查询和只为该查询服务的停止辅助函数；`SC`直接调用`SensorService_Detect()`，由识别流程统一保证“主动监听优先、未命中才查蓝牙、恢复透传后再监听”的顺序。
- 必查边界：查询前主动帧命中、查询前监听超时、蓝牙已连接、蓝牙未连接、AT查询失败、透传恢复后主动帧命中、主动帧两次未命中后V4/V3/DSM交互回退及命令切换。
- 通过标准：主动帧命中时本轮不进入蓝牙AT查询且不出现`0x000D0021`；主动帧未命中时仍打印蓝牙链路检查和透传恢复后监听阶段；协议识别结果及原始探测包保持可观察。

### 4.2 空气中DM4密度无效不计通信故障

- 源码位置：`service_debug_command.c`的`SensorWireless_CommTest()`；调用链为DM4识别 -> 切换密度模式 -> `SensorService_ReadDensity()` -> `SC`结果计数和日志。
- 改前问题：DM4位于空气中时可能返回R04为0、R07为NaN。8字节请求、应答和校验均成功，但协议层以`SENSOR_DATA_STALE`表示当前密度无有效值，旧`SC`通过通用结果函数把它计为通信失败并打印`0x000D0024`。
- 具体改法：仅当返回值为`SENSOR_DATA_STALE`且当前V4通信方式为交互模式时，`SC`增加成功计数并打印“交互通信正常，当前密度无有效值（空气中允许）”；不写频率、密度和温度输出，也不改变协议驱动及正式测量接口的返回值。
- 必查边界：交互模式有效密度、交互模式R07为NaN、交互模式其它通信或格式错误、主动模式快照过期、主动模式无密度新数据、传感器模式不匹配和密度模式切换失败。
- 通过标准：交互模式R04为0、R07为NaN时`SC`该项打印`[正常]`且失败计数不增加；主动上报超时及其它错误仍打印`[异常]`和原错误码；正式测量流程仍能收到`SENSOR_DATA_STALE`。

## 5. 数据流和异常闭环

- 识别链路：`SC` -> `SensorService_Detect()` -> 首次V4主动监听；未命中后才执行蓝牙链路查询，恢复透传后再次监听，最后进入R01/V3/DSM交互探测。
- 密度链路：DM4识别成功 -> `SensorService_EnableDensityMode()` -> `SensorService_ReadDensity()`；有效结果按原格式打印，交互模式空气密度无效只改变调试汇总，主动超时和其它错误仍进入通用失败记录。
- 本次不修改传感器驱动、错误码、全局故障状态、正式测量状态机、CPU2/CPU3共享数据或参数存储。

- 预期与通过标准：首次主动帧命中后直接完成V4识别，不打印蓝牙AT查询异常，不出现`0x000D0021`。

### T02 V4交互模式空气探头

- 前置条件：DM4处于交互通信，探头在空气中；确认R04为0、R06为有限温度、R07为NaN。
- 步骤：执行`SC`并保存R02/R04/R06/R07原始应答和最终汇总。
- 预期与通过标准：模式切换和8字节交互校验成功；密度读取打印`[正常]`及“当前密度无有效值（空气中允许）”，失败数不因`0x000D0024`增加。
- 执行状态：现场原始帧已证明R04为0、R06为27.61、R07为NaN；V1.42.5.0目标板汇总尚未复测。

### T03 V4交互模式有效介质

- 前置条件：DM4浸入可形成有效密度的稳定介质，处于交互通信。
- 步骤：执行`SC`，记录频率、密度、温度和汇总。
- 预期与通过标准：三项值通过范围检查并按原格式输出；成功计数增加且不进入空气无效提示分支。
- 执行状态：未执行，缺少本轮真实介质台架。

### T04 主动流超时和其它错误保持失败

- 前置条件：分别制造主动帧超时、8字节应答超时、校验失败或模式不匹配。
- 步骤：执行`SC`并记录错误码和汇总计数。
- 预期与通过标准：主动模式`SENSOR_DATA_STALE`及其它错误仍打印`[异常]`，保留原错误码并增加失败数，不被空气无效特例吞掉。
