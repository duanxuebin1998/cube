# CPU2 V1.20.3.0 / CPU3 V1.18.2.0 AS5145 错误重试与提交门禁整理改动与测试方案

日期：2026-07-01

## 版本变化

- CPU2：`V1.20.2.0 -> V1.20.3.0`。
- CPU3：`V1.18.2.0` 保持不变。
- 升级级别：CPU2 `patch`。
- 升级原因：调整 AS5145 编码器 SSI 错误重试和持续故障上报策略，并整理提交标题版本号门禁、文档资料和索引。

## 协议版本/兼容性

- `DEVICE_PROTOCOL_VERSION`：保持 `13`。
- 本次不新增共享命令、共享寄存器、输入寄存器长度或跨 CPU 状态字段。
- CPU2 对外错误码字段不变，仍通过现有 `g_measurement.device_status.error_code` 上报编码器错误。
- CPU3 固件行为不变，可继续使用 `V1.18.2.0`；提交标题按仓库规则同时标注 CPU2/CPU3 版本。

## 参数存储兼容性

- CPU2 `DEVICE_PARAM_VERSION`：`3 -> 3`。
- `DeviceParameters` 结构大小：不变。
- 升级是否清参数：否。
- FRAM A/B 分区地址、`magic`、`struct_size`、`param_version`、`crc` 校验规则不变。
- CPU3 本机参数存储版本保持 `0x0005`，本机 FRAM 布局不变。
- 现场动作：不需要因本次版本恢复出厂或重新下发全量参数；建议升级后重点复核编码器异常恢复和持续故障日志。

## 本次改动点

- CPU2 AS5145 SSI 错误处理改为前 3 次错误立即重试，超过阈值后只记录一次持续故障详情。
- CPU2 持续编码器错误不停止 TIM1，也不阻断后续定时采样；后续有效帧恢复后自动清除编码器错误状态。
- CPU2 有效帧门控改为单帧完整解析且无协议错误后即标记首个可信位置，避免连续有效帧门控导致上电后可用位置迟滞。
- CPU2 清理编码器错误诊断中未使用的统计计数和原始帧缓存，减少中断路径共享状态。
- CPU2 SPI busy 和 DMA 启动失败路径记录编码器超时错误和诊断输出，不再递归进入 SSI 错误重试流程。
- 新增 `tools/check_commit_subject_versions.py`、`tools/test_check_commit_subject_versions.py` 和 `tools/git-hooks/commit-msg`，提交标题按路径范围校验 CPU2/CPU3 固件版本号。
- 更新 `.gitattributes`、`AGENTS.md` 和版本测试 README，明确本地 hooksPath、提交标题版本号和推送前检查要求。
- 整理 SI7000 进一步兼容需求、CPU2 全局错误响应滞后分析、LNG 菜单核对资料和 SIL 外部资料索引。

## 影响范围

- CPU2 AS5145 编码器采样、错误重试、持续故障日志和首个可信位置判定。
- CPU2 编码器异常恢复：断线、空帧、校验失败、OCF 未完成、COF 和 SPI/DMA 异常。
- 本地 Git 提交流程：`commit-msg` 钩子会按暂存文件判断提交标题应包含哪些 CPU 版本号。
- 文档资料和索引：SI7000 需求、CPU2 全局错误响应分析、LNG 菜单核对和 SIL 外部资料。

## 复杂项详细测试步骤

### AS5145 正常采样和恢复

1. CPU2 冷启动，确认 AS5145 初始化和 TIM1 采样启动。
2. 保持编码器链路正常，执行回零和点动，确认首个有效 SSI 帧后位置可信。
3. 制造 1 到 3 次短时异常帧，确认系统立即重试且不持续刷屏。
4. 恢复编码器链路，确认下一次有效帧会清除编码器错误并继续位置更新。
5. 重复一次正式测量或固定点运动，确认编码器错误处理没有引入停机或位置迟滞。

### AS5145 持续异常

1. 制造持续断线、空帧或 OCF 未完成场景。
2. 观察前 3 次错误重试日志。
3. 超过阈值后确认只输出一次持续故障详情。
4. 保持异常 1 分钟，确认 TIM1 没有被错误路径停止，日志不刷屏。
5. 恢复编码器连接，确认有效帧恢复后系统可重新进入正常采样。

### 提交标题门禁

1. 确认 `git config core.hooksPath` 输出为 `tools/git-hooks`。
2. 运行 `py -m unittest tools.test_check_commit_subject_versions`。
3. 运行 `py tools\check_commit_subject_versions.py --subject "fix: 调整 AS5145 编码器 SSI 错误重试和持续故障上报（CPU2 V1.20.3.0 / CPU3 V1.18.2.0）"`。
4. 暂存正式文件后运行 `git diff --cached --check` 和 `py tools\check_version_bumped.py`。
5. 提交后推送前运行 `py tools\check_commit_subject_versions.py --range origin/MAIN..HEAD`。
