# CPU3 V1.12.1.0 长按确认进入配置菜单稳定性优化改动与测试方案

日期：2026-06-11

## 1. 版本

- CPU2：保持 V1.13.0.1
- CPU3：V1.12.0.0 -> V1.12.1.0

## 2. 兼容性

- `DEVICE_PROTOCOL_VERSION` 保持 7。
- 不改变 CPU2/CPU3 共享命令码、状态码、输入寄存器、CPU2 设备参数字段或 CPU2 `DeviceParameters` 结构。
- CPU2 `DEVICE_PARAM_VERSION` 保持 3，从 CPU2 V1.13.0.1 升级时不会因本次 CPU3 改动触发 CPU2 参数恢复出厂。
- CPU3 本地显示/通信参数结构不变，`CPU3_PARAM_VERSION` 保持 `0x0004`，升级后不会重建 CPU3 本地参数。
- 本次只改变 CPU3 本地按键识别、长按确认进入配置菜单、长按返回确认页和普通按键残留处理逻辑。

## 3. 改动内容

### 3.1 长按时间

- TIM1 长按采样周期约为 100ms。
- `REQUIRED_PRESS_COUNT` 从 `30` 调整为 `15`，长按触发时间从约 3.0 秒改为约 1.5 秒。
- 更新注释，避免把“30 次”误写成“3 次”。

### 3.2 消抖和目标锁定

- EXTI 按键下降沿增加 50ms 软件消抖，低于门限的同键重复下降沿直接忽略。
- 状态页长按检测增加目标键锁定：确认长按或返回长按开始后，直到触发或松手前，不允许其它键覆盖当前长按目标。
- 如果旧目标键已经释放，但 TIM1 还没来得及采样清锁，新按下的确认/返回可以清理旧目标并接管长按检测，避免“先按其它键后再长按确认”无法进入配置菜单。
- 状态页 `UP/DOWN` 仍不作为普通按键进入菜单队列，菜单态 `UP/DOWN/SURE/BACK` 普通按键保持原有流程。

### 3.3 TIM1 采样一致性

- 状态页启动长按采样前执行 `__HAL_TIM_SET_COUNTER(&htim1, 0)`。
- 启动前同步清除 `TIM_FLAG_UPDATE`，减少首次采样时间漂移。
- TIM1 中断仍只投递长按动作，不直接绘制菜单页或执行复杂逻辑。

### 3.4 释放保护

- 长按触发后立即清空普通按键队列。
- 记录触发长按的按键，并进入释放保护。
- 用户松开触发键并稳定超过 50ms 后，才允许新的普通按键入队。
- `Display_ProcessPendingInput()` 处理长按动作后立即返回，不在同一轮继续消费残留普通按键。
- 预期交互为：状态页长按确认约 1.5 秒出现“是否进入罐上操作?”，松开确认键后，再短按确认进入主菜单。

## 4. 影响范围

- 影响 CPU3 状态页长按确认进入配置菜单的触发时间和稳定性。
- 影响 CPU3 状态页长按返回进入取消测量确认或故障原因页的触发稳定性。
- 影响菜单态普通按键的入队时机：释放保护期间的残留普通按键会被丢弃。
- 不影响 CPU2 运动控制、液位/水位算法、外部协议地址、参数存储或 CPU2/CPU3 共享协议版本。

## 5. 重点测试

| 测试项 | 步骤 | 预期结果 |
| --- | --- | --- |
| 长按确认时间 | 状态页按住确认键 | 约 1.5 秒出现“是否进入罐上操作?” |
| 二次确认保护 | 长按确认触发后继续按住确认键 | 不自动进入主菜单 |
| 确认进入菜单 | 长按触发后松开确认键，再短按确认 | 进入配置主菜单 |
| 返回退出确认页 | 长按触发后松开确认键，再短按返回 | 退出确认页并回到状态页 |
| 误触返回 | 按住确认过程中轻触返回键 | 不打断确认长按，不进入返回长按逻辑 |
| 误触上下 | 按住确认过程中轻触上/下键 | 不影响确认长按 |
| 旧键释放后接管 | 状态页短按返回后立刻按住确认 | 确认长按可以重新启动并进入确认页 |
| 同键抖动 | 按确认时制造轻微抖动 | 不因重复下降沿反复清零导致长按失败 |
| 菜单普通按键 | 进入菜单后短按上下/确认/返回 | 菜单翻页、确认、返回保持正常 |

## 7. 实物回归范围

- 连续 30 次状态页长按确认，记录触发时间、失败次数和是否自动越过确认页。
- 长按确认过程中轻触返回/上/下键，确认误触不会打断确认长按。
- 先短按返回或其它可启动长按检测的键，松开后马上长按确认，确认可以正常进入配置菜单确认页。
- 在串口通信和状态页持续刷新时测试长按确认，确认菜单入口不卡顿。
- 在 OLED 静电恢复后测试长按确认，确认按键链路没有因显示恢复而长期延迟。
- 如不同机器手感差异明显，配合示波器确认 PF2/PF3 按键线是否存在异常下降沿或外部上拉不足。

## 8. 未验证风险

- 当前本地验证只能证明代码约束和构建结果，无法替代面板按键实物抖动和整机线束干扰测试。
- 如果硬件按键线空闲态不稳定或静电干扰很强，50ms 软件消抖和目标锁定只能降低概率，仍需评估外部上拉、RC 消抖或线束屏蔽。
- 长按触发后必须松开再短按确认进入主菜单，用户操作习惯需要现场确认是否接受。
