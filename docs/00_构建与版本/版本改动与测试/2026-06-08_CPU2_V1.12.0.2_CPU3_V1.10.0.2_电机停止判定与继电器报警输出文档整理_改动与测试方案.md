# 2026-06-08 CPU2 V1.12.0.2 / CPU3 V1.10.0.2 电机停止判定与继电器报警输出文档整理改动与测试方案

## 版本变化

- CPU2: `V1.12.0.1 -> V1.12.0.2`
- CPU3: `V1.10.0.1 -> V1.10.0.2`
- 升级级别：build
- 升级原因：CPU2 电机停止判定和错误传递行为变化，CPU3 菜单文案和文档索引发生用户可见调整。

## 协议版本/兼容性

- `DEVICE_PROTOCOL_VERSION` 保持 7。
- 不改变 CPU2/CPU3 共享寄存器地址、字段顺序、命令码、参数默认值、参数 signedness 或外部协议响应语义。
- CPU2 固件内部电机运动状态读取接口从布尔返回调整为错误码加输出参数；调用方需要按错误码处理 TMC5130 通信异常。
- CPU3 继电器相关显示口径从“四路继电器方式2”统一为“四路继电器报警输出”，协议布局不变。

## 详细改动点

- `MotorDriver_ReadMovingState()` 综合读取 `RAMPSTAT.vzero`、延迟后二次确认、`VACTUAL` 和目标位置差值，目标位置差值超过容差时继续视为运动中。
- `MotorCtrl_IsDriverMoving()` 改为返回 `NO_ERROR`、`PARAM_ERROR` 或 `MOTOR_TMC_COMM_ERROR`，通过输出参数返回运动状态。
- Wartsila 密度测量、阻塞移动、目标停止等待、命令切换停止等待、运行期位置轮询和液位传感器停止判断同步改为显式处理运动状态读取失败。
- CPU2 停止等待异常日志改为记录统一运动状态读取错误码，避免直接依赖单次 `RAMPSTAT` 读取。
- CPU2/CPU3 继电器报警输出相关注释、菜单项、协议变更记录、改动与测试方案和 README 索引统一命名。
- 新增 CPU2 电机程序与函数梳理 HTML，补充 SIL 功能安全认证资料和相关索引。

## 影响范围

- CPU2 电机控制：停止判定、阻塞等待、目标到位、液位传感器停止门控、Wartsila 测量路径。
- CPU3 显示菜单：继电器报警输出菜单文案。
- 文档：构建版本、协议记录、问题分析、界面菜单、SIL 功能安全认证资料和设备说明书。

## 重点测试点

### 电机停止判定

准备条件：
- CPU2 固件烧录到可连接 TMC5130 的测试设备。
- 可触发上行、下行、停止、命令切换和目标到位场景。

步骤：
- 执行普通上行/下行运动，观察运行中显示状态保持为上行或下行。
- 目标到位后确认停止状态能稳定清除。
- 在换向过零附近观察是否出现提前结束运动的误判。
- 人为制造或模拟 TMC5130 通信异常，确认调用方返回错误码而不是按已停止继续执行。

预期结果：
- 运动中不误判停止。
- 目标到位后不会长时间停留在运动中。
- 通信异常能进入错误处理或停止保护路径。

### Wartsila 和液位传感器路径

准备条件：
- 配置 Wartsila 测量参数和液位传感器使能条件。

步骤：
- 触发 `motorMoveUpToPositionOrAir()`，确认电机停止判断和空气/油状态检测流程正常。
- 液位模式采样前确认电机未停止时不会读取液位。
- TMC5130 读取失败时确认不会误认为电机已停止。

预期结果：
- 测量流程不会因运动状态读取失败继续执行危险动作。
- 正常停止后测量流程继续。

### CPU3 菜单和文档

准备条件：
- CPU3 显示板或菜单模拟环境。

步骤：
- 进入输出配置菜单，确认继电器入口显示为“继电器报警输出”。
- 复核协议变更记录和版本改动文档中不再使用“方式2”作为主要命名。

预期结果：
- 菜单文案和文档口径一致。
- 不引入新增协议版本要求。
