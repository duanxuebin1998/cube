# CPU2 V1.14.0.1 电机点动与位置模式流程优化改动与测试方案

日期：2026-06-13

## 版本变化

| 项目 | 旧版本 | 新版本 | 说明 |
| --- | --- | --- | --- |
| CPU2 固件版本 | `V1.14.0.0` | `V1.14.0.1` | 优化电机点动与位置模式运动流程 |
| CPU3 固件版本 | `V1.13.0.0` | `V1.13.0.0` | 未修改 CPU3 |
| `DEVICE_PROTOCOL_VERSION` | `8` | `8` | 不改变 CPU2/CPU3 共享协议 |

本次属于 CPU2 电机运动内部流程收敛和文档补齐，按 build 升级 CPU2 固件版本。

## 协议版本/兼容性

- 不新增 CPU2/CPU3 共享命令、状态、输入寄存器、保持寄存器、结构体或设备参数字段。
- 不改变 BJ/BJP 本地串口测试命令格式、返回码口径或 CPU3 显示协议。
- 电机目标越界仍使用既有 `PARAM_RANGE_ERROR` (`0x00110003`)。
- `DEVICE_PROTOCOL_VERSION` 保持 8，可与 CPU3 V1.13.0.0 按协议 8 继续配套。

## 参数存储兼容性

- CPU2 `DEVICE_PARAM_VERSION`: `3 -> 3`。
- `DeviceParameters` 结构大小：不变。
- 升级是否清参数：否；从 V1.14.0.0 升级到 V1.14.0.1 不会因参数存储版本或结构大小触发恢复出厂。
- 现场动作：正常升级即可。若 FRAM A/B 分区本身 CRC 或元信息损坏，仍按既有异常处理恢复出厂参数。

## 详细改动点

| 模块 | 改动 |

| `motor_ctrl_motion_api.c` | 新增 `MotorMotionTargetPlan`，统一描述起点、目标、距离、方向和是否已到位 |
| `motor_ctrl_motion_api.c` | 新增相对目标和绝对目标规划 helper，正式位置模式和点动位置模式共用目标规划口径 |
| `motor_ctrl_motion_api.c` | 收敛运动前准备，统一处理编码器就绪、驱动就绪和可选健康检查 |
| `motor_ctrl_motion_api.c` | 收敛命令切换中断和临时速度恢复，避免异常退出漏恢复默认速度 |
| `motor_ctrl_motion_api.c` | 收敛起步观察窗口，保留启动阶段速度刷新、位置轮询和显示状态更新 |
| `motor_ctrl_motion_api.c` | 收敛点动运行期守护，统一检查驱动健康、重量碰撞、丢步检测和命令切换 |
| `motor_ctrl_motion_api.c` | 收敛停止后刷新，统一执行 TMC5130 位置同步或健康检查 |
| `tools/check_motor_motion_target_plan.py` | 新增静态检查，防止目标规划 helper、范围检查和点动/位置入口脱节 |
| 文档 | 新增点动与位置模式分层优化方案、剩余台架验证规程、当前改动与待测项汇总、计划审计、详细流程图和策略评估记录 |

## 影响范围

| 范围 | 影响 |
| --- | --- |
| 正式相对运动 | 目标规划和速度恢复走统一 helper，行为目标保持不变 |

| 文档和验证 | 电机运动流程图、计划、风险和待测项可从 README 追溯 |

## 测试点

| 编号 | 测试点 | 准备条件 | 步骤 | 预期结果 | 通过标准 |
| --- | --- | --- | --- | --- | --- |
| T01 | 静止位置查询 | 设备静止，串口可用 | 连续发送 `YS/YC` | 位置和驱动状态正常 | 无持续编码器错误，`VACTUAL=0` |
| T02 | 点动相对下行 | 传感器位置在 200~1000mm 安全范围 | 发送 `BJ-20,0.3` | 下行并停止 | 返回成功，位移方向正确 |
| T03 | 点动相对上行 | 传感器位置在 200~1000mm 安全范围 | 发送 `BJ+20,0.3` | 上行并停止 | 返回成功，位移方向正确 |
| T04 | 点动绝对合法目标 | 目标在安全范围内 | 发送 `BJP880,0.3` | 运动到目标附近 | 返回成功，误差在既有容差内 |
| T05 | 点动绝对越界目标 | 目标超过罐高或台架上限 | 发送 `BJP1100,0.3` | 不启动电机 | 返回 `PARAM_RANGE_ERROR` |
| T06 | 正式相对下行 | 设备位置安全 | 发送 `A-10` | 下行并停止 | 返回成功，后续 `YC` 静止一致 |
| T07 | 正式相对上行 | 设备位置安全 | 发送 `A+10` | 上行并停止 | 返回成功，后续 `YC` 静止一致 |
| T08 | 命令切换中断 | 运动过程中可发串口命令 | 运动中发送查询或停止命令 | 运动停止并恢复响应 | 默认速度恢复，后续命令可用 |
| T09 | 长距离软停止 | 台架允许长距离运行 | 长距离运动中发送停止 | 电机停止 | 状态不挂死，后续可继续运动 |
| T10 | 大负距离越界 | 当前位置接近下限且有人监控 | 发送会换算到 0 以下的相对运动 | 不进入危险运动 | 返回参数错误或保持安全停止 |
| T11 | 速度恢复 | 先用临时速度运动，再发默认速度运动 | 比较后续默认速度行为 | 临时速度不泄漏 | 后续速度与参数一致 |
| T12 | 编码器重试观察 | 运动后立即查询 | 观察是否出现 `ENCODER_PARITY_ERROR` 重试 | 偶发重试可恢复 | 不连续失败，不影响最终状态 |

## 回归范围

- 正式相对运动、正式绝对位置、点动相对运动和点动绝对位置。
- 目标范围边界：0、罐高、罐高外、负值和已经到位。
- 命令切换、软停止、速度恢复和停止后位置同步。
- 编码器记步模式下的 `YS/YC` 位置对比和 TMC5130 驱动状态。
- 连续找液位 V1.14.0.0 引入的速度模式接口，确认本次电机流程收敛未破坏主线新功能。

## 未验证风险

- 合入当前 `MAIN` 并升级到 V1.14.0.1 后，尚未重新烧写最终合并固件做完整台架回归。
- 前序台架中出现过两次可恢复的 AS5145 编码器校验失败重试，后续复测未复现；现场仍需观察运动后首帧采样、线束屏蔽、接地和编码器供电抗干扰。
- T09/T10 长距离软停止和大负距离越界未在最终合并版本上实测。
- 台架机械安全限制为传感器位置不低于 200mm、不高于 1000mm；固件通用目标范围仍按 0 到罐高判断，未把 200mm 作为软件硬限位。
