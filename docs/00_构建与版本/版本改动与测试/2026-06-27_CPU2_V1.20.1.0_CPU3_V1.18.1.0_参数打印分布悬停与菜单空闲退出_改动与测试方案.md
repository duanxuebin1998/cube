# CPU2 V1.20.1.0 / CPU3 V1.18.1.0 参数打印、分布悬停与菜单空闲退出改动与测试方案

日期：2026-06-27

## 版本变化

- CPU2：`V1.20.0.0 -> V1.20.1.0`。
- CPU3：`V1.18.0.0 -> V1.18.1.0`。

## 协议版本/兼容性

- `DEVICE_PROTOCOL_VERSION`：保持 `13`。
- 不新增共享保持寄存器、输入寄存器、命令码或状态码。
- 本次改变的是 CPU2 参数保存/诊断打印、分布密度悬停时间执行口径、CPU3 菜单空闲退出和参数菜单显示口径，CPU2/CPU3 仍建议成对升级，便于现场日志和菜单行为一致。

## 参数存储兼容性

- CPU2 `DEVICE_PARAM_VERSION`：`3 -> 3`。
- `DeviceParameters` 结构大小：不变。
- 升级是否清参数：否。
- FRAM A/B 分区地址、`magic`、`struct_size`、`param_version`、`crc` 校验规则不变。
- CPU3 本机参数存储版本保持 `0x0005`，本机 FRAM 布局不变。
- 现场动作：不需要因本次版本单独恢复出厂或重新下发全量参数；建议升级后抽查参数写入、保存跳过和菜单显示。

## 本次改动点

- CPU2 参数打印改为统一场景入口，区分上电全量、恢复出厂全量、人工全量、保存摘要和保存跳过。
- CPU2 Modbus 0x10 写持久化参数前捕获旧参数快照，主循环延后保存到 FRAM 时统一打印参数差异。
- CPU2 只写 command 或继电器清锁存命令时不触发 FRAM 保存，也不会打印误导性的参数差异。
- CPU2 分布密度逐点悬停统一按菜单配置的 `spreadPointHoverTime` 秒解释，进入延时前换算为毫秒，与单点稳定窗口口径一致。
- CPU2 DSM V2 调试密度读取和单点展示 mock 使用 `kg/m3 x100` raw，演示打印显示两位密度。
- CPU2 编码器、电机初始化、持久化位置恢复和位置源恢复日志改为结构化中文输出，默认关闭上电位置详细诊断。
- CPU3 菜单增加 120 秒空闲自动退出到状态页；电机运行监控页和扭力等待页不参与普通菜单空闲退出。
- CPU3 显示设置页提升语言和屏幕密码入口，参数返回映射按实际入口修正。
- CPU3 保留项过滤按完整 UTF-8 “保留”前缀比较，避免只比较半个汉字。
- CPU3 液位找液阈值和液位滞后阈值菜单显示为 `Hz`、1 位小数；水位稳定距离、罐底后编码器修正和相关短名顺序同步调整。
- 同步密度流程页、协议变更记录、默认值说明、CPU3 菜单单位清单、版本记录和契约检查脚本。

## 影响范围

- CPU2 参数存储保存入口、Modbus 写参数后的保存判定和串口诊断日志。
- CPU2 分布密度测量逐点悬停时间，现场节拍会从原误按毫秒执行修正为按秒执行。
- CPU2 调试/演示密度显示和初始化日志可读性。
- CPU3 OLED 菜单前景页空闲退出、显示设置入口、参数单位显示和返回路径。
- 文档与检查脚本：密度流程页、协议/默认值/菜单说明和密度契约脚本。

## 重点测试点

| 测试项 | 前置条件 | 步骤 | 预期结果 | 通过标准 |
| --- | --- | --- | --- | --- |
| 上电参数全量打印 | CPU2 正常启动且 FRAM 参数有效 | 上电观察串口日志 | 仅在上电加载完成后打印一次全量参数表 | 来源、版本、大小、CRC 和分组字段清晰，无重复刷屏 |
| Modbus 持久化写参差异 | 主站可写 CPU2 保持寄存器 | 写入一个或多个持久化参数 | 保存前打印变更项和旧值/新值 | 只列出实际变化字段，FRAM A/B 保存摘要成功 |
| command 写入不保存 | 主站仅写 command 两个寄存器 | 下发测量或调试命令 | 不触发设备参数保存 | 无参数差异打印，无 FRAM 保存摘要 |
| 继电器清锁存不保存 | 继电器锁存清除寄存器可写 | 只写清锁存字段 | 不触发 FRAM 保存 | 清锁存命令生效但参数保存跳过 |
| 保存跳过 | 写入值与当前持久化参数一致 | 重复写同一参数值 | 输出保存跳过提示 | 不递增参数更新标志，不写 FRAM |
| 分布密度悬停单位 | `spreadPointHoverTime=10` | 执行普通分布密度测量 | 每个点位悬停约 10 秒 | 与单点稳定窗口同按秒解释 |
| 单点展示两位密度 | 串口调试可触发展示 mock | 运行单点展示调试流程 | 密度、标密、计重密度按两位打印 | raw 与 `kg/m3 x100` 一致 |
| CPU3 菜单空闲退出 | 进入普通菜单页 | 120 秒不按键 | 自动退出到状态页并清空待处理按键 | 状态页刷新，无残留菜单按键 |
| 业务等待页不空闲退出 | 进入电机运行监控或扭力等待页 | 120 秒不按键 | 页面继续保持业务等待 | 不误退出、不打断等待流程 |
| CPU3 显示设置入口 | 进入显示设置 | 查看语言、屏幕密码和显示基础 | 语言/屏幕密码作为显示设置页入口显示 | 返回路径正确，4 行显示不越界 |
| 液位阈值菜单单位 | 查看液位参数页 | 浏览找液阈值和滞后阈值 | 单位为 `Hz`，默认 `150/200` 显示为 `15.0/20.0 Hz` | 菜单显示与默认值文档一致 |
