# 2026-06-08 CPU3 V1.10.1.0 菜单选择型参数编辑优化改动与测试方案

## 版本变化

- CPU2：保持 V1.12.0.2。
- CPU3：V1.10.0.2 -> V1.10.1.0。
- `DEVICE_PROTOCOL_VERSION`：保持 7。

## 协议版本与兼容性

- 不改变 CPU2/CPU3 共享寄存器地址、寄存器数量、参数字段数值编码和参数存储结构。
- 不改变 DSM、Wartsila、LTD、SI7000 等外部协议响应语义。
- 本次只改变 CPU3 OLED 参数菜单的人机交互：有限枚举、开关和模式类参数由数字逐位输入改为上下键候选选择。
- “非法配置”只作为异常值显示占位，不允许作为可写候选。
- 水位测量方式未确认独立枚举语义，继续保留数字编辑路径，避免错误套用液位测量方式文案。

## 详细改动点

- 在 CPU3 参数元数据中，将故障自动回零、故障停止测量、位置源自动切换、记步模式、是否测罐底、是否测水位、是否测单点密度、分布测顺序、分布测模式、液位/水位/密度/温度数据源、语言、密度手输上传、是否息屏、更新罐高标志和罐底后编码器修正挂接到 `ret_arr_word`。
- 在 CPU3 菜单显示中新增位置源自动切换候选：禁用、启用。
- 在 CPU3 菜单显示中新增记步模式候选：编码器、电机。
- 优化 `selectparaword()` 和 `operationselect()`：
  - 进入选择页时默认高亮当前参数值。
  - 候选列表不显示最后的“非法配置”写入项。
  - 保存或返回后重置选择页静态状态。
  - 候选表为空或长度异常时显示非法参数提示并返回参数页。

## 影响范围

- 影响 CPU3 OLED 参数菜单的显示和编辑体验。
- 不影响 CPU2 参数归一化、FRAM 存储、内部 Modbus 寄存器布局和 CPU3 下发的数值编码。
- 数值型参数继续使用原数字输入流程，例如罐高、阈值、距离、密码、小数点位数和手输值。

## 重点测试项

### 选择型参数进入和显示

准备条件：
- CPU3 固件 V1.10.1.0。
- CPU2 与 CPU3 通讯正常，设备处于允许修改参数的状态。

步骤：
1. 进入参数配置菜单。
2. 分别进入故障自动回零、位置源自动切换、记步模式、是否测罐底、分布测模式、数据源、是否息屏和 COM 协议等选择型参数。
3. 按确认进入修改。

预期结果：
- 参数值页面显示中文或英文候选含义，不显示裸数字。
- 选择页默认高亮当前参数值。
- 上下键可在合法候选中循环切换。

通过标准：
- 所有选择型参数均不再进入数字逐位输入页。
- 当前值高亮与实际参数值一致。

### 选择保存和返回取消

准备条件：
- 选择一个允许修改的 0/1 开关参数。

步骤：
1. 进入选择页后切换到另一个候选。
2. 按返回退出。
3. 重新进入该参数查看当前值。
4. 再次进入选择页切换候选并按确认保存。
5. 重新读取参数。

预期结果：
- 返回取消时不写入新值。
- 确认保存后新值写入 CPU2 或 CPU3 本机参数，并可回读显示。

通过标准：
- 返回和确认的行为区分明确，没有误写。

### 非法配置占位不可写

准备条件：
- 任意选择型参数。

步骤：
1. 在选择页连续按上下键循环候选。
2. 检查候选列表是否出现“非法配置”。

预期结果：
- “非法配置”不作为候选项显示。
- 如果已有参数值超出合法范围，参数显示页可显示“非法配置”，进入选择页时高亮回落到最后一个合法候选。

通过标准：
- 用户无法通过菜单写入“非法配置”占位值。

### 数值型参数回归

准备条件：
- 进入参数配置菜单。

步骤：
1. 分别进入液位罐高、液位盲区、分布点间距、屏幕密码、小数点位数、液位手输值等数值型参数。
2. 按确认修改。

预期结果：
- 数值型参数仍进入原数字逐位输入页面。
- 范围检查和单位/小数点显示保持不变。

通过标准：
- 本次选择型优化未影响数值参数编辑。
