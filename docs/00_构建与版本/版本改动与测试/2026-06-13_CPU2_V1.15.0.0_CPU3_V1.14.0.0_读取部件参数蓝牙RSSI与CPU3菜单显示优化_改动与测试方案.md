# CPU2 V1.15.0.0 / CPU3 V1.14.0.0 读取部件参数蓝牙RSSI与CPU3菜单显示优化改动与测试方案

日期：2026-06-13

## 1. 版本变化

| 项目 | 旧版本 | 新版本 | 说明 |
| --- | --- | --- | --- |
| CPU2 固件版本 | `V1.14.0.1` | `V1.15.0.0` | 读取部件参数增加蓝牙连接 RSSI 快照，瓦锡兰密度点读取补频率异常保护 |
| CPU3 固件版本 | `V1.13.0.0` | `V1.14.0.0` | 显示 RSSI、重组测量/调试菜单、优化扭力获取等待页和字模 |
| `DEVICE_PROTOCOL_VERSION` | `8` | `9` | `WirelessPairingStatus` 输入寄存器尾部追加 RSSI 运行态字段 |
| CPU2 `DEVICE_PARAM_VERSION` | `3` | `3` | `DeviceParameters` 持久化结构不变 |
| CPU3 本机参数版本 | `0x0004` | `0x0004` | 本机显示/通信参数存储布局不变 |

## 2. 协议版本与兼容性

- 协议版本 9 在协议版本 8 的输入寄存器末尾追加 `connection_valid`、`rssi_valid`、`rssi`、`connection_error_code` 和 `rssi_update_counter`。
- 新字段追加在四路继电器运行态之后，不移动协议版本 8 已有无线滑环匹配结果和继电器运行态字段。
- `REG_ENG` 顺延到 `REG_WIRELESS_PAIRING_RSSI_UPDATE_COUNTER + REG_SIZE_U32`。
- CPU2/CPU3 必须同为协议版本 9 才能正确读取和显示当前蓝牙连接 RSSI；协议版本 8 的旧端不应解释新增尾部输入寄存器。
- CPU2 `CMD_READ_PART_PARAMS` 只查询当前连接状态和 RSSI，不执行扫描、不重新配对、不保存默认连接。

## 3. 参数存储兼容性

- CPU2 `DEVICE_PARAM_VERSION` 保持 `3`，`DeviceParameters` 结构大小不变，`param_version`、`struct_size`、`magic` 和 `crc` 校验规则不变。
- 从 CPU2 V1.14.0.1 升级到 V1.15.0.0 不会因参数存储版本或结构大小触发恢复出厂参数。
- 本次不复用或改变 CPU2 持久化参数字段语义，旧 FRAM 参数通常保留。
- CPU3 本机参数版本保持 `0x0004`，不触发屏幕亮度、显示源或通信参数重新初始化。
- 现场升级前仍建议记录关键测量参数，升级后重点核对协议版本状态、菜单入口和读取部件参数页显示。

## 4. 详细改动点

| 模块 | 改动 |
| --- | --- |
| CPU2 无线滑环 | 新增当前连接状态和 RSSI 快照读取，读取部件参数态按节流周期刷新快照，失败时发布错误码和无效 RSSI |
| CPU2/CPU3 内部 Modbus | 两端同步协议版本 9、`WirelessPairingStatus` 字段、输入寄存器宏和打包/解析顺序 |
| CPU3 状态页 | 读取部件参数完成态显示位置、扭力、温度、频率、电容、X/Y 角和 RSSI；无效 RSSI 显示 `RSSI:N/A` |
| CPU3 菜单 | 测量命令拆分为密度单点测量和密度分布测量，水位命令归组，分布类密度命令归入密度分布测量，传感器运动命令归入浮子运动控制 |
| CPU3 调试显示 | 调试指令显示完整名称；获取空载/满载扭力时显示独立等待页，完成后返回扭力配置菜单 |
| CPU3 字库 | 使用确认后的“控”字模，避免浮子运动控制菜单乱码 |
| CPU2 瓦锡兰密度测量 | 密度点读取时频率无效会重置稳定采样，超时且没有有效频率或当前频率无效时返回 `SONIC_FREQ_ABNORMAL` |
| 文档与工具 | 更新屏幕菜单 Word/Markdown、状态页确认表、协议记录、默认值文档、程序流程导航、版本测试方案和 RSSI 契约检查脚本 |

## 5. 重点测试点

| 测试项 | 准备条件 | 步骤 | 预期结果 | 通过标准 |
| --- | --- | --- | --- | --- |
| 协议版本匹配 | 刷入 CPU2 V1.15.0.0 和 CPU3 V1.14.0.0 | 上电后查看设备状态页和协议字段 | 协议版本为 9，状态页无协议不匹配提示 | CPU3 能正常读取 CPU2 参数和输入寄存器 |
| RSSI 有效显示 | CH9141K 已连接从机，透传链路正常 | 执行读取部件参数并等待 RSSI 刷新周期 | 状态页显示 `RSSI:<值>dB` | 数值随 CPU2 快照刷新，页面无旧业务数据混入 |
| RSSI 无效显示 | 断开从机或模拟 RSSI 查询失败 | 执行读取部件参数 | 状态页显示 `RSSI:N/A`，CPU2 发布错误码 | 不触发重新配对，不破坏 UART6 透传恢复 |
| 命令切换打断 | 读取部件参数态发起其他测量或返回 | 观察 CPU2 状态、CPU3 页面和 UART6 | RSSI 查询可退出，后续命令正常执行 | 无卡死、无长期占用 AT 模式 |
| 菜单结构 | CPU3 主菜单进入测量命令和调试指令 | 逐项检查密度单点测量、密度分布测量、水位命令、浮子运动控制 | 菜单名称、顺序和用户确认口径一致 | 返回键返回上级菜单，不跳到错误页面 |
| 扭力获取等待页 | 进入扭力配置，执行获取空载扭力和获取满载扭力 | 观察执行中和完成后页面 | 执行中显示获取扭力中，完成后返回扭力配置菜单 | 不退出到状态页面，不丢失配置上下文 |
| 字库显示 | 进入浮子运动控制菜单 | 检查“控”字显示 | 字形正确，无乱码或缺字 | `font_check.py` 通过，实机显示可读 |
| 瓦锡兰无效频率保护 | 模拟频率为 0 或无效采样 | 执行瓦锡兰区间密度读取点 | 超时无有效频率时返回频率异常 | 不把无效频率误写为有效空气点 |
