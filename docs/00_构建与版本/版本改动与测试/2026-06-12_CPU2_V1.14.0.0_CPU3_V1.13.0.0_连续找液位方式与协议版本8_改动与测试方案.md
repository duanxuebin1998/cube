# CPU2 V1.14.0.0 / CPU3 V1.13.0.0 连续找液位方式与协议版本8改动与测试方案

日期：2026-06-12

## 版本变化

| 项目 | 旧版本 | 新版本 | 说明 |
| --- | --- | --- | --- |
| CPU2 固件版本 | `V1.13.2.0` | `V1.14.0.0` | 新增连续找液位执行方式 |
| CPU3 固件版本 | `V1.12.1.0` | `V1.13.0.0` | 同步液位方式菜单和参数范围 |
| `DEVICE_PROTOCOL_VERSION` | `7` | `8` | `liquidLevelMeasurementMethod` 参数语义扩展 |

本次新增液位测量方式和跨 CPU 参数语义，按 minor 升级 CPU2/CPU3 固件版本，并提升共享协议版本。

## 协议版本/兼容性

- `liquidLevelMeasurementMethod` 仍使用原保持寄存器和原 32 位字段，不新增或移动寄存器。
- 液位测量方式语义为：`0=相对频率`、`1=定频`、`2=密度连续找液位`、`3=超声预留`、`4=连续相对频率`、`5=连续定频`。
- CPU2 在 `SearchOilLevel()` / `FollowOilLevel()` 中保留 0/1 原步进式频率方案；2 进入密度阈值速度闭环；4/5 进入频率偏差速度闭环。
- CPU3 参数元数据把液位测量方式有效范围同步为 `0..5`，菜单文案新增“连相对频率”和“连定频”。
- 协议版本 7 的 CPU2 不支持 2/4/5 新执行路径；协议版本 7 的 CPU3 不知道新语义。CPU2/CPU3 必须同为协议版本 8。

## 参数存储兼容性

- CPU2 `DEVICE_PARAM_VERSION`: `3 -> 3`。
- `DeviceParameters` 结构大小：不变。
- 升级是否清参数：否；从 V1.13.2.0 升级到 V1.14.0.0 不会因参数存储版本或结构大小触发恢复出厂。
- 现场动作：正常升级即可。若现场需要启用新方式，应确认并下发 `liquidLevelMeasurementMethod`、目标频率/目标密度、找液阈值、滞后阈值和滞后时间。

## 详细改动点

| 模块 | 改动 |
| --- | --- |
| `measure_oilLevel.c` | 新增密度连续找液位/跟随闭环，按密度偏差计算方向和速度 |
| `measure_oilLevel.c` | 新增连续相对频率和连续定频闭环，按频率偏差计算方向和速度 |
| `measure_oilLevel.c` | 保留 0/1 原步进式频率精找路径，避免旧参数行为被替换 |
| `measure_waterLevel.c` | 水位细找前若仍在水中，先上行脱离水区再低速下行细找 |
| `motor_ctrl_motion_api.c` / `motor_ctrl.h` | 新增 `MotorCtrl_StartVelocity()` 非阻塞速度模式启动接口 |
| CPU2/CPU3 参数头 | `DEVICE_PROTOCOL_VERSION` 同步提升到 8 |
| CPU3 参数表和显示 | 液位测量方式范围同步为 `0..5`，菜单新增连续方式短名 |
| CPU3 菜单短名 | 收敛参数列表页短名，避免 OLED 列宽裁剪 |
| 文档和脚本 | 同步协议记录、菜单文档、默认值文档和契约检查脚本 |

## 影响范围

| 范围 | 影响 |
| --- | --- |
| CPU2 液位测量 | 方法 2/4/5 会进入速度闭环，需要现场验证方向、速度、死区和稳定计数 |
| CPU2 水位测量 | 粗找后仍在水中时增加脱水动作，降低细找入口直接结束风险 |
| CPU2 电机控制 | 新增速度模式启动接口，连续闭环依赖该接口按方向和速度更新运动 |
| CPU3 参数菜单 | 液位测量方式可选择新值，参数列表短名显示更短 |
| 共享协议 | 协议版本 8 与协议版本 7 不兼容，应按严格相等检查拦截混用 |

## 测试点

| 编号 | 测试点 | 准备条件 | 步骤 | 预期结果 | 通过标准 |
| --- | --- | --- | --- | --- | --- |
| T01 | 原相对频率方式回归 | 液位方式为 0 | 执行找液位和跟随 | 仍走原粗找/精找路径 | 不进入连续速度闭环 |
| T02 | 原定频方式回归 | 液位方式为 1，配置目标频率 | 执行找液位和跟随 | 仍走原步进式精找路径 | 找液行为与旧版本一致 |
| T03 | 密度连续找液位 | 液位方式为 2，配置目标密度和阈值 | 执行找液位 | 按密度偏差上下行，稳定后记录液位 | 电机方向、速度和稳定判定符合现场液面变化 |
| T04 | 密度连续跟随 | 液位方式为 2 | 进入液位跟随 | 偏差超出滞后阈值时继续速度闭环 | 命令切换可退出并停机 |
| T05 | 连续相对频率 | 液位方式为 4 | 执行找液位 | 粗找得到空气/液体频率后按中值连续闭环 | 端点保护不把空气端或油端误认为稳定 |
| T06 | 连续定频 | 液位方式为 5，配置目标频率 | 执行找液位 | 按当前频率和目标频率偏差闭环 | 稳定后记录液位 |
| T07 | 水位细找入口在水中 | 粗找停止后探头仍处于水中 | 执行水位测量 | 先上行脱离水区再低速下行细找 | 不因第一次采样在水中直接结束 |
| T08 | CPU3 液位方式菜单 | CPU3 进入参数菜单 | 浏览液位测量方式 | 显示原四项及新增连续相对频率、连续定频 | 可选择 0..5，非法值按既有策略处理 |
| T09 | CPU3 参数列表短名 | CPU3 进入参数列表页 | 浏览参数项 | 参数名不挤占数值列 | 短名宽度检查通过 |
| T10 | 协议不匹配 | CPU2/CPU3 使用不同协议版本 | 启动通信 | CPU3 按严格相等检查提示不兼容 | 不允许混用协议 7 和 8 |

- CPU2 水位低速/快速测量流程，尤其是水中脱离、零点附近保护和丢步检测。
- CPU2 电机速度模式、方向切换、慢停和称重碰撞保护。
- CPU3 参数菜单、液位方式选项、参数列表短名和中文字库。
- CPU2/CPU3 协议版本检查、系统参数恢复出厂默认值和旧 FRAM 参数加载。

## 未验证风险

- 未做实物联调，三种连续液位方案仍需现场验证电机方向、速度响应、稳定死区、命令切换退出和故障停机。
- 密度连续闭环依赖传感器密度读数稳定性，现场需确认无液、气泡、液面扰动和温度变化下的误判边界。
- 水位细找前脱水逻辑需要在真实水位工况验证，重点关注粗找停在水中、零点附近和水位电容抖动场景。
