# CPU2 V1.13.0.0 点动长距离运动接口与 BJ 测试命令改动与测试方案

日期：2026-06-11

## 版本变化

- CPU2：`V1.12.2.0 -> V1.13.0.0`
- CPU3：保持 `V1.11.2.0`
- 升级级别：minor，原因是新增 CPU2 长距离点动运动接口和串口 `BJ/BJP` 测试命令。

## 协议版本与兼容性

- `DEVICE_PROTOCOL_VERSION` 保持 `7`。
- 不新增 CPU2/CPU3 共享命令码、状态码、寄存器地址或参数字段。
- `BJ+`、`BJ-`、`BJP` 仅为 CPU2 本地串口调试命令，不改变内部 Modbus、DSM 或 Wartsila 外部协议。
- 既有 `MotorCtrl_MoveToPosition()` 和 `MotorCtrl_MoveAndWait()` 保持原有位置模式方案；新增接口供长距离移动场景按调用方选择使用。
- TMC5130 BSP 新增公开 `stpr_rotate()` 速度点动接口；`stpr_stop()` 停机后会对齐 `XTARGET` 和 `RAMPMODE`，减少速度模式和位置模式切换后的目标状态残留。

## 参数存储兼容性

- CPU2 `DEVICE_PARAM_VERSION`：保持 `3`。
- `DeviceParameters` 结构大小：不变。
- 升级是否清参数：否；从 CPU2 `V1.12.2.0` 升级到 `V1.13.0.0` 不会因参数存储版本触发恢复出厂。
- 现场动作：正常升级即可；如果使用新点动接口做长距离移动，建议先在空载或低风险距离验证位置源、方向和速度参数。

## 本次修改

- 新增 `MotorCtrl_JogMoveAndWait(float mm, int dir, uint32_t speed_x100)`，按相对距离、方向和速度进入速度点动模式。
- 新增 `MotorCtrl_JogMoveToPosition(float target_mm, uint32_t speed_x100)`，按当前有效位置源判断方向并点动到绝对位置。
- 点动内部循环持续刷新有效位置源，按当前速度、驱动加速度和毫米换算系数计算降速距离和低速停机距离。
- 接近目标时自动从高速切换到低速，进入最终停机距离后提前停机，停稳后再次刷新位置。
- 若最终位置已经超过目标容差，返回 `MEASUREMENT_POSITION_ERROR`，不把超限当作成功。
- 运行期间保留命令切换、驱动健康检查、位置源有效性检查、驱动状态刷新、扭力碰撞保护、丢步检测、运行超时和临时速度恢复。
- 新增 `motor_jog_text()` 和 `motor_jog_to_position_text()` 测试封装。
- 串口 B 测试命令新增：
  - `BJ+<mm>[,<速度m/min>]`：点动模式上行相对运动测试。
  - `BJ-<mm>[,<速度m/min>]`：点动模式下行相对运动测试。
  - `BJP<target_mm>[,<速度m/min>]`：点动模式绝对位置测试。

## 影响范围

- CPU2 电机控制服务中的长距离运动调用能力。
- CPU2 TMC5130 BSP 速度模式控制入口和停机后的目标模式恢复。
- CPU2 串口 B 本地测试命令解析和现场测试封装。
- CPU3、内部 Modbus、DSM 外部协议、Wartsila 外部协议和参数存储结构不受影响。

| 绝对位置点动 | 当前有效位置已知 | 下发 `BJP19450,1.5` | 自动判断方向并运行到目标附近 | 终点在允许容差内，未出现超限成功 |
| 低速停机距离 | 选择较高速度和长距离 | 观察串口输出 | 进入低速后仍预留最终停机距离 | 低速段不会因惯性越过目标后仍返回成功 |

| 命令切换 | 点动运行中下发新命令 | 观察运动和返回值 | 当前运动被打断并安全停机 | 新命令切换路径不被阻塞 |

| 旧接口回归 | 使用原有调用入口 | 调用 `MotorCtrl_MoveToPosition()`、`MotorCtrl_MoveAndWait()` | 继续走位置模式方案 | 旧接口行为不被替换 |
