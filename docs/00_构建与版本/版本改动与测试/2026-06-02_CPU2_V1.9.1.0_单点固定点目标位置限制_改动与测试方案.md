# CPU2 V1.9.1.0 单点固定点目标位置限制改动与测试方案

## 版本变化

- CPU2: V1.9.0.0 -> V1.9.1.0
- CPU3: 未变化，保持 V1.8.0.0

## 协议版本和兼容性

- 本次不修改 `DEVICE_PROTOCOL_VERSION`。
- 本次不新增命令、寄存器、参数字段或 CPU2/CPU3 共享结构体。
- 固定点/单点位置参数仍按原有寄存器写入和读取；变化只发生在 CPU2 执行命令前的位置合法性检查。
- 目标位置非法时 CPU2 返回 `PARAM_RANGE_ERROR` 并进入错误状态，CPU3 和上位机按既有错误码通道读取。

## 改动内容

- 新增 `SinglePoint_CheckTargetPosition()`，统一检查单点类目标位置。
- 合法范围为 `blindZone <= target <= tankHeight`，单位为 0.1mm。
- 单点测量 `singlePointMeasurementPosition` 在移动前检查。
- 固定点监测 `singlePointMonitoringPosition` 在移动前检查。
- 瓦锡兰密度分布测后回固定点前复用同一检查，避免目标非法时先移动。
- 目标非法报错前打印流程名、原因、目标位置、零点、罐底盲区、当前位置、尺带长度和错误码。
- 以下情况返回 `PARAM_RANGE_ERROR`：
  - `tankHeight == 0`
  - `blindZone > tankHeight`
  - `target > tankHeight`
  - `target < blindZone`

## 影响范围

- 影响 CPU2 单点测量命令。
- 影响 CPU2 固定点监测命令。
- 影响瓦锡兰密度分布测后回固定点位置的移动阶段。
- 不影响普通运行到指定位置命令。
- 不影响密度分布内部测点移动。
- 不影响找零点、找液位、找水位、找罐底流程。
- 不影响参数写入本身，非法值仍可写入，但执行相关单点类命令时会报错并阻止电机动作。

## 台架测试准备

- CPU2 刷写 V1.9.1.0。
- CPU3 可继续使用 V1.8.0.0。
- 确认罐高参数 `tankHeight`、罐底盲区参数 `blindZone` 已写入合理值。
- 记录执行前电机实际位置、`singlePointMeasurementPosition`、`singlePointMonitoringPosition`、错误码和设备状态。

## 测试用例

### 1. 单点测量正常目标

步骤：
- 设置 `singlePointMeasurementPosition` 满足 `blindZone <= target <= tankHeight`。
- 下发单点测量命令。

预期结果：
- CPU2 不报 `PARAM_RANGE_ERROR`。
- 电机按目标位置移动。
- 到位后进入单点读取流程。

通过标准：
- 命令可正常执行。
- 错误码保持正常或只出现后续传感器读取相关错误，不应出现目标位置参数超限。

### 2. 单点测量超过零点

步骤：
- 设置 `singlePointMeasurementPosition > tankHeight`。
- 下发单点测量命令。

预期结果：
- CPU2 报 `PARAM_RANGE_ERROR`。
- 电机不应开始向上或向下移动。
- 报错前日志应包含“单点测量”、原因、目标位置、零点、罐底盲区、当前位置、尺带长度和错误码。

通过标准：
- 错误码为 `PARAM_RANGE_ERROR`。
- 电机状态不进入持续运动。

### 3. 单点测量进入罐底盲区

步骤：
- 设置 `singlePointMeasurementPosition < blindZone`。
- 下发单点测量命令。

预期结果：
- CPU2 报 `PARAM_RANGE_ERROR`。
- 电机不应移动到盲区内。
- 报错前日志应包含“单点测量”、原因、目标位置、零点、罐底盲区、当前位置、尺带长度和错误码。

通过标准：
- 错误码为 `PARAM_RANGE_ERROR`。
- 电机无移动动作。

### 4. 固定点监测正常目标

步骤：
- 设置 `singlePointMonitoringPosition` 满足 `blindZone <= target <= tankHeight`。
- 下发固定点监测命令。

预期结果：
- CPU2 不报 `PARAM_RANGE_ERROR`。
- 电机移动到固定点后进入固定点监测读取或样机数据刷新流程。

通过标准：
- 固定点监测可持续运行。
- 目标位置到位逻辑正常。

### 5. 固定点监测超过零点

步骤：
- 设置 `singlePointMonitoringPosition > tankHeight`。
- 下发固定点监测命令。

预期结果：
- CPU2 报 `PARAM_RANGE_ERROR`。
- 电机不会继续上行到零点以上。
- 报错前日志应包含“固定点监测”、原因、目标位置、零点、罐底盲区、当前位置、尺带长度和错误码。

通过标准：
- 错误码为 `PARAM_RANGE_ERROR`。
- 电机未执行上行动作。

### 6. 固定点监测进入罐底盲区

步骤：
- 设置 `singlePointMonitoringPosition < blindZone`。
- 下发固定点监测命令。

预期结果：
- CPU2 报 `PARAM_RANGE_ERROR`。
- 电机不向罐底盲区移动。
- 报错前日志应包含“固定点监测”、原因、目标位置、零点、罐底盲区、当前位置、尺带长度和错误码。

通过标准：
- 错误码为 `PARAM_RANGE_ERROR`。
- 电机未执行盲区方向移动。

### 7. 瓦锡兰测后回固定点非法目标

步骤：
- 设置 `singlePointMonitoringPosition > tankHeight` 或 `< blindZone`。
- 执行会触发测后回固定点的瓦锡兰密度分布流程。

预期结果：
- 测后回固定点阶段返回 `PARAM_RANGE_ERROR`。
- CPU2 不执行回固定点移动。
- 报错前日志应包含“瓦锡兰测后回固定点”、原因、目标位置、零点、罐底盲区、当前位置、尺带长度和错误码。

通过标准：
- 错误码为 `PARAM_RANGE_ERROR`。
- 电机在该阶段没有朝非法目标移动。

## 回归范围

- 单点测量。
- 固定点监测。
- 瓦锡兰密度分布测后探底频率触发路径。

## 未验证风险

- 当前只完成本地编译和静态检查，未做现场电机动作验证。
- 需要确认 CPU3/上位机显示 `PARAM_RANGE_ERROR` 时的提示是否满足现场可读性。
- 需要确认现场是否存在把固定点位置设置在盲区内作为特殊操作的历史用法；如果存在，需要另行定义专用强制命令，而不是复用自动测量/监测命令。
