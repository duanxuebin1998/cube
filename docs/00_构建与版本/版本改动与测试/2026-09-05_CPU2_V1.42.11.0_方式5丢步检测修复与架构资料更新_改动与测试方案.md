# CPU2 V1.42.11.0 方式5丢步检测修复与架构资料更新改动与测试方案

## 1. 版本与目的

- CPU2：`V1.42.10.0 -> V1.42.11.0`（PATCH）。
- CPU3：保持 `V1.41.0.0`。
- 目的：修复方式5液位定频闭环在换向、变速、停止等待和低速检测切换时使用错误方向或速度累计期望位移的问题，并纳入当前已完成的 SI PLC 对接协议、系统架构和软件架构资料。
- 范围边界：本次明确不纳入称重探底可靠性改造；普通液位运动仍保留原有向下绝对称重阈值保护。

## 2. 协议版本与兼容性

- `DEVICE_PROTOCOL_VERSION` 保持 35；CPU2/CPU3 共享寄存器、共享命令、共享状态和 SI 对外寄存器语义不变。
- CPU2 `DEVICE_PARAM_VERSION` 保持 3，CPU3 `CPU3_PARAM_VERSION` 保持 `0x0007`；参数结构、字段偏移、CRC 范围和 FRAM 布局不变，升级不恢复出厂、不清除现场参数。
- 方式5改动只调整 CPU2 内部丢步检测输入和窗口统计，不新增命令、状态、故障码或参数。
- SI PLC 对接协议 PDF 当前文件与上一版本二进制不同，但逐页栅格比对未发现视觉差异；不能据此声明对外协议内容发生变化。

## 3. 本次修改

### 3.1 方式5按有效指令积分期望位移

- 源码位置：`motor_ctrl_lost_step_detect.c` 的 `MotorCtrl_CheckLostStepAutoTimingWithSpeed()` 及其方式5私有状态；声明位于 `motor_ctrl.h`。
- 改前问题：通用丢步检测按窗口首尾位置和固定阈值判断，方式5闭环的换向、速度变化和停机等待没有形成与实际指令一致的期望位移窗口，可能用新方向解释旧位移或继续按旧速度累计停止时段，造成误报。
- 具体改法：新增方式5专用累计状态。每次调用先按“上一有效方向和速度”结算上一个时间段的期望位移和三路实际有效前进量，再保存本次新方向和速度；速度为 0 时只刷新三路前沿，不累计期望位移。
- 必查边界：首次进入、同方向变速、上转下、下转上、运动转停止、停止转运动、HAL tick 回绕、非法方向、负速度、超上限速度、窗口未满和期望位移为 0 均需复核。
- 通过标准：每段期望位移等于该段已下发速度与持续时间的积分；换向后的首个样本不把旧方向位移计入新方向；停止等待期间期望位移不增长；非法输入返回 `PARAM_RANGE_ERROR`。

### 3.2 三路位置按指令方向累计有效前进量

- 源码位置：`MotorCtrl_UpdateMethod5ForwardProgress01mm()`、`MotorCtrl_AccumulateMethod5ForwardProgress()` 和 `MotorCtrl_StoreMethod5LostStepSnapshot()`。
- 改前问题：窗口首尾差值会受换向、回退和抖动抵消或放大，无法稳定表达业务位置、电机模型和编码器在当前指令方向上的实际进展。
- 具体改法：业务位置、电机模型位置和编码器位置分别维护方向前沿，只有越过当前指令方向上的最远前沿时才累计有效前进量；回退、抖动和重复到达旧位置均计 0。窗口保存三路累计值与累计期望位移快照。
- 必查边界：三路信号的正负方向不同、编码器抖动、短时回退后恢复、跨方向切换、累计量长时间增长和窗口索引回绕均需复核。
- 通过标准：单调前进量正常累计；回退和未越过前沿的恢复不重复累计；电机模型有明显前进而编码器跟随不足时仍可返回 `ENCODER_LOST_STEP`；电机位置源场景保持既有只记录、不返回编码器丢步的处理。

### 3.3 液位定频闭环传递当前方向、速度和检测状态

- 源码位置：`oil_level_frequency.c` 的 `FrequencyLevel_CheckMotionGuards()`、`FrequencyLevel_ReadCurrentWithGuards()` 和 `FrequencyLevel_RunClosedLoopConfigured()`。
- 改前问题：运动保护只接收一个方向，无法区分“本轮位置/碰撞保护方向”和“上一段已生效的丢步统计方向”；细调速度变化和换向前停机也没有显式结算上一指令时段。
- 具体改法：保护函数分别接收保护方向、有效指令方向和有效指令速度。换向停机前用旧方向、速度 0 调用方式5接口结算上一时段；运动状态或低速检测启停发生变化时重建窗口，同一运动阶段的连续速度变化由方式5接口逐段积分。
- 必查边界：定频初始运动、细调速度连续变化、细调速度低于 `0.03 m/min`、低速后重新启用检测、稳定停机、上下限保护和称重碰撞保护均需复核。
- 通过标准：丢步检测只在已经存在有效运动指令且检测启用时运行；低速禁用和重新启用不会继承旧窗口；换向前先结算旧方向，换向后重建方向前沿；位置和称重保护返回码不变。

### 3.4 协议与架构资料

- 资料位置：SI PLC 对接协议 PDF、`CG01.系统架构设计-V1.2.docx` 和 `ER02.储罐在线自动计量仪软件架构设计V0.4.docx`。
- 改前问题：当前工作区已经形成相应资料修订，但尚未纳入版本记录；静态文档与本次固件修复属于不同证据层级，需要在提交中分别说明。
- 具体改法：按当前文件状态纳入版本；对 PDF/DOCX 做只读渲染检查，不对其技术内容作超出来源的扩展解释。
- 必查边界：页码、目录、表格、分页、正文裁切、图文对应关系和协议对外语义均需人工复核。
- 通过标准：Word 原生分页下正文无重叠或裁切；SI PDF 所有页面可渲染；架构文档可打开且主体内容可读。ER02 末页旧总页数字段作为已知问题记录，不据此判定正文失效。
