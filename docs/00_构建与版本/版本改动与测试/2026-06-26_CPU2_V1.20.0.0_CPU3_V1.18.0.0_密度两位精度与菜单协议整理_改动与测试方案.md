# CPU2 V1.20.0.0 / CPU3 V1.18.0.0 密度两位精度与菜单协议整理改动与测试方案

日期：2026-06-26

## 版本变化

- CPU2：`V1.19.0.0 -> V1.20.0.0`。
- CPU3：`V1.17.0.0 -> V1.18.0.0`。

## 协议版本/兼容性

- `DEVICE_PROTOCOL_VERSION`: `12 -> 13`。
- 内部密度 raw 从 `kg/m3 x10` 升级为 `kg/m3 x100`，CPU2/CPU3 自有协议按两位小数解释密度字段。
- 共享寄存器地址、字段长度和命令码不后移；本次协议升级原因是共享参数与测量数据的密度倍率语义变化。
- CPU2/CPU3 必须同为协议版本 13；协议版本 12 和 13 混用会导致内部密度字段倍率解释不一致。
- DSM、Wartsila、SI协议边界继续保持原对外口径，主站不需要因内部 raw 倍率调整解析。

## 参数存储兼容性

- CPU2 `DEVICE_PARAM_VERSION`: `3 -> 3`。
- `DeviceParameters` 结构大小：不变。
- 升级是否清参数：否。
- CPU2 旧 FRAM 中 `protocolVersion < 13` 时，运行期一次性迁移 `oilLevelDensity`、`oilLevelThreshold`、`oilLevelHysteresisThreshold` 和 `densityCorrection`，再写回 `protocolVersion = 13`。
- CPU3 本机参数存储版本：`0x0004 -> 0x0005`；加载 `0x0003` 或 `0x0004` 时迁移本机手输密度 `screen_input_d`，并保留 `0x0003` 屏幕亮度默认值迁移路径。
- 现场动作：升级前记录关键密度、液位找液阈值、液位滞后阈值和密度修正值；升级后确认两位小数显示和旧值换算结果。

## 本次改动点

- CPU2/CPU3 密度宏、密度修正基准和密度参数迁移统一到 `kg/m3 x100`。
- CPU3 状态页、密度参数菜单和密度手输值按两位小数显示。
- CPU2 频率找液兼容路径将新 raw 阈值折算回历史 Hz 阈值，避免旧 0/1 测量方式阈值被放大。
- 修复频率跟随稳定判断对浮点 `frequency_difference` 使用整数 `abs()` 的问题。
- CPU3 参数菜单按拖拽排序工具结果重排，新增 `tools/cpu3_menu_sorter.html` 供后续导出排序结果。
- 继电器相关显示名称从 R1~R4 统一为 K1~K4，内部 `RELAY*` 协议符号保持不变。
- AO 高报警液位默认值改为罐高，写参归一化时异常高低报警组合恢复为高报警罐高、低报警 0。
- DSM、Wartsila、SI协议密度协议边界和文档同步整理，补充密度精度、综合密度模式和 SI 契约检查脚本。
- 密度两位小数改造方案移动到“已实现”，同步协议、默认值、菜单、设备说明书和 README 索引。

## 影响范围

- 影响 CPU2 参数存储运行期迁移、液位找液阈值兼容折算、密度测量和外部协议边界转换。
- 影响 CPU3 参数菜单顺序、菜单命名、密度显示、参数手输值、状态页和本机 FRAM 参数版本。
- 影响协议版本 13 的跨 CPU 兼容判断，旧版本 CPU2/CPU3 不应与本版本混用。
- 不影响保持寄存器地址、输入寄存器长度、共享命令号、CPU2 参数存储结构大小。

## 重点测试点

| 测试项 | 前置条件 | 步骤 | 预期结果 | 通过标准 |
| --- | --- | --- | --- | --- |
| 旧 FRAM 密度迁移 | 设备保存过协议 12 或更早参数 | 升级后启动 CPU2，读取密度相关参数和 `protocolVersion` | 密度参数按 x10 到 x100 迁移，协议版本写回 13 | 旧 1 位小数值升级后显示为等价两位小数 |
| 密度修正迁移 | 旧参数存在非零密度修正 | 升级后读取 `densityCorrection` | 零点从 10000 迁移到 100000，修正量数值不变 | 显示修正量与升级前等价 |
| 频率找液兼容 | 液位测量方式为旧频率方案 | 设置找液/滞后阈值并运行频率找液 | CPU2 内部折算回历史 Hz 阈值 | 电机跟随阈值不被 x100 raw 放大 |
| 密度连续找液 | 液位测量方式为密度连续 | 设置 1.50/2.00 kg/m3 阈值 | 按两位密度阈值参与比较 | 阈值显示和算法输入一致 |
| CPU3 密度显示 | CPU3 正常显示 | 浏览状态页、密度参数和手输密度 | 密度显示两位小数 | 无缺字、无越界、无 1 位旧口径残留 |
| 菜单排序 | CPU3 正常显示 | 遍历参数配置和操作菜单 | 菜单顺序符合导出结果 | 参数未丢失，跨菜单移动位置正确 |
| K1~K4 命名 | CPU3 正常显示 | 浏览继电器通道设置、报警配置和报警状态 | 显示 K1~K4 | 不再显示 R1~R4 作为当前菜单名称 |
| AO 默认高报警 | 恢复出厂或新参数初始化 | 读取 AO 高/低报警液位 | 高报警为罐高，低报警为 0 | 写参异常时归一化结果符合文档 |
| DSM 密度边界 | DSM 主站读取密度 | 读取密度和密度修正相关寄存器 | 对外保持原 x10 口径 | 主站无需修改解析 |
| Wartsila 密度边界 | Wartsila 主站读取密度 | 读取密度区间相关字段 | 对外保持 scale=10/x10 | 主站无需修改解析 |
| SI协议密度边界 | SI 主站读取密度 | 读取 0.01 kg/m3 口径字段 | 对外保持既有 0.01 kg/m3 | golden frame 检查通过 |
