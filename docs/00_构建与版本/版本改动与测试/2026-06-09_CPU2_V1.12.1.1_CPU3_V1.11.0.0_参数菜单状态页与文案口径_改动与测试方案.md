# CPU2 V1.12.1.1 / CPU3 V1.11.0.0 参数菜单、状态页与文案口径改动与测试方案

## 版本变化

- CPU2：`V1.12.1.0 -> V1.12.1.1`
- CPU3：`V1.10.1.0 -> V1.11.0.0`
- 升级级别：CPU2 build、CPU3 minor。CPU2 仅调整参数注释和串口打印中文口径；CPU3 调整 OLED 参数配置首页、菜单层级、继电器报警状态只读页、选择项显示、串口协议联动、保存前保护确认流程和状态页测量结果显示策略。

## 协议版本与兼容性

- `DEVICE_PROTOCOL_VERSION` 保持 `7`。
- 不改变 CPU2/CPU3 共享寄存器地址、字段顺序、命令码、参数存储结构或外部协议响应语义。
- CPU2 仅调整中文口径，不改变计算逻辑、默认值、参数布局或保存格式。
- CPU3 本机 FRAM 参数结构未新增字段；旧存储读取后，串口协议预留值会收敛为计量仪协议，并按协议自动套用推荐串口参数。
- 旧 CPU2 固件只要协议版本仍为 `7`，与本版 CPU3 的参数读写和命令下发保持兼容。

## 参数存储兼容性

- CPU2 `DEVICE_PARAM_VERSION`：保持 `3`，不涉及 CPU2 参数结构升级。
- CPU2 `DeviceParameters` / `struct_size`：不变化。
- 升级是否恢复出厂参数：本次 CPU3 改动不会触发 CPU2 参数恢复出厂。
- CPU3 本机通信/显示参数结构不新增字段；但加载旧 FRAM 后会对 COM1/COM2/COM3 执行协议归一化，可能把历史预留协议值改为计量仪协议，并把串口参数改为对应协议推荐值。
- 现场升级建议：升级前记录 COM1/COM2/COM3 协议和串口参数；升级后重点复核外部主站通讯。

## 本次修改

- CPU2 参数注释、串口打印和扭力/探底相关中文口径统一为“扭力/探底”等现场用语，不改变碰撞检测、扭力校准、罐高测量或参数保存逻辑。
- 参数配置首页改为五类：测量参数、输出配置、通信设置、显示设置、维护设置。
- 运行策略从设备信息中拆出并移动到测量参数；设备信息、参数校验集中到维护设置。
- 标定液位值、修正液位值、标定水位值、标定罐高值、单点测量位置、单点监测位置和电机调试位置继续随指令输入，不作为参数配置项展示。
- 带参指令菜单项和下发确认页只显示指令名，不在指令名后追加参数值；参数值仅在输入页和参数写入确认页显示。
- 水位测量方式改为选择式编辑，屏幕显示为“低速模式/快速模式”，写入值限制为 `0/1`，CPU2 仍兼容原 `0/非0` 语义。
- COM 协议菜单只显示计量仪、瓦锡兰、LTD、SI 四个有效选项；SI 仍写入真实协议值 `5`。
- 写任一 COM 串口参数后执行协议优先归一化：计量仪/DSM `4800 8N1`，瓦锡兰 `4800 8N1`，LTD `115200 8N1`，SI `9600 8O1`。
- 对运行策略、电机/编码换算、罐高/罐底、水位关键阈值、通信串口参数和恢复出厂设置增加“参数保护”额外确认页；不新增维护权限或更高等级密码。
- 继电器 R1~R4 子页新增只读“报警状态”入口，显示报警值、HH/H/HH-H/L/LL/LL-L、任意报警和清锁存运行态；状态来自 CPU2 输入寄存器快照，不进入参数写入流程。
- CPU3 状态页新增显示上下文归类，密度、温度、液位、水位、频率、电容和罐高按设备状态选择数据源，避免待机、运动、维护或故障状态混入旧业务结果。
- 位置固定取 `debug_data.sensor_position`，扭力固定取 `debug_data.current_weight`，允许位置或扭力为 `0` 时仍在正常状态页路径显示。
- CPU3 菜单列表、参数详情标题、下发确认页、参数保护页和选择项列表按 OLED 单行宽度使用短名或裁剪，避免长中文/英文名称越过单行显示边界。
- 同步新增 CPU3 状态页不同状态显示信息确认表，作为现场逐状态复核依据。

## 影响范围

- CPU2 串口打印、参数注释和文档中的扭力/探底中文口径。
- CPU3 OLED 参数配置菜单、参数详情页、选择式编辑流程、保存前确认流程。
- CPU3 OLED 继电器报警输出菜单和只读报警状态页。
- CPU3 OLED 状态页显示上下文、结果选源、位置/扭力固定显示和分页内容。
- CPU3 本机 COM1/COM2/COM3 参数写入和 FRAM 保存。
- 不影响 CPU2 测量流程、参数存储布局、共享协议版本和保持寄存器地址。
