# 继电器报警限值写入与参数打印改动与测试方案

## 版本变化

- CPU2: `V1.16.0.1` -> `V1.16.1.0`
- CPU3: `V1.15.1.0` -> `V1.15.2.0`

## 协议版本和兼容性

- `DEVICE_PROTOCOL_VERSION` 保持 10。
- 本次不新增 CPU2/CPU3 共享寄存器、命令码、输入寄存器尾段或保持寄存器字段。
- 继电器报警 HH/H/L/LL 阈值、报警滞回等字段仍按既有 IEEE754 float 原始位解释，寄存器地址和字段语义不变。
- 本次修复 CPU3 菜单写参数时的发送载荷组织方式，解决旧版本写入 float 参数时字序被反转的问题。
- 旧 CPU2 与新 CPU3 或新 CPU2 与旧 CPU3 的协议版本仍匹配为 10，但建议 CPU2/CPU3 成对升级，便于同时获得写入修复和完整参数打印。

## 参数存储兼容性

- CPU2 `DEVICE_PARAM_VERSION` 保持 3。
- `DeviceParameters` 结构大小不变。
- 从旧版本升级不会因参数存储版本或结构大小变化触发恢复出厂参数。
- 现场升级前仍建议记录当前继电器报警参数，升级后重点复核 R1~R4 的报警阈值、滞回、报警模式和接点配置。

## 本次修改

- CPU3 参数配置发送给 CPU2 时，float 参数直接使用 IEEE754 原始 32 位值交给 `CPU2_CombinatePackage_Send()` 处理字序，避免旧逻辑先按字节重组再由发送层换字导致 CPU2 收到错误浮点值。
- CPU3 double 参数按高低 32 位原始值组织，保持与发送层字序处理一致。
- CPU3 整型参数保留 `offset` 扣减逻辑，本机参数写入路径只对非 float/double 参数应用 `offset`。
- CPU2/CPU3 `print_device_params()` 补全继电器报警配置打印，新增无效值、HH/H/L/LL 阈值、滞回、阻尼和清锁存字段。
- `tools\bump_version.py` 增加 UTF-8/GBK 版本头读取和按原编码写回能力，避免 CPU2 GBK 版本头阻塞升版。

## 影响范围

- 影响 CPU3 菜单写入 CPU2 保持寄存器的参数配置路径。
- 影响 CPU2/CPU3 参数打印输出内容。
- 不改变 CPU2 参数存储布局、默认值、恢复出厂逻辑和协议版本。
- 不改变外部 Modbus 地址、SI7000/DSM/Wartsila 协议映射或 AO 输出运行态。

## 重点测试点

### 继电器 float 阈值写入

准备条件：
- CPU2 与 CPU3 使用本次版本。
- R1~R4 继电器报警参数可通过 CPU3 菜单编辑。
- 串口可查看 CPU2 参数打印。

步骤：
1. 在 CPU3 菜单分别设置 R1~R4 的 HH、H、L、LL 阈值和报警滞回。
2. 写入后触发 CPU2 参数打印。
3. 对比菜单输入值和打印出的 `HH/H/L/LL/滞回`。

预期结果：
- CPU2 打印值与 CPU3 菜单输入值一致，允许按参数小数位产生显示精度内差异。
- 不再出现明显异常的大数、负数或 IEEE754 字序反转后的异常值。

通过标准：
- R1~R4 每一路至少覆盖一个非零阈值和一个非零滞回。
- 写入后掉电重启或重新读取参数时数值仍保持一致。

### 继电器参数打印完整性

准备条件：
- 继电器配置中至少覆盖禁用、无源输出、不同报警位、常开/常闭和报警模式开/关组合。

步骤：
1. 触发 CPU2 和 CPU3 参数打印。
2. 检查每一路继电器是否打印两行：配置枚举行和阈值详情行。
3. 确认 `无效值`、`HH`、`H`、`L`、`LL`、`滞回`、`阻尼`、`清锁存` 均有输出。

预期结果：
- 每一路继电器输出完整，不再只打印模式、报警源、报警位、接点和报警模式。
- 未定义枚举值显示为 `未定义`，不会影响后续字段输出。

通过标准：
- R1~R4 均完整输出新增字段。
- 串口工具显示无乱码、无明显截断。

### 非浮点参数回归

准备条件：
- 可通过 CPU3 菜单写入至少一个整型 CPU2 参数和一个 CPU3 本机参数。

步骤：
1. 修改整型 CPU2 参数并读取确认。
2. 修改 CPU3 本机通信或显示参数并保存重启确认。

预期结果：
- 整型参数仍按既有 `offset` 口径写入。
- CPU3 本机参数保存、重启加载和通信重配请求保持原行为。

通过标准：
- 非浮点参数写入无回归。

## 回归范围

- CPU3 参数菜单进入、编辑、确认、取消和写入反馈。
- CPU2 保持寄存器写入和读取回读。
- CPU2/CPU3 参数打印。
- 版本号显示和构建产物命名。
- 版本脚本对 UTF-8 CPU3 版本头、GBK CPU2 版本头和 UTF-8 `CHANGELOG.md` 的读写。
