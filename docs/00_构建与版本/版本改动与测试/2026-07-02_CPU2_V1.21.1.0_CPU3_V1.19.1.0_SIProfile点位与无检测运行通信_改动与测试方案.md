## 协议版本/兼容性

- `DEVICE_PROTOCOL_VERSION` 保持 14，本次不改变 CPU2/CPU3 共享协议契约。
- 仍要求 CPU2/CPU3 均为协议版本 14 才能正确使用独立 SI Profile 命令、SI Profile 参数、`profile_source` 和输入寄存器点阵。
- SI Profile `40001` 首点语义保持为绝对位置；本次修复 CPU2 执行路径，确保首点不再被误叠加罐底位置。
- SI Profile 点 0 对外上报位置固定为 0，后续点上报实际绝对运动位置，便于 DCS/PLC 区分空气点和真实采样点。

## 参数存储兼容性

- CPU2 `DEVICE_PARAM_VERSION`: 3 -> 3。
- `DeviceParameters` / `struct_size`: 不变。
- 升级是否清参数：否；从 V1.21.0.0 升级到 V1.21.1.0 不会因参数存储版本触发恢复出厂参数。
- CPU3 本机参数版本保持 `0x0006`，不改变本机 FRAM 布局。
- 现场动作：升级后复核 SI Profile 首点、步距、停留、探底频次、自动 Profile 使能和探底修正罐高等参数值即可，无需因本次升级重新下发全部参数。

## 本次改动点

- CPU2 SI Profile 首点按 `40001` 配置值作为绝对目标位置执行，不再叠加罐底位置。
- CPU2 SI Profile 点 0 上报位置固定为 0，后续点使用运动绝对位置作为输出位置，并同步到保存结果的温度位置字段。
- CPU2 SI Profile 到点后先按低密度频率判定空气点，再等待无效频率，避免空气点因零频或无效频率等待被误判为失败。
- CPU2 普通无检测阻塞运动不再调用带密度传感器通信的运行日志；强制调试无检测运行仍保留传感器通信，串口测试命令 `B/BE` 的 `S`/`,1` 控制保持独立。
- CPU3 本机参数保存不再被 CPU2 测量状态限制误拦截；CPU2 忙态或禁止普通参数写入时，CPU3 本机参数仍可保存。
- CPU3 SI 自动 Profile 使能按布尔选项显示，探底修正罐高参数在探底、Wärtsilä 和 SI Profile 相关菜单组可见。
- 同步 SI 协议契约检查脚本、SI 官方资料中文整理、故障码统一表、LNG 菜单文档和相关 README/索引。

- CPU2 无检测阻塞运动接口的密度传感器通信行为。
- CPU3 参数写入入口和 SI 相关菜单可见性。

## 重点测试项

| 测试项 | 前置条件 | 步骤 | 预期结果 | 通过标准 |
| --- | --- | --- | --- | --- |
| SI Profile 首点绝对位置 | CPU2/CPU3 均为协议 14；配置 `40001` 首点 | 通过 PLC 或 CPU3 菜单启动 SI Profile，记录首个非零目标位置 | CPU2 直接移动到 `40001` 对应绝对位置 | 首点不再额外叠加罐底位置 |
| SI Profile 点 0 输出 | 已启动 SI Profile | 读取 SI Profile 输入寄存器第 0 点位置、密度和温度 | 第 0 点位置为 0 | 第 0 点对外位置恒为 0 |
| SI Profile 后续点输出 | 首点和步距配置有效 | 读取第 1 点及后续点位置 | 后续点位置为实际运动绝对位置 | 输入寄存器和保存结果中的位置一致 |
| 空气点低密度频率判定 | 可模拟或实测低密度频率 | 运行 SI Profile 到空气点 | 先按空气点停止，不被无效频率等待卡住 | 空气点能按预期结束并输出有效状态 |
| 普通无检测运行不通信 | 接入传感器通信抓包或日志 | 触发普通 `MotorCtrl_MoveBlockingNoDetect` 路径 | 不产生密度传感器运行通信 | 运行过程无 `Read_Density()` 类传感器通信 |
| 强制调试无检测运行仍通信 | 启用强制调试路径 | 触发强制调试无检测运行 | 保留传感器通信和运行日志 | 抓包或日志能看到传感器通信 |
| 串口测试命令独立控制 | 接入 CPU2 串口 | 执行 `B/BE` 测试命令并组合 `S` 或 `,1` 参数 | 串口测试命令按自身参数决定是否通信 | 不受普通无检测接口修改影响 |
| CPU3 本机参数忙态保存 | CPU2 处于测量或禁止普通写参状态 | 在 CPU3 修改 SI 自动 Profile 使能或报警限值并保存 | CPU3 本机参数保存成功 | 断电重启后参数仍保持 |
| CPU3 菜单显示 | CPU3 实机或菜单检查工具可用 | 查看 SI、Wärtsilä、探底相关参数组 | SI 自动 Profile 为布尔选项，探底修正罐高可见 | 菜单项不丢失、不截断、不乱码 |
