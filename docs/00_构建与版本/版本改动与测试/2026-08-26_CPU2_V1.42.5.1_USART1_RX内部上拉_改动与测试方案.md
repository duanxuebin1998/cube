# CPU2 V1.42.5.1 USART1 RX内部上拉改动与测试方案

## 1. 文档目的和适用版本

本文记录CPU2 V1.42.5.1相对V1.42.5.0的USART1 RX GPIO上拉变更、兼容性、验证证据和未验证边界。本次仅修改CPU2，不修改CPU3，不推送远端。

## 2. 版本、协议和参数存储兼容性

- CPU2：`V1.42.5.0 -> V1.42.5.1`，BUILD。
- CPU3：保持`V1.40.1.0`。
- `DEVICE_PROTOCOL_VERSION`保持35；CPU2/CPU3共享寄存器、共享命令、共享状态和共享字段不变。
- CPU2 `DEVICE_PARAM_VERSION`保持3；`DeviceParameters`结构、`struct_size`、CRC范围和FRAM布局不变，升级不恢复出厂、不清除现场参数。
- USART1 PA9 TX、PA10 RX复用功能仍为GPIO_AF7_USART1，串口帧格式、115200波特率、DMA流和中断配置保持兼容；仅PA10内部偏置从无上下拉改为上拉。

## 4. 逐项改动清单

### 4.1 USART1 RX启用内部上拉

- 源码位置：`LTD_MAIN_CPU2/Core/Src/usart.c`的`HAL_UART_MspInit()` USART1分支；配置来源为`LTD_MAIN_CPU2/LTD_MAIN_CPU2.ioc`的`PA10`条目。
- 改前问题：PA9 TX与PA10 RX合并使用`GPIO_NOPULL`初始化，USART1 RX在外部驱动释放或连接不稳定时没有芯片内部上拉偏置，输入电平容易悬空。
- 具体改法：先以`DEBUG_TXD1_Pin`、`GPIO_MODE_AF_PP`、`GPIO_NOPULL`和`GPIO_AF7_USART1`初始化PA9；再以`DEBUG_RXD1_Pin`、同一复用模式和`GPIO_PULLUP`初始化PA10。`.ioc`同步增加`PA10.GPIO_PuPd=GPIO_PULLUP`及对应参数声明。
- 必查边界：PA9 TX仍为无上下拉；PA10 RX复用号、速度和模式不变；USART1 DMA、中断、波特率和启动顺序不变；外部已有下拉或推挽驱动时需现场确认电平冲突和静态电流。
- 通过标准：编译产物中USART1初始化无合并的TX/RX `GPIO_NOPULL`配置，PA10使用`GPIO_PULLUP`；CubeMX重新生成后保留PA10上拉设置。
