## 2. 主要改动

### 2.1 AO传感器位置源

- AO过程源固定为储罐液位、传感器位置和水位。
- 传感器位置直接读取测量调试快照；编码轮模式按编码器就绪门控，电机记步模式按驱动初始化有效门控，`0.0mm`允许作为有效位置。
- 储罐液位和水位继续只在匹配跟随命令和状态下更新；位置源就绪后持续跟随，不受测量命令门禁限制。

### 2.2 初始、过程与保持状态

- 原非跟随电流改为初始电流；首次有效过程目标成功写入AD5421前发布初始状态。
- 第一个成功过程写入建立RAM缓存，缓存包含成功电流、同轮阻尼后输入值和比例。
- 命令切换、重新搜索、自动恢复等待新样本或过程样本暂时无效时发布保持状态，继续使用上次成功过程目标。
- 保持期间冻结阻尼时间；恢复有效输入后从保持值继续。AD5421写失败不更新缓存。
- 禁用、输出源/电流模式/量程变化清缓存；位置源下罐高或记步方式变化也清缓存。真实设备故障优先于仿真。

### 2.3 CPU3通信健康与快照门禁

- 已建立公开快照后，第1～2次连续失败只记录并重试；连续第3次失败才作废状态、参数、协议和固定点公开快照并完整重同步。
- 连续第10次请求失败仍锁存CPU2通信超时故障；任一严格合法响应清零连续失败，只有完整状态快照才能解除故障锁存。
- 新增成功、超时、CRC、地址、功能码、长度、UART ORE/FE/NE/PE、UART事务失败、TX DMA启动失败、当前/最大连续失败和最近失败原因等RAM计数。
- UART错误回调向通信层传递实际HAL `ErrorCode`，便于区分底层错误来源。

### 2.4 CPU3维护页和AO运行页

- 维护设置新增三页“CPU2通讯”，显示请求总数、失败率、错误分类、当前/最大连续失败和最近失败原因。
- 统计上电清零，仅用于当前运行期诊断，不属于共享寄存器、CPU3本机参数或掉电记录。
- AO参数和运行页同步显示传感器位置源、初始/过程/保持状态、输入值、比例和最近成功下发电流。

## 4. 现场与台架验证

以下项目不能由静态契约和交叉编译替代：

- 三种AO过程源在真实4～20mA负载上的端点、线性、阻尼和环路精度。
- 传感器位置`0.0mm`、编码轮未就绪、电机记步初始化无效和罐高/记步方式切换清缓存。
- 命令切换、重新搜索、自动恢复、暂时无样本时的保持电流，以及恢复有效样本后的阻尼连续性。
- AD5421写失败、断环/HART异常、真实设备故障与仿真同时存在时的优先级和缓存不更新边界。
- 分别注入超时、CRC、地址、功能码、长度、UART ORE/FE/NE/PE、事务失败和TX DMA启动失败，核对三页维护统计。
- 协议23/24交叉烧写时严格版本门禁，以及协议24配套恢复后的完整重同步。
