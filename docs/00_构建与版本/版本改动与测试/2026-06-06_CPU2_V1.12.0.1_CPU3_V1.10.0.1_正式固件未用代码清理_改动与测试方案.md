# CPU2 V1.12.0.1 / CPU3 V1.10.0.1 正式固件未用代码清理改动与测试方案

日期：2026-06-06

## 1. 版本变化

| 固件 | 旧版本 | 新版本 | 升级级别 | 原因 |
| --- | --- | --- | --- | --- |
| CPU2 | `V1.12.0.0` | `V1.12.0.1` | build | 删除已确认未用源码接口后 `.hex` 哈希变化，需要追踪构建产物 |
| CPU3 | `V1.10.0.0` | `V1.10.0.1` | build | 删除已确认未用源码接口和旧兼容分发文件后 `.hex` 哈希变化，需要追踪构建产物 |

## 2. 协议版本和兼容性

- `DEVICE_PROTOCOL_VERSION` 保持 7。
- 不改变 CPU2/CPU3 共享 Modbus 寄存器地址、长度、字段含义、命令码或参数解释口径。
- 不改变 SI、DSM、CPU2/CPU3 共享输入寄存器的正式读写语义。
- CPU2 仍负责写入测量结果输入寄存器，CPU3 仍负责读取 CPU2 输入寄存器；被删除的是未调用的反向解析/备用写入路径。
- CPU3 旧 `com_manager` 文件删除后，正式通信分发仍由现有 `app_main` 和各协议模块路径承担。

## 3. 详细改动点

### 3.1 CPU2 删除项

- 删除 `CH9141EVT.c/.h` 旧 AT 初始化备用入口。
- 删除 `fault_manager` 旧接口：`g_faultInfo`、`update_errorcode()`、`check_fault_with_threshold()`。
- 删除 `measure_waterLevel` 未用接口：`read_oil_capacitance()`、`UpdateWaterLevelIfValid()`。
- 删除 `AS5145_GetLastOkTick()`。
- 删除 `TMC5130 stpr_readInt()`。
- 删除输入寄存器反向解析链路及只被该链路引用的 `MotorCtrl_SetSpeed()`。
- 删除 `WIRELESS_Read_IntParam()` 及其内部解析辅助函数。
- 删除 `ErrorLog_Report()`，保留 `ErrorLog_ReportDetail()`。

### 3.2 CPU3 删除项

- 删除 `Communication/common/com_manager.c/.h` 旧兼容分发模块。
- 删除 OLED 未用接口 `CLS_scope()`、`oled_map_128_64()`。
- 删除 CPU3 时钟设置入口 `Cpu3Clock_SetDateTime()`。
- 删除设备状态错误设置入口 `setEquipStateError()`。
- 删除 DSM 备用发送入口、输入寄存器单读写接口和未用版本占位注释。
- 删除 SI 站号 get/set 接口。
- 删除 CPU2 通信初始化入口 `CommuToCPU2Init()`。
- 删除 CPU3 写测量结果到输入寄存器的备用路径。
- 删除 CPU2 单参数同步入口 `DeviceParams_SyncOneToCPU2()`。

### 3.3 工具脚本和文档

- 调整 `tools/check_si_protocol_contract.py`：保留对 CPU2 正向写入和 CPU3 正向读取的强校验，对已删除的 CPU2 反向读取和 CPU3 写入死接口改为存在时校验。
- 更新 `CHANGELOG.md`，记录版本变化、兼容性、删除项和验证结果。
- 更新未用代码逐项确认文档，将“后续实施计划”改为“已实施记录”。
- 新增本版本改动与测试方案，并更新本目录索引。
