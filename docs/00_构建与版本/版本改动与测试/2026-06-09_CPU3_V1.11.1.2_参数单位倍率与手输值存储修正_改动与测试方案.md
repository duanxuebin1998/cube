# CPU3 V1.11.1.2 参数单位倍率与手输值存储修正改动与测试方案

日期：2026-06-09

## 1. 版本

- CPU2：保持 V1.12.1.2
- CPU3：V1.11.1.1 -> V1.11.1.2

## 2. 兼容性

- `DEVICE_PROTOCOL_VERSION` 保持 7。
- 不改变 CPU2/CPU3 共享保持寄存器地址、字段顺序、命令码或 CPU2 `DeviceParameters` 结构。
- CPU2 `DEVICE_PARAM_VERSION` 保持 3，不触发 CPU2 设备参数恢复出厂。
- CPU3 本地显示/通信参数结构变更，`CPU3_PARAM_VERSION` 从 `0x0002` 升至 `0x0003`。
- 从旧 CPU3 固件升级后，CPU3 本地显示/通信参数会按默认值重建并写回 FRAM，避免旧结构布局被误读。

## 3. 改动内容

### 3.1 参数菜单单位补充

- 电机限速显示单位改为 `m/min`，小数位保持 2 位，对应原始值 `0.01m/min`。
- 液位找液阈值、液位滞后阈值显示单位改为 `Hz`，小数位改为 0 位，对应 CPU2 算法直接比较的整数频率差。
- 水位跟随电容阈值、水位寻找电容阈值、水位滞后电容阈值显示单位改为 `pF`，小数位保持 3 位，对应原始值 `pF x1000`。
- 零点电容显示单位改为 `pF`，小数位保持 1 位，对应原始值 `0.1pF`。
- 探底角度阈值显示单位改为 `°`，小数位保持 0 位。

### 3.2 参数文案和倍率修正

- “磁通量D”改为“密度修正”，显示单位为 `kg/m3`，小数位 1 位。
- “磁通量T”改为“温度修正”，显示单位为 `℃`，小数位 1 位。
- 气相温度、标定尺带温度显示单位统一为 `℃`，小数位保持 1 位。
- 密度手输值按 `kg/m3 x10` 显示和输入，范围从 `0~2000`、3 位小数改为 `0~20000`、1 位小数。
- 密度手输值显示范围从旧口径 `0.000~2.000 kg/m3` 修正为 `0.0~2000.0 kg/m3`。

### 3.3 CPU3 本地手输值存储修正

- CPU3 本地液位手输值、水位手输值、密度手输值、温度手输值字段从 `uint8_t` 改为 `int32_t`。
- 保持上传手输密度开关为 `uint8_t`。
- 修正后液位/水位手输值最大 `99999.9mm`、密度手输值最大 `2000.0kg/m3`、温度手输值 `-50.0~200.0℃` 均可按菜单原始倍率保存，不会被 8 位字段截断。

## 4. 影响范围

- 影响 CPU3 参数菜单列表页、详情页、输入页的单位、文案和范围显示。
- 影响 CPU3 本地 FRAM 中显示/通信参数的结构布局和版本号。
- 不影响 CPU2 传感器算法、运动控制、水位逻辑、外部协议地址或 CPU2 参数存储。

## 6. 实物联调

1. 进入参数菜单，确认以下参数列表页、详情页、输入页单位显示正确：
   - 电机限速：`m/min`
   - 液位找液阈值：`Hz`，整数显示
   - 液位滞后阈值：`Hz`，整数显示
   - 水位跟随电容阈值：`pF`
   - 水位寻找电容阈值：`pF`
   - 零点电容：`pF`
   - 水位滞后电容阈值：`pF`
   - 探底角度阈值：`°`
   - 密度修正：`kg/m3`
   - 温度修正：`℃`
   - 密度手输值：`kg/m3`
   - 气相温度、标定尺带温度：`℃`

2. 输入并保存典型手输值，断电重启后确认读回不截断：
   - 液位手输值：`12345.6mm`
   - 水位手输值：`23456.7mm`
   - 密度手输值：`1000.0kg/m3`
   - 温度手输值：`25.0℃`

3. 从旧 CPU3 固件升级到 V1.11.1.2，确认 CPU3 本地参数版本不匹配时会恢复默认显示/通信配置并写回 FRAM。

4. 确认 CPU2 参数保持不变，外部协议读写地址和 CPU2 运行逻辑不受影响。

## 7. 回归风险

- CPU3 本地参数结构升级会重建本地显示/通信参数；现场如依赖非默认 COM 配置，升级后需重新设置。
- 参数菜单新增单位和文案后，OLED 排版需实物确认是否存在单行过长或输入页遮挡。
- 本次未给扭力类参数和尺带伸缩率补单位，这些仍需算法或现场口径确认后单独处理。
