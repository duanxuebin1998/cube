## 协议版本/兼容性

- `DEVICE_PROTOCOL_VERSION` 保持 14，本次不改变 CPU2/CPU3 共享协议契约。
- 仍要求 CPU2/CPU3 均为协议版本 14 才能正确使用独立 SI Profile 命令、SI Profile 参数、`profile_source` 和输入寄存器点阵。
- SI Profile 成功锁存后先进入完成态，随后由 CPU2 自动排队 `CMD_FIND_OIL`，下一轮主循环恢复找液位和液位跟随。
- SI Profile 失败或检测到有效命令切换时，不排队 `CMD_FIND_OIL`，避免覆盖外部新命令。

## 参数存储兼容性

- CPU2 `DEVICE_PARAM_VERSION`: 3 -> 3。
- `DeviceParameters` / `struct_size`: 不变。
- 升级是否清参数：否；从 V1.21.1.0 升级到 V1.21.2.0 不会因参数存储版本触发恢复出厂参数。
- CPU3 本机参数版本保持 `0x0006`，不改变本机 FRAM 布局。
- 现场动作：升级后复核 SI Profile 首点、步距、停留、探底频次、自动 Profile 使能和报警限值即可，无需因本次升级重新下发全部参数。

## 本次改动点

- CPU2 `CMD_SiProfile()` 在成功打印和状态锁存后，若没有有效命令切换请求，则把 `g_deviceParams.command` 置为 `CMD_FIND_OIL`。
- CPU2 保留 SI Profile 完成态发布，外部主机仍可先读取 `10005`、`30006` 和 `30021~30620` 的 profile 完成结果。
- CPU2 在有待执行命令时保留原命令，不用自动找液位覆盖手动、维护或其它外部命令。
- `tools/check_si_protocol_contract.py` 增加静态契约检查，防止后续实现重新丢失成功后排队 `CMD_FIND_OIL` 的行为。
- 同步 SI 协议需求总览、兼容映射表、PLC 联调检查表和 SI profile 程序流程页，补齐 Profile 完成后回 Auto 的生命周期说明。
- 整理传感器新一代安全通信协议卷、SI 官方资料中文整理、SIL 功能安全外部资料、CPU3 当前屏幕菜单树和相关 README/索引。

## 重点测试项

| 测试项 | 前置条件 | 步骤 | 预期结果 | 通过标准 |
| --- | --- | --- | --- | --- |
| SI Profile 成功后回液位跟随 | CPU2/CPU3 均为协议 14；SI Profile 参数有效 | 通过 PLC 或 CPU3 菜单启动 SI Profile，等待 profile 完成后继续观察主循环状态 | profile 先进入完成态，随后 CPU2 自动执行 `CMD_FIND_OIL` | 外部可读到 profile 完成结果，之后设备恢复液位跟随 |
| 新命令不被覆盖 | SI Profile 运行结束前下发手动或维护命令 | 在 profile 即将结束时触发命令切换 | CPU2 保留新命令，不自动写入 `CMD_FIND_OIL` | 新命令按预期执行，日志显示 pending command kept |
| Profile 失败不自动找液位 | 构造 SI Profile 运行失败或阻塞 | 启动 SI Profile 并触发失败出口 | 不排队 `CMD_FIND_OIL` | 故障状态和错误码保持，未进入液位跟随 |
| SI 协议完成态读取 | PLC 按原地址读 `10005`、`30006`、`30021~30620` | Profile 完成后立即读取一次，再等待找液位恢复后再次读取 | 完成点数和点阵有效，后续找液位不清除已锁存 profile 数据 | PLC 能读取完整 profile 结果 |
| 自动 Profile 生命周期 | 开启 `40011` 并配置 `40010/40012/40013` | 等待自动触发 SI Profile 并完成 | 自动 Profile 完成后同样回液位跟随 | 自动和手动触发路径一致 |
