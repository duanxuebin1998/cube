# CPU3 V1.11.1.1 继电器报警阈值动态单位改动与测试方案

## 版本变化

- CPU2：保持 `V1.12.1.2`
- CPU3：`V1.11.1.0 -> V1.11.1.1`
- `DEVICE_PROTOCOL_VERSION`：保持 `7`
- 升级级别：CPU3 build。仅改变 OLED 参数菜单显示单位，不改变共享寄存器、参数结构、参数值倍率、范围校验或 CPU2 执行逻辑。

## 协议版本与兼容性

- 不改变 CPU2/CPU3 共享寄存器地址、字段顺序、命令码或输入寄存器。
- 不改变 `DeviceParameters` 结构大小，CPU2 `DEVICE_PARAM_VERSION` 保持 `3`。
- 不启用新的 `is_check`，不改变 `valuemin` / `valuemax`，不改变现场可写入范围。
- R1~R4 报警阈值和报警滞回仍按 IEEE754 float 原始位传输；本次只在 CPU3 显示层根据同一路“报警取值源”选择单位。

## 本次修改

- 新增 CPU3 参数显示单位解析：普通参数继续使用 `param_meta[].unit`。
- R1~R4 的 HH/H/L/LL 报警阈值和报警滞回不写静态单位，显示时读取同一路 `relayAlarm[channel].alarm_source`：
  - 储罐液位：`mm`
  - 水位：`mm`
  - 浮子位置：`mm`
  - 液相温度：`℃`
  - 无或非法值：不显示单位
- 参数列表页、详情页和输入页统一走动态单位解析，避免同一参数在不同页面单位不一致。
- 同步更新 `CPU3参数单位与范围补充清单.md` 和界面文档索引。

## 影响范围

- CPU3 参数菜单列表页中 R1~R4 报警阈值/滞回的当前值显示。
- CPU3 参数详情页中 R1~R4 报警阈值/滞回的当前值显示。
- CPU3 参数输入页中 R1~R4 报警阈值/滞回的输入单位提示。
- 不影响继电器报警输出配置写入、CPU2 参数保存、继电器运行态、报警判断或锁存清除逻辑。
