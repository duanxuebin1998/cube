# 附件与源文件清单

更新日期：2026-07-20

本文用于说明 `docs/` 中 DOCX、XLSX、PDF、DAT、ZIP 等非 Markdown 文件的用途和维护口径。它是人工维护索引，不是 skill 生成版本文档的规则，也不作为提交新版本的强制检查项。

## 使用边界

- 项目正文优先维护 Markdown；Office、PDF、DAT、ZIP 多数是源表、原始记录、外部资料或历史阅读件。
- 默认不生成、不检查、不同步 PDF；只有明确需要交付 PDF 时才处理。
- 后续版本提交生成新文档时，仍按既有 skill 规则写入 `版本改动与测试/`，本文可后补，不阻塞提交。
- 原厂资料、标准、芯片手册和外部包不批量改名；需要补说明时优先补 README 或 Markdown 摘要。

## 后续维护建议

1. 新增 Office、PDF、DAT、ZIP 附件时，优先放到对应业务目录，并在该目录 README 写用途。
2. 如果附件会长期参与维护，补一个 Markdown 摘要，说明权威来源、版本、维护责任和更新触发条件。
3. 同名 Markdown 与 PDF/DOCX 同时存在时，先确认 README 口径；一般以 Markdown 为正文，PDF/DOCX 为导出件或历史源稿。
