# 故障代码表权威来源判定

更新日期：2026-07-02

本文用于记录 CPU2/CPU3 两份历史 `LTD故障代码表.xlsx` 的合并结果，避免后续继续出现两个故障代码表。当前正式表格入口已经统一为 `docs/00_构建与版本/故障码/LTD故障代码统一表.xlsx`。

## 结论

- 故障码定义的最终依据是 CPU2 源码：`LTD_MAIN_CPU2/Services/ParamStorage/system_parameter.h` 中的 `ErrorCode`。
- `docs/00_构建与版本/故障码/当前程序故障代码清单.md` 是当前源码的可检索 Markdown 清单，列出 73 项 `ErrorCode`、类别区间和上报路径。
- `docs/00_构建与版本/故障码/LTD故障代码统一表.xlsx` 是唯一表格维护入口，已包含 73 项当前故障代码总表、分类规则、链路复查、治理摘要、旧表差异、CPU2 设备参数/测量结果和 CPU3 显示/保持寄存器/`param_meta` 辅助页。
- 历史 CPU2 分表的故障代码总表已并入统一表；历史 CPU3 分表只作为合并来源，不再作为故障码定义或显示辅助的维护入口。
- 如果 Excel 表和源码冲突，以源码为准；维护表格时先按 CPU2 `ErrorCode` 和 CPU2 日志原因更新统一表，再同步 CPU3 显示文案或辅助页。

## 判定依据

| 对象 | 判定 |
| --- | --- |
| CPU2 `ErrorCode` 枚举 | 故障码产生和上报的源头，包含当前 73 项，包括 `NO_ERROR`、`STATE_SWITCH` 和 5 个 `AD5421_*` 错误码 |
| CPU2 `ErrorLog_GetCodeName/ReasonByCode` | 当前覆盖 CPU2 `ErrorCode` 枚举中的故障码，用于日志名称和原因口径 |
| CPU3 `ErrorCode` 枚举 | 与 CPU2 枚举保持一致，额外保留 `SENSOR_COMM_TIMEOUT = SENSOR_DEVICE_COMM_TIMEOUT` 兼容别名 |
| CPU3 `Display_GetErrorReasonByCode` | 用于屏幕显示原因，覆盖故障态错误码；`NO_ERROR`、`STATE_SWITCH` 不作为故障原因显示 |
| Markdown 当前清单 | `当前程序故障代码清单.md` 由当前 CPU2 `ErrorCode` 整理，便于文本检索、审阅和协议资料引用 |
| 统一 Excel 总表 | 当前 73 项，已按源码补齐 `AD5421_INIT_ERROR`、`AD5421_WRITE_CURRENT_ERROR`、`AD5421_FAULT_PIN_ERROR`、`AD5421_READFAULT_ERROR`、`AD5421_READBACK_ERROR`，并补充责任域、故障层级、处理策略、当前使用状态、治理意见和兼容性影响 |
| 分类规则和链路复查页 | 记录当前分类口径、源码使用统计、CPU2 日志覆盖、CPU3 显示覆盖、预留/历史保留和第 3 阶段调用点评审候选 |
| 旧表差异页 | 记录历史 CPU3 表中的旧口径条目，例如 `MOTOR_OVERCURRENT`、`ENCODER_DATA_LOST`、`MEASUREMENT_ZERO_CALIB_TIMEOUT`，明确不作为当前故障码定义 |

## 维护顺序

1. 先检查 `LTD_MAIN_CPU2/Services/ParamStorage/system_parameter.h` 的 `ErrorCode`。
2. 同步检查 `LTD_MAIN_CPU2/Services/Utilities/error_log.c` 的 `ErrorLog_GetCodeName()` 和 `ErrorLog_GetReasonByCode()`。
3. 同步检查 `LTD_DISPLAY_CPU3/Application/system_param/system_parameter.h` 的 `ErrorCode` 兼容枚举。
4. 同步检查 `LTD_DISPLAY_CPU3/Application/display/display.c` 的 `Display_GetErrorReasonByCode()`。
5. 先更新 `docs/00_构建与版本/故障码/当前程序故障代码清单.md`，再更新 `docs/00_构建与版本/故障码/LTD故障代码统一表.xlsx`，必要时同步统一表中的分类规则、链路复查、治理摘要或 CPU3 辅助页。
6. 如果错误码调用点、语义、显示或协议映射发生变化，同步复核统一表中的兼容性影响，并检查版本改动与测试资料。

## 当前处理

- 统一表已补齐 5 个 `AD5421_*` 错误码，并在“整理说明”中记录权威来源和两份旧表的合并原因。
- Markdown 当前清单已按当前源码列出 73 项故障码、上报路径、分类治理基线、链路复查结论和维护检查项。
- 统一表已补充“分类规则”“链路复查”“治理摘要”三个工作表；当前标注运行使用 54 项、非故障状态 2 项、预留/历史保留 17 项，并列出 8 个第 3 阶段调用点评审候选。
- CPU3 显示、设备参数、测量结果、保持寄存器和 `param_meta` 辅助资料已合并进统一表；后续只维护统一表，不再维护 CPU2/CPU3 两份分表。
