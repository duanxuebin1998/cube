2. 当前上报和显示链路

故障码不是单点资料。一个新增或改写的错误码至少需要穿过 CPU2 业务、CPU2 日志、CPU2/CPU3 共享寄存器、CPU3 显示和外部协议口径。

CPU2 业务代码测量、电机、编码器、传感器、参数和 AO 输出路径返回具体 ErrorCode。
统一故障出口最终故障优先通过 fault_manager 写入 g_measurement.device_status.error_code。
CPU2/CPU3 共享REG_DEVICE_STATUS_ERROR_CODE 以 32 位错误码传递给 CPU3。
CPU3 显示Display_GetErrorReasonByCode() 转换为屏幕故障原因。
外部协议DSM 使用 INPUTREGISTER_ERRORNUM；SI 当前把非零错误码合成为联锁/卷尺报警。
治理边界：只改文档不会改变固件行为；改日志或显示会改变用户可见文案；改返回码或新增编号会改变外部可见故障语义，需要同步 CPU2/CPU3 和协议资料。

3. 当前主要问题

大类混合责任域

0x0D 同时包含传感器、密度、无线滑环和蓝牙链路；0x13 同时包含其他系统错误和 AD5421。

通用码承担过多语义

PARAM_ERROR、PARAM_ADDRESS_OVERFLOW、SENSOR_RESP_FORMAT_ERROR、SENSOR_DEVICE_COMM_TIMEOUT、MOTOR_TMC_COMM_ERROR 都存在定位粒度偏粗的问题。

预留码和运行码已标注

17 项当前未见运行触发点，已在统一表标注为预留/历史保留，原则是不删除、不复用旧值。

外部协议口径偏二值

SI 的 10004 Interlock 和 10009 Reel Alarm 当前主要判断是否存在故障，没有进一步按故障族细分。

5. 可以先统一归类整理的故障码

这些整理可以先落在文档和 Excel 分类字段上，不必立即新增编号。

统一目标建议纳入的故障码整理方向
无线/滑环链路类SLIPRING_COMM_FAIL、SLIPRING_BCC_ERROR、SLIPRING_PACKET_LOSS、SLIPRING_SIGNAL_WEAK、WIRELESS_HOST_COMM_TIMEOUT、WIRELESS_SLAVE_COMM_TIMEOUT文档上从传感器大类中单独列出无线链路责任域；后续再决定是否建立新类型区间。
AO/AD5421 输出类AD5421_INIT_ERROR、AD5421_WRITE_CURRENT_ERROR、AD5421_FAULT_PIN_ERROR、AD5421_READFAULT_ERROR、AD5421_READBACK_ERROR虽然当前值在 0x13，文档和表格应作为独立 AO/AD5421 责任域维护。
传感器数据质量类DENSITY_INVALID、DENSITY_UNSTABLE、SONIC_FREQ_ABNORMAL、SENSOR_TEMPERATURE_ERROR、SENSOR_VOLTAGE_ERROR区分“通信失败”和“返回数据不可信”，方便测量流程决定是否重试或退出。
测量阶段失败类MEASUREMENT_OILLEVEL_*、MEASUREMENT_WEIGHT_*、MEASUREMENT_DENSITY_*、MEASUREMENT_ZERO_*按流程阶段归档：找液位、寻重、密度测量、零点校验。
参数存储完整性类PARAM_EEPROM_FAIL、PARAM_CRC_ERROR、PARAM_UNINITIALIZED和程序内调用错误分开，便于判断是否涉及 FRAM/参数恢复。
参数调用合法性类PARAM_RANGE_ERROR、PARAM_ADDRESS_OVERFLOW、PARAM_ERROR后续优先拆分 PARAM_ERROR 和被滥用的地址/缓冲区错误。

6. 建议拆分或复用专用码的对象

拆分不等于马上新增编号。建议先从“复用已有专用码”和“补充日志上下文”开始，再评估是否新增 enum。

当前故障码当前问题建议方向优先级影响
SENSOR_DEVICE_COMM_TIMEOUT传感器主链路、无线主机、无线从机都可能被归到设备通信超时。优先复用 WIRELESS_HOST_COMM_TIMEOUT / WIRELESS_SLAVE_COMM_TIMEOUT；必要时再新增传感器主链路超时。高改返回码会影响外部可见错误值。
SENSOR_RESP_FORMAT_ERROR响应格式、AT 响应、字段解析异常混在一起。可拆为传感器响应格式错误、无线/AT 响应格式错误、解析字段错误。高新增码需要 CPU2/CPU3/文档同步。
PARAM_ERROR出现面广，语义接近程序内部参数调用兜底。先按调用点分组；可拆为空指针/非法调用、配置冲突、运行参数非法。高涉及大量调用点，需要分批。
PARAM_ADDRESS_OVERFLOW可能同时表示地址越界、内部指针或缓冲区异常。保留地址越界；新增或复用内部访问参数非法类错误。中需要确认每个调用点实际含义。
MOTOR_TMC_COMM_ERRORTMC SPI 通信、寄存器读回、运行期驱动状态可能都回到同一个码。可拆为 TMC 通信超时、寄存器读回失败、驱动状态异常。中影响电机故障定位和恢复策略。
MEASUREMENT_POSITION_ERROR目标越界、最终偏差、位置源异常可读性不足。可拆为目标位置越界、最终位置偏差过大、位置源无效。中影响测量失败显示和日志定位。
AD5421_READFAULT_ERRORREADFAULT 读取失败和 READFAULT 状态异常容易混淆。可拆为 READFAULT 读取失败、READFAULT 状态故障。中AO 输出诊断更清晰，但需要 CPU3 显示同步。
OTHER_PERIPHERAL_CONFIG_ERROR其他外设配置兜底过宽。减少新增调用；能归到 AO、传感器、无线、参数配置的优先归类。低先做文档和调用点评审。

7. 建议标注为预留或历史保留的对象

以下符号当前在排除 enum、日志和显示映射后未看到明确运行触发点。建议保留编号，不删除、不复用旧值，只在文档和表格中标注状态。

故障码建议状态说明
MOTOR_FAIL_SETTING、MOTOR_RESET_FAIL预留/历史保留未看到明确运行触发点，保留显示和日志映射。
ENCODER_POWERON_CHANGE预留/历史保留编码器上电变化可作为未来诊断项，但当前不建议删除。
SENSOR_TEMPERATURE_ERROR、SENSOR_VOLTAGE_ERROR预留可留给传感器自诊断或设备上报错误细分。
SLIPRING_BCC_ERROR、SLIPRING_PACKET_LOSS预留建议纳入无线/滑环链路类，暂不新增运行触发。
MEASUREMENT_HEIGHT_DEVIATION、MEASUREMENT_DENSITY_RANGE_INVALID预留/待确认测量流程中可保留为后续更细分的阶段失败码。
PARAM_UNINITIALIZED、PARAM_CRC_ERROR历史保留/待确认和参数存储完整性有关，保留有利于未来 FRAM 初始化和升级诊断。
WEIGHT_SENSOR_SATURATION预留扭力硬件饱和诊断项，当前不建议移除。
OTHER_ADDRESS_READ_ERROR、OTHER_POWER_FLUCTUATION系统预留仍作为系统级兜底保留，但不建议新代码优先使用。
AD5421_FAULT_PIN_ERROR历史保留/硬件未接入当前 FAULT 引脚未形成实际检测链路，文档应明确该状态。
兼容原则：预留和历史保留码不应删除，也不应把旧值复用给新语义。确需新增时采用追加编号，避免破坏 CPU3、上位机、日志和历史记录解释。
