3. 拆分规则

  1. 责任域不同，必须拆分。例如传感器内部故障不能继续与外部通信超时共用一个编号。
  2. 现场检查方法不同，必须拆分。例如电机堵转、相线短路和相线断路分别对应机构、绝缘和连续性检查。
  3. 同一操作的失败阶段不同，且能稳定判断时拆分。例如密度找液位超时与频率找液位超时分开。
  4. 触发点虽然不同，但现场现象、责任域和处理方法完全一致时可以共用，例如内部调用前置条件异常统一归入 22-5。
  5. 优先保持一代类别和子码对照；一代大类不足以定位时，在二代类别内新增子码，不强行复用旧含义。
  6. 历史编号、保留编号和取消编号永久冻结，不分配给新的故障含义。
