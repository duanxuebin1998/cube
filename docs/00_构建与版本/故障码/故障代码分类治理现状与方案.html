本文记录二代计量仪当前故障代码的分类规则、编号范围、保留与停用处理及协议兼容性。详细故障说明见正式工作簿，完整调用点和迁移关系见内部技术工作簿。

1. 当前基线

  • CPU2枚举共65项，其中2项为非故障状态，63项为共享故障。
  • CPU3同步65项定义，并额外定义本机故障 20-7 / 0x00140007。
  • 故障寄存器仍为32位，地址和宽度不变；参数存储结构和版本不变。
  • 屏幕显示十进制“类别代码-故障码”，正式资料不以十六进制作为现场主编号。

3. 保留与停用

保留3项：12-6编码器上电变化、15-16实高偏差过大、21-5扭力传感器饱和。当前流程不主动产生，启用前必须补齐调用点和验证。

停用12项：MOTOR_FAIL_SETTING、MOTOR_RESET_FAIL、SLIPRING_BCC_ERROR、SLIPRING_PACKET_LOSS、SENSOR_TEMPERATURE_ERROR、SENSOR_VOLTAGE_ERROR、DENSITY_UNSTABLE、MEASUREMENT_DENSITY_RANGE_INVALID、AD5421_FAULT_PIN_ERROR、OTHER_UNKNOWN_ERROR、OTHER_ADDRESS_READ_ERROR、OTHER_POWER_FLUCTUATION。

停用项只保留在CPU2 V1.24.0.0历史表；旧编号不得复用于新的故障含义。

4. 兼容性

  • 协议17重新分类并调整故障子码，与协议16及更早版本的数值解释不兼容。
  • CPU2和CPU3必须使用相同的 DEVICE_PROTOCOL_VERSION。
  • 现场选择共享故障码表以CPU2程序版本为准，不以CPU3版本或共享协议版本代替。
  • CPU3本机20-7按CPU3程序版本确认。
  • 一代计量仪历史表和CPU2 V1.24.0.0历史表保持独立，不回写当前编号。
