# 故障码资料入口

更新日期：2026-07-01

本目录统一保存 CPU2/CPU3 故障码表格资料和可检索 Markdown 清单。故障码定义以 CPU2 源码和 CPU2 表为准，CPU3 表仅作为显示、保持寄存器和 `param_meta` 辅助资料。

| 目录 | 用途 |
| --- | --- |
| `当前程序故障代码清单.md` | 按当前源码整理的 73 项 `ErrorCode`、类别区间、上报路径和维护检查项 |
| `故障代码分类治理现状与方案.html` | 面向决策的故障码现状、分类方向、统一归类、拆分建议和实施包 |
| `CPU2/` | CPU2 故障代码总表，作为当前故障码表格维护入口 |
| `CPU3/` | CPU3 显示侧、保持寄存器和本机参数辅助表 |

维护故障码时先看 `../故障代码表权威来源判定.md`。新增或修改故障码后，必须同时检查 CPU2 `ErrorCode`、CPU2 日志原因、CPU3 兼容枚举、CPU3 显示原因和相关协议/版本资料。

当前 `CPU2/LTD故障代码表.xlsx` 的总表已和 CPU2 `ErrorCode` 保持一致：73 项，含 `NO_ERROR`、`STATE_SWITCH` 两个非故障状态。两份 XLSX 的附件责任边界见 `../附件与源文件清单.md`：CPU2 表是故障码表格维护入口，CPU3 表是显示和寄存器辅助资料，不得反向覆盖 CPU2 故障码定义。
