# 故障码资料入口

更新日期：2026-06-27

本目录统一保存 CPU2/CPU3 故障码表格资料。故障码定义以 CPU2 源码和 CPU2 表为准，CPU3 表仅作为显示、保持寄存器和 `param_meta` 辅助资料。

| 目录 | 用途 |
| --- | --- |
| `CPU2/` | CPU2 故障代码总表，作为当前故障码表格维护入口 |
| `CPU3/` | CPU3 显示侧、保持寄存器和本机参数辅助表 |

维护故障码时先看 `../故障代码表权威来源判定.md`。新增或修改故障码后，必须同时检查 CPU2 `ErrorCode`、CPU2 日志原因、CPU3 兼容枚举、CPU3 显示原因和相关协议/版本资料。

两份 XLSX 的附件责任边界见 `../附件与源文件清单.md`：CPU2 表是故障码表格维护入口，CPU3 表是显示和寄存器辅助资料，不得反向覆盖 CPU2 故障码定义。
