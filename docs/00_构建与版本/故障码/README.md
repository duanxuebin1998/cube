# 故障码资料入口

更新日期：2026-07-16

本目录统一维护二代计量仪CPU2/CPU3故障码的正式资料、内部技术资料和历史表。协议19故障码没有形成独立固件，随共享协议21正式发布；首个组合为CPU2 `V1.27.0.0`、CPU3 `V1.25.0.0`。协议18及更早固件仍按对应历史页解释，不能套用当前编号。

| 文件 | 用途 |
| --- | --- |
| `LTD故障代码统一表.xlsx` | 正式工作簿，包含CPU2 V1.27.0.0起使用的现行故障项目、CPU2 V1.25.0.0～V1.26.0.0历史页、CPU2 V1.24.0.0历史页、一代计量仪历史页、设备参数和测量结果 |
| `LTD内部技术与治理资料.xlsx` | 内部维护工作簿，保存完整码、内部标识、调用点、链路复查、分类规则、治理摘要、一代对照和分阶段编号迁移 |
| `当前程序故障代码清单.md` | 当前源码中的131项CPU2定义、129项共享故障、1项CPU3本机故障、历史冻结项和维护要求 |
| `故障码整体治理执行、当前进度与窗口交接计划.md` | 本轮长期计划执行情况、当前进度、剩余发布和台架工作 |
| `故障代码分类治理现状与方案.html` | 当前分类规则、拆分结果、一代对照和兼容性影响 |
| `故障码第3阶段调用点评审.md` | 协议15、16实施阶段的调用点评审历史快照 |
| `故障码第3.2阶段日志增强清单.md` | 2026-07-10调用点和日志治理历史快照 |

当前正式工作簿收录130个故障项目：129个CPU2/CPU3共享故障码和1个CPU3本机故障码；使用中127项、保留3项。`NO_ERROR`、`STATE_SWITCH` 两个非故障状态只保存在源码、当前清单和内部技术资料中。

现场查询顺序为：先确认一代或二代，再按CPU2程序版本选择共享故障表。CPU3本机 `20-7` 单独按CPU3程序版本确认。`DEVICE_PROTOCOL_VERSION` 用于判断CPU2与CPU3能否配套运行，不替代现场选表所需的CPU2程序版本。

历史页分三层维护：

- `历史故障代码_CPU2V1.25.0.0-V1.26.0.0` 保存该CPU2版本范围的64个历史故障项目，包含当前开发版拆分前的10个通用码。
- `历史故障代码_CPU2V1.24.0.0` 保存更早开发基线，包含协议17阶段已停用的12项。
- `一代计量仪历史故障代码` 归档一代资料版本v1.0（2026-05-23），只用于一代设备。

二代编号优先采用“一代类别加10、相同含义保留子码”。责任域或现场处理方式不同必须拆分；一代没有直接同义项时使用二代新增子码，并在内部表保留对照来源。所有历史编号永久冻结，不复用于其它含义。

当前有故障码的类别为11电机驱动、12编码器、13传感器与密度、14零点与位置检测、15测量过程、17参数与存储、18模拟输出与自检、20设备通信链路、21扭力检测、22系统与软件。10、16、19保留代际类别位置但当前不分配故障码。
