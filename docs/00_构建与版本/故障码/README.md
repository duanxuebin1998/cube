# 故障码资料入口

更新日期：2026-07-11

本目录统一保存 CPU2/CPU3 故障码正式资料、内部技术资料、可检索 Markdown 清单和治理方案。73 项共享故障码定义以 CPU2 源码为准；CPU3 本机扩展码以 CPU3 枚举为准。

| 文件 | 用途 |
| --- | --- |
| `LTD故障代码统一表.xlsx` | 正式发布工作簿：包含“文档简介”“故障代码”“设备参数”“测量结果”4 张表 |
| `LTD内部技术与治理资料.xlsx` | 内部维护工作簿：保存程序字段、寄存器映射、参数原表、分类规则、链路复查和阶段治理记录 |
| `当前程序故障代码清单.md` | 按当前源码整理的 73 项共享码、CPU3 本机扩展码、类别区间、上报路径、治理基线和维护检查项 |
| `故障代码分类治理现状与方案.html` | 面向决策的故障码现状、分类方向、统一归类、拆分建议、预留标注和实施包 |
| `故障码第3阶段调用点评审.md` | 针对 8 项候选故障码整理调用点语义、可统一归类方向、可拆分方向和分阶段实施建议 |
| `故障码第3.2阶段日志增强清单.md` | 基于当前源码重新扫描的 166 个故障码产生函数组、238 个故障码产生语句、日志缺口、上下文风险、治理结论和验证方法 |
| `故障码整体治理执行、当前进度与窗口交接计划.md` | 故障码治理全阶段计划、当前完成度、剩余任务、审批门槛、验证要求和可复制交接提示词 |

维护故障码时先看 `../故障代码表权威来源判定.md`。新增或修改故障码后，先判断共享码或 CPU3 本机码，再检查对应枚举、日志/显示原因、统一表和协议/版本资料。
