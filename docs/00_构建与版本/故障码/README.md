# 故障码资料入口

更新日期：2026-07-14

本目录统一维护CPU2/CPU3故障码正式资料和内部技术资料。当前故障代码适用于CPU2 `V1.25.0.0`，配套CPU3版本为 `V1.23.0.0`；共享协议版本为17，CPU2、CPU3必须使用相同协议版本。

| 文件 | 用途 |
| --- | --- |
| `LTD故障代码统一表.xlsx` | 正式工作簿，包含当前故障代码、CPU2 V1.24.0.0历史故障代码、一代计量仪历史故障代码、设备参数和测量结果 |
| `LTD内部技术与治理资料.xlsx` | 内部维护工作簿，保存完整码、枚举、调用点、链路复查、分类规则、治理摘要和编号迁移 |
| `当前程序故障代码清单.md` | 当前源码中的65项CPU2定义、63项共享故障、CPU3本机故障和维护要求 |
| `故障码整体治理执行、当前进度与窗口交接计划.md` | 本轮计划执行情况、当前进度、剩余验证和交接顺序 |
| `故障代码分类治理现状与方案.html` | 当前分类规则、编号范围和兼容性影响 |
| `故障码第3阶段调用点评审.md` | 协议15实施前后的重点调用点评审历史记录 |
| `故障码第3.2阶段日志增强清单.md` | 2026-07-10调用点历史快照和当前编号说明 |

当前正式工作簿收录64个故障项目：63个CPU2/CPU3共享故障码和1个CPU3本机故障码。使用中61项，保留3项。`NO_ERROR`、`STATE_SWITCH` 两个非故障状态只保存在源码、Markdown和内部技术资料中。

“历史故障代码_CPU2V1.24.0.0”工作表冻结CPU2 V1.24.0.0开发基线，不随后续删除、合并或重编号改写。CPU2产生的共享故障码按CPU2程序版本选表，CPU3程序版本和 `DEVICE_PROTOCOL_VERSION` 不作为CPU2共享故障码表的选择依据。CPU3本机 `20-7` 单独按CPU3程序版本确认。

“一代计量仪历史故障代码”工作表归档一代计量仪资料版本v1.0（2026-05-23），只用于一代设备。先确认设备代际，再按一代主控程序版本和表内说明查询。

屏幕故障码使用十进制“类别代码-故障码”。当前有故障的类别为11电机驱动、12编码器、13传感器与密度、14零点与位置检测、15测量过程、17参数与存储、18模拟输出与自检、20设备通信链路、21扭力检测、22系统与软件。10、16、19保留代际对应类别但当前不分配故障码。

协议17重新分类并调整故障子码，协议16及更早版本不能直接套用当前编号。现场查表按CPU2程序版本，CPU2和CPU3能否配套运行按共享协议版本严格相等判断。
