# 故障码资料入口

更新日期：2026-07-12

本目录统一维护CPU2/CPU3故障码正式资料和内部技术资料。当前共享协议版本为15，CPU2、CPU3必须成对使用。

| 文件 | 用途 |
| --- | --- |
| `LTD故障代码统一表.xlsx` | 正式工作簿，包含文档简介、故障代码、设备参数和测量结果 |
| `LTD内部技术与治理资料.xlsx` | 内部维护工作簿，保存完整码、枚举、调用点、链路复查、分类规则、治理摘要和编号迁移 |
| `当前程序故障代码清单.md` | 当前源码中的77项共享定义、75项共享故障、CPU3本机故障和维护要求 |
| `故障码整体治理执行、当前进度与窗口交接计划.md` | 长期治理计划的执行进度、兼容性、待验证项和窗口交接顺序 |
| `故障代码分类治理现状与方案.html` | 分类和拆分方案的内部评审资料 |
| `故障码第3阶段调用点评审.md` | 重编号前的重点调用点评审，以及协议15实施结果对照 |
| `故障码第3.2阶段日志增强清单.md` | 2026-07-10调用点历史快照，以及当前编号对照和诊断现场记录 |

当前正式工作簿收录76个故障项目：75个CPU2/CPU3共享故障码和1个CPU3本机故障码。使用中61项，保留15项。`NO_ERROR`、`STATE_SWITCH` 两个非故障状态只保存在内部技术资料中。

屏幕故障码使用十进制“类别代码-故障码”格式。新版分类为11电机驱动、12编码器、13传感器与密度、14通信链路、15测量流程、16模拟量输出、17参数存储、18扭力检测、19系统与软件。CPU3本机主控通信故障显示为14-12。

协议版本15调整了故障码取值，旧编号不兼容。维护或发布时先确认CPU2、CPU3协议版本一致，再核对正式工作簿、内部技术工作簿、日志映射和屏幕显示。
