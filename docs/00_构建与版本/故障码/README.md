# 故障码资料入口

更新日期：2026-07-02

本目录统一保存 CPU2/CPU3 故障码表格资料、可检索 Markdown 清单和治理方案。故障码定义以 CPU2 源码为准，表格维护入口统一收敛到 `LTD故障代码统一表.xlsx`；CPU3 显示、保持寄存器和 `param_meta` 辅助资料已合并到统一表的 CPU3 辅助页。

| 文件 | 用途 |
| --- | --- |
| `LTD故障代码统一表.xlsx` | 唯一故障码表格维护入口：包含 73 项当前故障代码总表、分类规则、链路复查、治理摘要、旧表差异、CPU2/CPU3 参数和显示辅助页 |
| `当前程序故障代码清单.md` | 按当前源码整理的 73 项 `ErrorCode`、类别区间、上报路径、分类治理基线、链路复查结论和维护检查项 |
| `故障代码分类治理现状与方案.html` | 面向决策的故障码现状、分类方向、统一归类、拆分建议、预留标注和实施包 |

维护故障码时先看 `../故障代码表权威来源判定.md`。新增或修改故障码后，必须同时检查 CPU2 `ErrorCode`、CPU2 日志原因、CPU3 兼容枚举、CPU3 显示原因和相关协议/版本资料。

当前 `LTD故障代码统一表.xlsx` 的“故障代码总表”已和 CPU2 `ErrorCode` 保持一致：73 项，含 `NO_ERROR`、`STATE_SWITCH` 两个非故障状态。旧 CPU2/CPU3 两份同名表已合并，避免后续继续出现两个故障代码表。

2026-07-02 已补充第二步分类治理内容：统一表新增“分类规则”“链路复查”“治理摘要”三个工作表；当前 73 项按责任域统计为运行使用 54 项、非故障状态 2 项、预留/历史保留 17 项，并标出 8 个后续第 3 阶段调用点评审候选。
