# 构建与版本文档索引

更新日期：2026-08-03

本目录保存 CPU2/CPU3 构建说明、版本升级记录和每次版本发布对应的改动与测试方案。

当前最新正式组合为CPU2 `V1.36.2.0` / CPU3 `V1.36.0.0`、共享协议31；协议31首个正式组合为双端`V1.36.0.0`。协议31复用`0x0116~0x0117`发布Newhall扭力模块温度，并增加CPU3显示；双端必须严格配套。

## 人工索引边界

- `版本总览.md`、`附件与源文件清单.md` 和 `新增资料落位检查表.md` 只用于查找和人工复核，不改变后续版本文档生成规则。
- 资料迁移、目录整理或链接修改后可运行 `py tools\check_docs.py` 做本地快速自检；它只读检查仓库文档结构和 Markdown 相对链接，不生成文档。
- 新版本提交时仍按既有 skill 规则在 `版本改动与测试/` 下新增改动与测试方案。
- 这些人工索引可以在版本提交后补充，不应阻塞版本号、`CHANGELOG.md` 或发布资料提交。

本 README 只保留入口，不展开完整历史版本表。完整列表集中维护在 `版本总览.md`，避免入口页过长；新版本文档仍由既有 skill 规则生成到 `版本改动与测试/`。

## 参数存储升级提示

- CPU2 升级是否恢复出厂参数以 `CPU2参数存储升级清单.md` 为准。
- 后续每份版本改动与测试方案都要写明 CPU2 `DEVICE_PARAM_VERSION`、`DeviceParameters` 结构大小是否变化、升级是否会恢复出厂参数，以及现场升级前后的处理动作。
- 最新正式组合为CPU2 `V1.36.2.0`、CPU3 `V1.36.0.0`、共享协议31。协议31只改变既有调试槽语义和显示消费；CPU2 `V1.36.1.0`修复CH9141K RSSI半ACK清理与透传恢复，`V1.36.2.0`补齐液位标定后AO量程归一化。两次PATCH均不改变CPU2参数存储版本3、`DeviceParameters`结构、参数FRAM校验范围或CPU3本机FRAM布局，不因升级清除现场参数。
