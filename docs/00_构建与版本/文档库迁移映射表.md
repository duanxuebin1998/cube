## 后续批次原则

1. 每批只移动同一业务域的少量文件。
2. 移动前用 `rg` 搜文件名和旧路径，确认引用面。
3. 移动后同步 README、治理清单和相关计划/改动记录。
4. 不直接处理 PDF 生成、转换或重命名，除非单独确认。
5. 本地预览站只通过 `docs-site/scripts/sync-content.mjs` 同步源文档，不手工修改生成目录，也不把 `docs-site/` 加入 Git 跟踪。
