## 判定规则

| 类型 | 维护口径 | 后续处理 |
| --- | --- | --- |
| 同目录同名 Markdown + PDF | Markdown 作为可维护正文，PDF 视为历史导出件或交付阅读件 | 暂不删除；后续可统一移动到导出件目录或在 README 标明“以 Markdown 为准” |
| 外部 PDF、芯片手册、标准文档 | 原始资料，不修改正文 | 保留原厂文件名，放在 `00_原始资料/`、`00_外部资料/` 或芯片手册目录 |
| DOCX/XLSX 表格 | 可能是原始确认表、现场交付表或维护表 | 补 Markdown 索引说明用途、责任人和是否仍在维护 |
| HTML 流程页 | 当前作为流程图、结构图或历史阅读页保留 | 放入业务目录并由文档站统一入口跳转 |
| `docs-site/` 生成内容 | 本地预览层，不是业务资料权威来源 | 只改 `docs/` 源文档；`docs-site/` 整体忽略，不提交 |
| 旧 `site/` 与旧静态站脚本 | 已淘汰展示层 | 不恢复、不发布；旧页面需要追溯时看 Git 历史 |
