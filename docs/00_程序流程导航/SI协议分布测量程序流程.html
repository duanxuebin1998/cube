1. 文档边界

本文只梳理 SI Profile 分布测量。普通分布测、国标测、每米测、区间测和 Wartsila 分布测仍以 CPU2 密度流程页为准。

CPU3 负责

外部 COM 协议分发、SI RTU 从站、屏幕菜单触发、地址窗口、功能码、异常响应、保持寄存器快照、CPU3 本机 SI 参数、自动 profile 调度、时间戳、报警合成和对 CPU2 的命令/参数桥接。

CPU2 负责

真实运动、探底、底部采样目标与后续 profile 候选点生成、Point0 对外位置字段处理、逐点按 dwell 稳定采样、运行中判定液面以上点、完成锁存、完成计数、错误码和点阵结果发布。

2. 跨 CPU 总体流程

SI 分布测量被拆成两段：CPU3 负责协议入口和触发，CPU2 执行独立 profile，结果再经 CPU2 输入寄存器回到 CPU3，最后转换成 SI 的 100xx/300xx 状态和点阵。

1. 外部帧进入CPU3 外部 COM 端口选择 COM_PROTO_SI 后，端口分发调用 si_modbus_process_for_dispatch()。
2. CPU3 翻译地址和 CRC 正确后，CPU3 刷新线圈、保持寄存器、离散输入和输入寄存器快照，再按功能码读写。
3. 触发 profile00004 Profile 写 ON、CPU3 屏幕选择 SI Profile 或自动调度到点时，CPU3 锁存 profile 开始时间并向 CPU2 写 CMD_SI_PROFILE。
4. CPU2 执行CPU2 主循环取走命令，进入 CMD_SiProfile()，读取 CPU2 保存的 SI profile 参数，执行探底、底部采样和后续候选点采样；profile 前不单独执行 SearchOilLevel()，Point0 对外位置字段固定写 0。
5. 结果回读CPU2 把点阵和完成状态写入输入寄存器，CPU3 周期读回后，SI 层再映射为 100xx 和 300xx。

4. CPU3 触发和调度流程

CPU3 既处理外部 PLC 手动 profile，也负责按 RTC 周期自动触发 profile。两条路径最终都下发同一条 CPU2 命令。

4.1 手动 profile

  1. 手动入口包括外部主机通过 FC05 写 00004，以及 CPU3 屏幕在密度分布测量菜单中选择 SI Profile。
  2. 外部主机写入值必须为 0xFF00 才触发；屏幕入口经 ifsendcmd 确认后由 cmd_nopara_process() 下发。
  3. CPU3 先在 SI 影子线圈区把模式线圈互斥，只保留 Profile 位。
  4. CPU3 调用 si_profile_request_start()，统一锁存 30007~30010 后续要读到的开始时间，并通过 CPU2 命令保持寄存器下发 CMD_SI_PROFILE。
  5. CPU3 自身不执行测量，也不在 CPU3 中拼点位。

4.2 自动 profile

  1. CPU3 主循环每轮在显示任务和外部 COM 处理前调用 si_modbus_periodic_task()。
  2. 自动使能为 0、周期为 0、RTC 不可读时直接返回。
  3. 以当日 40012:40013 为基准时间，按 40010 分钟周期判断当前分钟是否到点。
  4. 同一分钟内用 s_si_auto_last_trigger_minute 去重，避免主循环多次下发。
  5. 到点后锁存时间戳并下发 CMD_SI_PROFILE，与手动 profile 使用同一套 CPU2 测量流程。

4.3 参数写入

  1. 40001~40003 写入 CPU2 参数通道，CPU3 会先更新影子值，保证写后回读能看到新值。
  2. 40010~40023 写入 CPU3 本机参数，供自动调度和报警合成使用。
  3. 40010 禁止写 0；40011 限制为 0 或 1；40012 限制 0~23；40013 限制 0~59。
  4. 保持寄存器地址不可写或越界时，CPU3 返回 SI Modbus 异常响应，不下发 CPU2。

5. CPU2 独立 profile 执行流程

CPU2 的 SI profile 不再复用普通分布测量参数，也不走 Wartsila 测后探底流程。它读取独立 SI 参数，先确定底部采样运动目标，再按底部点、绝对首点、步距和罐高生成候选点；不预先找液位，逐点采样时遇到液面以上点即停止且不写入该点。对外点阵中 Point0 的位置字段固定写 0，Point1 的位置字段固定等于 40001。profile 成功锁存后，CPU2 会排队 CMD_FIND_OIL，在下一轮主循环恢复液位跟随。

5.1 公共命令入口

  1. CPU2 主循环优先处理原始串口命令，其次处理 g_deviceParams.command 中已挂起的正式命令。
  2. 主循环取走 CMD_SI_PROFILE 后立即把 g_deviceParams.command 清为 CMD_NONE，避免下轮重复执行。
  3. ProcessMeasureCmd() 对非取消类命令先执行 MeasureStart()，进行故障信息、电机和扭力初始化，并清除上一轮 SI 辅助状态。
  4. 命令分发遇到 CMD_SI_PROFILE 后进入 CMD_SiProfile()。

5.3 点位生成规则

  1. 先把底部位置负值压到 0；如果罐高无效，则按 MAX_MEASUREMENT_POINTS * increment 做运行期兜底上限。
  2. 第 0 个运动/采样目标为底部位置，也就是 points01[0] = bottom；写入 SI 点阵时 Point0 的位置字段固定为 0。
  3. 后续可编程点从 first_point 绝对位置开始，之后每点增加 increment；Point1 对外位置等于 40001，Point2 等于 40001 + 40002，PointN 等于 40001 + (N-1) * 40002。
  4. 候选点生成不因实际底部位置高于 first_point 而跳过首点；如果 40001=500mm，第一个可编程测点仍按 500mm 运行和输出。
  5. 候选点生成时只按罐高和 200 点上限停止，不依赖预先测得的液位。
  6. 逐点采样时如果当前候选点被判定为液面以上点，则停止本轮 profile，且不把该点写入有效点阵。
  7. profile 成功锁存后，若没有其它待执行命令，则排队 CMD_FIND_OIL，由下一轮主循环恢复液位跟随；失败或命令切换不排队。
  8. 这套点位不使用普通分布测的 spreadTopLimit、spreadMeasurementDistance、spreadMeasurementCount。

5.4 逐点采样

  1. 点位单位从 0.1mm 转为 mm，调用 MotorCtrl_JogMoveToPosition() 移动。
  2. 移动期间如果检测到命令切换，返回 STATE_SWITCH，上层直接退出，不锁存完成。
  3. 每点按 dwell_time_s 转毫秒作为稳定采样窗口，窗口内仍可被命令切换打断。
  4. 调用 SI profile 专用采样窗口读取密度和频率；密度低于空气阈值或频率越过液位频率时，判定为液面以上点。
  5. 液体点写入 DensityDistribution.single_density_data[]；液面以上点只作为停止条件，不写入有效点数。
  6. 至少有 1 个有效点时，写入点数、最后一个有效 profile 点位置、平均温度和平均密度。

6. 结果发布和对外输出

profile 成功不是 CPU3 自行判定，而是 CPU2 写入 profile_complete_latched 和 profile_complete_counter 后，CPU3 通过内部 Modbus 读回并转换。

6.1 CPU2 写共享输入寄存器

  1. 成功测量后，CPU2 保存旧 profile_complete_counter。
  2. 把临时 DensityDistribution temp 整体赋给全局 g_measurement.density_distribution。
  3. 置 profile_complete_latched=1。
  4. 把 profile_complete_counter 加 1。
  5. 清 profile_blocked_by_process。
  6. 设备状态置 STATE_SPREADPOINTOVER。
  7. 若 g_deviceParams.command == CMD_NONE，排队 CMD_FIND_OIL，下一轮主循环执行找液位和液位跟随。

6.2 CPU3 读回结果

  1. CPU3 内部主板 Modbus 轮询 CPU2 输入寄存器。
  2. read_measurement_result_from_InputRegisters() 恢复设备状态、SI 辅助状态、分布平均值、点数和最多 200 个点。
  3. SI 模块处理外部请求前调用 si_modbus_sync_from_system()，把最新 g_measurement 转成快照。
  4. 只有 profile_complete_latched != 0 时，CPU3 才把点数和点阵开放给外部读；未完成时点阵区域保持 0。

7. 异常、切换和边界行为

Modbus 帧异常

地址不匹配或 CRC 错误时 CPU3 不回包；功能码、地址、数量或值域非法时返回标准异常响应。

参数写入异常

40001~40003 和 40010 不能写 0；自动使能、时、分有独立范围限制；保留保持寄存器拒写。

命令切换

CPU2 移动、悬停或读数中检测到命令切换时返回 STATE_SWITCH，视为正常打断，不锁存完成。

运行失败

探底、点位生成、移动或读数失败时，CPU2 置 profile_blocked_by_process=1，打印错误并 SET_ERROR(ret)，不更新新的 profile 完成态。

点位生成失败

first 或 increment 运行期仍非法、地址为空、无有效测点等会返回参数或测量错误，CPU2 不发布完成锁存。

逐点测量失败

电机移动失败、稳定采样窗口异常、读数失败都会向上返回错误，CPU2 设置错误并阻止本轮 profile 完成。

8. 维护检查点

后续修改 SI 分布测量时，最容易出错的是把外部地址语义下沉到 CPU2，或把普通分布测量参数误当成 SI profile 参数。

  • 改 40001~40003 时，同时核对 CPU3 SI协议写入口、CPU2/CPU3 保持寄存器映射、CPU2 DeviceParameters 字段和参数存储默认值。
  • 改 profile 点位规则时，同步更新 CPU2 CMD_SiProfile()、SI 映射表、golden frame 或协议契约脚本。
  • 改完成态、阻塞态或报警位时，同时核对 CPU2 输入寄存器发布、CPU3 输入寄存器读取、SI 离散输入合成。
  • 改自动调度时，明确 CPU3 RTC、去重分钟、手动 profile 时间戳和自动 profile 时间戳是否仍同口径。
  • 改外部密度倍率时，必须同时检查内部 DENSITY_RAW_SCALE=100、SI 16 位上限和 DSM/Wartsila 外部协议口径。
  • 本流程涉及共享协议行为，提交前需运行 py tools\check_si_modbus_frames.py 和 py tools\check_si_protocol_contract.py。
