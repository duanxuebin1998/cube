# 流程排查入口

更新日期：2026-07-11

本文按现场排查问题的路径组织程序流程入口。调查类型是预览站生成连续回溯路径的正式分类依据；具体业务链路、当前流程、历史版本差异和验证资料仍从既有清单派生，不在本文复制正文。

## 使用边界

- 流程事实以对应 HTML 流程页、源码和版本改动与测试方案为准；本文只做查找入口。
- `调查类型` 只允许使用测量、通信、参数、故障、版本五类；它负责给现场现象分组，不替代业务链路和流程证据清单。
- 如果后续固件改动命中流程变化，仍按既有规则更新 `docs/00_程序流程导航/` 下的对应 HTML/SVG 和跨页导航。
- 本文可在流程页更新后补充，不作为版本提交的强制检查项。
