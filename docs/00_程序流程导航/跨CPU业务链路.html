2. 分业务路线

液位测量与跟随链路

从 CPU3 菜单或外部协议发起找液位/液位跟随，CPU2 执行找液位、闭环跟随和状态上报，CPU3 再显示或对外响应。

1. CPU3 指令来源菜单参数与指令下发：菜单发找液位、标定或修正指令
2. CPU3 内部通道CPU2 内部通信与轮询：通过 UART5/Modbus 写 CPU2 命令或参数
3. CPU2 命令入口测量命令总入口：统一进入测量公共准备和命令分发
4. CPU2 测量核心液位测量与跟随：完成粗找、精找、阈值确定和跟随闭环
5. 状态回读Modbus 与 CPU3 通信：CPU2 更新输入寄存器和状态
6. CPU3 显示/协议显示刷新与按键事件：状态页刷新，外部 DSM/Wartsila/SI协议可读取结果

水位测量与跟随链路

水位链路与液位类似，但传感模式、阈值和盲区策略不同，建议从命令入口一路跟到 CPU2 水位详细流程。

1. CPU3 指令来源菜单参数与指令下发：菜单或外部协议选择找水/水位跟随
2. CPU3 内部通道CPU2 内部通信与轮询：写 CPU2 命令，运行期轮询输入寄存器
3. CPU2 命令入口测量命令总入口：统一公共准备后分发到水位流程
4. CPU2 测量核心水位测量与跟随：找水、跟随、盲区和错误出口
5. 状态回读Modbus 与 CPU3 通信：水位状态、错误码和结果进入通信寄存器
6. CPU3 显示/协议显示刷新与按键事件：显示端刷新水位状态或等待下一轮

密度、单点和分布测量链路

密度链路同时涉及 CPU2 测量算法、分布点回读和 CPU3 的 Wartsila/SI协议适配。

1. 外部/菜单入口Wartsila 与 SI协议适配：Wartsila/SI协议或菜单触发密度类指令
2. CPU3 内部通道CPU2 内部通信与轮询：写命令并在完成后分批读取密度分布点
3. CPU2 命令入口测量命令总入口：按密度、单点、区间、瓦锡兰场景分发
4. CPU2 测量核心密度与单点测量：完成单点、分布、区间密度测量和状态发布
5. 状态/点表回读Modbus 与 CPU3 通信：结果、profile 完成标志和点表供 CPU3 读取
6. 外部协议响应Wartsila 与 SI协议适配：Wartsila/SI协议将缓存结果映射给外部系统

读取部件参数、RSSI 与 AO 运行态链路

读取部件参数由 CPU3 菜单下发，CPU2 周期刷新传感器快照并查询 CH9141K 当前连接 RSSI；协议 10 起返回 RSSI，协议 11 起在 RSSI 后追加 AO 运行态，CPU3 轮询尾部输入寄存器后在状态页显示。

1. CPU3 菜单入口菜单参数与指令下发：读取部件参数位于测量/维护入口，下发 CMD_READ_PART_PARAMS
2. CPU3 内部轮询CPU2 内部通信与轮询：运行轮询读取输入寄存器尾部 WirelessPairingStatus 和 AoOutputRuntime 字段
3. CPU2 命令入口测量命令总入口：进入读取部件参数命令并保持 STATE_READPARAMETEROVER 持续刷新
4. CPU2 传感器快照传感器与无线通信：每 1s 刷新位置、扭力、温度、频率、电容、角度，每 5s 查询蓝牙 RSSI
5. CPU2 寄存器发布Modbus 与 CPU3 通信：协议版本 10 起在继电器运行态后追加 RSSI，协议 11 起追加 AO 目标/实际/错误运行态
6. CPU3 状态显示显示刷新与按键事件：读取参数完成页显示 RSSI 或 N/A，状态页显示协议兼容和 AO/AD5421 故障原因

AO 模拟电流输出与 HART 链路

AO 输出由 CPU3 菜单参数使能，CPU2 根据液位/故障/调试状态刷新 AoOutput 运行态，AD5421 输出电流，HART 和 CPU3 状态页读取同一运行数据。

1. CPU3 AO 菜单菜单参数与指令下发：AO使能为 0/1 设备参数，确认后通过内部 Modbus 写 CPU2
2. CPU2 参数生效参数存储与系统配置：AoOutputEnable 默认关闭，写入后作为 AoOutput_Update 的硬开关
3. 液位结果来源液位测量与跟随：找液位/跟随更新液位结果时同步刷新 AO 输出目标
4. AO 服务与硬件扭力与继电器输出：AoOutput_Update 计算目标、限幅、节流写 AD5421，并记录运行态
5. HART/AD5421 接口HART 接口：HART 命令 2/3 返回 AO 电流和百分比，AD5421 错误进入故障码
6. CPU3 状态回读显示刷新与按键事件：协议 11 起输入尾段显示 AO 运行态和 AD5421 故障原因

参数修改、保存和同步链路

CPU3 菜单和外部协议都可能修改参数，必须区分 CPU3 本机参数、CPU2 设备参数和共享寄存器缓存。

1. 显示/协议入口菜单参数与指令下发：用户输入参数或外部协议写保持寄存器
2. 本机参数支撑本机参数、FRAM、时钟与外设恢复：CPU3 通信/显示参数保存到 FRAM 并触发串口重配
3. 内部写入CPU2 内部通信与轮询：CPU2 设备参数通过 0x10 写入 CPU2
4. CPU2 通信入口Modbus 与 CPU3 通信：CPU2 接收保持寄存器写入并更新参数结构
5. CPU2 参数存储参数存储与系统配置：延后保存、默认值、范围和系统配置
6. 业务生效液位测量与跟随：测量流程在下一次执行时读取新参数

故障、恢复和状态展示链路

CPU2 是主要故障产生和恢复位置，CPU3 负责轮询状态、显示提示，并在外部协议里反馈故障结果。

1. 故障产生电机与位置模型：电机、位置、扭力碰撞或传感异常触发错误条件
2. CPU2 故障管理故障管理与恢复：SET_ERROR、状态切换、恢复尝试和错误输出
3. CPU2 通信发布Modbus 与 CPU3 通信：设备状态、错误码和测量状态进入寄存器
4. CPU3 轮询缓存CPU2 内部通信与轮询：输入寄存器刷新 g_measurement
5. CPU3 显示显示刷新与按键事件：状态页和菜单页展示设备状态
6. 外部协议DSM 协议与命令映射：DSM/Wartsila/SI 读取缓存状态

外部协议到 CPU2 测量链路

外部 COM 先在 CPU3 分发，协议层只做映射和缓存，真正测量动作仍由 CPU2 命令入口完成。

1. 外部 COM外部 COM 协议分发与 RS485 发送：COM1/COM2/COM3 按端口参数选择协议处理
2. DSM 映射DSM 协议与命令映射：DSM 读写线圈/保持寄存器映射到缓存或 CPU2 指令
3. Wartsila/SIWartsila 与 SI协议适配：协议适配层映射参数、结果和密度点
4. CPU3 内部通道CPU2 内部通信与轮询：需要 CPU2 动作时通过内部 Modbus 下发
5. CPU2 命令入口测量命令总入口：命令进入 CPU2 正式测量状态机
6. CPU2 结果发布Modbus 与 CPU3 通信：运行结果回到 CPU3 缓存并对外响应

3. 使用建议

查一个命令为什么没执行

先看 CPU3 是否把命令写入内部 Modbus，再看 CPU2 命令入口是否接收，最后看对应测量页的异常出口。

查结果为什么没显示

先看 CPU2 是否发布输入寄存器，再看 CPU3 内部轮询是否刷新缓存，最后看显示页或外部协议页。

查参数为什么没生效

区分 CPU3 本机参数、CPU2 设备参数和协议缓存，按参数链路逐页核对。
