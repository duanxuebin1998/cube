2026-07-01 SI Profile 流程变更补充

  • CPU3 的 00004 Profile 和自动调度改为下发 CMD_SI_PROFILE，CPU2 不再把 SI profile 映射到普通分布密度测量。

  • 点阵从 Point0 开始，Point0 对外位置字段固定为 0；Point1 等于 si_profile_first_point 绝对位置，后续按 si_profile_increment 递增；下一点将超过液面、达到罐高上限或达到 200 点上限时停止，不采集液面以上点。

3.1 命令入口与业务分组

本图把单点、监测、综合、四类分布密度、瓦锡兰流程按业务归类，并明确 STATE_SWITCH、错误和成功发布的不同出口。

错误出口Application/Inc/fault_manager.h:141-151：SET_ERROR 对非 NO_ERROR/STATE_SWITCH 会置故障并 return。
分布包装Application/Src/measure_density.c:799-948：四类分布测量成功后才发布 profile 完成沿。

3.2 单点测量与固定点监测

单点测量是一次性流程，固定点监测是常驻循环。两者都要校验目标位置并移动到指定点，但固定点监测显式把 STATE_SWITCH 当正常退出。

单点测量Application/Src/measure_density.c:1471-1493：置单点状态、再次 MeasureStart()、校验位置、移动、采样并置完成。
固定点监测Application/Src/measure_density.c:1496-1547：移动到监测点后循环读取，命令切换直接返回。
位置校验Application/Src/measure_density.c:130-158：目标点必须位于 blindZone 和 tankHeight 范围内。

3.3 单点密度稳定采样

单点读数不是“读一次”。它会按 200ms 周期读取频率、密度、温度；密度为 0 时跳过稳定判断；非零后按频率/密度/温度波动重新计时，最多等待 5 分钟后兜底。

稳定窗口Application/Src/measure_density.c:1225-1459：稳定窗口由 spreadPointHoverTime * 1000 得到，未配置则 5000ms。
兜底策略Application/Src/measure_density.c:1288-1339：5 分钟未稳定时，优先使用最后一次非零密度；否则密度按 0 写入。
波动阈值Application/Src/measure_density.c:1427-1458：频率 1Hz、密度 0.1、温度 0.2℃ 任一超差就重置稳定计时。

3.4 分布密度测点生成

四种分布模式共用同一个测量内核，但测点生成规则完全不同。普通模式等分有效高度，国标按 3m/4.5m 分段，每米测按 1m 步长，区间测按上下限均分。

内核入口Application/Src/measure_density.c:722-794：先找液位，再切密度模式，再按模式生成测点。
测点规则Application/Src/measure_density.c:356-711：普通、国标、每米、区间四种测点构建函数分别实现。
维护关注Application/Src/measure_density.c:737：EnableDensityMode() 返回值未检查，模式切换失败可能延后到读数阶段暴露。

3.5 分布密度逐点执行与发布

测点生成后统一进入逐点执行：移动到点位、悬停、调用单点稳定采样、累计平均值。成功后包装函数写入全局 profile 并递增完成计数。

逐点执行Application/Src/measure_density.c:259-344：逐点移动、悬停、稳定采样、累计平均值。
完成沿Application/Src/measure_density.c:823-829、862-868、901-907、940-946：四类分布成功后置完成锁存并 counter+1。
悬停单位Application/Src/measure_density.c:274-296 中 spreadPointHoverTime 按菜单秒配置，进入延时前换算为 ms；SinglePoint_ReadSensor() 中同一参数也按秒生成稳定窗口。

3.6 国标 Density20 删点过滤

国标模式采完后会按液位和 Density20 差值阈值压缩测点。图中按源码的 3m、4.5m 分界和 n=3/4/5 三类点数展开。

过滤入口Application/Src/measure_density.c:1047-1139：按液位和测点数执行删点，删点后调用重算平均。
比较字段Application/Src/measure_density.c:970-990：默认使用 standard_density 作为 Density20 RAW。
未接参数Application/Src/measure_density.c:788：oil_standard_th 暂时硬编码为 10，并带 TODO。

3.7 瓦锡兰密度分布

瓦锡兰流程不先找液位，而是按配置高度扫描密度点。点被判为空气后，切到液位模式下行寻找 OIL 作为液面，再删除距离液面太近的尾部测点并发布 profile。

范围扫描Application/Src/wartsila_density_measurement.c:457-594：用下限、上限、间隔生成扫描目标，遇空气点后下行找液面。
空气判定Application/Src/wartsila_density_measurement.c:65-82：密度低于 100 或频率高于液位频率均判为空气点。
测后动作Application/Src/measure.c:1056-1147：发布 profile 后等待 CPU3 读取，按周期可回固定点、探底，再切回 CMD_MONITOR_SINGLE。

3.8 综合测量与发布差异

综合测量先显式找液位，然后调用普通分布内核。该内核内部又会再次找液位；综合测量写入密度分布结果，但没有像分布命令一样置 profile 完成沿。

综合流程Application/Src/measure.c:1153-1186：先找液位、切密度模式、再调用普通分布测量内核并写全局结果。
重复找液位Application/Src/measure.c:1159-1172 与 Application/Src/measure_density.c:729-734：综合入口和密度内核都会执行找液位。
发布差异综合测量没有设置 profile_complete_latched 和 profile_complete_counter，与四类分布密度指令不一致。

5. 问题点与维护建议

  • 部分密度模式切换未检查返回值。
    Density_MeasureByMode_Exact() 和综合测量里直接调用 EnableDensityMode()，若切换失败，错误可能延后到读数阶段才暴露。
  • 综合测量与分布命令发布完成沿不一致。
    四类分布命令会置 profile_complete_latched 并递增 counter；综合测量只写 density_distribution，没有完成沿。
  • 综合测量存在重复找液位。
    综合入口先 SearchOilLevel()，随后 Density_MeasureByMode_Exact() 内部再次找液位，耗时和状态变化需要评估。
  • 国标过滤阈值仍是硬编码。
    oil_standard_th = 10 带 TODO，尚未接入真实参数；现场调阈值时文档和代码可能不一致。
  • 单次单点测量对 STATE_SWITCH 的处理不如监测清晰。
    单点测量使用 SET_ERROR(ret) 包装移动/采样结果，STATE_SWITCH 不报错但后续可能继续执行完成态。
  • 单点稳定采样 5 分钟超时仍返回 NO_ERROR。
    有非零密度时用最后一次非零值，否则密度填 0；上层无法仅从返回码区分“真正稳定”和“超时兜底”。
  • 瓦锡兰测后会改写命令为固定点监测。
    瓦锡兰完成或探底失败后设置 g_deviceParams.command = CMD_MONITOR_SINGLE，调试时要把这视作流程内自动切换。
