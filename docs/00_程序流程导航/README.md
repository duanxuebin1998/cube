# 程序流程导航

更新日期：2026-07-01

本目录是整机程序流程的统一入口，用于从业务链路视角串起 CPU3 交互、CPU2 执行、协议通信、状态回读和故障处理。CPU2/CPU3 单侧详细流程已并入本目录下的 `CPU2/` 和 `CPU3/`。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | CPU2/CPU3 程序流程统一入口，按整机业务、CPU2、CPU3 和专题流程跳转 |
| `流程排查入口.md` | 按现场问题类型组织流程入口，只做导航，不改变流程页生成规则 |
| `跨CPU业务链路.html` | 按液位、水位、密度、参数、故障、外部协议等业务链路串联 CPU3 与 CPU2 处理路径 |
| `SI协议分布测量程序流程.html` | SI Profile 分布测量跨 CPU 专题流程，覆盖外部触发、自动调度、CPU2 点位生成、采样、状态和寄存器输出 |
| `LNG计量仪系统框图.html` | 按整机拓扑、硬件连接、CPU2/CPU3 数据闭环、外部协议、测量执行和安全恢复整理的系统框图 |
| `LNG计量仪设备说明书.html` | LNG 计量仪设备结构、测量流程、通信接口、参数维护和故障处理说明 |

## 阅读建议

1. 不知道从哪查时，先看 `流程排查入口.md`，按现场问题类型进入。
2. 已经知道要查整机链路、CPU2 执行细节还是 CPU3 交互细节时，打开 `index.html` 或 `跨CPU业务链路.html`。
3. 如果流程变化涉及入口、状态机、命令分发、异常出口、通信链路或显示/参数交互，需要同步更新本目录入口和对应 CPU2/CPU3 流程页。

## 维护规则

- 本目录保存跨 CPU 导航、整机链路、系统框图、设备说明以及 CPU2/CPU3 单侧流程正文。
- HTML 当前作为流程阅读页保留；若新增长期维护的说明，应优先补 Markdown 索引或迁移到文档站页面。
- `CPU2/assets/` 和 `CPU3/assets/` 只保存流程 HTML 使用的样式和交互脚本，不作为独立文档入口，也不放业务说明。
- 更新流程入口后，同步检查 `docs/README.md`、`docs/00_程序流程导航/CPU2/README.md`、`docs/00_程序流程导航/CPU3/README.md`。
