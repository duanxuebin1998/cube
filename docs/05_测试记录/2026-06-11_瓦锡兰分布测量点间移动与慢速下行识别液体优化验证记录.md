# 2026-06-11 瓦锡兰分布测量点间移动与慢速下行识别液体优化验证记录

## 背景

本次验证对应 CPU2 瓦锡兰分布测量流程优化：

1. 起始点定位和点间移动不切换液位模式，不做运动中液位检测。
2. 到点后使用密度模式读取的实际密度值和浮点频率判定液体/空气。
3. 实际密度值 `< 100` 或浮点频率 `> oilLevelFrequency` 时判为空气。
4. 密度读取 5 分钟超时后输出密度 `0`，按空气点处理。
5. 空气点不保存，切液位模式慢速下行，首次识别到液体后把当前位置作为液位。
6. 最终只保留 `point.position_mm < level_mm - wartsila_max_height_above_surface` 的液体点。
7. 测量失败时不把临时结果覆盖为新的有效分布结果。
