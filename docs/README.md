## 命名原则

- 项目自有文档优先使用中文文件名，便于按业务场景查找。
- `CPU2`、`CPU3`、`SI7000`、`DSM`、`UART6`、`LNG`、`TMC5130A` 等协议、模块、芯片或产品名保留英文。
- `README.md`、`CHANGELOG.md`、`LICENSE`、脚本和工具文件名保留项目约定命名。
