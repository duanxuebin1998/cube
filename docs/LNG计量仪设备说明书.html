一、适用范围

本说明书适用于当前工程主线中的 `LTD_MAIN_CPU2` 主控测量板和 `LTD_DISPLAY_CPU3` 显示通讯板。设备用于液位、罐底/罐高、水位、密度单点、密度分布、瓦锡兰区间密度等测量，并通过 CPU3 外部串口对接 DSM、Wartsila、LTD、SI7000 等协议。

版本要求：CPU2 和 CPU3 必须成对使用协议版本 12。固件版本只用于显示和发布追踪，跨 CPU 能力兼容以 `DeviceParameters.protocolVersion` 是否等于当前 `DEVICE_PROTOCOL_VERSION` 为准。
项目当前基线说明
CPU2V1.12.0.0主控测量板，负责测量流程、电机、编码器、扭力、传感器、参数 FRAM、继电器报警输出和内部 Modbus。
CPU3V1.10.0.0显示通讯板，负责屏幕菜单、COM1/2/3 外部协议、CPU2 轮询和参数同步。

二、安全注意事项

机械运动风险：设备会驱动电机、尺带、浮子或传感器动作。执行上行、下行、强制运动、罐底测量、液位/水位跟随、B/BE 往返诊断、无线滑环匹配前，必须确认现场机械行程、人员位置、罐内工况和传感器连接安全。
场景要求原因
上电或复位确认电机 24V、TMC5130、CPU2 复位链路状态，观察启动安全停机日志。CPU2 V1.10.0.0 起已加入启动安全停机和编码器首帧门控；当前 V1.12.0.0 仍需现场确认真实保持力和机械自锁。
强制上行/下行只在维护人员确认行程安全后执行。强制命令可以绕过部分普通测量流程条件，不应作为常规测量动作。
B/BE 串口诊断用于低层运动诊断，不能替代正式测量命令；退出依赖新的有效命令。B/BE 会持续循环，且有意隔离业务错误，只看电机停稳或编码器目标。
无线滑环匹配测量或传感器通信过程中不要直接匹配，等待设备待机、故障或维护状态。匹配期间 CPU2 会接管 UART6，使 CH9141K 离开透传业务。
参数修改长期运行态例如液位跟随、水位跟随、固定点监测期间不要改关键参数。CPU3 已禁止部分长期状态下写参数，避免旧缓存覆盖和运行中边界突变。

CPU2 是动作和测量的执行端。它保存设备参数，执行正式命令，驱动电机和传感器链路，并把测量结果打包为内部输入寄存器供 CPU3 读取。

四、上电与版本兼容

启动顺序要点

1
GPIO 安全态

CPU2 启动时电机驱动默认禁用，TMC5130 SPI 片选保持空闲高电平，避免旧运动目标在复位窗口继续驱动。

2
早期安全停机

SPI2 初始化完成后，CPU2 执行 MotorCtrl_BootSafeStop()，清理 TMC5130 残留 VMAX/XTARGET，并保持电机输出受控。

3
参数加载和归一化

CPU2 从 FRAM A/B 分区读取参数，校验 magic、版本、结构大小和 CRC。旧协议升级时，协议字段和故障自动恢复重跑次数会按当前版本补默认值。

4
编码器首帧门控

编码轮记步模式下，普通运动和上电默认命令必须等编码器首帧有效。编码器未就绪时会拦截普通运动。

5
CPU3 协议检查

CPU3 轮询 CPU2 后读取协议版本。协议不匹配时，设备状态页应提示不兼容，不建议混用不同协议版本固件。

六、现场操作流程

首次上电或换板后的建议流程

  1. 核对 CPU2、CPU3 固件版本和共享协议版本，确认协议版本均为 7。
  2. 检查 COM1/COM2/COM3 的协议、波特率、校验和停止位，确认与上位机或 PLC 一致。
  3. 确认传感器类型、传感器编号、传感器软件版本能正确读取。
  4. 设置或核对液位罐高、水位罐高、液位探头距差、盲区、最大下行距离、罐底检测模式等基础参数。
  5. 执行回零点或标定零点，确认编码轮和电机位置基准一致。
  6. 按现场工艺执行液位标定、水位标定、罐高标定、空载扭力和满载扭力。
  7. 执行读取部件参数，确认传感器、电机、编码器、扭力、水位电容、姿态角等通道正常。
  8. 先做单次液位、水位、罐底和单点密度验证，再开启长期跟随或固定点监测。

七、测量功能说明

零点与罐底

零点用于建立尺带和编码器的上端基准。标定零点成功后，CPU2 会同时清编码轮零点和电机卷筒参考点，并切回编码轮记步。罐底测量通过扭力、角度或组合方式识别罐底，完成后计算当前实高，并在满足条件时修正编码器位置。

  • 罐底粗找和精找下行前都会检查最大尺带长度，限制值为 tankHeight + maxDownDistance。
  • 传感器位置低于 1 m 且原速度高于 0.50 m/min 时，罐底下行速度会被压到 0.50 m/min。
  • 探底修正罐高为 0 时沿用液位罐高；非 0 时用于罐底后编码器修正目标。
  • 实高偏差超过最大允许偏差时，只跳过编码器修正，不应把编码器强行改到目标位置。

液位测量和液位跟随

液位测量依赖液位传感器信号、罐高、盲区、液位阈值、滞后阈值和测量方式。长期液位跟随流程会在进入跟随前确认位置源，必要时从编码轮记步切换到电机步进记步，并重新寻找液位点。

阶段说明
初始化执行测量初始化，确认电机和传感器可用，处理必要回零。
找液位按当前液位测量方式搜索液位，成功后更新液位结果和 SI7000 辅助状态。
位置源处理若允许自动切换并处于长期跟随类流程，切到电机步进记步后重新找点。
跟随/监测长期稳定状态下维持液位跟随，并允许命令切换中断。

水位测量和水位跟随

水位跟随以水位电容为闭环判断依据。水位目标电容等于零点电容加水位跟随电容阈值；寻找电容阈值用于闭环稳定带，滞后电容阈值用于稳定监测中判断是否需要重新寻找水位。

参数单位/倍率用途
water_cap_thresholdx1000水位目标电容增量。
water_find_cap_thresholdx1000闭环跟随稳定带半宽。
water_lag_cap_thresholdx1000稳定监测阶段判断水位变化的偏差阈值。
water_stable_threshold0.1 mm快速翻转找点时判断水位估计波动是否稳定。

闭环每 500 ms 读取一次电容。偏水时上行，偏空气时下行，步长按偏差分为 0.2 mm、3.0 mm 和 10.0 mm。连续稳定约 2.5 s 后进入稳定监测；稳定监测中只在电容偏离目标超过滞后阈值时回到闭环。

密度单点、固定点和分布测量

  • 单点测量使用单点测量位置，执行前会校验目标在 blindZone <= target <= tankHeight 范围内。
  • 固定点监测使用单点监测位置，属于长期运行态，CPU3 会限制参数写入。
  • 分布测量支持最多 200 个测点，测点数量、间距、上下限、悬停时间由密度测量参数决定。
  • SI7000 协议输出 profile 数据时，只在 profile 完成锁存后输出点数和有效点阵，范围外保持 0。

瓦锡兰区间密度

瓦锡兰区间密度测量完成后，会等待 CPU3 读取结果，再根据“瓦锡兰探底间隔”判断是否执行测后探底。需要探底时，流程先回到固定点监测位置，只移动不读取密度；固定点移动失败时跳过后续探底，不通过最终错误出口置错误态。

参数说明
瓦锡兰探底间隔0 表示不探底；1~100 表示每 N 次瓦锡兰分布测后探底一次；大于 100 按 1 处理。
探底修正罐高用于瓦锡兰测后探底或罐底后编码器修正；0 表示沿用液位罐高。
密度点上限/下限/间距控制瓦锡兰密度区间测点范围和间隔。

罐高参数罐底检测模式、角度阈值、扭力阈值、更新罐高标志、实高最大偏差、罐底后编码器修正。罐底识别、实高计算和编码器修正。最大下行距离来自水位参数组的 maxDownDistance。
磁通量参数磁通量 D、磁通量 T、上次液位修正液位、气相温度、尺带伸缩率、标定尺带温度。密度/温度修正和尺带温度补偿。尺带补偿参数需与现场标定口径一致。
密度测量参数是否测罐底、是否测水位、分布测点数、点间距、最高点距液面、最低点距罐底、悬停时间。分布测量和区间测量策略。分布测点数范围 1~200，悬停时间范围 0~600 s。
Wartsila 参数最高密度点、最低密度点、密度点间距、最高点液面距、瓦锡兰探底间隔、探底修正罐高。瓦锡兰区间测量和测后探底。探底修正罐高为 0 时沿用液位罐高。
继电器/AO 输出四路继电器报警输出配置、只读报警状态、输出范围、报警电流、故障电流、调试电流。继电器和 4-20 mA 输出。继电器报警输出包含 HH/H/L/LL 阈值、滞回、接点类型、无效值策略和锁存清除；每路继电器子页可只读查看报警值、HH/H/HH-H/L/LL/LL-L、任意报警和清锁存运行态；旧 DO 报警入口已删除；AO 正常起点/终点电流范围为 4.00~20.00mA，状态/报警/故障/调试电流范围为 3.20~24.00mA，菜单按 mA 小数 2 位显示。
CPU3 本机参数语言、数据源、手输值、小数位、屏幕密码、息屏、COM1/2/3 配置。显示端、外部串口和手输数据源。选择 SI7000 协议后串口会自动收敛为 9600 8O1。

参数写入限制

  • 待机态和普通测量完成态允许写参数。
  • 液位跟随、水位跟随、固定点监测等长期运行态不允许按普通完成态放行参数写入。
  • CPU3 批量同步会跳过 CPU2 可能自动更新的字段，例如位置源和电机局部周长，避免旧缓存覆盖 CPU2 新值。
  • 涉及共享字段语义变化时必须升级协议版本，并同步更新 CPU2/CPU3 两端结构体、寄存器和菜单。

端口硬件串口默认串口参数默认协议

可选协议包括 DSM、Wartsila、LTD、预留协议 1、预留协议 2 和 SI7000。SI7000 被选中后，固件会把对应串口归一化为 9600 8O1，避免菜单组合出 PLC 不兼容配置。

DSM V1.228 外部协议

  • CPU3 外部 DSM 层支持 0x03、0x04、0x05、0x10 核心功能码，并保留部分现场兼容行为。
  • 外部状态码通过 CPU3 DSM 转换层翻译，避免直接暴露 CUBE 内部扩展状态。
  • 写线圈只有合法地址且写入 0xFF00 时触发命令；写 0x0000 只回包不动作。
  • DSM V1.228 第 6 段保持寄存器当前按占位兼容处理，能响应但不参与 CPU2 算法。
  • 调试模式在 DSM 外部状态中映射为维护模式，避免上位机收到未知内部状态 0x0033。

SI7000 外部协议

区域当前实现限制
串口要求Modbus RTU，9600 8O1，站号优先使用现有从站地址。选择 SI7000 协议后自动收敛串口配置。
功能码支持 FC01/FC02/FC03/FC04/FC05/FC06。保留线圈写入返回非法地址，避免误写。
输入寄存器位置、温度、密度、液位、profile 点阵、时间戳和当前时间。密度按协议 kg/m3 x100 输出，超过 16 位会钳位。
保持寄存器40001~40003 桥接到分布测量参数，其余自动 profile 和报警设定点为影子回读。影子寄存器当前不写入 CPU2 参数存储，掉电保持需后续新增参数。
状态位Bottom Reference、Profile Complete、Probe At Liquid Level、报警位等由共享状态字段和影子阈值合成。Lower/Upper Level Sensor 当前无可靠内部来源，固定为 0。

Wartsila 和 LTD

Wartsila 协议由 CPU3 外部 Modbus 模块处理，密度分布点已扩展到 200 点。瓦锡兰区间密度流程还会与 CPU2 的测后探底和固定点监测流程联动。LTD 协议作为外部协议选项保留，并与 CPU2 传感器类型和 UART6 传感器通信流程相关。

统一错误日志

CPU2 日志字段使用制表符分隔，现场建议优先搜索 错误。再按阶段过滤：

阶段：错误重试阶段：重试成功阶段：错误报警阶段：最终报错

阶段含义
错误重试当前操作失败，但流程还会继续尝试。
重试成功前面发生过失败，后续尝试恢复成功。
错误报警不是最终报错，但现场需要关注，可能会停止电机或继续尝试。
最终报错由故障管理统一出口打印，表示本次业务流程进入最终错误状态。

测量失败自动恢复

任意测量类指令失败后，系统保持原错误状态和错误码，并进入自动恢复检查。恢复检查每 1 秒读取一次部件参数，只有所有部件恢复正常后，才清除错误并从头重新执行失败前的完整测量命令。

参数行为
fault_auto_recovery_retry_limit = 0关闭恢复确认成功后的原命令自动重跑。
1~10恢复确认成功后，最多自动重跑原命令的次数。
>10CPU2 启动或参数加载时归一化为默认值 3。
新命令打断自动恢复期间收到新命令，会取消当前恢复流程并执行新命令。

无线滑环最近匹配

CPU2 支持正式命令 CMD_PAIR_NEAREST_WIRELESS_SLIPRING = 117 和串口调试命令 SPR，用于按 RSSI 近距离规则匹配最近的 CH9141K 无线滑环从机。

  1. 维护人员确认目标从机上电，并尽量让附近只有目标从机或目标从机距离最近。
  2. CPU2 接管 UART6，进入 CH9141K AT 配置流程。
  3. 确认主机模式，扫描候选，按 RSSI 阈值和差值选择目标。
  4. 连接目标 MAC，保存默认连接，复位模块并恢复透传。
  5. 探测无线主机和从机链路，并把结果和 MAC 通过输入寄存器发布给 CPU3。

匹配成功后 CPU3 显示无线滑环匹配完成和两行 MAC；匹配失败时 CPU2 进入故障态，CPU3 按错误码显示，详细失败阶段看 CPU2 串口日志。

十二、联调检查清单

上电检查

  • CPU2/CPU3 固件版本与协议版本一致。
  • 启动日志显示安全停机结果和编码器首帧状态。
  • 屏幕状态页没有协议不匹配提示。
  • 读取部件参数能成功返回传感器、扭力、电机、编码器和水位电容相关数据；进入完成态后数据会持续刷新，且新命令可打断。

测量检查

  • 回零点、液位测量、水位测量、罐高测量均能正常结束或给出明确错误码。
  • 单点测量和固定点监测目标位置在盲区到罐高范围内。
  • 分布测量点数不超过 200，点距、上下限和悬停时间符合现场要求。
  • 水位跟随参数换算后，目标电容、寻找带和滞后带符合实际传感器响应。
  • 瓦锡兰测后探底频率、探底修正罐高和固定点监测位置已按现场工况配置。

外部协议检查

  • COM 口波特率、数据位、校验和停止位与外部主站一致。
  • DSM 主站读取设备状态时得到 DSM V1.228 对外状态码，不直接解析内部状态。
  • SI7000 协议端口被自动归一化到 9600 8O1。
  • Wartsila 主站读取密度点数、点阵和测后探底结果时，CPU2/CPU3 版本成对匹配。

故障排查

  • 串口日志先搜索 错误，再按模块过滤电机、编码器、传感器、扭力、参数、通信、测量或系统。
  • 检查是否达到故障自动恢复重跑上限，参数值是否被误写为 0。
  • 传感器异常时区分传感器本体、无线主机、无线从机和 UART6 硬件错误。
  • 罐底或水位搜索失败时，核对最大下行距离、盲区、零点电容、扭力阈值和角度阈值。
  • 复位后位置漂移时，复核启动安全停机、编码器首帧和位置源门控日志。
