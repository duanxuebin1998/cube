# 硬件原理图资料索引

更新日期：2026-06-06

本目录用于归档 CUBE 项目的硬件原理图、板级连接图、本安接口和硬件链路整理资料。原始图纸放入 `00_原始资料`，二次整理文档放在本目录根部，便于固件开发、联调和问题定位时按板卡或接口快速查找。

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `00_原始资料/储罐自动计量仪原理图汇总.pdf` | 原始 PDF 图纸，包含 30 页储罐自动计量仪板级框图和分板原理图 |
| `储罐自动计量仪原理图汇总整理.md` | 按总体架构、板卡、接口、电源、本安链路和固件关联整理的阅读笔记 |
| `原理图与固件对照问题清单.md` | 对照 CPU2/CPU3 固件后的问题、风险和优化建议清单 |
| `原理图与固件对照问题清单.html` | 问题清单的 HTML 阅读版，包含目录和打印友好样式 |

## 使用建议

- 固件开发优先阅读整理文档中的“固件关联点”和“接口整理”，再回到原始 PDF 查具体页号。
- 真实接线、安规、本安参数和 PCB 走线仍以原始 PDF、BOM、PCB 文件和硬件评审结论为准。
- 新增硬件资料时保留原始文件名；若文件名过于模糊，再补充中文整理文档说明来源、页号和适用范围。
