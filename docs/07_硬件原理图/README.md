## 使用建议

- 固件开发优先阅读整理文档中的“固件关联点”和“接口整理”，再回到原始 PDF 查具体页号。
- 真实接线、安规、本安参数和 PCB 走线仍以原始 PDF、BOM、PCB 文件和硬件评审结论为准。
- 新增硬件资料时保留原始文件名；若文件名过于模糊，再补充中文整理文档说明来源、页号和适用范围。
- 同名 Markdown、HTML 或 PDF 同时存在时，Markdown 作为维护源，HTML/PDF 作为阅读或导出件。
- 原始图纸放 `00_原始资料/`，不要在根目录直接堆新 PDF；固件侧解释、接口注意事项和问题清单写成 Markdown。
