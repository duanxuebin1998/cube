## 总体架构

第一页是整机板级框图，核心结构如下：

| 模块 | 图纸表现 | 主要连接 |
| --- | --- | --- |
| 对外接线腔 | 外部接线入口，包含可选 `220AC 转 24DC` 电源 | 通过排线和插槽连接母板 |
| 母板 | 作为 CPU2 主控板、CPU3 板、CPU4 板和对外接线腔之间的转接底板 | 母型插槽、公型插头、排线插座 |
| 主控板 | CPU2 相关主板，图中标注主控板和“本安部分” | 电机、编码器、称重传感器、导电滑环、4-20mA、HART、CPU3 485 |
| CPU3 板 | 显示和外部通讯板 | 上位机 485、CPU2 485、BPM、HART、瓦锡兰协议通讯、显示板 |
| CPU4 板 | 温度采集相关板 | 9V 供电、温度通讯、瓦锡兰温度计接口 |
| 本安部分 | 以红色虚线框标注，覆盖无线供电、传感器、HART、温度采集等接口 | 需要结合本安参数、隔离器件和安规评审单独确认 |

整机可以按三条主链路理解：

| 链路 | 说明 |
| --- | --- |
| 测量控制链路 | CPU2 控制电机驱动、编码器、称重传感器、传感器驱动板和无线从机链路 |
| 显示通讯链路 | CPU3 负责 OLED/显示、外部 RS485、CPU2 通讯、HART/BPM 等接口 |
| 温度采集链路 | CPU4/RTD 板负责温度采集和瓦锡兰温度计接口，本安小板负责信号限能 |

## 电源整理

| 电源域 | 来源/生成位置 | 主要用途 |
| --- | --- | --- |

| `24V` | 主控板页 8，48V 转 24V | 传感器/外部接口/后级电源 |

| `9V` | 主控板页 8、LTD-01-02 页 10、CPU4 页 25 | 继电器、无线/本安小板、CPU4/AB09DT 相关链路 |
| `5V` | 主控板页 8、CPU3 页 21、HART 页 23 | 模拟、隔离电源、CPU3/子板后级 |
