# 原油浮子电容极板：油水界面与含水率测量原理

更新日期：2026-07-24

适用范围：结合《图纸-24-传感器为原油》中的 TM-80N 电容式界面测量板、两块界面测量极片、AD7150 资料和公开论文/专利，分别分析“每块极片本地共面”和“两块极片面对面跨板”两种接线。本文只把电路图能够证明的内容写成事实，把接线拓扑和几何结构写成待实物确认的工程推断。

> **当前证据结论**
>
> - **图纸已经确认功能网络名称：**测量板 `J1=UP CIN`、`J2=UP EXC`、`J3=DN CIN`、`J4=DN EXC`，其中 CIN 是电容输入、EXC 是交变激励；极片 PCB 本地有 `J1/UP`、`J2/DOWN`，整机图画出了两块极片。
> - **图纸没有给出四根功能线到两块极片的逐针线束表。**因此不能把方案 A 或方案 B 写成已经确认的现场接法。
> - 只按 `UP/DN + CIN/EXC` 的命名关系推断，方案 B 的落线更自然：一块板承担 CIN，另一块板承担 EXC，上、下各组成一个跨板通道；这只是图纸倾向，不是现场事实。
> - 如果第 43 页的大面积铜区全部作为面对面有效面积，AD7150 的动态量程和机械间隙会很紧张。该反证提示：真实结构可能只使用局部有效窗口、Guard（保护电极）/屏蔽限制电场，或者实际采用方案 A。
> - 焊盘到工作铜区、背面大铜、GND/Guard、主动面朝向、板距、真实油水端点、`C(h)`（电容随界面高度变化的曲线）、温漂、损耗和漏电均未实测。本文数值只用于说明量级和曲线形状，不是产品台架数据或精度承诺。

### 0.1 先分清图纸事实、工程推断和现场事实

| 现场事实 | 需要断电逐针通断、单板响应和板距响应取得 | 目前没有现场线束表、实物通断或台架曲线 |

| 模型 | 同一通道的 CIN 和 EXC 在哪里 | 本文怎样使用 |
| --- | --- | --- |
| 方案 A：每板共面 | 同一块极片的上、下电极 | 独立完整分析；界面位置使用实物 `C(h)` 或经验证的共面电场模型 |
| 方案 B：两板面对面 | 分居两块相对极片 | 图纸命名优先支持的检查假设；只有通断和几何响应成立后才能使用平行板公式 |

两种方案都有两块板，不能用“板的数量”判断。判断依据是同一通道的 CIN、EXC 在同板闭合还是跨板闭合；边缘场、阻焊层和背面铜是锁定结构后要加入的修正，不是第三种接线方案。

### 0.2 界面高度和含水率是两道不同的题

“测油水界面”和“测原油含水率”都利用油、水电性质不同，但不是同一个问题。

| 场景 | 肉眼类比 | 仪器要回答什么 | 应使用的模型 |
| --- | --- | --- | --- |
| 上油、下水，分界清楚 | 杯子里有一条清晰分界线 | 分界线到哪一个高度了 | 界面位置、面积占比或空间灵敏度模型 |
| 油里均匀散布细小水滴 | 看似均匀的乳状液 | 这一小块样品中有多少水 | 有效介电常数 + 乳状液混合模型 + 实物标定 |
| 水滴已经连成导电通路 | 水成为连续相 | 当前信号还是“电容”吗 | 电导/复阻抗模型；低频单一电容值通常不够 |

一句话概括信号链：

```text
EXC 建立交变电场
        ↓
油、水或乳状液改变储存电荷和漏电的能力
        ↓
CIN 接收电荷，AD7150 输出数字量
        ↓
软件按“界面模型”或“含水率模型”解释读数
```

### 0.4 后文常用的硬件和物理词

- **共面电容/边缘场**：两个电极在同一板面，电场像从缝隙向外散开的光，主要感知板面附近的液体。
- **平行板电容**：两个电极面对面，主电场穿过两板之间的液体。
- **寄生电容**：线缆、PCB、支架带来的非目标底数，像电子秤上的容器自重。
- **CAPDAC**：AD7150 内部的“电子去皮”，相当于先扣除电子秤上的容器自重；它能把静态底数移到测量窗口中间，但不会扩大可测增量范围。
- **标定/反演**：用已知高度或已知含水率建立刻度叫标定；拿测得的电容倒查未知高度或含水率叫反演。
- **油连续/水连续**：油连成“海”、水滴是“岛”叫油连续；水连成“海”后叫水连续，低频漏电通常明显增强。
- **Guard（保护电极）**：像遮光罩或护栏，用来引导不希望进入敏感区的电场或表面漏电；它不是默认的工作电极。

## 1. 图纸能确认什么，现场落线还缺什么

### 1.1 图纸已经确认的功能网络

位号是“本板局部编号”。就像不同楼都可以有“101 室”，测量板的 J1 和极片板的 J1 不能只凭名字直接当成同一个物理插座。

| 图纸位置 | 图纸能够确认 | 图纸不能确认 |
| --- | --- | --- |
| 第 40 页，`TM-80N-2024-25` | 测量板 `J1=CIN1`、`J2=EXC1`、`J3=CIN2`、`J4=EXC2`；各连接器另有 GND | 四个连接器各自接到哪块极片 |
| 第 41 页，`TM-80N-2024-26` | 丝印明确写成 `J1/UP CIN`、`J2/UP EXC`、`J3/DN CIN`、`J4/DN EXC` | 丝印是否与最终线束完全一致 |
| 第 43 页，`TM-80N-2024-28` | 一块极片 PCB 正面有分段铜区，另一面有大铜面；本地 `J1=UP`、`J2=DOWN` | 每个焊盘到哪段铜；背面大铜是 GND、Guard、信号还是悬空 |
| 第 50 页，`TM-80N-2024-35` | 原油浮子中有一块测量板和两块界面测量极片 | 两板的逐针线束、主动面朝向、间距、重叠面积和固定方式 |

### 1.2 两种候选接线怎样落到两块极片

| 测量板功能网络 | 方案 A：每板本地闭合 | 方案 B：同高度跨板闭合 |
| --- | --- | --- |
| `J1 / UP CIN` | 极片 A 的本地 `J1/UP` | CIN 极片的本地 `J1/UP` |
| `J2 / UP EXC` | 极片 A 的本地 `J2/DOWN` | EXC 极片的本地 `J1/UP` |
| `J3 / DN CIN` | 极片 B 的本地 `J1/UP` | CIN 极片的本地 `J2/DOWN` |
| `J4 / DN EXC` | 极片 B 的本地 `J2/DOWN` | EXC 极片的本地 `J2/DOWN` |

方案 A 需要 `J1+J2` 落到同一块板、`J3+J4` 落到另一块板；方案 B 需要 `J1+J3` 落到 CIN 板、`J2+J4` 落到 EXC 板。两块极片复用同一 PCB 图时，本地 `J1/J2` 会在两块板上重复出现，这不等于它们已经按某一种方案接好。

### 1.3 从原理和图纸命名看，哪种接法更可能

| 证据 | 对方案判断的意义 |
| --- | --- |
| 测量板 `J1/J2` 都标 `UP`，分别为 CIN/EXC | 更自然地支持方案 B 的上窗口跨板通道 |
| 测量板 `J3/J4` 都标 `DN`，分别为 CIN/EXC | 更自然地支持方案 B 的下窗口跨板通道 |
| 每块极片本地只有 `UP`、`DOWN` 两个功能名 | 与“一块 CIN 板 + 一块 EXC 板、各自提供上下电极”的方案 B 映射一致 |
| 极片正面存在多块分段铜区 | A、B 都可以解释，单凭铜形不能定案 |
| 大铜区若全部面对面参与测量 | 方案 B 可能超出 AD7150 动态量程，并使所需板距落到平行板近似失效区 |
| 整机图没有逐针线束表 | A、B 都不能成为已确认现场事实 |

**当前最稳妥的结论是：**仅按功能网络命名，方案 B 比方案 A 更像设计者原本的意图，应优先按方案 B 的落线去查；但大面积电极与 AD7150 量程之间又存在明显疑点。现场通断完成前，两套公式都只能作为候选模型，不能直接写进产品换算。

## 2. 所有方案共用的基础：电容怎样感知油和水

### 2.1 电场、电容、介质和介电常数

电场可以理解为通电电极周围的一张“作用地图”。两个导体不需要金属接触，也可以通过电场储存能量；油、水或乳状液进入这张地图后，会改变同样电压下能够存住的电荷。

电容可以理解为“两个导体之间能隔空存多少电荷”。定义为：

\[
C=\frac{Q}{V}
\]

- \(C\)：电容，单位 F；本项目通常使用 pF（皮法，\(10^{-12}\) F）和 fF（飞法，\(10^{-15}\) F）。
- \(Q\)：导体上积累的电荷。
- \(V\)：两个导体之间的电压。

当几何结构不变时，介质越容易被电场极化，电容通常越大。用相对介电常数 \(\varepsilon_r\) 描述这种能力：

- 原油常见量级约为 2.1～2.5；
- 纯水在室温低频理想近似下约为 78；
- 实际地层水还可能含盐并导电，此时不能只把它看成“介电常数很大的理想绝缘体”。

本文演算统一取：

\[
\varepsilon_o=2.3,\qquad \varepsilon_w=78
\]

它们只是示例值。真实产品必须按油品、温度、盐度和频率标定。

混合物的**有效介电常数** \(\varepsilon_{\text{eff}}\) 是传感器对整片敏感区域看到的等效结果，不是把油和水的两个介电常数简单平均。它同时受到含水率、液滴形态、连续相、频率和温度影响。

后文会反复使用下面这些符号和资料名：

| 符号或资料 | 白话解释 |
| --- | --- |
| \(\varepsilon_0=8.854\times10^{-12}\ \text{F/m}\) | 真空介电常数，是把几何尺寸和介质特性换算成电容的基础比例，不是油或水自己的参数 |
| \(\varepsilon_r,\ \varepsilon_{\text{eff}}\) | 相对介电常数和有效介电常数，都是无量纲的“相对倍数” |
| pF、fF | 都是很小的电容单位；\(1\ \text{pF}=1000\ \text{fF}\) |
| \(\Phi\)、\(E\) | \(\Phi\) 是电势，可类比为地形高度；\(E\) 是电场强度，可类比为坡度和方向 |
| \(k\)、\(\Gamma(k)\) | \(k\) 是铜宽、间隙或周期组成的几何比例；\(\Gamma\) 是把该几何形状换算成单位长度电容的函数 |
| Gerber、有限元电场仿真 | Gerber 是描述 PCB 铜形的制造文件；有限元仿真是把空间切成许多小单元后数值求解电场 |

还要分清三个容易混淆的量：

| 名称 | 白话含义 | 对量程的影响 |
| --- | --- | --- |
| 绝对电容 \(C\) | 当前总共测到多少 pF | 必须能被芯片输入和 CAPDAC 居中 |
| 动态跨度 \(\Delta C=C_{\max}-C_{\min}\) | 从全油到全水实际变化多少 pF | 必须落在固定配置的动态窗口内 |
| 固定寄生 \(C_p\) | 线缆、PCB、支架带来的静态底数 | 主要消耗 CAPDAC/绝对底数余量；若随介质变化则也会消耗动态余量 |

### 2.2 从激励到数字：EXC、CIN、CDC、AD7150 和 CAPDAC

- **EXC（Excitation，激励）**：向传感电极施加交变信号，相当于“发出”电场。
- **CIN（Capacitance Input，电容输入）**：接收因充放电转移的电荷，相当于“接收”端。
- **CDC（Capacitance-to-Digital Converter，电容数字转换器）**：把电容变成数字量的器件类别。
- **AD7150**：双通道 CDC。单通道在固定 CAPDAC 代码下，最大量程档的总输入窗口典型约 4 pF；数据手册规定条件下最小总窗口约 3.2 pF。
- **CAPDAC**：可补偿约 10 pF 的静态传感器/线缆底数，像电子秤“去皮”。它不会把 3.2/4 pF 的固定动态窗口变成 13.2/14 pF。
- **GND 与 Guard**：GND 是电路参考地；Guard 是受控保护网络，用来改变杂散电场或截获表面漏电。二者都不能在没有通断证据时当成工作电极。

AD7150 的 AutoCAPDAC 可以在满足条件时重新居中，但运行中切换会产生分段和瞬态。除非固件明确记录 CAPDAC 代码、重建连续电容并验证拼接误差，否则不能把 AutoCAPDAC 当作无缝扩大量程。

“标称能看到 1 fF 变化”不等于整机含水率就有相应精度。线缆、PCB、安装、温度、挂壁、导电水、模型选择和样品不均匀都可能远大于芯片的最小分辨格。

### 2.3 实际液体既会存电，也可能漏电

理想电容像一只能反复充放电的储水袋；漏电像袋上开了小孔。含盐水、潮湿污染或绝缘层针孔会让“储存”和“漏掉”同时发生，可用并联导纳表示：

\[
Y=G+j\omega C
\]

- \(C\)：储存电荷的部分；
- \(G=1/R_p\)：并联漏电导；
- \(\omega=2\pi f\)：角频率。
- \(Y\)：导纳，表示交流电流通过的容易程度；
- \(j\)：只用于区分与电压相位不同的储能分量，不表示多出了一只实际器件。

对 AD7150 的近似电荷转移关系，EXC 与 CIN 之间的并联电阻可能表现成附加电容：

\[
C_{\text{leak}}\approx \frac{1}{4R_pf_{\text{EXC}}}
\]

所以“水让电容增大”和“水形成漏电让芯片误读”可能同时出现。只读一个电容数字量，不能把两者完全分开。AD7150 本身也不能独立输出并联电阻或损耗角；它只能让人从漂移、超量程、噪声或异常读数中怀疑漏电。要确认漏电或损耗，仍需 LCR 表、绝缘测试，或额外的频率/相位观测。

### 2.4 清晰界面、乳状液、体积含水率和质量含水率

- **清晰分层**：上面主要是油、下面主要是水，目标是找分界高度。
- **油连续乳状液**：油连成“海”，水以小液滴“岛”分散其中；经过标定后可以尝试估算局部含水率。
- **水连续状态**：水连成“海”，油变成分散相；低频漏电和极化往往更强。
- **相反转**：油连续与水连续的角色发生交换，原来的含水率公式通常不再适用。

| 名称 | 含义 | 不能混叫成什么 |
| --- | --- | --- |
| 界面高度 | 清晰油层和水层的分界位置 | 乳状液含水率 |
| 局部水体积分数/持水率 | 传感区域内水占总体积的比例 | 整个油罐的平均含水率 |
| 水质量分数 | 称重时水的质量占总质量的比例 | 水体积分数 |
| 管道 water cut | 单位时间流过截面中的水相比例 | 静态罐底水层高度 |

体积分数回答“一杯里水占多少空间”，质量分数回答“称重时水占多少重量”。如果需要把水体积分数 \(\phi\) 换成质量分数 \(w\)，还要使用密度：

\[
w=\frac{\phi\rho_w}{\phi\rho_w+(1-\phi)\rho_o}
\]

### 2.5 读懂后文算法和公式需要的七个词

| 术语 | 白话解释 |
| --- | --- |
| 正算 | 已知结构、介质或界面高度，计算应该得到多少电容 |
| 反演 | 根据测得电容倒查界面高度、有效介电常数或含水率 |
| 标定 | 用已知高度或已知含水率样品给仪表建立刻度 |
| 灵敏度 | 曲线斜率；移动 1 mm 或增加 1% 水时电容变化越大，灵敏度越高 |
| 残差 | 实测点与模型预测值之间尚未解释掉的差 |
| 滞回 | 界面上升和下降经过同一位置时读数不同，常由挂壁、气泡或吸附造成 |
| 不确定度 | 结果周围的可信范围，不等于已经确认发生了一次固定错误 |

## 3. 方案 A：每块极片各自形成共面电容

本章完整分析方案 A，但不把它写成现场已确认接法。它假设每块极片本地 J1/UP 与 J2/DOWN 分别接到同一 AD7150 通道的 CIN 与 EXC；若假设成立，单独接入一块极片时就应存在稳定本体电容，近板润湿响应应远强于改变两板间距的响应。

### 3.1 方案 A 的假设接线

方案 A 不是“整机只有一块板”，而是**每一块极片在本板内形成一个完整电容回路**：

| AD7150 通道 | 测量板端口 | 目标极片端子 | 板内回路 |
| --- | --- | --- | --- |
| 通道 1 | `J1/CIN1` | 极片 A 的 `J1/UP` | 极片 A 上电极，CIN 侧 |
| 通道 1 | `J2/EXC1` | 极片 A 的 `J2/DOWN` | 极片 A 下电极，EXC 侧 |
| 通道 2 | `J3/CIN2` | 极片 B 的 `J1/UP` | 极片 B 上电极，CIN 侧 |
| 通道 2 | `J4/EXC2` | 极片 B 的 `J2/DOWN` | 极片 B 下电极，EXC 侧 |

这张接线成立必须同时满足：

1. 每块极片的 `J1/UP` 与 `J2/DOWN` 分别连接本板的上、下工作电极；
2. 上、下电极彼此绝缘，且都不是 GND/屏蔽；
3. 通道 1 的 CIN1、EXC1 都落在极片 A，通道 2 的 CIN2、EXC2 都落在极片 B；
4. 测量板各连接器另有的 GND/屏蔽脚不能被误当成工作电极；
5. 两块板的背面大铜网络仍需通断确认。

### 3.2 电场为什么能伸到板外

同一块板的上、下铜区不相对，电场不能走完全笔直的最短路径，只能从铜边缘向板外弯曲。它像两片在同一平面、上下相邻但不接触的金属片：

```text
液体区域                 )))))) 边缘场 ))))))

正面上部： J1/UP（CIN）   █████
                              )))))) 板外边缘场
正面下部： J2/DOWN（EXC） █████
PCB：      ─────────────────────────────
背面铜：   - - - GND / Guard / 浮置 / 信号？- - -
```

背面铜如果接地或接 Guard，会像遮光罩一样改变电场方向，通常减小背侧干扰，但也可能缩短向液体中的检测深度。其真实网络必须通断确认。

#### 3.2.1 共面电容基本式

对每一块周期性共面或指叉极片，可用单位长度电容的概括式。令 \(i=1,2\) 分别表示极片 A、B：

\[
C'_i=\varepsilon_0\varepsilon_{\text{eff},i}\Gamma_i(k)
\]

\[
C_i=C_{p,i}+C'_i L_i
\]

- \(C'_i\)：第 \(i\) 块板的单位长度电容，单位 F/m；
- \(L_i\)：有效电极长度，必须用 m；
- \(\Gamma_i(k)\)：由本板铜宽、上/下间隙、周期、层叠和边界条件决定的无量纲几何函数；
- \(C_{p,i}\)：对应通道的线缆、PCB、背面铜和结构件形成的固定寄生电容；
- \(\varepsilon_{\text{eff},i}\)：第 \(i\) 块板边缘场所看到的等效介电常数。

边缘场随离板距离快速衰减。用电极周期 \(p\) 表示主要空间谐波时：

\[
\Phi(z)\propto e^{-2\pi z/p}
\]

\[
|E(z)|^2\propto e^{-4\pi z/p}
\]

这说明：贴在板面的油膜、挂蜡或气泡，可能比更远处的大体积液体更影响读数。

> 缺少 Gerber、铜网、层叠和背面铜网络时，不能只输入“铜宽和间隙”就精确算出当前极片电容。方案 A 更可靠的工程方法是实物标定。

### 3.3 方案 A 怎样测界面

#### 3.3.1 从电场能量看“为什么界面移动会改电容”

对第 \(i\) 块共面极片，忽略强导电损耗时：

\[
C_i-C_{p,i}
=
\frac{1}{V_i^2}
\int_{\Omega}\varepsilon(\mathbf r)|\mathbf E_i(\mathbf r)|^2\,dV
\]

这表示传感器不是把敏感区内每一滴液体等权平均，而是按 \(|E_i|^2\) 加权。界面位于高度 \(h\) 时，可以定义水相的电场权重：

\[
x_i(h)
=
\frac{\displaystyle\int_{\Omega_w(h)}
|\mathbf E_i(\mathbf r)|^2\,dV}
{\displaystyle\int_{\Omega_f}
|\mathbf E_i(\mathbf r)|^2\,dV}
\]

- \(\Omega_w(h)\)：界面以下被水占据的敏感区域；
- \(\Omega_f\)：极片附近全部有效液体区域；
- \(x_i\) 是“电场看见的水占比”，不一定等于几何体积比例。

这里把 \(|E_i|^2\) 当作固定权重，是便于理解的**冻结场形/一阶灵敏度近似**。严格来说，油换成水后电场分布本身也会改变，不能拿一张空气中的场图直接精算全量程电容。真实铜区、涂层和附近金属未知时，很难直接完成这个三维积分，所以工程上仍应以已知界面高度的实物 \(C_i(h)\) 标定为准。

#### 3.3.2 单块板的 S 形正算与反算

每块板的上、下电极之间都有自己的共面敏感区。界面穿过第 \(i\) 块板的敏感区时，响应通常是平滑 S 形，可分别使用经验标定模型：

\[
x_i(h)=\frac{1+\tanh\left(\dfrac{h-h_{0,i}}{s_i}\right)}{2}
\]

\[
C_i(h)=C_{o,i}+x_i(h)(C_{w,i}-C_{o,i})
\]

- \(C_{o,i}\)：第 \(i\) 块板的油端渐近电容；
- \(C_{w,i}\)：第 \(i\) 块板的水端渐近电容；
- \(h_{0,i}\)：第 \(i\) 块板敏感区的曲线中心高度；
- \(s_i\)：第 \(i\) 块板的过渡宽度参数；
- \(x_i\)：本板电场加权后的归一化响应，不是天然等于含水率。

\(s_i\) 可以理解为“曲线有多陡”，但它本身不是完整窗口宽度。对上式：

\[
h_{90\%}-h_{10\%}\approx2.197s_i
\]

\[
h_{98\%}-h_{2\%}\approx3.892s_i
\]

所以本例 \(s=6\) mm 时，10%～90% 过渡约 13.18 mm，本例建议的 2%～98% 有效反演区约 23.35 mm。2%～98% 不是通用标准，实际阈值要由端点噪声、重复性和标定残差确定。\(s\) 越小，曲线越陡，中心处高度灵敏度越高，但对局部污染和机械位置误差也可能更敏感。

两块板的用途取决于机械安装：

- 若两块板安装在不同高度，\(h_{0,1}\ne h_{0,2}\)，两条 S 曲线形成上、下两个检测窗口；
- 若两块板并排安装在同一高度，\(h_{0,1}\approx h_{0,2}\)，可用平均值提高稳定性，用差值发现单侧挂壁、气泡或污染；
- 具体属于哪一种，必须由第 50 页之外的装配尺寸或实物确认。

若两块板同高并排，可先分别归一化，再计算：

\[
\bar x=\frac{x_1+x_2}{2}
\]

\[
\Delta x=x_1-x_2
\]

- \(\bar x\) 用于降低两块板共同的随机噪声；
- \(\Delta x\) 正常应接近零，明显偏大时提示单侧挂壁、气泡、污染、线缆差异或局部流型不均；
- 不能直接平均原始 pF，除非两块板的油端、水端和跨度已经匹配。

由电容反演高度：

\[
x_i=\frac{C_i-C_{o,i}}{C_{w,i}-C_{o,i}}
\]

\[
h=h_{0,i}+s_i\,\operatorname{atanh}(2x_i-1)
\]

反演必须满足：

\[
0<x_i<1
\]

不能把超量程读数先裁剪成 0 或 1，再套反函数。两端会发散。

曲线斜率：

\[
\frac{dC_i}{dh}
=\frac{2(C_{w,i}-C_{o,i})x_i(1-x_i)}{s_i}
\]

位置不确定度近似为：

\[
u_h\approx\frac{u_C}{|dC/dh|}
\]

这个短式只计算“本次电容随机噪声”造成的局部高度误差，默认油端、水端、\(h_0\)、\(s\) 和曲线模型都完全准确。正式误差预算还应先传播归一化端点误差。令：

\[
D=C_w-C_o,\qquad x=\frac{C-C_o}{D}
\]

在先忽略相关性的情况下：

\[
u_x^2\approx
\left(\frac{u_C}{D}\right)^2
+
\left[\frac{(C-C_w)u_{C_o}}{D^2}\right]^2
+
\left[\frac{(C-C_o)u_{C_w}}{D^2}\right]^2
\]

\[
u_h^2\approx
u_{h_0}^2
+
\left[\operatorname{atanh}(2x-1)u_s\right]^2
+
\left[\frac{s}{2x(1-x)}u_x\right]^2
+
u_{\text{model}}^2
\]

\(u_{\text{model}}\) 用来包含重复性、上升/下降滞回、温漂和 S 形模型不能解释的残差。若端点、温度补偿或两个通道共用同一参考，误差可能相关，不能简单把所有项当成独立平方相加。

所以中间斜坡区最适合反推高度；油端、水端平台只适合判断“低于窗口”或“高于窗口”。本例在中心 \(x=0.5\) 且只计 \(u_C=0.005\) pF 时，\(u_h\approx0.026\) mm；在 \(h=15\) mm 处同样噪声会放大到约 0.196 mm。这里仍未计入端点、温漂和模型误差。

#### 方案 A 数值案例

以下只演示其中一块极片；另一块板使用同一组公式，但必须有自己的标定参数。

假设实物标定得到：

\[
C_o=1.20\ \text{pF},\quad C_w=3.50\ \text{pF}
\]

\[
h_0=25\ \text{mm},\quad s=6\ \text{mm}
\]

| 界面高度 \(h\) | 归一化响应 \(x_i\) | 电容 \(C_i\) | 斜率 \(dC_i/dh\) |
| ---: | ---: | ---: | ---: |
| 5 mm | 0.001271 | 1.202923 pF | 0.000973 pF/mm |
| 15 mm | 0.034445 | 1.279224 pF | 0.025498 pF/mm |
| 25 mm | 0.500000 | 2.350000 pF | 0.191667 pF/mm |
| 35 mm | 0.965555 | 3.420776 pF | 0.025498 pF/mm |
| 45 mm | 0.998729 | 3.497077 pF | 0.000973 pF/mm |

例如 \(C=1.279224\) pF：

\[
x_i=\frac{1.279224-1.20}{3.50-1.20}\approx0.034445
\]

\[
h=25+6\operatorname{atanh}(2\times0.034445-1)\approx15.00\ \text{mm}
\]

建议只在：

\[
0.02\le x_i\le0.98
\]

时输出连续高度。本例约对应 13.32～36.68 mm；区间外只输出“低于有效窗口”或“高于有效窗口”。

#### 两块共面板安装在不同高度的双窗口案例

为说明两块板怎样共同找界面，假设：

- 极片 A 的中心高度 \(h_{0,1}=15\) mm；
- 极片 B 的中心高度 \(h_{0,2}=35\) mm；
- 两块板都取 \(C_o=1.20\) pF、\(C_w=3.50\) pF、\(s=4\) mm。

| 界面高度 | 极片 A 的 \(x_1/C_1\) | 极片 B 的 \(x_2/C_2\) | 可读结论 |
| ---: | ---: | ---: | --- |
| 0 mm | 0.000553 / 1.201271 pF | 0.000000 / 1.200000 pF | 界面低于两个窗口 |
| 15 mm | 0.500000 / 2.350000 pF | 0.000045 / 1.200104 pF | 界面穿过极片 A 的敏感中心 |
| 25 mm | 0.993307 / 3.484606 pF | 0.006693 / 1.215394 pF | 界面位于两块板的中心高度之间 |
| 35 mm | 0.999955 / 3.499896 pF | 0.500000 / 2.350000 pF | 界面穿过极片 B 的敏感中心 |
| 50 mm | 1.000000 / 3.500000 pF | 0.999447 / 3.498729 pF | 界面高于两个窗口 |

这与方案 B 的“双窗口”外观相似，但物理来源不同：

- 方案 A 的每条曲线来自一整块共面板的上、下电极；
- 方案 B 的每条曲线来自两块面对面板在同一高度的跨板电极对；
- A 的曲线通常更圆滑，B 的理想面积曲线更接近分段线性。

### 3.4 两个通道怎样合成界面结果

先对每个通道单独归一化：

\[
x_i=\frac{C_i-C_{o,i}}{C_{w,i}-C_{o,i}}
\]

如果两块板处在相同高度，可用噪声不确定度加权平均：

\[
\bar{x}=\frac{w_1x_1+w_2x_2}{w_1+w_2},
\qquad
w_i=\frac{1}{u_i^2}
\]

同时计算一致性量：

\[
\Delta x=x_1-x_2
\]

\(\Delta x\) 过大可能表示倾斜界面、局部气泡、挂蜡、单板进水或通道故障，此时不应盲目平均。

只有两个通道的随机误差相互独立，且权重确实取 \(w_i=1/u_i^2\) 时，平均值的不确定度才可简化为：

\[
u_{\bar x}\approx\frac{1}{\sqrt{w_1+w_2}}
\]

如果两块板共用温度误差、同一批端点标定或同一处挂壁，这些是相关误差，平均不会把它们消掉。工程上还应做单板润湿试验，定义通道耦合比：

\[
k_{21}=\frac{\Delta C_2}{\Delta C_1}
\quad\text{（只改变极片 A 附近介质时）}
\]

\[
k_{12}=\frac{\Delta C_1}{\Delta C_2}
\quad\text{（只改变极片 B 附近介质时）}
\]

若耦合比很大，两个通道就不能再当作完全独立的两次测量，需要使用二通道标定矩阵或重新调整屏蔽、板距和采样时序。

如果两块板位于不同高度，应分别标定 \(C_1(h)\)、\(C_2(h)\)，并用加权最小二乘联合求界面：

\[
\hat h=
\arg\min_h
\sum_{i=1}^{2}
\left[
\frac{C_i-C_{i,\text{model}}(h)}
{u_{C_i}}
\right]^2
\]

处于端点平台的通道只能提供“界面高于/低于窗口”的区间信息，不能强行输出高分辨率连续高度。

不同高度双窗口的通俗状态表如下：

| 极片 A（下窗口） | 极片 B（上窗口） | 应输出什么 |
| --- | --- | --- |
| 油端平台 | 油端平台 | 界面低于两个有效窗口 |
| 过渡区 | 油端平台 | 用极片 A 曲线反演连续高度 |
| 水端平台 | 油端平台 | 界面位于两个窗口之间，只输出区间 |
| 水端平台 | 过渡区 | 用极片 B 曲线反演连续高度 |
| 水端平台 | 水端平台 | 界面高于两个有效窗口 |
| 油端平台 | 过渡区或水端平台 | 上窗口比下窗口“更湿”，空间顺序矛盾；判接线、污染、倾斜界面或流型异常 |
| 过渡区 | 水端平台 | 上窗口比下窗口“更湿”，同样判异常 |
| 过渡区 | 过渡区 | 窗口可能重叠、界面倾斜或响应耦合；使用联合拟合并检查残差 |

### 3.5 方案 A 特有换算：共面电容 C→εeff，再进入共用含水率模型

只有当敏感区被**相对均匀的油连续乳状液**填充时，才能走下面的链：

```text
实测 C
  → 同一极片、同一温度下的 C ↔ εeff 实物标定
  → 得到 εeff
  → 选择与连续相和液滴形态相符的混合模型
  → 估算水体积分数 φ
```

不能把：

\[
x_i=\frac{C_i-C_{o,i}}{C_{w,i}-C_{o,i}}
\]

直接叫做“含水率”。它首先只是第 \(i\) 块板界面标定中的归一化响应。

共面结构没有像理想平行板那样简单可靠的几何反演式。最低限度应使用两种以上已知介质做 \(C\leftrightarrow\varepsilon_{\text{eff}}\) 标定，更推荐用多点查表或多项式，并把温度和油品作为标定维度。

对第 \(i\) 块板，可把标定写成：

\[
\varepsilon_{\text{eff},i}=f_i(C_i,T,\text{oil type})
\]

如果只在很窄范围内做两点线性近似：

\[
K_i=\frac{C_{r,i}-C_{o,i}}{\varepsilon_r-\varepsilon_o}
\]

\[
\varepsilon_{\text{eff},i}
\approx
\varepsilon_o+\frac{C_i-C_{o,i}}{K_i}
\]

其中参考液体的 \(\varepsilon_r\) 必须已知，且线缆、安装、温度和板面状态与测量时一致。宽量程更适合用查表，不应强行使用一条直线。

为了把方案 A 的全部输入输出跑通，下面调用第 6 章的油连续 Maxwell-Garnett 模型。该混合模型不属于共面拓扑本身；只有独立证据确认“油是连续相、水是孤立小液滴”时才能使用：

\[
r=\frac{\varepsilon_{\text{eff}}}{\varepsilon_o}
\]

\[
\phi=
\frac{(\varepsilon_w+2\varepsilon_o)(r-1)}
{(\varepsilon_w-\varepsilon_o)(r+2)}
\]

这只是一个有相态前提的混合模型。水滴连成导电网络、水成为连续相或样品出现清晰分层时，必须停止使用它。

**贯通算例：方案 A 的 \(C\rightarrow\varepsilon_{\text{eff}}\) 换算，再调用第 6 章油连续模型**

假设某块共面板在当前油品和温度附近，实物多介质标定可局部近似为：

\[
C=1.0+0.05\varepsilon_{\text{eff}}\quad\text{pF}
\]

在这个假设算例中，把 \(C=1.131568\) pF 作为一条示例读数，则：

\[
\varepsilon_{\text{eff}}
=\frac{1.131568-1.0}{0.05}
\approx2.63136
\]

再取 \(\varepsilon_o=2.3,\ \varepsilon_w=78\)，代入上面的油连续 Maxwell-Garnett 反算式：

\[
\phi\approx0.05000=5.000\%\ \text{vol}
\]

同一标定下纯油为 \(1.115000\) pF，因此 5% 水只增加约 16.568 fF。这一完整链路是“实测 pF → 本板标定得到 \(\varepsilon_{\text{eff}}\) → 在相态成立时得到 \(\phi\)”；不能跳过中间两步。

对这个 Maxwell-Garnett 反算，局部灵敏度为：

\[
\frac{\partial\phi}{\partial\varepsilon_{\text{eff}}}
=
\frac{3(\varepsilon_w+2\varepsilon_o)}
{(\varepsilon_w-\varepsilon_o)\varepsilon_o(r+2)^2}
\]

本例约为 0.14398/介电常数单位。若电容随机不确定度为 5 fF，而局部标定斜率仅为 0.05 pF/介电常数单位，则 \(u_{\varepsilon}\approx0.1\)，仅随机噪声就对应约 1.44 个百分点的含水率不确定度；这还没有计入模型、油品、温度、盐度和漏电。

若两块板处于同一份均匀样品中，可分别得到 \(\phi_1,\phi_2\)：

\[
\bar\phi=\frac{\phi_1+\phi_2}{2},
\qquad
\Delta\phi=\phi_1-\phi_2
\]

只有两块板都在各自标定范围内、且 \(|\Delta\phi|\) 小于验证得到的允许差值时，才输出平均含水率；否则应报告“样品不均匀、单侧污染或通道异常”。

该量级说明两块板之间的零点差、温漂和漏电必须先校准，不能仅靠平均值自动消除。

### 3.6 方案 A 的标定、量程、误差和优缺点

**界面标定**

1. 固定真实安装、线缆、背板和温度；
2. 分别记录全油、全水稳定值；
3. 以已知高度逐步升高界面，记录上升曲线；
4. 再逐步降低，检查挂壁造成的下降曲线和滞回；
5. 分别拟合两块板的 \(C_{o,i},C_{w,i},h_{0,i},s_i\)，保留未参与拟合的高度做验证；
6. 根据噪声和斜率划定有效反演区。

**乳状液含水率标定**

1. 每块板分别做 \(C\leftrightarrow\varepsilon_{\text{eff}}\) 多介质或已知含水率样品标定，不能直接复制另一块板的系数；
2. 含水率样品必须有独立参考方法，并明确是体积分数还是质量分数；
3. 覆盖实际油品、温度、盐度、液滴尺寸和乳化方式，同时记录油连续、相反转、水连续和清晰分层标签；
4. 标定样品与验证样品分开，低含水区要单独评估 fF 级零漂、噪声和漏电；
5. 两通道分别反演 \(\phi_1,\phi_2\)，先做一致性判定，再决定是否输出平均值；
6. 超出油品、温度、相态或电容标定范围时，只输出“超出模型适用范围”，不能外推一个看似精确的百分数。

**AD7150 量程和 CAPDAC**

本例单通道油端 1.20 pF、水端 3.50 pF，动态跨度为 2.30 pF。它小于固定 CAPDAC 设置下标称约 4 pF 的总输入窗口，但这只说明示例跨度在数学上可能容纳。工程上还必须同时满足：

\[
\max(C_{o,i},C_{w,i})-\min(C_{o,i},C_{w,i})
+\text{温漂/污染/噪声余量}
<\text{固定设置下可用动态窗口}
\]

未知线缆寄生、板内底数 \(C_{p,i}\) 是否落在 CAPDAC 可补偿范围内仍需实测。CAPDAC 用来把静态底数重新居中，不会自动扩大固定设置下的动态油水跨度；运行中切换 CAPDAC 还会带来量程拼接和瞬态处理问题。

**主要误差**

- 板面油膜、挂蜡、沉积物和气泡正处于最高灵敏区；
- 背面铜、金属支架和另一块极片可能改变场形或产生通道间耦合；
- 保护层厚度、吸水和针孔造成长期漂移；
- 电极周期决定检测深度，远离板面的液体权重很低；
- 共面几何误差难以仅靠简单尺寸公式修正；
- 导电水产生表面漏电和电极极化。

**优点**

- 单块 PCB 即可形成电容；
- 结构薄，不依赖两板严格平行；
- 适合贴壁、管外或只能从一侧接近液体的场合。

**缺点**

- 检测深度浅、响应非线性；
- 对表面污染和附近金属非常敏感；
- 两块板必须分别标定；若同高并排安装，还要处理通道差异和单侧污染。

**方案 A 的完整处理链**

```text
J1/J2→极片A、J3/J4→极片B
  → 读取两个原始电容与超量程/漏电/噪声状态
  → 分别扣除零点并按本板端点归一化
  → 清晰界面：各自 C_i(h) + 双通道状态/联合拟合
  → 均匀油连续乳状液：各自 C_i→εeff,i→φ_i
  → 检查两板一致性、量程、温度、相态和模型残差
  → 输出连续高度、区间、含水率，或明确的无效状态
```

### 3.7 方案 A 应呈现的判型特征

若方案 A 成立，现场应观察到以下特征：

1. 每块板的 J1/UP、J2/DOWN 分别到达两个彼此绝缘、均不接 GND 的工作电极；
2. 通道 1 的 CIN1/EXC1 都落在极片 A，通道 2 的 CIN2/EXC2 都落在极片 B；
3. 分别单独接入极片 A、B 时，对应通道已经存在稳定本体电容；
4. 液体贴近本板的上/下电极间隙时响应显著；
5. 接入另一块板后，主信号仍由各自板内 J1-J2 决定，而不是必须两板相对才出现。

不需要先做完整油水台架，也能用四个小动作快速判别：

| 动作 | 通道 1 期望 | 通道 2 期望 | 支持的结论 |
| --- | --- | --- | --- |
| 只接极片 A，极片 B 断开 | 有稳定本体电容 | 仅线缆/开路底数 | A 板内可以独立闭合通道 1 |
| 手持绝缘水袋靠近 A 板铜缝 | 明显变化 | 只有较小串扰 | A 板是通道 1 的共面敏感面 |
| 只接极片 B，极片 A 断开 | 仅线缆/开路底数 | 有稳定本体电容 | B 板内可以独立闭合通道 2 |
| 改变两板相对距离但不改各板表面介质 | 变化应远小于直接润湿 | 变化应远小于直接润湿 | 两板间距不是主工作间距 |

“明显”和“较小”不能靠感觉，应该记录 \(\Delta C_1,\Delta C_2\) 并形成耦合比。若改变两板间距反而产生主响应，应重新检查是否存在跨板电容或屏蔽接法。

若实物通断与上述端口分组不一致，应回查线束、图纸版本和端子命名；不要在未确认时混用平行板公式。

## 4. 方案 B：两块极片面对面形成跨板电容

图纸中的 `UP CIN/UP EXC`、`DN CIN/DN EXC` 命名更自然地支持本方案，因此它是优先检查的接线假设；但只有端子对应表、线束版本或实物通断证明同一通道的 CIN 与 EXC 确实分居两块板，才能把它当成现场模型。即使跨板接线成立，平行板公式还要求主动面相对，并确认板距、平行度、有效重叠面积和边缘场占比。

### 4.1 方案 B 的跨板接线

只有在线束把同一通道拆到两块相对极片时，两块极片才会共同组成面对面电容：

| 功能 | 极片 A：方案 B 中的 CIN 板 | 极片 B：方案 B 中的 EXC 板 |
| --- | --- | --- |
| 上窗口 | 本地 `J1/UP` → 测量板 `J1/CIN1` | 本地 `J1/UP` → 测量板 `J2/EXC1` |
| 下窗口 | 本地 `J2/DOWN` → 测量板 `J3/CIN2` | 本地 `J2/DOWN` → 测量板 `J4/EXC2` |
| 背面铜 | GND/Guard/信号/悬空待通断 | GND/Guard/信号/悬空待通断 |

这种接法下，每块极片在每个高度只需要一个有效信号铜网；两块板合起来形成 CIN-EXC 电极对。它在端子数量和功能分组上均可成立；是否与实物一致，取决于四个功能网络到两块极片 UP/DOWN 的逐针通断，而不是连接器 J 编号表面相同与否。

方案 B 成立还必须同时满足：

1. 两块极片的主动面相对，并保持已知间距、平行度和重叠面积；
2. 同一个通道的 CIN 与 EXC 确实被拆到两块不同极片；
3. 每块板每个高度只有一路主要工作信号，连接器另有的 GND/屏蔽脚不作为工作电极；
4. 背面大铜的 GND、Guard、信号或悬空状态已经通过通断确认；
5. 下文接线图只是方案 B 的电气等效图，不代表第 43 页实际铜区形状和分组。

### 4.2 理想平行板和绝缘层修正

#### 4.2.1 电场怎样穿过三层材料

白话看，EXC 板把交变电场从铜面推出，电场依次穿过“第一侧绝缘层 → 液体净间隙 → 第二侧绝缘层”，最后到达 CIN 板。三层沿主电场方向首尾相接，所以它们的“电气厚度”串联相加：

```text
EXC 铜板 → 绝缘层 t1/εc1 → 液体 d/εr → 绝缘层 t2/εc2 → CIN 铜板
```

- 液体介电常数越大，液体这一段的电气厚度 \(d/\varepsilon_r\) 越小；
- 但即使理想化地让 \(\varepsilon_r\rightarrow\infty\)，两层绝缘仍在，电容不会无限增大；
- 窗口内部大部分是近似直穿的主电场，板边仍有弯曲的边缘场。

因此实际总电容更完整地写成：

\[
C=C_p+C_{\text{main}}+C_{\text{edge}}
\]

\[
C_{\text{main}}=
\frac{\varepsilon_0A}
{d/\varepsilon_r+t_1/\varepsilon_{c1}+t_2/\varepsilon_{c2}}
\]

\(C_{\text{edge}}\) 与板边、支架和周围介质有关，一般通过空载/已知介质标定或有限元修正；下面的手算案例暂把不能区分的固定部分并入 \(C_p\)。

#### 4.2.2 理想式和涂层修正式

理想平行板：

\[
C=\varepsilon_0\varepsilon_r\frac{A}{d}
\]

- \(A\)：两板有效重叠面积；
- \(d\)：两板之间的液体净间隙；
- \(\varepsilon_r\)：板间液体相对介电常数。

实际 PCB 表面通常有阻焊或绝缘涂层。一般式：

\[
C_B=C_p+
\frac{\varepsilon_0A}
{\dfrac{d}{\varepsilon_r}
+\dfrac{t_1}{\varepsilon_{c1}}
+\dfrac{t_2}{\varepsilon_{c2}}}
\]

如果两侧绝缘材料相同，可令：

\[
t=t_1+t_2,\qquad \varepsilon_c=\varepsilon_{c1}=\varepsilon_{c2}
\]

得到：

\[
C_B=C_p+\frac{\varepsilon_0A}{d/\varepsilon_r+t/\varepsilon_c}
\]

注意：

- \(d\) 是两侧涂层表面之间的**液体净间隙**，不是铜面总距离；
- \(t\) 在简化式中是两侧涂层总厚度；
- \(C_p\) 是并联固定寄生，不能塞进串联电气厚度的分母。

#### 4.2.3 先看一个 10 mm 数值案例

假设：

- \(A=1\ \text{cm}^2\)；
- \(d=10\ \text{mm}\)；
- 两侧绝缘层总厚 \(t=200\ \mu\text{m}\)；
- \(\varepsilon_c=3.5\)；
- \(C_p=1.0\ \text{pF}\)。

| 板间介质 | 计算总电容 |
| --- | ---: |
| 全油，\(\varepsilon_o=2.3\) | 1.201005 pF |
| 25% 窗口面积为水 | 2.345019 pF |
| 50% 窗口面积为水 | 3.489033 pF |
| 75% 窗口面积为水 | 4.633047 pF |
| 全水，\(\varepsilon_w=78\) | 5.777062 pF |

把全油和全水拆开看更直观。油状态的串联电气厚度为：

\[
\frac{10\ \text{mm}}{2.3}
+
\frac{0.2\ \text{mm}}{3.5}
=4.404969\ \text{mm}
\]

因此有效板间电容约 0.201005 pF，再加 \(C_p=1\) pF，得到 1.201005 pF。全水状态的串联电气厚度为：

\[
\frac{10\ \text{mm}}{78}
+
\frac{0.2\ \text{mm}}{3.5}
=0.185348\ \text{mm}
\]

有效板间电容约 4.777062 pF，再加寄生后得到 5.777062 pF。水的介电常数很大，但两侧绝缘层把上限钳制为：

\[
C_{\max}
=C_p+\frac{\varepsilon_0A}{t/\varepsilon_c}
\quad(\varepsilon_r\rightarrow\infty)
\]

总跨度约为：

\[
\Delta C=5.777062-1.201005=4.576057\ \text{pF}
\]

若面积减半为 \(0.5\ \text{cm}^2\)，油端约 1.100502 pF，水端约 3.388531 pF，跨度约 2.288029 pF。面积减半，扣除固定寄生后的有效跨度也近似减半。

> **AD7150 量程提醒：** 4.576057 pF 的油水跨度已经超过固定 CAPDAC 设置下标称约 ±2 pF 的输入窗口（总跨度约 4 pF）。这组参数只能用于物理量级演示，不能直接作为可用设计。实际结构需要减小面积、增大间距，或设计经过验证的受控 CAPDAC 重定心；CAPDAC 能扣除静态底数，但不会自动扩大一次固定设置下的动态跨度。通用判据应为 \(\Delta C+M<C_{\text{window}}\)，其中 \(M\) 是温漂、污染、噪声和端点漂移的工程余量；不能把“刚好等于 4 pF”判成可用。

#### 4.2.4 从 AD7150 量程反推板距：筛选可行性，不直接给机械定值

板距不能脱离有效面积、涂层和芯片动态窗口单独确定，因此先按 AD7150 量程做可行性筛选。AD7150 最大量程档在固定 CAPDAC 代码下，单通道总输入窗口典型约 4 pF，数据手册规定条件下最小约 3.2 pF。为给温漂、污染、端点漂移、装配误差和介质相关边缘场留出余量，本文暂把全油到全水的**主场动态跨度**控制在：

\[
\Delta C_{\text{main}}\le 2\ \text{pF}
\]

这是工程预算，不是芯片手册指标。固定寄生 \(C_p\) 主要消耗 CAPDAC 和绝对底数余量；会随油水变化的边缘场才直接占用这 2 pF 动态预算。

采用本例的 \(\varepsilon_o=2.3\)、\(\varepsilon_w=78\)、两侧涂层总厚 \(t=0.2\ \text{mm}\)、\(\varepsilon_c=3.5\)，当 \(A\) 使用 cm²、\(d\) 使用 mm 时：

\[
\Delta C(\text{pF})
=0.8854A
\left[
\frac{1}{d/78+0.2/3.5}
-
\frac{1}{d/2.3+0.2/3.5}
\right]
\]

双面涂层模型在极小间隙处会由涂层的“电气厚度”主导，因此同一个目标跨度可能出现一小一大两个数学根。小根位于极小间隙的上升支路，不适合作为机械设计依据；本文只采用较大间隙的下降支路。先解出 \(\Delta C=2\ \text{pF}\) 的较大间隙根，再把板距乘以 1.2 作为量程筛选系数：

| 单通道有效重叠面积 \(A\) | 2 pF 较大间隙根 | 板距乘 1.2 后的量程筛选值 |
| ---: | ---: | ---: |
| 0.5 cm² | 约 12.1 mm | 约 15 mm |
| 1.0 cm² | 约 28.9 mm | 约 35 mm |
| 2.0 cm² | 约 62.4 mm | 约 75 mm |
| 5.0 cm² | 约 163 mm | 约 200 mm |

这里的 \(A\) 是**一个通道、一个窗口、真正参与跨板耦合的有效重叠面积**，不是整块 PCB 外形面积；\(d\) 是两侧涂层表面之间的液体净间隙。

以 \(A=1\ \text{cm}^2\) 为例，固定寄生先不计入动态差值：

| 净间隙 \(d\) | 全油主场电容 | 全水主场电容 | 油水动态跨度 |
| ---: | ---: | ---: | ---: |
| 10 mm | 0.201 pF | 4.777 pF | 4.576 pF，超出典型 4 pF 窗口 |
| 20 mm | 0.101 pF | 2.824 pF | 2.723 pF，余量偏小 |
| 25 mm | 0.081 pF | 2.344 pF | 2.263 pF，仍高于 2 pF 预算，仅作过渡测试点 |
| 35 mm | 0.058 pF | 1.750 pF | 1.692 pF，动态余量较充足 |

> **这些数值不能直接叫“推荐机械板距”。**1 cm² 方形电极边长只有约 10 mm，而表中 35 mm 已明显大于横向尺寸，此时边缘场会占主导，理想一维平行板公式本身不再准确。75 mm、200 mm 更主要是在说明“大面积方案 B 与 AD7150 固定动态窗口不匹配”，而不是建议真的把板装得这么远。

因此，方案 B 的工程结论应这样使用：

1. 若只做量程初筛，\(A\approx0.5\ \text{cm}^2\) 时 15 mm 是依赖两侧各约 0.1 mm 完整涂层的计算值；若不依赖涂层限制水端电容，保守筛选应提高到约 17～20 mm。
2. \(A\approx1\ \text{cm}^2\) 时，可先用 20、25、35 mm 三档卡具测量；25 mm 仍高于本例 2 pF 主场预算，35 mm 才在手算中落入预算，但二者都不能直接定为产品尺寸。
3. 如果实际板距只能是 10～15 mm，应缩小单通道有效重叠窗口、使用受控 Guard/屏蔽，或更换更适合大动态范围的前端；不能让整片大铜区全部直接重叠。
4. 当 \(d\) 接近或大于电极横向尺寸时，必须使用三维电场仿真和全油/全水实物标定，不能继续依赖理想平行板公式定尺寸。
5. 当前图纸没有给出有效重叠面积、板距和涂层厚度，因此本文只能完成量程可行性筛选，不能给出唯一生产尺寸。

### 4.3 方案 B 怎样测水平油水界面

本节的通用公式与端点数值无关。为便于和方案 A 的双窗口曲线直接对比，后面的双窗口案例**另设**已经标定的油端 \(1.20\) pF、水端 \(3.50\) pF；它不沿用 4.2 节 10 mm 几何算例的 \(1.201005/5.777062\) pF。两组数值都是假设算例，不是台架实测。

假设两板竖直、油水界面水平，并横向切过整个窗口。水占据窗口高度：

\[
\ell_w=\operatorname{clip}(h-h_b,0,H)
\]

- \(h_b\)：窗口底部高度；
- \(H\)：窗口高度；
- \(h\)：界面高度。

单位面积油、水电容：

\[
c_o=\frac{\varepsilon_0}{d/\varepsilon_o+t/\varepsilon_c}
\]

\[
c_w=\frac{\varepsilon_0}{d/\varepsilon_w+t/\varepsilon_c}
\]

窗口宽度为 \(W\) 时：

\[
C_B(h)=C_p+W[c_o(H-\ell_w)+c_w\ell_w]
\]

完整油、水端点：

\[
C_o=C_p+WHc_o
\]

\[
C_w=C_p+WHc_w
\]

于是窗口内部：

\[
x_B=\frac{C-C_o}{C_w-C_o}=\frac{\ell_w}{H}
\]

\[
h=h_b+Hx_B
\]

反算时必须保留未裁剪的 \(x_B\)，并根据端点噪声和标定重复性设置归一化容差 \(\delta_x\)：

- \(x_B<0\) 或 \(x_B>1\)：读数已经越过标定端点，只能报“超出标定范围/无有效反演”，不能仅凭这个值断言界面在窗口外；
- \(0\le x_B\le\delta_x\)：只能说 \(h\le h_b\)；
- \(1-\delta_x\le x_B\le1\)：只能说 \(h\ge h_b+H\)；
- 只有 \(\delta_x<x_B<1-\delta_x\) 且工况确为水平清晰界面时，才能输出连续高度。

\(\delta_x\) 不是固定理论常数，应由全油/全水端点的噪声、漂移和重复性验证确定。HTML 演示计算器默认取 0.02，并允许按实测修改。

这就是“平台—近似线性斜坡—平台”：

- 界面在窗口下方：读数停在油端平台，只能说 \(h\le h_b\)；
- 界面穿过窗口：电容近似随水占面积线性增加；
- 界面在窗口上方：读数停在水端平台，只能说 \(h\ge h_b+H\)。

#### 双窗口案例

假设：

- 下窗口覆盖 0～20 mm；
- 上窗口覆盖 30～50 mm；
- 每个窗口标定油端 1.20 pF、水端 3.50 pF。

| 界面高度 | 下窗口电容 | 上窗口电容 | 白话判断 |
| ---: | ---: | ---: | --- |
| -5 mm | 1.20 pF | 1.20 pF | 两个窗口都在油里 |

| --- | --- | --- |

#### 4.3.1 方案 B 的界面误差怎样计算

令：

\[
D=C_w-C_o,\qquad x=\frac{C-C_o}{D},\qquad h=h_b+Hx
\]

各输入对高度的局部影响为：

\[
\frac{\partial h}{\partial C}=\frac{H}{D}
\]

\[
\frac{\partial h}{\partial C_o}=-\frac{H(1-x)}{D},
\qquad
\frac{\partial h}{\partial C_w}=-\frac{Hx}{D}
\]

\[
\frac{\partial h}{\partial H}=x,
\qquad
\frac{\partial h}{\partial h_b}=1
\]

忽略相关性时：

\[
u_h^2\approx
\left(\frac{Hu_C}{D}\right)^2
+
\left[\frac{H(1-x)u_{C_o}}{D}\right]^2
+
\left(\frac{Hxu_{C_w}}{D}\right)^2
+
(xu_H)^2
+
u_{h_b}^2
+
u_{\text{model}}^2
\]

若只计算随机电容噪声，可简化为：

\[
u_h\approx\frac{H\,u_C}{|C_w-C_o|}
\]

例如窗口 \(H=20\) mm、跨度 2.30 pF、随机电容不确定度 \(u_C=0.005\) pF 时，仅随机噪声对应 \(u_h\approx0.0435\) mm。若油端、水端和机械窗口也有不确定度，实际值会更大。

### 4.4 油水沿电场方向分层时，公式完全不同

如果油、水不是横向占据不同面积，而是沿两板间距方向一层层排开，它们相当于串联。这里的“面积并联”和“厚度串联”是介质排列形成的**等效电路**，不是重新接了导线；下面使用理想一维主场近似，界面附近的边缘场仍需由实物标定修正：

\[
\frac{1}{C-C_p}
=
\frac{d_o}{\varepsilon_0\varepsilon_oA}
+
\frac{d_w}{\varepsilon_0\varepsilon_wA}
+
\frac{t_1}{\varepsilon_0\varepsilon_{c1}A}
+
\frac{t_2}{\varepsilon_0\varepsilon_{c2}A}
\]

这种图只用于演示沿主电场方向的局部宏观分层，不代表常见的“上油下水”重力稳定界面。

并且：

\[
d_o+d_w=d
\]

液体部分的等效介电常数是谐均值：

\[
\frac{1}{\varepsilon_{\text{eff}}}
=
\frac{1-\phi_d}{\varepsilon_o}
+
\frac{\phi_d}{\varepsilon_w}
\]

\[
\phi_d=
\frac{1/\varepsilon_{\text{eff}}-1/\varepsilon_o}
{1/\varepsilon_w-1/\varepsilon_o}
\]

这里的 \(\phi_d=d_w/d\) 是**宏观层厚比例**，不是乳状液含水率，也不能再套 Maxwell-Garnett。

### 4.5 方案 B 特有换算：平行板电容 C→εeff，再进入共用含水率模型

只有板间区域被相对均匀乳状液完全填充时，才可以先由几何反演表观介电常数。

令：

\[
C_m=C-C_p
\]

则：

\[
\varepsilon_{\text{eff}}
=
\frac{d}
{\dfrac{\varepsilon_0A}{C_m}
-\dfrac{t_1}{\varepsilon_{c1}}
-\dfrac{t_2}{\varepsilon_{c2}}}
\]

必须满足：

\[
C>C_p
\]

并且分母为正，否则应报“无物理解或寄生/几何输入错误”。

之后再根据乳状液连续相选择混合模型：

```text
实测 C
  → 扣除 Cp
  → 用面对面几何反演 εeff
  → 选择油连续/近对称混合模型
  → 估算水体积分数 φ
```

**贯通算例：方案 B 的 \(C\rightarrow\varepsilon_{\text{eff}}\) 换算，再调用第 6 章油连续模型**

继续使用 4.2 节的几何参数，并假设样品已被独立确认是油连续、相对均匀的乳状液。5% 水的 Maxwell-Garnett 结果为：

\[
\varepsilon_{\text{eff}}\approx2.631365
\]

代入面对面涂层公式：

\[
C
=1\ \text{pF}
+
\frac{\varepsilon_0(1.0\times10^{-4}\ \text{m}^2)}
{0.010\ \text{m}/2.631365+2.0\times10^{-4}\ \text{m}/3.5}
\approx1.229535\ \text{pF}
\]

这里已经把 \(1\ \text{cm}^2\) 换成 \(1.0\times10^{-4}\ \text{m}^2\)，把 10 mm 和 0.2 mm 分别换成 0.010 m 和 \(2.0\times10^{-4}\) m，才能与 \(\varepsilon_0\) 的 F/m 单位一致。

因此，与本结构纯油 1.201005 pF 相比，5% 油连续乳状液增加约 28.530 fF。反向计算时：

1. 把模型生成的 \(C=1.229535\) pF 当作示例读数；
2. 扣除 \(C_p=1\) pF，并用本节几何反演式得到 \(\varepsilon_{\text{eff}}\approx2.63137\)；
3. 代入 Maxwell-Garnett 反算式，得到 \(\phi\approx5.000\%\ \text{vol}\)。

注意，4.2 节表格中的“25%/50%/75% 窗口面积为水”描述的是**清晰界面的面积占比**，不是乳状液含水率；即使数字同为 5%，两种工况的电容公式和结果也不同。

面对面几何反演还可能进入数学上所说的“病态”区，也就是对小误差异常敏感。令 \(C_m=C-C_p\)，当 \(C_m\) 很小或：

\[
\frac{\varepsilon_0A}{C_m}
\approx
\frac{t_1}{\varepsilon_{c1}}
+
\frac{t_2}{\varepsilon_{c2}}
\]

时，反演分母接近零，\(C_p\)、面积、间距或涂层的微小误差都会被放大。此时必须报“几何反演不稳定”，不能继续输出含水率。

清晰界面应走 4.3 节的面积模型；沿电场宏观分层应走 4.4 节的串联模型，二者都不应进入乳状液混合公式。

### 4.6 方案 B 的标定、误差和优缺点

**界面标定**

1. 固定两板间距、平行度、重叠面积、线缆和温度；
2. 分别记录上、下窗口的全油 \(C_o\) 和全水 \(C_w\)；
3. 以已知高度让界面逐步穿过两个窗口；
4. 分别拟合每个窗口的底部高度、有效高度和非线性修正；
5. 做上升/下降循环，评估挂壁、气泡和滞回；
6. 用未参与拟合的高度验证。

**几何与含水率标定**

1. 用卡具或量具记录真实重叠面积 \(A\)、液体净间隙 \(d\)、两侧涂层厚度 \(t_1,t_2\) 和平行度；
2. 在空气、已知介电常数液体或标准电容条件下估计 \(C_p+C_{\text{edge}}\)，不能把未知固定项全部交给混合模型吸收；
3. 分别取得全油、全水和多组已知含水率乳状液，样品必须有独立参考值；
4. 覆盖温度、油品、盐度、乳化方式和相态，清晰分层、油连续、水连续分别标记；
5. 先验证几何反演得到的 \(\varepsilon_{\text{eff}}\)，再验证 \(\varepsilon_{\text{eff}}\rightarrow\phi\)，不要只看最终百分数拟合得好不好；
6. 留出独立验证集，并把量程、模型残差和漏电判废条件写入输出规则。

**几何误差传播**

令：

\[
D_e=\frac{d}{\varepsilon_r}+\frac{t}{\varepsilon_c},
\qquad
C_{\text{main}}=\frac{\varepsilon_0A}{D_e}
\]

小误差的一阶关系为：

\[
\frac{\delta C_{\text{main}}}{C_{\text{main}}}
\approx
\frac{\delta A}{A}
-
\frac{\delta D_e}{D_e}
\]

\[
\delta D_e
\approx
\frac{\delta d}{\varepsilon_r}
-
\frac{d\,\delta\varepsilon_r}{\varepsilon_r^2}
+
\frac{\delta t}{\varepsilon_c}
-
\frac{t\,\delta\varepsilon_c}{\varepsilon_c^2}
\]

沿用 4.2 节案例，若 \(d=10\) mm 的装配误差为 0.1 mm，且只看间距这一项：

- 油状态的有效板间电容约变化 0.987%，折算总电容约 0.00198 pF；
- 水状态的有效板间电容约变化 0.692%，但因有效电容更大，折算总电容约 0.0330 pF。

这说明“相对误差不大”不等于绝对 pF 误差可以忽略，尤其在高介电水端。

**主要误差**

- 板间距、平行度、重叠面积和装配偏移；
- 两板间积存气泡、油膜、蜡和沉积物；
- 阻焊/绝缘层厚度不均、吸水或针孔；
- 板边缘场使理想面积模型出现圆滑过渡；
- 面积过大或间距过小导致静态电容超出测量/补偿范围；
- 导电盐水形成 EXC-CIN 漏电通路。

**优点**

- 主电场和采样体积直观；
- 两块极片和两组 CIN/EXC 的关系自然；
- 界面面积模型、间距试验和几何量级较容易解释。

**缺点**

- 机械间距和平行度直接影响读数；
- 两块板、支架和绝缘结构更复杂；
- 板间隙可能积液、挂蜡或困住气泡；
- 高介电水和较大面积可能带来量程风险。

**方案 B 的完整处理链**

```text
同一通道的 CIN/EXC 分别到两块相对极片
  → 读取两个窗口的原始电容、量程、漏电和噪声
  → 清晰水平界面：面积并联公式 + 双窗口状态机
  → 沿板间距宏观分层：厚度串联公式
  → 均匀乳状液：扣 Cp/边缘项 → 几何反演 εeff → 相态模型反演 φ
  → 检查板距、平行度、CAPDAC、反演分母、温度和相态
  → 输出连续高度、区间、含水率，或明确的无效状态
```

### 4.7 方案 B 应呈现的判型特征

1. 逐针通断证明：每块板在 UP、DOWN 各只有一个主要信号网；
2. 证明两块板分别承担 CIN 和 EXC；
3. 单块板测得的主要是小寄生，两板组合后互电容明显增大；
4. 用绝缘垫片设置多组已知间距 \(d\)。固定介质、面积和涂层时，应优先检查：

   \[
   \frac{1}{C-C_p}
   =
   \frac{d}{\varepsilon_0\varepsilon_rA}
   +
   \frac{t}{\varepsilon_0\varepsilon_cA}
   \]

   即 \(1/(C-C_p)\) 对 \(d\) 是否近似线性。只有涂层电气厚度相对 \(d\) 可忽略时，才可简化为 \(C-C_p\propto1/d\)；
5. 比较“只润湿单板表面”和“填充两板间隙”，若后者响应显著更强，更支持方案 B。

快速判别表：

| 动作 | 期望读数 | 支持方案 B 的证据 |
| --- | --- | --- |
| 只保留极片 A，极片 B 断开 | 主要只剩小寄生 | 单块板不是完整主电容 |
| A、B 两板主动面相对接入 | 互电容明显出现 | 主回路跨越两块板 |
| 在板间放入不同厚度绝缘垫片 | \(1/(C-C_p)\) 对 \(d\) 近似线性 | 主场受板间距控制 |
| 只在单板外侧贴水膜 | 变化小于填满板间液体 | 主敏感体积在两板之间 |
| 上窗口局部填水、下窗口保持油 | 主要改变通道 1 | 上、下跨板窗口分组成立 |

这些试验必须使用同一线缆、同一 CAPDAC 设置和稳定温度，并先取得开路、短路和已知标准电容基线。若单块板已经有与双板相近的强响应，或间距规律不成立，就不能继续把实物当作理想平行板。

## 6. 两种方案共用的含水率反演：混合模型、漏电与产品边界

### 6.1 先确认各方案已经得到可信的 εeff

- **方案 A：**实测 C → 共面感应板的多介质 `C↔εeff` 实物标定或经验证的电场模型 → εeff。
- **方案 B：**实测 C → 扣除 `Cp`/边缘项并计入绝缘层 → 由已确认的面积、板距反演 εeff；几何不可靠时同样改用实物标定。

方案 A、B 的 `C→εeff` 具体算法已分别在 3.5、4.5 节给出；本章系统说明两种结构共用的 `εeff→含水率` 步骤。前两章为跑通数值案例已提前调用本章的油连续模型，但模型选择、公式边界和产品判据以本章为准。只有传感区被相对均匀乳状液完全填充时，才能使用后面的混合模型；清晰界面和宏观分层必须回到各自方案的界面或层厚公式。

#### 乳状液混合模型只用于相对均匀乳状液

以下公式中的：

- \(\varepsilon_o\)：油相介电常数；
- \(\varepsilon_w\)：水相介电常数；
- \(\varepsilon_e\)：传感器反演的有效介电常数；
- \(\phi\)：水体积分数。

#### 线性体积模型

\[
\varepsilon_e=(1-\phi)\varepsilon_o+\phi\varepsilon_w
\]

\[
\phi=\frac{\varepsilon_e-\varepsilon_o}{\varepsilon_w-\varepsilon_o}
\]

它简单，但相当于假设电场和相态排列很特殊，常会严重高估油连续微小水滴的影响。

#### 对数模型

\[
\ln\varepsilon_e=(1-\phi)\ln\varepsilon_o+\phi\ln\varepsilon_w
\]

\[
\phi=\frac{\ln\varepsilon_e-\ln\varepsilon_o}
{\ln\varepsilon_w-\ln\varepsilon_o}
\]

#### Maxwell-Garnett 油连续模型

适用于油为连续相、水以近似孤立小液滴分散：

\[
\varepsilon_e=
\varepsilon_o
\frac{\varepsilon_w+2\varepsilon_o+2\phi(\varepsilon_w-\varepsilon_o)}
{\varepsilon_w+2\varepsilon_o-\phi(\varepsilon_w-\varepsilon_o)}
\]

反演：

\[
r=\frac{\varepsilon_e}{\varepsilon_o}
\]

\[
\phi=
\frac{(\varepsilon_w+2\varepsilon_o)(r-1)}
{(\varepsilon_w-\varepsilon_o)(r+2)}
\]

#### 对称 Bruggeman 模型

这个模型对油、水两相采用对称处理，不先指定哪一相一定是连续“背景”。它可用来比较相态不明确或接近转变区时的模型差异，但仍只是混合假设，不能替代连续相判断和实物标定。

\[
\phi\frac{\varepsilon_w-\varepsilon_e}{\varepsilon_w+2\varepsilon_e}
+
(1-\phi)\frac{\varepsilon_o-\varepsilon_e}{\varepsilon_o+2\varepsilon_e}
=0
\]

固定 \(\varepsilon_e\) 后可直接反演：

\[
\alpha_w=\frac{\varepsilon_w-\varepsilon_e}{\varepsilon_w+2\varepsilon_e},
\qquad
\alpha_o=\frac{\varepsilon_o-\varepsilon_e}{\varepsilon_o+2\varepsilon_e}
\]

\[
\phi=-\frac{\alpha_o}{\alpha_w-\alpha_o}
\]

#### 专利 US9116105B2 使用的油连续 Bruggeman 型关系

\[
\varepsilon_e=\frac{\varepsilon_o}{(1-\phi)^3}
\]

\[
\phi=1-\left(\frac{\varepsilon_o}{\varepsilon_e}\right)^{1/3}
\]

该式只在油为连续相、\(\varepsilon_o>0\)、\(\varepsilon_e>0\) 且 \(0\le\phi<1\) 的前提下使用；相反转、水连续、强导电或明显分层时必须停用。这不是上面的对称 Bruggeman 方程，不能混为同一个公式。

### 6.2 5% 水的模型差异案例

取：

\[
\varepsilon_o=2.3,\qquad \varepsilon_w=78,\qquad \phi=5\%
\]

Maxwell-Garnett 预测：

\[
\varepsilon_e\approx2.631365
\]

再假设某个传感器在局部范围的标定关系为：

\[
C=1.0+0.05\varepsilon_e\quad\text{pF}
\]

则：

- 纯油：1.115000 pF；
- 5% 水：1.131568 pF；
- 模型预测变化：16.568 fF。

简单线性介电模型会预测约 189.250 fF，约为 Maxwell-Garnett 结果的 11.4 倍。说明“同样 5% 水”，只因微观排列假设不同，预测信号就可能相差一个数量级。

### 6.3 体积含水率与质量含水率不能混用

\[
w=
\frac{\phi\rho_w}
{\phi\rho_w+(1-\phi)\rho_o}
\]

\[
\phi=
\frac{w/\rho_w}
{w/\rho_w+(1-w)/\rho_o}
\]

- \(\phi\)：水体积分数；
- \(w\)：水质量分数；
- \(\rho_w,\rho_o\)：测量温度下的水、油密度。

介电混合模型通常首先给出体积分数。化验报告若给质量百分数，必须按密度换算，不能把两个“百分数”直接比较。

### 6.4 产品实现优先使用带温度项的实物标定

\[
\hat{\phi}
=a_0+a_1x+a_2x^2+a_T(T-T_0)+a_{xT}x(T-T_0)
\]

\(x\) 可以是由多介质标定得到的 \(\varepsilon_{\text{eff}}\)，也可以是经过底数、漂移和通道一致性修正后的特征量。系数必须由独立参考含水率样品拟合，并用未参与拟合的油品、温度和含盐水样验证。

### 6.5 漏电等效量可能比模型预测的含水变化还大

取：

\[
f_{\text{EXC}}=32\ \text{kHz}
\]

若 EXC-CIN 之间并联漏电为 100 MΩ：

\[
C_{\text{leak}}
\approx\frac{1}{4\times100\ \text{M}\Omega\times32\ \text{kHz}}
=78.125\ \text{fF}
\]

它约为上面“5% 水模型预测变化 16.568 fF”的 4.7 倍。若把这个附加量错误地全当成介电变化，示例模型可能把实际为 5% 的样品反演成约 23.5%。

即使漏电提高到 1 GΩ：

\[
C_{\text{leak}}\approx7.8125\ \text{fF}
\]

仍与微量水信号处于同一数量级。

### 6.6 产品算法必须先判工况

建议算法按以下顺序工作：

1. 检查原始电容、超量程、跳变、噪声和通道一致性；
2. 检查是否可能存在导电短路、涂层破损或严重挂壁；
3. 判断当前是清晰分层、油连续乳状液，还是疑似水连续相；
4. 清晰分层走界面模型；
5. 油连续均匀乳状液才走 \(\varepsilon_{\text{eff}}\rightarrow\phi\) 混合模型；
6. 水连续或强导电状态只报告状态/故障，不能继续输出看似精确的低频电容含水率。

## 7. 怎样把模型变成可用仪表：实物复核、标定与验证

### 7.1 先记录实际落线，不预设 A 或 B

先把两块实物极片按机械位置临时记为 A、B，再逐根记录：

| 测量板功能网络 | 实际到达的极片 | 实际本地端子 | 最终到达的铜区/GND/Guard |
| --- | --- | --- | --- |
| `J1 / CIN1 / UP` | A 或 B，现场填写 | `J1/UP` 或 `J2/DOWN` | 现场填写 |
| `J2 / EXC1 / UP` | A 或 B，现场填写 | `J1/UP` 或 `J2/DOWN` | 现场填写 |
| `J3 / CIN2 / DN` | A 或 B，现场填写 | `J1/UP` 或 `J2/DOWN` | 现场填写 |
| `J4 / EXC2 / DN` | A 或 B，现场填写 | `J1/UP` 或 `J2/DOWN` | 现场填写 |

完成后按结果判定：

- **支持方案 A：**`J1+J2` 到同一块极片，`J3+J4` 到另一块极片，而且每块板单独已经形成稳定主电容；
- **支持方案 B：**`J1+J3` 到同一块 CIN 极片，`J2+J4` 到另一块 EXC 极片，而且单板只有小寄生、两板组合后主互电容才出现；
- 若两种矩阵都不满足，应优先检查线束版本、端子错标、GND/Guard 误接或图纸漏画，不能强行选择最近的一种公式。

### 7.2 LCR 表与 CDC 的中性复核顺序

LCR 表是测量电感、电容、电阻和损耗的仪器；CDC 是 AD7150 这类“电容转数字”芯片。建议顺序为：

1. 设备断电，逐针量出 J1～J4 到两块极片、本地端子、正面铜区和背面大铜的真实网络；
2. 记录开路、短路和已知标准电容基线，确认量具、线缆和夹具本身的底数；
3. 只接极片 A，记录两个通道的空气基线、单板局部润湿响应、噪声和漏电；再只接极片 B 重复；
4. 若每块板单独已形成主电容并满足 A 的矩阵，进入方案 A 的共面标定；
5. 若单板主要只有小寄生且满足 B 的矩阵，把主动面相对接入，使用多组已知板距和相同介质复核 \(1/(C-C_p)\) 对 \(d\) 的关系；
6. 只有板间填液响应占主导、板距规律与三维场/实测一致时，才锁定方案 B；
7. 模型锁定后，用油、水完全覆盖有效敏感区，取得各通道端点和动态跨度，检查 AD7150/CAPDAC 余量；
8. 以已知高度让界面上升、下降，拟合两条 \(C_i(h)\) 曲线并记录滞回；
9. 在条件允许时同时观察电容、损耗角（耗散成分相对储能成分的指标）或并联电阻，而不是只记一个 C 值；AD7150 不能单独给出后两项，需由 LCR 表、绝缘测试或额外观测取得。

### 7.3 标定和验证不能用同一批数据

- 使用实际机械结构、涂层、线缆和温度范围；
- 测上升、下降两条曲线；
- 设置稳定时间，避免气泡和挂壁未稳定；
- 标定样本和验证样本分开；
- 报告重复性、迟滞、温漂和窗口外状态，不只报告拟合残差。

#### 含水率标定和验证

- 明确含水率是体积分数还是质量分数；
- 样品必须有独立参考方法；
- 覆盖实际油品、温度、盐度和乳化方式；
- 记录油连续、相反转和水连续状态；
- 低含水区单独评估 fF 级漂移和漏电；
- 不把单一油品、单一温度的标定曲线直接推广到全部原油。

### 7.4 仍需实物确认的关键问题

1. 两块极片本地 J1/UP、J2/DOWN 到正面工作铜区的逐针通断，以及是否存在端子错标；
2. 正面分段铜区的真实网络分组；
3. 背面大铜是 GND、Guard、信号电极还是悬空；
4. 两块极片的主动面朝向、安装高度、间距、重叠面积和固定方式；
5. 当前油、水端点电容、`C(h)`、温漂、噪声、损耗、漏电和迟滞；
6. AD7150 配置、CAPDAC、输出码换算和异常状态处理；
7. 真实油品、地层水盐度、涂层材料和工作温度；
8. 独立参考含水率和界面高度标定数据。

在这些问题完成前，本文能给出的是**两套候选模型、图纸倾向、数量级筛选和判别方法**，不能替代现场通断、台架验证、计量标定或产品精度认证。
