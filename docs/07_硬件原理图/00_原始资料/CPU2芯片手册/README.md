# CPU2 芯片手册

更新日期：2026-06-27

本目录保存 CPU2 侧使用的芯片、模块和第三方硬件资料。资料名优先保留供应商型号或原始文件名，便于和数据手册、采购资料、硬件评审记录对应。

## 文件说明

| 路径 | 用途 |
| --- | --- |
| `TMC5130A_datasheet_rev1.21.pdf` | TMC5130A 电机驱动器数据手册 |
| `CH9141K/` | CH9141K 无线收发芯片规格书和模块说明 |

## 阅读建议

- 排查电机控制、位置模型或驱动器寄存器问题时，先看 `docs/03_问题分析与整改/` 的项目整理文档，再回到 TMC5130A 手册查原始寄存器定义。
- 排查蓝牙、无线滑环或串口通信链路时，先看 `docs/01_协议与寄存器/CPU2通信与解耦/` 的项目整理文档，再回到 CH9141K 原始资料核对模块能力。

## 维护规则

- 第三方资料保留原始文件名；如文件名无法表达用途，可在 README 中补充说明，不直接改动原始资料。
- CPU2 自有分析、适配方案和调试结论不要写进芯片手册目录，优先放到对应业务目录。
- 新增芯片资料时，同步更新本 README 和 `docs/00_构建与版本/CPU2文档索引.md`。
