# 硬件原理图原始资料

本目录保存硬件原理图和供应商资料的原始文件。这里的文件用于追溯来源，不直接作为可持续维护的说明文档；需要解释固件关联、接口含义或问题结论时，应在上一级目录编写 Markdown 整理文档。

## 维护规则

- 原始图纸保留原文件名，避免和硬件版本、供应商资料脱节。
- 不直接修改原始 PDF；需要说明时新增或更新上一级 Markdown 整理文档。
- 新增图纸时在本 README 记录来源、版本和适用范围，并在 `docs/07_硬件原理图/README.md` 增加入口。
- 固件开发结论以原理图、BOM、PCB 文件和硬件评审结论共同确认，本目录只提供原始资料追溯。
