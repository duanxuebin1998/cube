## 转换范围与说明

- 两个 DDB 的当前 `Documents` 目录均只有 `A0000-A0.prj`、`A0000-A0.SO1`、`A0000-A0.SO2` 三个有效文档，因此每份 PDF 只归档这 3 页。
- 项目总览仍保留 `A0000-A0.SO3` 至 `A0000-A0.SO6` 和旧的 5 页编号，但这些文档当前并不存在；转换时没有虚构或补建缺失页面。
- DDB 回收站和历史记录中的旧页面不属于当前有效设计，未纳入 PDF。
- 原始 Protel 缓存中有多个不同器件共用 `Component_1` 名称；转换时依据器件型号、封装和兼容引脚定义消歧，避免 CH9141K、AP3015、SCT2230、XKT001、天线、晶振和二极管符号互相覆盖。
- PDF 未叠加 KiCad 图框，以避免新增图框遮挡原图标题和页码；原图中的标题、网络名、器件参数和设计备注均保留。
- 真实接线、器件选型和硬件版本仍应结合原始 DDB、BOM、PCB 文件及硬件评审结论确认。
