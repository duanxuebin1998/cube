## 2. 总体数据流

当前编码器链路不依赖主循环轮询，数据流如下：

~~~mermaid
flowchart LR
    A["TIM1 每 10 ms 触发"] --> B["SPI5 DMA 读取 4 字节"]
    B --> C["ISR 只投递原始事件"]
    C --> D["8 项环形队列"]
    D --> E["PendSV 每次最多处理 4 项"]
    E --> F["SSI 帧解析与状态校验"]
    F -->|有效| G["启动同步或运行增量检查"]
    G --> H["累计 g_encoder_count"]
    H --> I["尺带长度与传感器位置"]
    H --> J["FRAM A/B 持久化"]
    F -->|异常| K["连续确认与位置可信度判断"]
    K --> L["发布错误快照并关闭电机 ENN"]
~~~

关键设计原则：

- 硬件中断只采集和投递，不解析业务字段、不打印、不访问 FRAM；
- PendSV 承担有界解析、连续异常确认、RAM 位置累计和持久化调度；
- 位置是否可用由“角度已同步、累计位置可信、无锁存故障”共同决定；
- 编码轮模式下编码器故障参与业务停机，电机模式下编码器只作为后台诊断源；
- 任何无法补回的未知位移都不能由后续单圈角度推算补偿。

## 3. 采样调度与中断边界

### 3.1 采样周期

TIM1 当前参数为：

| 项目 | 当前值 |
| --- | ---: |
| Prescaler | 7499 |
| Period | 99 |
| APB2 定时器时钟 | 75 MHz |
| 触发周期 | 约 10 ms |
| 采样频率 | 约 100 Hz |

启动定时器成功后会立即主动触发第一帧读取，不需要等待第一个 10 ms 周期。

### 3.2 SPI5 DMA

AS5145 通过 SPI5 只读采集，每次固定接收 4 字节。4 字节中包含 18 位有效 SSI 载荷和尾部无效位。

TIM1、SPI DMA 完成和 SPI 错误回调只执行：

- 拉高或拉低必要片选；
- 保存 4 字节原始帧；
- 保存 HAL 状态、SPI 错误码、采样时刻和事件序号；
- 投递固定长度事件；
- 挂起 PendSV。

这些中断路径不执行：

- printf 或 ErrorLog；
- SSI 业务解析；
- 编码器累计值换算；
- FRAM 读写；
- 阻塞等待和业务慢停。

### 3.3 ISR 到 PendSV 事件队列

当前使用 8 项环形事件队列，事件类型包括：

- 完整 SSI 帧；
- SPI 错误；
- 定时触发时无法启动 SPI/DMA。

队列满时不覆盖尚未处理的数据，而是增加 queue_overrun_count，并把本次溢出转换为编码器超时证据。

PendSV 优先级为 15，每次最多处理 4 项编码器事件。处理不完时重新挂起 PendSV，从而避免一次异常处理无限占用延后服务。

因为 PendSV 可以抢占线程态业务，所以即使主循环停留在长时间测量、运动、等待或通信函数中，编码器采集、异常确认和硬停仍然能够执行。

## 4. SSI 帧格式与有效性判断

### 4.1 解析字段

18 位 SSI 有效载荷解析为：

| 字段 | 位宽 | 当前用途 |
| --- | ---: | --- |
| angle | 12 bit | 单圈绝对角度，范围 0～4095 |
| OCF | 1 bit | Offset Compensation Finished，0 表示补偿未完成 |
| COF | 1 bit | CORDIC Overflow，1 表示运算或磁场范围异常 |
| LIN | 1 bit | Linearity Alarm，1 表示线性度告警证据 |
| MagINCn | 1 bit | 磁场增强状态，低有效，仅诊断 |
| MagDECn | 1 bit | 磁场减弱状态，低有效，仅诊断 |
| parity | 1 bit | 帧携带的偶校验位 |

### 4.2 阻止位置累计的帧

以下帧不会进入角度累计：

- 4 字节全 0x00；
- 4 字节全 0xFF；
- 偶校验失败；
- OCF 等于 0；
- COF 等于 1；
- SPI/DMA 启动或接收失败；
- PendSV 事件队列溢出。

全 0 和全 0xFF 优先按断线或总线异常映射为 ENCODER_TIMEOUT，不继续把它们解析为正常角度。

### 4.3 LIN 当前策略

当前 SSI_LINEARITY_FAULT_ENABLED 等于 0，因此：

- LIN 等于 1 时仍累计 lin_count；
- 原始 LIN 状态继续出现在 ENC?；
- LIN 当前不拒绝位置；
- LIN 当前不形成 12-13 锁存停机。

MagINCn 和 MagDECn 同样只保留原始状态，不参与当前故障判定。

因此，ENC? 中出现大量 LIN 计数而通信质量仍为 100%，符合当前实现口径。通信质量代表链路、校验和处理情况，不代表磁场和线性状态全部正常。

## 5. 持久化记录与上电恢复

### 5.1 V2 A/B 记录

当前编码器持久化记录包含：

| 字段 | 作用 |
| --- | --- |
| magic | 识别编码器记录 |
| version | 当前写入 V2 |
| struct_size | 防止结构长度不匹配 |
| generation | A/B 记录选新 |
| persist_reason | 区分普通保存和紧急保存 |
| encoder_count | 软件累计多圈计数 |
| prev_angle | 同一快照时刻的单圈角度 |
| sample_sequence | 对应的样本序号 |
| crc | 保护主体字段 |
| commit_marker | 最后单独提交，排除半写记录 |

FRAM 布局：

| 区域 | 地址 |
| --- | ---: |
| 编码器 A 槽 | 历史 FRAM_ANGLE_ADDRESS，通常为 0x1000 |
| 编码器 B 槽 | A 槽加 0x40，通常为 0x1040 |
| 独立掉电回执 | 0x1180 |

### 5.2 上电选择规则

上电时按以下顺序恢复：

1. A/B 两个 V2 槽都有效时，选择 generation 较新的记录；
2. 只有一个 V2 槽有效时，允许继续运行并安排冗余修复；
3. V2 都无效但存在有效 V1 记录时，恢复 V1 并迁移到 V2；
4. 所有格式都无效时，RAM 置零仅用于确定性初始化，position_valid 保持 0；
5. 所有记录无效时返回 ENCODER_POWERON_FAIL，即 12-5，普通测量不能把 0 当成可信位置。

只有明确回零、零点标定或人工位置修正，才能重新建立可信累计位置。

## 6. 启动首次角度同步

启动采集后最长等待 1500 ms。同步过程如下：

1. 第一帧有效角度建立候选角度；
2. 下一帧与候选角度的最短路径差不能超过 16 counts；
3. 超过 16 counts 时丢弃前一组稳定证据，以当前角重新开始；
4. 连续 3 帧稳定后完成角度同步；
5. 冷启动同步完成时，将当前角与 FRAM 保存角比较；
6. 差值不超过 320 counts 时，把这段差值补入 g_encoder_count；
7. 差值超过 320 counts 时撤销 position_valid，锁存 ENCODER_POWERON_CHANGE，即 12-6。

16 counts 用于确认上电静止状态下的角度稳定，不是运行速度上限。320 counts 用于覆盖普通未保存差值及适当余量，不表示允许设备在断电期间发生任意移动。

12-6 发生后，普通新命令不能重新建立累计位置。只有正式回零或零点标定命令可以解除上电跳变禁用，并在 set_encoder_zero 成功后重新保存可信零点。

## 7. 运行角度展开与动态物理上限

### 7.1 单圈最短路径展开

当前角与上一可信角的差值按照单圈最短路径展开：

    delta = current_angle - prev_angle
    delta >  2048 时，delta -= 4096
    delta < -2048 时，delta += 4096

正常样本执行：

    g_encoder_count += delta

随后更新 prev_angle、可信样本时刻、样本序号、业务位置和持久化请求。

### 7.2 动态候选增量上限

运行物理上限按 20 m/min、实际采样间隔和编码轮周长动态计算：

    limit =
        ceil(20000 × 4096 × dt_ms × 1.25
             ÷ (60000 × 编码轮周长 mm))
        + 8 counts

最终上限不超过 2048 counts。

其中：

- 20000 mm/min：产品极限最大速度；
- 1.25：25% 动态余量；
- 8 counts：机械抖动、量化和采样偏差余量；
- dt_ms：当前候选帧与上一可信帧的真实间隔。

典型值：

| 编码轮周长 | 采样间隔 | 候选增量上限 |
| --- | ---: | ---: |
| 95.0 mm | 10 ms | 约 188 counts |
| 107.9 mm | 10 ms | 约 167 counts |

### 7.3 运行候选处理

| 条件 | 处理 | 位置可信度 |
| --- | --- | --- |
| dt 等于 0 | 拒绝，返回 12-1 | 不主动推进基准 |
| dt 大于 50 ms | 拒绝，不补算断档位移；推进角度和时间基准 | 置为不可信 |
| limit 等于 0 | 拒绝，返回 12-17 | 按位置源策略处理 |
| 绝对增量大于 limit | 拒绝，不更新累计值和可信角 | 电机模式下置为不可信 |
| 方向与电机状态不一致 | 只增加统计 | 保持当前状态 |
| 候选正常 | 累计 delta 并刷新位置 | 保持可信 |

超过 50 ms 的断档会推进 prev_angle 和采样时间基准，因此同一次断档不会继续沿用旧时间基准并派生连续 3 次超时。断档期间的真实位移不补算，因为 AS5145 只提供单圈角度，无法证明断档期间跨过了多少圈。

## 8. 业务位置换算

编码器累计值与业务位置的关系为：

    显示编码值 = -g_encoder_count
    圈数 = 显示编码值 / 4096
    尺带长度 = 编码轮周长 × 圈数
    传感器位置 = 罐高 - 尺带长度

业务尺带长度和传感器位置使用 0.1 mm 单位；编码轮周长参数原始单位为 0.001 mm。

位置换算函数本身不对负值或罐高上限钳位。因此一旦上游累计位置错误，传感器位置可能真实显示为超过罐高。当前设计选择在采样连续性和业务结果检查处暴露并阻断异常，而不是在换算末端静默截断。

## 9. 两种位置源

### 9.1 编码轮记步

编码轮模式下：

- g_encoder_count 直接更新 cable_length 和 sensor_position；
- 已确认的编码器故障参与业务停机；
- 运动前必须满足累计位置可信、角度已同步且无故障锁存。

### 9.2 电机记步

电机模式下：

- 业务位置由 TMC5130 XACTUAL、切换基准和卷筒模型计算；
- 编码器仍以约 100 Hz 持续后台采集；
- SSI 异常继续进入 ENC? 统计；
- 编码器异常不让当前电机位置控制停机；
- 断档或物理不可能增量仍可撤销编码器位置可信度；
- 编码器不可信时禁止直接切回编码轮。

### 9.3 切换到电机位置源

切换到电机位置源不是单纯修改参数。当前流程会：

1. 读取可信 XACTUAL；
2. 记录当前编码轮尺带长度和电机步数基准；
3. 临时切到电机位置源；
4. 实际下行一圈；
5. 根据编码轮长度变化测量当前位置局部周长；
6. 反向运动一圈返回切换位置；
7. 校验周长范围和返回位置；
8. 成功后保存位置源参数和电机位置快照；
9. 任一步失败时回滚原位置源和基准。

### 9.4 切回编码轮位置源

必须同时满足：

- AS5145_GetLastError 返回 NO_ERROR；
- Encoder_HasTrustedPosition 为真；
- Encoder_IsReady 为真；
- 不存在 AS5145 锁存故障。

其中 Encoder_IsReady 同时要求 position_valid、angle_synchronized 和无锁存故障。

## 10. 故障确认、停机与清除

### 10.1 当前故障码

| 故障码 | 名称 | 主要来源 |
| --- | --- | --- |
| 12-1 | ENCODER_TIMEOUT | SPI/DMA、全 0/全 FF、队列溢出、采样断档 |
| 12-2 | ENCODER_PARITY_ERROR | SSI 偶校验失败 |
| 12-3 | ENCODER_LOST_STEP | 运动丢步检测或周长标定不足 |
| 12-5 | ENCODER_POWERON_FAIL | A/B 记录无效或累计位置失信 |
| 12-6 | ENCODER_POWERON_CHANGE | 上电角度变化超过 320 counts |
| 12-10 | ENCODER_DIFF_EXCESS | 周长标定值过大 |
| 12-12 | ENCODER_CORDIC_OVERFLOW | COF 等于 1 |
| 12-13 | ENCODER_LINEARITY_WARNING | LIN 等于 1，当前停机入口已屏蔽 |
| 12-14 | ENCODER_OCF_INCOMPLETE | OCF 等于 0 |
| 12-15 | ENCODER_FIRST_SAMPLE_TIMEOUT | 启动或重新同步等待超时 |
| 12-16 | ENCODER_CIRCUMFERENCE_CALIBRATION_ERROR | 电机位置源周长标定异常 |
| 12-17 | ENCODER_POSITION_JUMP | 运行候选增量超过动态物理上限 |

### 10.2 编码轮模式确认规则

- ENCODER_POWERON_CHANGE 或累计位置已经失信：立即锁存；
- 其它异常：同一个错误码连续 3 次才锁存；
- 错误码变化时，按新错误重新从第 1 次计数；
- 未锁存前收到正常帧，连续异常计数清零；
- 锁存后收到正常帧，只增加恢复正常帧数；
- 锁存后不自动清故障，也不把故障前后角差补入累计位置。

### 10.3 电机模式确认规则

电机模式下 SSI 异常：

- 更新最近错误和分类统计；
- 不累计连续坏帧；
- 不形成编码器业务停机锁存；
- 不覆盖电机位置源的业务位置。

### 10.4 故障停机顺序

锁存编码器故障时：

1. 在短临界区发布 STATE_ERROR、实际错误码和 zero_point_status；
2. 执行内存屏障；
3. 立即关闭 TMC5130 驱动 ENN；
4. 后续同步错误出口或业务检查再执行慢停和最终错误日志。

因此，主循环即使被阻塞，编码器锁存故障仍能先发布错误状态并立即切断电机驱动。

### 10.5 清错所有权

只有新的顶层正式业务命令调用 Encoder_BeginNewProcess，才允许解除普通 AS5145 锁存。以下入口不能越权清除：

- 下一帧正常编码器数据；
- fault_info_init；
- MeasureStart；
- 粗找、精找和回零内部重试；
- 普通参数初始化。

运行故障解除后，需要重新稳定同步 3 帧。重同步只建立新的单圈角和时间基准，不补故障期间位移。

12-6 另外具有上电跳变锁存，只有 CMD_BACK_ZERO 或 CMD_CALIBRATE_ZERO 能解除该位置禁用。

通用自动恢复模块明确把 12-6、12-13、12-17 和 12-16 视为不可自动重跑故障。

## 11. 普通持久化

### 11.1 请求条件

当前累计值与最近成功保存值的绝对差达到 256 counts 时提出保存请求，即约 1/16 圈。

停止、回零和人工位置修正等线程态场景可以调用同步保存接口，单次最多尝试 3 次。

### 11.2 A/B 提交步骤

每次保存写入非活动槽：

1. 生成新 generation；
2. 写入 commit_marker 等于 0 的完整记录；
3. 完整读回记录；
4. 比较全部未提交内容；
5. 单独写入 commit marker；
6. 再次完整读取；
7. 校验 magic、版本、结构长度、原因、角度范围、CRC 和 marker；
8. 只有全部成功后才切换活动槽，并推进 g_encoder_saved。

任何失败都不会推进已保存基线。

### 11.3 延后与退避

普通保存由 PendSV 调度：

- SSI 仍有待处理事件时延后；
- 单次 PendSV 最多提交一份位置快照；
- 保存失败后退避 200 ms；
- 退避结束后提交当时最新快照，不反复保存过期位置。

## 12. 24 V 低压紧急保存

### 12.1 请求入口

只有编码器累计位置可信时才开放紧急保存布防。

ADC 模拟看门狗检测到 24 V 低压时，中断只执行：

- 锁存低压状态；
- 禁用重复看门狗中断；
- 预约 FRAM 紧急所有权；
- 投递 ENCODER_EMERGENCY_SOURCE_ADC 请求；
- 挂起 PendSV。

中断不直接访问 FRAM。

### 12.2 PendSV 提交流程

紧急保存流程为：

1. 进入 FRAM 紧急所有者；
2. 先作废旧掉电回执；
3. 提交编码器 V2 A/B 新记录；
4. 提交独立掉电回执；
5. 回执记录真实 ADC 或软件测试来源、编码器代次和累计值；
6. 退出 FRAM 紧急所有者；
7. 成功后发布一次性 RAM 结果快照；
8. 失败最多跨 3 次 PendSV 尝试。

真实 ADC 低压请求优先于 PWRTEST 软件测试请求。PWRTEST 只验证存储链，不能作为真实掉电成功证据。

### 12.3 上电回执判定

上电宣布“上次掉电保存成功”必须同时满足：

- MCU 复位原因包含 BOR 或 POR；
- 回执来源为真实 ADC 低压；
- 回执 CRC 和 commit marker 有效；
- 回执 generation 与当前选中的 A/B 记录一致；
- 回执 encoder_count 与当前活动记录一致。

真实掉电复位下，回执存在但不完整或与 A/B 不一致时升级为 23-6。软件测试回执、软件复位和非掉电复位只保留诊断，不伪造成真实掉电结果。

## 13. ENC? 诊断输出

ENC? 查询只读取一致 RAM 快照，不在查询路径访问 SPI5 或 FRAM。

### 13.1 第一行：编码器累计与连续性状态

| 字段 | 含义 |
| --- | --- |
| 当前累计 | g_encoder_count，单位 1/4096 圈 |
| 已保存 | 最近成功提交到活动 V2 槽的累计值 |
| 未保存差值 | 当前累计减已保存值，保留方向 |
| 当前单圈 | 最近可信 prev_angle |
| 已保存单圈 | 最近提交时的单圈角 |
| 单圈差值 | 当前角与已保存角的最短路径差 |
| 位置有效 | position_valid |
| 普通保存中 | 是否仍有普通或紧急快照待提交 |
| 紧急保存中 | A/B 与回执流程是否尚未完成 |
| 存储代次 | 当前活动 V2 generation |
| 活动槽 | A 或 B |
| 最近提交 | 本次上电最近一次提交结果 |
| 上次掉电保存 | 启动时固定的回执判定 |
| 故障锁存 | AS5145 是否已锁存 |
| 锁存码 | 已锁存的实际错误码 |
| 最近错误 | 未锁存时的最近瞬态错误或锁存码 |
| 同步 | 单圈角是否已同步 |
| 重同步 | 是否处于运行故障后的基准重建 |
| 启动稳定 | 当前连续稳定帧数 |
| 候选增量 | 最近一次运行或启动候选差值 |
| 上限 | 最近一次候选物理上限 |
| 间隔 | 候选与上一可信样本间隔 |
| 拒绝原因 | 最近拒绝分类 |
| 拒绝总数 | 本次上电累计拒绝样本数 |
| 方向不一致 | 编码增量方向与电机状态不一致次数 |

拒绝原因编码：

| 数值 | 含义 |
| ---: | --- |
| 0 | 未拒绝 |
| 1 | 启动候选不稳定 |
| 2 | 上电角度变化过大 |
| 3 | 采样间隔异常 |
| 4 | 超过动态物理上限 |

### 13.2 第二行：SSI 原始帧与分类统计

第二行包括：

- 最近 4 字节原始帧；
- 解析是否有效；
- angle、OCF、COF、LIN、MagINCn、MagDECn 和 parity；
- 当前连续错误码、连续次数和锁存后恢复正常数；
- 总帧数；
- 传输/队列异常证据；
- 队列溢出、超时、校验、OCF、COF、LIN、位置跳变和其它分类次数；
- 最近正常和最近异常时刻。

当前“异常证据”字段来自 transfer error 和 queue overrun 计数，不等于所有 parity、OCF、COF、LIN 和位置跳变分类次数之和。分析时应结合后面的各分类字段。

### 13.3 第三行：通信质量

当前三项质量定义为：

    链路质量 =
        (完整帧数 - 全 0/全 FF 帧数)
        ÷ (完整帧数 + SPI 启动/接收失败数)

    校验质量 =
        (完整帧数 - parity 错误帧数)
        ÷ 完整帧数

    处理质量 =
        (完整帧数 + 传输失败数 - 队列溢出数)
        ÷ (完整帧数 + 传输失败数)

统计范围为本次上电。三项质量不包含：

- OCF；
- COF；
- LIN；
- MagINCn/MagDECn；
- 方向不一致；
- 物理位置跳变；
- 累计位置是否可信。

因此“链路、校验、处理均为 100%”不能单独证明编码器整体健康。

## 14. 当前主要策略边界与风险

### 14.1 12-17 后编码轮模式的位置可信度

当前超过动态物理上限的候选样本会被拒绝。电机记步模式下会同时撤销编码器 position_valid；编码轮记步模式下当前不会在第一帧 12-17 时立即撤销 position_valid，而是按同码连续 3 次锁存。

锁存后收到新的正式命令时，当前实现可以重新同步 3 帧并建立新角度基准，但不会补故障期间位移。如果连续 12-17 来自真实机构位移而不是电气毛刺，累计位置可能继续保留偏差。

这是当前最需要明确的产品策略边界：

- 若 12-17 被定义为可恢复的角度毛刺，当前“拒绝、锁存、重新同步”策略能够保留原累计值；
- 若 12-17 被定义为累计位置连续性已经无法证明，则锁存时应撤销 position_valid，并只允许回零或人工位置修正。

本文只记录当前实现和风险，不在文档任务中修改该产品语义。

### 14.2 LIN 告警已屏蔽

LIN 当前仅统计，不停车，也不进入通信质量百分比。持续 LIN 等于 1 可能来自磁钢安装、气隙、偏心、磁场或位解析口径，需要真实编码器、示波器和机械安装检查后再决定是否重新启用 12-13。

### 14.3 单圈编码器可观测性

AS5145 只能提供单圈角度。超过 50 ms 的断档、断电期间移动或未知多圈运动不能由后续单圈角唯一重建。当前软件对运行断档撤销位置可信度，但最终能力仍依赖：

- 断电期间机构自保持；
- 24 V 提前预警时序；
- CPU2 和 FRAM 保持供电时间；
- 真实最大速度和采样周期；
- 回零能力。

### 14.4 PendSV 与 FRAM 时延

普通和紧急编码器保存当前仍在 PendSV 中执行有界 FRAM 事务。代码已经通过 SSI 积压优先、单快照预算、紧急所有者和失败退避降低风险，但仍需台架测量：

- 单次 FRAM 最坏读写和读回时间；
- 10 ms 采样下队列峰值；
- CPU2/CPU3 通信、AO、UART 与编码器同时运行时的 PendSV 等待时间；
- 低压保持窗口内三次紧急尝试是否来得及完成。

### 14.5 位置换算不钳位

传感器位置超过罐高时，位置换算层不会静默截断。这有利于暴露累计错误，但上层测量必须继续保留罐高和结果范围检查，不能把换算函数当成最终安全边界。

## 16. 验证建议

### 16.1 静态与主机验证

- 检查 ISR 调用链不存在打印、FRAM 和阻塞等待；
- 注入启动稳定帧、320 counts 上电边界和代次回绕；
- 注入 1、2、3 帧同码异常及好坏交替；
- 验证超过 50 ms 断档只产生一次旧基准超时证据；
- 验证 95.0 mm 和 107.9 mm 周长下的动态上限；
- 验证编码轮和电机模式下 position_valid 与停机策略；
- 验证 A/B 单槽、双槽、CRC、marker 和 V1 迁移；
- 验证 ENC? 百分比与分类计数定义一致。

### 16.2 目标板与台架验证

- 最大 20 m/min 双方向连续运动；
- 10 ms 采样下 SPI5 波形和角度连续性；
- 全 0、全 FF、parity、OCF、COF、SPI BUSY 和 DMA 错误注入；
- 主循环长时间阻塞时的采集、硬停和 CPU3 可见性；
- 电机模式后台编码器异常及禁止切回；
- LIN 持续置位的磁钢、气隙、偏心和解析复核；
- FRAM 各写入阶段随机断电；
- 24 V 快速切断、缓慢下降和短时跌落恢复；
- 12-17 后真实位置是否仍可信的产品策略验证。

## 17. 证据结论

从当前源码静态调用链可以确认：

- 编码器采集和故障硬停不依赖阻塞主循环；
- SSI 异常帧不会直接污染累计位置；
- 超过 50 ms 的断档不会连续沿用同一旧时间基准；
- 上电位置、运行候选和位置源切换均有明确门禁；
- A/B 记录、提交标记、CRC、掉电回执和 ENC? 诊断已经形成完整软件链。

静态源码不能证明：

- 100 Hz 采样在所有中断负载下都无丢帧；
- FRAM 紧急保存一定早于掉电失效；
- LIN 持续置位不影响测量精度；
- 12-17 后未补位移仍满足绝对位置要求；
- 当前实现已经通过真实设备、台架、现场或 SIL 验证。

在完成对应实测前，应继续把上述项目保留为开放验证项。
