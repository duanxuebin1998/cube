# CPU2 称重探底可靠判定方案

日期：2026-09-03（2026-09-07 更新触底减重量、绝对下限、释放及 SI 联动）

状态：相对减重量判定和下行绝对低重量保护随 CPU2 V1.44.0.0 / CPU3 V1.43.0.0、共享协议37提交纳入，提交哈希以 Git 记录为准。目标板制动和称重参数仍需验证。最终构建与提交范围见[本次改动与测试方案](../../00_构建与版本/版本改动与测试/2026-09-07_CPU2_V1.44.0.0_CPU3_V1.43.0.0_称重探底与下行保护_改动与测试方案.md)。

适用范围：没有陀螺仪、只能使用称重值和位置信息完成探底的传感器

## 1. 方案结论

第一版只采用四个核心动作：

```text
预计罐底附近才允许称重触发
-> 提前降到现有探底低速
-> 第一次触发后按实际刹车过行程上提
-> 第二次在相近位置触发才确认罐底
```

本方案不增加复杂滤波、分段点动、三次多数表决或陀螺仪辅助。进入检测窗口时用已有低通称重建立固定基准，达到设定减重量才产生候选；固定绝对下限500用于入口和释放校验，候选不能单独发布探底成功。

检测提前距离、离底余量、位置重复容差仍是内部定值。本次不新增参数：“探底扭力阈值”保留名称、地址和值，只改为触底减重量；绝对重量下限固定500。上一轮新增参数方案未发布，已取消。

## 2. 要解决的问题

1. 真实触底引起的称重变化可能小于正常运行波动，单次称重值不能可靠证明触底。
2. 正常下行过程中也可能越过现有称重阈值，不能在任意位置直接判定罐底。
3. 触发停止后仍有较长刹车距离，固定上提一小段可能无法真正离底。
4. 称重方案用于无陀螺仪传感器，必须独立完成判断。

本方案的基本取舍是：称重负责发现候选，位置窗口负责限制候选范围，两次触发位置的一致性负责最终确认。

## 3. 当前实现中可以直接复用的部分

本方案最初依据 `MAIN@83a3b7b2ed39` 梳理，随后完成位置窗口和释放优化。本次以 `MAIN@b2b1840bd1ce` 及已有称重暂存改动为基础，加入减重量和绝对下限；本文记录工作树实现，不代表已发布。

当前实现已经具备以下基础：

- `SearchBottom()` 已执行一次粗找和两次精找，不需要再建立一套新的大状态机。
- `bottom_weight_threshold` 改为触底减重量，候选条件为 `current_weight <= W_base - W_drop`；绝对下限固定500。
- 通用下行保护已有相对变轻阈值 `weight_lower_limit_ratio`，可以继续承担检测窗口外的异常运动保护。
- 精找阶段已有接近罐底后的低速档位，最低使用 `0.10 m/min`。
- 已有 `tankHeight + maxDownDistance` 最大下行保护、丢步检查、快停和命令切换处理。
- 已有罐底尺带位置和 `bottom_reference_valid`，可用于形成预计罐底位置。

第一版改造应复用上述能力，只调整称重触发的生效位置、触发位置记录、离底动作和两次精找结果比较。

## 4. 参数与内部定值

| 逻辑名称 | 单位 | 作用 | 第一版处理 |
| --- | --- | --- | --- |
| `L_enable` | 0.1 mm | 在预计罐底上方多远开始允许称重触发 | 内部暂定 300 mm，待台架确定 |
| `M_release` | 0.1 mm | 上提到首次触发位置后继续增加的离底余量 | 内部暂定 200 mm，待台架确定 |
| `T_repeat` | 0.1 mm | 两次精找触发位置允许的最大差值 | 内部暂定 10 mm，待台架确定 |

继续复用的现有参数：

- `WEIGHT_ABSOLUTE_MIN`：称重模块统一绝对重量下限 `W_abs`，内部固定500，不占参数槽。普通下行重量小于或等于500报碰撞；开始探底检测的当前重量须大于500。
- `bottom_weight_threshold`：触底减重量 `W_drop`，保留原名称“探底扭力阈值”、LTD/板间 `0x0216~0x0217`和旧数值，出厂值500。允许写入0..2147483647，使用时必须为正；升级不清零，现场需按新含义复核。
- `tankHeight` 和 `liquid_sensor_distance_diff`：没有可信历史罐底位置时，用于换算预计罐底位置。
- `maxDownDistance`：最大下行安全边界。
- 现有电机速度配置和精找低速档位。

运行时计算但不需要配置的量：

- `P_expected`：预计罐底尺带位置。
- `P_enable`：称重触发开始生效的位置。
- `P1`、`P2`：两次精找的触发位置。
- `P_stop`：触发快停后的实际停止位置。
- `P_release`：离底上提目标位置。
- `W_base`：进入检测窗口时已有 `stable_weight` 的快照，只在RAM保存，本轮粗找及两次精找不变。
- `W_candidate = W_base - W_drop`：必须大于 `W_abs`；否则参数与基准组合无效，不开始减重判定。

## 5. 从什么时候开始检测

### 5.1 预计罐底位置

`P_expected` 按以下顺序选择：

1. 运行时有效标志置位且尺带值为正的最近罐底参考。
2. 否则根据配置罐高换算；本次未新增罐底参考持久化机制：

   ```text
   P_expected = tankHeight - liquid_sensor_distance_diff
   ```

如果这些来源都无效，普通自动模式返回探底失败。首次安装需先核对罐高及探头距差，本次未新增专门的全程低速标定流程。

### 5.2 检测使能位置

本文约定尺带长度下行时增大：

```text
P_enable = P_expected - L_enable
```

- `当前位置 < P_enable`：不能产生罐底候选；通用相对碰撞和绝对低重量保护仍然有效，窗口外NORMAL不代表实际称重已恢复。
- `当前位置 >= P_enable`：尚无基准时要求当前称重大于 `W_abs`、`W_base-W_drop` 大于 `W_abs`、当前称重大于候选下限。满足后锁定基准，这一拍不产生候选；不满足立即停止，不把入口位置当罐底。
- 最大下行位置仍由现有 `tankHeight + maxDownDistance` 限制。

当前 `CheckWeightCollision()` 不使用原探底扭力阈值判罐底；下行时，当前重量小于或等于固定500，或相对变轻超限，任一成立均返回 `WEIGHT_COLLISION_DETECTED`，由现有调用链停机。称重粗找和精找先判断候选，候选成立时快停，不再进入普通碰撞分支；候选未成立时执行通用保护。原零点忽略区和运动方向条件保留；上行离底不增加低重量限制。丢步和最大下行保护继续保留，陀螺仪探底流程不新增通用称重门禁。使用NoDetect接口的退让运动仍不进行称重碰撞检测。

`L_enable` 必须覆盖罐高配置误差、安装偏差、尺带位置误差和罐底不平带来的提前量。它不能凭经验直接写死，需要通过现场数据取最大观测偏差并增加余量。

### 5.3 提前降速

候选检测窗口和速度分级使用独立内部定值。粗找按预计罐底、精找按上一次触发位置作为 `P_reference`，共同使用以下速度上限；若用户速度更低，保持用户低速。原有传感器位置低于 1 m 时不超过 `0.50 m/min` 的限制仍保留。

开始降速的位置按下式确定：

```text
P_slow = P_reference - 300 mm：限制到 0.50 m/min
P_probe = P_reference - 30 mm：限制到 0.10 m/min
```

300/30 mm 是试验定值，尚非实测制动距离，代码也没有新增制动模型。该调整把粗找最后 300 mm 的理想匀速耗时从约 180 s 降为 50.4 s；不包含加减速、通信和停机时间。必须实测不同速度、卷径和负载下的减速距离，尤其核查真实罐底早于预计位置的情形；不满足余量要求时应扩大对应减速距离。

## 6. 详细执行过程

### 6.1 进入探底

1. 确认当前使用称重探底模式，不读取或依赖陀螺仪。
2. 检查预计罐底位置、称重通信、位置源和最大下行边界是否有效。
3. 任一必要条件无效时停止探底并返回实际错误，不使用旧值伪装成功。

### 6.2 粗找阶段

1. 保留现有 `SearchBottomRough()`，用于快速接近预计罐底。
2. 到达 `P_slow` 后先限制到 `0.50 m/min`，到达 `P_probe` 后再限制到 `0.10 m/min`。
3. 在 `P_enable` 之前，即使 `current_weight` 越过触底阈值，也不得形成罐底候选；通用相对变轻及绝对低重量保护继续执行。
4. 进入 `P_enable` 后先校验入口并锁定基准；后续相对减重量达到设定值时停止粗找。滤波值后续变化不修改本轮基准。
5. 粗找位置只用于进入精找流程，不作为最终罐底结果。称重模式取消快停后额外 3 s 等待及重量复判，保留快停接口自身的等待；陀螺仪模式保留原等待和角度复判。

### 6.3 第一次精找

在检测区内，候选条件简化为：

```text
candidate_1 = 称重通信有效
           && 位置有效
           && 当前处于称重精找
           && 当前位置 >= P_enable
           && 本轮固定称重基准有效
           && current_weight <= W_base - W_drop
```

候选成立时必须按顺序执行：

1. 立即锁存触发时尺带位置 `P1`，不能等电机停稳后再记录。
2. 立即执行现有快停。
3. 电机停稳后记录 `P_stop_1`。
4. `P1` 是候选罐底位置；`P_stop_1` 只用于计算实际上提距离。

不增加连续帧计数或复杂滤波。称重阈值可以保持较灵敏，因为它不再直接代表探底成功。

### 6.4 按实际刹车过行程上提

第一次触发后的离底目标为：

```text
P_release = P1 - M_release
D_lift_1 = P_stop_1 - P_release
```

这等价于：

```text
实际上提距离 = 实际刹车过行程 + 离底释放余量
```

因此，刹车距离越长，上提距离会自动增加，不再依赖任意固定上提距离。

上提先检查位置到达 `P_release`；下一次精找前记录此刻有效帧序号，只接受其后收到的新称重帧。新帧称重大于 `W_abs` 且大于本轮固定候选下限才允许下探；旧缓存不放行，单帧低值继续等待。最多等待1000 ms，每20 ms检查通信、全局错误和命令切换；连续有帧但未恢复则报释放失败，通信故障保留原错误。等待期间不追加上提，不降低基准。时间均为内部常量，不新增参数；该重量恢复门禁取代旧版“称重仅辅助”的约定。

当前上提接口按电机步数执行，没有可复用的编码轮毫米到位容差。本流程采用暂定 5 mm 单侧容差：当前位置不低于目标超过 5 mm 即视为释放完成，已在目标上方则不再上提；不足超过 5 mm 返回 `MEASUREMENT_BOTTOM_RELEASE_FAIL`。现场日志中的约 4.2 mm 偏差不再消耗一次精找重试。5 mm 不等于已经验证机械释放安全。

如果位置无效、上提失败或目标越过其它安全边界，应停止并返回实际运动错误。

### 6.5 第二次精找

从 `P_release` 使用与第一次相同的分级速度策略再次下行：

1. 使用相同的 `P_enable` 和 `bottom_weight_threshold`。
2. 第二次候选成立时立即锁存 `P2`，然后快停。
3. 不增加第三次探测；两次结果不一致时直接判定本次无法可靠确认。

### 6.6 最终确认

确认条件为：

```text
abs(P2 - P1) <= T_repeat
```

满足条件时：

```text
P_bottom = min(P1, P2) + abs(P2 - P1) / 2
```

然后才允许：

- 保存罐底尺带位置。
- 计算罐高。
- 以确认后的平均罐底为参考，按相同释放函数完成最终上提并校验到位；启用编码器修正时，先将罐底参考随当前坐标平移，避免混用修正前后坐标。
- 设置 `bottom_reference_valid = 1`。
- 发布 `STATE_FINDBOTTOM_OVER`。

不满足条件时：

- 不更新罐底位置。
- 不设置新的罐底参考有效。
- 先执行安全上提，再返回“称重探底无法可靠确认”。
- 第一版可复用现有 `MEASUREMENT_WEIGHT_DOWN_FAIL`，同时增加包含 `P1`、`P2` 和位置差的日志；是否新增独立故障码另行审批。

## 7. 与现有代码的最小改造关系

| 现有位置 | 第一版改造 |
| --- | --- |
| `check_bottom_status()` | 称重模式增加 `P_enable` 和当前探底阶段门控；陀螺仪模式不受本方案影响 |
| `CheckWeightCollision()` | 不把 `bottom_weight_threshold` 解释为罐底；下行使用相对变轻和固定500绝对下限，保持原方向与零点忽略区规则 |
| `SearchBottomRough()` | 保留粗找，只在预计罐底附近允许称重候选；粗找结果不作为最终罐底 |
| `SearchBottomPrecise()` | 在快停前返回或保存触发位置，不再只记录停稳位置 |
| `SearchBottom()` | 保存两次精找位置，第一次后按 `P_release` 上提，第二次后比较位置差 |
| `CMD_MeasureBottom()` | 只有两次位置确认成功才设置 `bottom_reference_valid` |
| `SiProfile_ResolveReleasedPoint0FromCable()` | 复用头文件共享释放余量：称重 200 mm、角度 100 mm |
| `SiProfile_BuildPoints()` | 首点必须高于 Point0 且不高于罐高；无效计划返回 `MEASUREMENT_DENSITY_PLAN_INVALID`，点数清零 |

改造前两次精找各自覆盖罐底位置且未比较一致性。当前称重流程比较两次触发位置、动态释放并校验结果；角度精找仍以前次停稳位置为参考。

SI 的 `40001` 保持首个后续点的绝对位置语义。例如 Point0 为 345.8 mm、40001 为 100.0 mm 时，在 SI 测点运动前返回计划无效，禁止再下行至 100.0 mm。不会静默跳点或改成相对偏移。新探底使用实际释放位置，复用普通罐底使用同模式释放余量，允许存在运动到位公差内差异。切换位置源、改动安装参数或探底模式后需重新探底核对参考。

## 8. 回退结果的处理

当前 `CMD_MeasureBottom()` 在特定配置下，会在探底失败或结果偏差较大时使用参考罐高并发布完成。实施本方案时必须区分：

- 两次位置确认成功：真实称重探底结果，`bottom_reference_valid = 1`。
- 使用配置值或历史值回退：估算结果，可以为兼容性保留高度值，但不得标记为本次真实称重探底成功。

称重模式只允许“未找到候选”业务错误或成功后的高度偏差走既有参考回退；参数无效、入口称重不足、释放失败、通信及运动保护错误不允许被回退清除。内部重试同样仅保留未找到候选的业务重试。角度模式保留原兼容分支。

## 9. 必须记录的日志

每次探底至少记录：

```text
P_expected / P_enable（P_slow、P_probe 按参考点和内部距离计算）
current_weight / W_base / W_drop / W_candidate / W_abs
P1 / P_stop_1 / P_release / D_lift_1
P2 / abs(P2 - P1) / T_repeat
称重模式、速度、称重通信状态和位置源状态
最终结果：确认成功、位置不一致、未触发或真实故障
```

日志必须能区分“称重候选”“位置确认成功”“使用参考值回退”三种语义。

## 10. 参数定值方法

### 10.1 `L_enable`

采集不同罐体、安装位置和重复测量条件下，真实触底位置相对 `P_expected` 的偏差。取最早触底偏差的最大值并增加工程余量，确保称重检测不会启用过晚。

### 10.2 `M_release`

在不同负载、卷径、速度和供电条件下记录 `P1` 与 `P_stop_1`。从停止位置上提到 `P1` 以上，继续增加距离，直到机构压缩和尺带松弛可靠解除；该附加距离作为 `M_release`。

### 10.3 `T_repeat`

在相同罐底连续执行两次低速触底，统计 `abs(P2 - P1)`。根据正常重复误差上限增加余量，但不得大到能够覆盖正常运行中的随机误触发位置。

当前实现暂用 `L_enable = 300 mm`、`M_release = 200 mm`、`T_repeat = 10 mm`，速度距离300/30 mm、释放容差5 mm均为内部定值。原探底扭力阈值用作减重量，绝对下限固定500；称重速度仍共享0.50/0.10 m/min上限。这些运动定值和减重量都需要台架数据，不能由编译证明安全。

## 13. 仍未确定的点

1. 如果真实触底减重量始终小于设定值，无法产生候选；正常波动若也达到该减重量，仍可能误触发。入口绝对下限只能排除明显低重量，不能证明探头物理悬空；需实测确定下限和减重量。
2. 如果某种正常机械波动会在相同位置稳定重复出现，两次位置一致仍可能误判；必须在台架中专门复现并检查。
3. 首次安装且没有可信 `P_expected` 时，普通自动流程不能可靠决定从哪里启用检测，需要单独定义首次标定流程。
4. 速度分级距离、机构允许的最大触底过行程和最终参数数值都需要实测，当前不能由静态源码证明。
5. 失败回退是否需要新增对外结果质量状态，取决于 CPU3 和外部协议的兼容要求；本次协议37只改变原阈值含义，不新增参数或结果质量字段。
