电机尺带 TFIT 拟合逻辑详解

从卷筒半径变化出发，解释为什么尺带长度是圈数的二次函数；再把数学公式逐项映射到采样、最小二乘求解、参数写入和运行时消费代码。

正式源：docs/单文件 UTF-8 HTML依据：当前工作区源码

1核心结论与全链路

如果只记住一件事：TFIT 拟合的是“电机转了多少圈”与“编码轮实际走了多长”之间的关系。

TFIT 的本质：用电机输出轴圈数 n 作为自变量，用编码轮累计长度 y 作为观测值，拟合二次曲线，从曲线的斜率得到首圈/局部周长，从曲线的弯曲程度得到尺带厚度。
① 采电机XACTUAL → 圈数 n
② 采编码轮encoder count → 长度 y
③ 二次拟合y = a0+a1n+a2n²
④ 参数映射C0=a1，t=−a2/π
⑤ 人工应用TP / TU → 参数保存
最终模型
y = b + C0·n − πt·n²

b 是零点差，C0 是 n=0 处周长，t 控制曲率。

全局 TFIT
求 b、C0、t

允许用 TU 同时写入 C0 与 t。

局部 TFIT
求 Clocal、t

局部周长不是全局 C0；设计用途主要是用 TP 更新 t。

“求解成功”不等于“标定合格”。当前代码只检查点数、圈数跨度、矩阵可解和参数为正；RMSE 与最大误差只打印，不参与放行。

先统一单位，后面的公式才不会混乱。拟合数组实际保存两个整数：电机 tick 与编码轮长度 0.1 mm。

XACTUAL → n
n = motor_step / 1,536,000

每圈 tick 固定为 30 × 1600 × 32。n 是带符号圈数，代码中下行放带方向为正。

y0.1mm = (−count/4096) × encoderCirc0.001mm / 100

拟合时再乘 0.1 转成 mm。负号用于统一编码轮与电机模型的运动方向。

3卷筒物理模型：为什么会出现二次曲线

关键物理量不是“电机每圈永远走相同长度”，而是尺带放出后卷层逐渐变薄，下一圈的有效周长会变小。

紫色区域代表卷绕尺带；虚线是初始外轮廓。

模型的五个假设

1
厚度恒定

用单一 t 表示整段尺带的等效层厚。

2
层间紧密贴合

无明显空隙、起皱或堆叠偏移。

3
无滑移

电机圈数、卷筒转角和编码轮长度可一一对应。

4
圆形等效卷层

偏心和椭圆度只进入残差，不单独建模。

5
连续近似

把逐圈离散变化近似成可积分的连续半径。

t 是“拟合得到的等效层厚”，不一定等于卡尺测得的裸尺带材料厚度。张力、层间间隙和卷绕状态也可能被吸收到 t 中。

4尺带公式逐步推导

从半径开始，只需三步就能得到代码中的二次式。

半径随圈数线性变化

初始等效半径为 R0。下行放带 n 圈后，每圈减少厚度 t：

R(n) = R0 − t·n

半径换成每圈的瞬时周长

C0=2πR0，因此当前位置再转一圈能放出的长度为：

C(n) = 2πR(n) = C0 − 2πt·n

瞬时周长沿圈数积分

累计长度就是从 0 圈到 n 圈，每一小段周长的总和：

L(n) = ∫₀ⁿ(C0−2πt·u)du = C0·n − πt·n²
L(n) = C0·n − πt·n²线性长度　−　卷层变薄造成的二次修正
C0·n假设周长不变时的累计长度
πt·n²随着卷层变薄，需要扣除的长度
dL/dn = C(n)对累计长度求导，回到瞬时周长

上行与下行为什么可以共用同一二次式

下行放带：n ≥ 0

半径减小，L 为正；L=C0n−πtn²。

上行收带：n < 0

令 m=−n≥0，则 L=−(C0m+πtm²)；代回后仍是 C0n−πtn²。

加入零点偏移，得到全局拟合模型

电机 n=0 与编码轮 y=0 未必对应同一个物理位置，所以编码轮观测模型多一个常量 b：

y = b + C0·n − πt·n² + ε

ε 表示编码量化、偏心、滑移、张力和未建模机械误差。

5最小半径分段模型与长度反算

二次式不能无限延伸，否则半径最终会变成负数。运行代码把下行最小半径限制为 40 mm。

进入最小半径前

Rmin = 40 mm
Cmin = 2πRmin
n1 = (C0−Cmin)/(2πt)
L1 = C0·n1−πt·n1²

CPU2 下行运行模型

L(n) = {
  C0·n − πt·n²             0 ≤ n ≤ n1
  L1 + (n−n1)·Cmin          n > n1
}

n>n1 后继续放带，但固定按最小周长 Cmin 线性增长。上行 n<0 不做该截断。

拟合与运行模型存在一个重要差别：TFIT 求解器始终拟合完整二次式，没有拟合分段线性项。用于 TFIT 的样本若跨过 n1，单一二次曲线就不再是正确模型。

从长度反算圈数

区域反算公式代码选择
下行二次段n=(C0−√(C0²−4πtL))/(2πt)取与 n=0 连续的较小根
下行线性段n=n1+(L−L1)/CminL 超过 L1 后使用
上行m=(−C0+√(C0²+4πt|L|))/(2πt)，n=−mm 表示收带圈数
t≤0 退化n=L/C0按固定周长线性模型
反算的用途：由当前长度得到 n，再算瞬时周长 Cinst=dL/dn；该周长继续用于线速度换算/补偿和位置持久化阈值。

6全局拟合与局部拟合

两种模式使用同一批类型的样本，但坐标原点和允许写回的参数不同。

全局 TFIT · T1 / TR

y = a0 + a1·n + a2·n²
  • b=a0：编码轮长度零点偏移
  • C0=a1：全局 n=0 处周长
  • t=−a2/π：等效层厚

3 个未知数，使用 3×3 正规方程。

有效结果可由 TU 写 C0+t，或由 TP 只写 t。

VS

局部 TFIT · T2 / TV

Δy = a1·q + a2·q²
  • q=(step−step0)/Nrev
  • Δy=y−y0
  • Clocal=a1，t=−a2/π

截距固定为 0，使用 2×2 正规方程。

设计上只通过 TP 写 t；局部结果请求写全局 C0 会被拒绝。

为什么局部一次项不是全局 C0

假设局部启动点对应全局圈数 n0，令 n=n0+q。把全局长度在启动点前后相减：

L(n0+q)−L(n0) = (C0−2πt·n0)·q − πt·q²

括号内正是启动位置的瞬时周长 Clocal=C0−2πtn0。所以：

局部 a1 = Clocal，而不是 C0。局部坐标消除了固定零点偏移，适合从曲率估 t；但没有 n0 就不能仅凭 Clocal 还原全局 C0。
实现细节：T2 → TR 仍会执行全局求解，因为 TR 直接调用全局接口；若随后全局结果有效，TU 在代码路径上可以写 C0+t。操作时应保持命令模式一致：T1 配 TR/TU，T2 配 TV/TP。

7最小二乘求解器与质量指标

参数虽然出现在二次曲线里，但对 a0、a1、a2 都是线性的，因此可用普通线性最小二乘。

全局正规方程

[ Σ1   Σn   Σn² ] [a0]   [ Σy   ]
[ Σn   Σn²  Σn³ ] [a1] = [ Σny  ]
[ Σn²  Σn³  Σn⁴ ] [a2]   [ Σn²y ]
累加

逐点累计 XᵀX 和 Xᵀy，不保留额外矩阵。

消元

3×3 高斯消元；每列选择绝对值最大的主元候选行。

奇异判断

主元或局部行列式绝对值小于 1e−12 即失败。

结果质量怎么计算

残差 eᵢ = ŷᵢ − yᵢ
RMSE = √(Σeᵢ²/N)描述典型误差大小
Emax = max|eᵢ|描述最坏单点误差
当前没有质量阈值：只要 C0>0、t>0，结果就会被标成 valid，即使 RMSE 或最大误差很大。也没有 R²、置信区间、参数上限、离群点剔除或重复点降权。

10完整数值例子与交互计算器

默认使用当前出厂参数口径 C0=600 mm、t=0.200 mm。先看 50 圈时每个量如何变化。

静态算例：n=50

初始半径R0=600/(2π)=95.493 mm
50 圈后半径R=95.493−0.2×50=85.493 mm
瞬时周长C=600−2π×0.2×50=537.168 mm

一份结果至少要回答的 6 个问题

1
模式对吗？

T1/TR 还是 T2/TV，是否混用。

2
覆盖多大？

点数、n/q 最小值和最大值。

3
方向稳定吗？

有无回差、停走、松带。

4
参数合理吗？

C0、t 与机械测量量级是否一致。

5
残差多大？

RMSE 与最大误差能否接受。

6
独立复验了吗？

新参数是否改善独立尺长误差。

推荐命令配对：全局标定用 T1 → 运动 → T0 → TS → TR → 人工检查 → TU；局部厚度标定用 T2 → 运动 → T0 → TS → TV → 人工检查 → TP。
