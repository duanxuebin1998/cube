# 电机运动第三轮策略评估记录

更新日期：2026-06-12

> 当前复核（2026-07-08）：状态：已闭环（策略评估闭环）。当前 HEAD 保持正式位置模式与 Jog 速度模式分层，未替换默认 `MotorCtrl_MoveToPosition()`，与本文评估结论一致；剩余多速度/长距离和故障注入证据转入未处理验证文档。

## 1. 评估结论

第三轮已完成代码和现有台架记录审计。本轮不修改固件默认运动策略，不把 `MotorCtrl_MoveToPosition()` 替换为 Jog 速度模式。

当前推荐继续保持：

- 正式业务绝对位置运动继续使用 `MotorCtrl_MoveToPosition()`。
- Jog 相对和绝对运动继续作为 `BJ/BJP` 调试、长距离点动和提前减速方案验证入口。
- 两类入口共用 `MotorMotionTargetPlan` 做目标规划，但执行策略继续分离。

原因是现有台架数据只覆盖 `T04`、`T07`、`T08`、`T09`、`T10` 等有限场景，速度和距离范围偏窄，不能证明 Jog 反馈策略在正式测量全场景下优于当前位置模式。

## 2. 当前代码证据

| 路径 | 当前实现 | 保留原因 |
| --- | --- | --- |
| 正式距离运动 | `MotorCtrl_MoveAndWait()` 规划相对目标，调用 `MotorCtrl_MoveNoWait()` 下发位置目标，再由 `MotorMotion_WaitUntilStopWithTarget()` 等待到位 | 保留正式流程的起步观察、目标停机、撞底、丢步、命令切换和最终偏差判断 |
| 正式绝对位置运动 | `MotorCtrl_MoveToPosition()` 每轮刷新主动位置源，复用 `MotorMotion_BuildAbsoluteTargetPlan()`，再分段调用 `MotorCtrl_MoveAndWait()` | 保持正式业务入口的错误收尾和保护链路，不引入速度模式提前停机误差 |
| Jog 相对点动 | `MotorCtrl_JogMoveAndWait()` 复用相对目标规划后进入 `MotorMotion_JogMoveToTargetInternal()` | 用速度模式验证主动位置反馈、减速距离和慢停收尾 |
| Jog 绝对点动 | `MotorCtrl_JogMoveToPosition()` 复用绝对目标规划后进入 `MotorMotion_JogMoveToTargetInternal()` | 适合 `BJP` 台架验证，不直接承担正式测量业务 |
| 停稳收尾 | `MotorMotion_CheckStoppedAndRefresh()` 已被通用停机、正式到位和停止命令等待复用 | 只收敛停稳后的最终位置同步和活动状态清理，不改变各等待循环主体 |

## 3. 当前台架证据

已记录的可用证据：

| 项目 | 记录摘要 | 对第三轮的意义 |
| --- | --- | --- |
| T04 | `CMD_RUN_TO_POSITION` 到 `680.0mm`，最终 `YS` 约 `680.1mm` | 说明当前正式绝对位置模式在该点位可正常到位 |
| T07 | `BJ+20,1.0`，约 `628.8mm -> 648.2mm`，返回 `0x00000000` | 说明 Jog 相对上行在小行程下可用 |
| T08 | `BJ-20,1.0`，约 `648.2mm -> 628.7mm`，返回 `0x00000000` | 说明 Jog 相对下行在小行程下可用 |
| T09 | `BJP650,1.0`，终点 `649.5mm`，误差 `-0.5mm` | 说明 Jog 绝对点动在单一速度和目标附近可用 |
| T10 | `BJP1100,1.0` 被高位越界拒绝，合法 `BJP700,1.0` 返回成功 | 说明高位越界保护有效，但不覆盖低于 `200mm` 台架下限 |

当前证据不足：

- 未覆盖多速度，例如低速、中速、高速对比。
- 未覆盖长距离上行和长距离下行。
- 未覆盖接近 `200mm` 台架下限的安全策略。
- 未覆盖不同位置源下的同目标对比。
- 未覆盖 T15/T16 人工故障注入。
- 未记录 Jog 与正式位置模式在相同目标、相同速度、相同起点下的耗时和过冲对比。

## 4. 策略差异

| 差异项 | 正式位置模式 | Jog 速度模式 | 结论 |
| --- | --- | --- | --- |
| 下发方式 | 计算相对距离并下发 TMC5130 目标位置 | 下发速度模式，运行中按当前位置决定减速和停止 | 下发机制不同，不能直接互换 |
| 到位依据 | 驱动运动状态、目标位置窗口和最终偏差判断 | 主动位置反馈、剩余距离、估算停机距离和越界判断 | Jog 更依赖位置反馈质量和减速模型 |
| 错误收尾 | 通过正式等待链路做撞底、健康、丢步、命令切换和同步 | 异常统一慢停并恢复速度，再做最终越界校验 | 两者错误优先级不同 |
| 业务定位 | 正式测量、固定点、密度和测后回点 | 调试验证、点动、提前减速实验 | 默认业务入口应保持正式位置模式 |
| 版本影响 | 保持当前策略通常只属于结构优化 | 替换默认策略属于 CPU2 行为变化 | 替换前必须升版并补完整测试方案 |

## 5. 后续可回退实验方案

若后续要继续推进第三轮代码实验，只允许采用默认关闭、可回退、可对比的方式。

推荐实验路径：

1. 不替换 `MotorCtrl_MoveToPosition()` 默认路径。
2. 增加仅限台架的调试入口或内部开关，默认关闭。
3. 同一目标分别跑正式位置模式和 Jog 速度模式。
4. 记录起点、目标、终点、偏差、耗时、是否提前停机、返回码和关键日志。
5. 数据通过后，再单独制定行为变更方案。

建议测试矩阵：

| 维度 | 建议覆盖 |
| --- | --- |
| 目标位置 | `250mm`、`500mm`、`700mm`、`950mm` |
| 相对距离 | `20mm`、`50mm`、`200mm`、`500mm` |
| 方向 | 上行、下行 |
| 速度 | `0.3m/min`、`1.0m/min`、现场允许的较高速度 |
| 位置源 | 编码轮记步、电机记步 |
| 异常场景 | 命令切换、TMC/24V 故障、编码器首帧缺失、目标越界 |

## 6. 进入代码实验的条件

同时满足以下条件后，才建议进入第三轮代码实验：

- T15/T16 人工故障注入已经有记录。
- 明确 `200mm` 台架下限是否只是测试限制，还是要固化为固件边界。
- 至少完成正式位置模式和 Jog 速度模式在同目标、同速度、同方向下的 A/B 对比。
- 对比结果证明 Jog 策略在偏差、过冲或耗时上有明确收益。
- 已接受 CPU2 固件行为变化、版本升级和完整台架回归成本。
