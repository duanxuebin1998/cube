CPU2 找液位详细流程梳理

整理日期：2026-06-11；依据当前 worktree 源码梳理，不包含未落地的新测量方式设计。

历史/专题流程提示

找液位问题分析和旧流程梳理；当前权威流程以 CPU2 液位测量与跟随页为准。

当前权威流程：液位测量与跟随程序流程统一入口
主命令 CMD_FIND_OIL，串口正式命令字符 K 也会映射到该命令。
主入口 CMD_MeasureAndFollowOilLevel() 先找液位，再按配置切换电机记步并进入液位跟随。
核心分流 0/1 保留旧步进精找，2 走密度连续闭环，4 走相对频率速度闭环，5 直接走定频速度闭环。
结果字段 oil_level、Density_oil_level、probe_at_liquid_level、liquid_stable。

液位方式 找液位入口路径 精找/闭环方案 跟随方案
0 原有相对频率 频率粗找，读取 oil_frequency 和 air_frequency。 follow_frequency=(air+oil)/2，进入旧 SearchOilPrecise(100)。 旧频率跟随循环，偏差超滞后阈值后重新步进精找。
1 原有绝对频率 频率粗找，确认空气/油中边界。 follow_frequency=oilLevelFrequency，进入旧 SearchOilPrecise(100)。 旧频率跟随循环，偏差超滞后阈值后重新步进精找。

4 连续相对频率 沿用方式 0 的频率粗找。 follow_frequency=(air+oil)/2，进入 FrequencyLevel_RunClosedLoop(...SEARCH)。 FrequencyLevel_RunClosedLoop(...FOLLOW) 长驻跟随。
5 连续固定频率 不执行频率粗找，直接检查 oilLevelFrequency 是否在 1..6500 Hz。 FrequencyLevel_RunFixedClosedLoop(...SEARCH) 先校验并设置固定目标，再复用频率速度闭环。 FrequencyLevel_RunFixedClosedLoop(...FOLLOW) 长驻跟随。
其他未识别方式 按绝对频率目标处理。 保留旧 SearchOilPrecise(100) 兜底。 保留旧频率跟随循环。

3. 分支依据：参数、状态和结果字段

名称 当前作用 注意点
oilLevelFrequency 空气/油中粗判定阈值；方式 1 固定频率步进和方式 5 固定频率速度闭环下也作为目标频率。 OilLevel_IsCurrentFrequencyInAir() 为当前频率大于该值，OilLevel_IsCurrentFrequencyInOil() 为当前频率小于该值。
liquidLevelMeasurementMethod 本分支 CPU2 已区分 0、1、2、3、4、5 和其他未识别方式。 0/1 保留原有步进式频率找液位；2 走密度连续闭环；3 为超声预留；4 是相对频率速度闭环；5 是固定频率速度闭环。
oilLevelThreshold 连续频率找液位阶段的查找死区；未配置时默认 15Hz。 新增连续相对频率方式还会避免停在空气频率或油中频率端点附近，端点保护边距为 200Hz。
oilLevelHysteresisThreshold 连续频率跟随阶段的死区；未配置时默认 15Hz。 跟随稳定时电机停止并做可打断等待；偏差超出死区后重新按速度模式运动。
blindZone 液位盲区下限，单位 0.1mm。 位置非负且低于盲区时返回 MEASUREMENT_OILLEVEL_LOW，并清除外部协议命中/稳定状态。
tankHeight 液位罐高，单位 0.1mm。 跟随更新时若位置达到 tankHeight - 1000，返回 MEASUREMENT_OILLEVEL_HIGH。
oil_level 最终液位结果，单位 0.1mm。 由 debug_data.sensor_position 写入；负位置上报前钳位为 0。
probe_at_liquid_level / liquid_stable 给 CPU3/SI 等外部协议使用的辅助状态。 找液位开始和异常边界会清 0；找液位成功后置 1。

4. 单次找液位：SearchOilLevel

本节只看一次 SearchOilLevel() 的执行路径：当前主函数只负责调度，直接方式由 OilLevel_TryRunDirectSearchMethod() 分流；方式 2 直接进入密度闭环，方式 3 作为超声预留直接返回参数错误，方式 5 先校验 1..6500 Hz 定频目标再进入定频速度闭环；只有方式 0/1/4 和未知配置会继续调用运行态复位、液位模式启用、粗找、目标解析和搜索执行 helper。

流程图 2：SearchOilLevel 完整分支

4.1 运行态复位并启用液位模式

  1. OilLevel_ResetSearchRuntimeState() 清除 probe_at_liquid_level 和 liquid_stable，避免 CPU3 读到上一轮结果。
  2. 调用 fault_info_init() 清故障信息。
  3. OilLevel_EnableLevelModeWithRetry() 最多 3 次调用 EnableLevelMode()。
  4. 若返回 STATE_SWITCH，说明有新命令切换，直接返回，不记录为故障重试。
  5. 若液位模式启用失败，写入传感器模块的错误重试日志，延时 500ms 后重试。

4.2 粗找阶段：先判断探头当前在空气中还是油中

OilLevel_RunFrequencyCoarseSearch() 承担粗找阶段，最多循环 3 次，只服务于方式 0/1/4 和未知配置。方式 2、3、5 已在入口提前返回，不会执行本阶段。每次先用 DSM_Get_LevelMode_Frequence_Avg() 读取当前平均频率，再根据 oilLevelFrequency 判断探头位置。

条件 判断结果 动作
current_frequency < oilLevelFrequency 认为探头在油中。 若传感器位置高于盲区 100mm，先下行 100mm 确保完全在油中；通过 OilLevel_ReadAverageFrequencyWithRetry() 读取 oil_frequency；再调用 SearchAir() 上行找空气。
current_frequency > oilLevelFrequency 认为探头在空气中。 调用 SearchOil() 下行找油中，再由 SearchOil() 内部继续调用 SearchAir() 找空气侧边界。
current_frequency == oilLevelFrequency 粗找入口的两个宏都不命中。 本轮不进入空气/油中分支；若 3 次都没有 coarse_found，返回最后一次粗找错误码，默认是 MEASUREMENT_OILLEVEL_NOTFOUND。
粗找重试的实际覆盖范围： 粗找循环能重试入口平均频率读取失败和入口判定；油中/空气端点平均频率读取通过 OilLevel_ReadAverageFrequencyWithRetry() 局部重试。SearchOil()、SearchAir() 内部的运动、安全和命令切换错误仍通过 CHECK_ERROR() 直接向上返回，不会回到粗找循环继续尝试。

流程图 3：粗找阶段空气/油中边界搜索

4.3 频率平均值读取

DSM_Get_LevelMode_Frequence_Avg() 当前执行 10 次液位频率采样，每次间隔 2s，延时可被命令切换打断。采样完成后排序，去掉 2 个最大值和 2 个最小值，对中间 6 个值求平均并四舍五入为整数 Hz。

4.4 目标频率和后续入口选择

参数值 当前 CPU2 行为 说明
liquidLevelMeasurementMethod == 0 follow_frequency = (air_frequency + oil_frequency) / 2，然后 SearchOilPrecise(100) 原有相对频率方式保留步进式精找，不进入新增连续闭环。
liquidLevelMeasurementMethod == 1 follow_frequency = oilLevelFrequency，然后 SearchOilPrecise(100) 原有绝对频率方式保留步进式精找，不进入新增连续闭环。
liquidLevelMeasurementMethod == 2 DensityLevel_RunClosedLoop() 密度闭环速度模式：以 oilLevelDensity 为目标，低于目标下行，高于目标上行，速度按密度偏差限幅控制；该方式不执行频率粗找。
liquidLevelMeasurementMethod == 4 follow_frequency = (air_frequency + oil_frequency) / 2，然后 FrequencyLevel_RunClosedLoop() 新增连续相对频率方案，保留原粗找取空气/油中频率，再用速度模式连续逼近目标频率。
liquidLevelMeasurementMethod == 5 FrequencyLevel_RunFixedClosedLoop() 连续固定频率方案在 SearchOilLevel() 入口提前返回，不执行粗找；先用 FrequencyLevel_SetFixedTarget() 校验 oilLevelFrequency 是否在 1..6500 Hz 并写入固定目标，再用速度模式连续逼近固定目标频率。
其他未识别方式 follow_frequency = oilLevelFrequency 保留旧 SearchOilPrecise(100) 兜底路径，避免未知配置直接改变行为。

4.5 原有方式 0/1：步进式精找 SearchOilPrecise

方式 0/1 以及未识别方式保留旧精找：先按粗找结果确定 follow_frequency，再用当前频率与目标频率的偏差换算步进距离，并通过固定速度的 MoveAndWait 分段靠近液位。

流程图 4：SearchOilPrecise 步进式精找

4.6 连续速度闭环：方式 2/4/5

方式 2 在 SearchOilLevel() 入口直接进入 DensityLevel_RunClosedLoop(DENSITY_LEVEL_RUN_SEARCH)；方式 4 粗找完成后进入 FrequencyLevel_RunClosedLoop(FREQUENCY_LEVEL_RUN_SEARCH)；方式 5 直接进入 FrequencyLevel_RunFixedClosedLoop(FREQUENCY_LEVEL_RUN_SEARCH)。这三类闭环都使用电机速度模式，不再按步长调用 MotorCtrl_MoveAndWait()。

OilLevel_GetFrequencyDifference() = current_frequency - follow_frequency
偏差条件 方向 速度与稳定策略
密度方式：当前密度低于 oilLevelDensity 下行 按密度偏差比例计算速度，偏差越大速度越高，并受默认速度上限约束。
密度方式：当前密度高于 oilLevelDensity 上行 按相同的比例速度控制逻辑上行。
频率方式：difference > deadband 下行 按 FrequencyLevel_ComputeSpeedX100() 比例计算速度，并受默认速度上限约束。
频率方式：difference < -deadband 上行 按相同的比例速度控制逻辑上行。
频率方式：|difference| <= deadband 且相对频率方式靠近空气/油中端点 靠近空气端点下行；靠近油中端点上行 即使偏差已在死区内，也使用最小速度离开端点，避免把端点误判为液位界面。
频率/密度方式：偏差在死区内且无需端点修正 不动作 停止电机，稳定计数达到 3 次后记录液位并置位 probe_at_liquid_level、liquid_stable。

运动中每 200ms 采样一次频率，并持续执行位置边界、扭力碰撞和丢步检查。查找模式最长运行 600s；稳定后查找返回，跟随模式则继续长驻监控。

流程图 5：连续频率/密度速度闭环控制

4.7 成功结果写入

  1. 将 debug_data.sensor_position 作为液位结果来源。
  2. 若位置为负，OilLevel_ClampLevelForReport() 按 0 上报，避免无符号字段变成超大值。
  3. 写入 g_measurement.oil_measurement.oil_level。
  4. 同步写入 g_measurement.density_distribution.Density_oil_level，供密度分布相关流程复用。
  5. 置位 probe_at_liquid_level=1 和 liquid_stable=1。

5. 粗找边界：SearchOil / SearchAir

SearchOil：从空气侧下行找油中

  1. 若 debug_data.cable_length > 1000（0.1mm 单位，约 100mm），先上行 100mm，尽量保证探头在空气中。
  2. 调用 MotorCtrl_LostStepInit() 重置丢步检测。
  3. 循环调用 determine_level_status_motion()，若判定为 OIL 则退出循环。
  4. 未到油中时，下行运动，并持续打印传感器位置、记步参考和扭力值。
  5. 每轮检查丢步 MotorCtrl_CheckLostStepAutoTiming() 和扭力碰撞 CheckWeightCollision()。
  6. 若传感器位置低于 blindZone，停止并返回 MEASUREMENT_OILLEVEL_LOW。
  7. 到油中后慢停；若仍高于盲区 100mm，再下行 100mm，确保完全在油中。
  8. 通过 OilLevel_ReadAverageFrequencyWithRetry() 读取并保存 oil_frequency，随后调用 SearchAir() 找空气侧边界。

SearchAir：从油中上行找空气

  1. 调用 MotorCtrl_LostStepInit() 重置丢步检测。
  2. 循环调用 determine_level_status_motion()，若判定为 AIR 则退出循环。
  3. 未到空气时，上行运动，并持续检查丢步和扭力碰撞。
  4. 到空气后慢停；若尺带长度大于 100mm，再上行 100mm，确保探头全部在空气中。
  5. 通过 OilLevel_ReadAverageFrequencyWithRetry() 读取并保存 air_frequency。
  6. 若传感器位置高于盲区 100mm，再下行 100mm，为后续精找回到液位附近。

运动中液位状态判定

determine_level_status_motion() 通过 determine_level_status_internal(..., 0) 实现。它不会走完整的 DSM_Get_LevelMode_Frequence() 异常恢复流程，而是按传感器类型直接读取液位频率：

  • DSM_SENSOR：调用 Read_Level_Frequency()。
  • 其他传感器：调用 DSM_V2_Read_LevelFrequency()。

读取成功后，current_frequency > oilLevelFrequency 判为 AIR，否则判为 OIL。

6. 长驻跟随：FollowOilLevel

FollowOilLevel() 是长驻闭环函数，正常情况下不会自己结束。它只有在命令切换、传感器/电机/边界错误等情况下返回。

流程图 6：FollowOilLevel 长驻跟随

  1. 将设备状态设为 STATE_FLOWOIL。
  2. 方式 4 进入 FrequencyLevel_RunClosedLoop(FREQUENCY_LEVEL_RUN_FOLLOW)，方式 5 进入 FrequencyLevel_RunFixedClosedLoop(FREQUENCY_LEVEL_RUN_FOLLOW)，二者都按频率偏差连续调速。
  3. 方式 2 进入 DensityLevel_RunClosedLoop(DENSITY_LEVEL_RUN_FOLLOW)，按密度偏差连续调速。
  4. 方式 0/1 以及未识别方式保留旧循环：读取当前频率，超过滞后阈值后重新调用 SearchOilPrecise(100)。
边界 触发条件 处理
上限 tankHeight > 1000 且 sensor_position >= tankHeight - 1000 清 probe_at_liquid_level 和 liquid_stable，停电机，返回 MEASUREMENT_OILLEVEL_HIGH。
下限/盲区 sensor_position >= 0 且 sensor_position < blindZone 清外部协议辅助状态，停电机，返回 MEASUREMENT_OILLEVEL_LOW，上层进入盲区等待。
负位置 sensor_position < 0 不按盲区错误处理；写入结果时钳位为 0。

6.1 盲区等待

waitForTheLiquidLevelToExceedTheBlindZone() 会保持 probe_at_liquid_level=0、liquid_stable=0，循环读取液位频率。当 current_frequency > follow_frequency 时认为脱离盲区等待条件并返回。等待期间显式检查命令切换，返回 STATE_SWITCH 时不作为故障。

7. 传感器读取和异常恢复

DSM_Get_LevelMode_Frequence() 是静态读频率和精找阶段使用的通用读取函数。它的有效频率范围为 hz != 0 && hz <= 6500。

  1. 每轮最多读取 3 次液位频率。
  2. 读到有效频率后写入输出指针并返回 NO_ERROR。
  3. 若读到 0 或大于 6500 的异常频率，记录 SONIC_FREQ_ABNORMAL 重试日志，并执行 1s 可打断延时。
  4. 连续 3 次无效后进入模式恢复，最多 3 轮。
  5. 恢复逻辑会根据电机状态决定：若电机仍在动，只重新启用液位模式；若电机已停，先上行微动，再切密度模式等待稳定，最后切回液位模式。
  6. 恢复 3 轮仍无有效频率，返回 SONIC_FREQ_ABNORMAL。

8. 命令切换和错误传播

场景 当前处理
STATE_SWITCH 命令切换被视为正常打断，找液位、精找、平均频率采样和盲区等待都会向上透传，不参与故障重试。
电机移动失败、丢步、碰撞、传感器读取失败 大多通过 CHECK_ERROR() 或 OilLevel_StopBeforeReturn() 向上返回；后者会先调用 MotorCtrl_SlowStop()。
找液位成功 写入液位结果和密度分布液位缓存，并置位外部协议辅助状态。
边界错误 到达上限、盲区或频率跟随超速都会清除命中/稳定状态，避免 CPU3 或外部协议误判液位有效。

9. 风险和后续关注点

  • 原有液位方式 0/1 已保留：方式 0/1 仍使用原来的粗找 + SearchOilPrecise(100) 步进式精找；方式 2 使用密度连续闭环；方式 4 粗找后使用相对频率速度闭环；方式 5 不粗找，校验 1..6500 Hz 固定目标后直接使用固定频率速度闭环；方式 3 作为超声预留直接返回 PARAM_ERROR。当前 SearchOilLevel() 已拆为调度函数和私有 helper，便于维护方式边界。
  • 粗找循环不是完整三次业务重试：入口读频率和端点平均频率读取可重试；SearchOil()、SearchAir() 内部运动、安全类错误仍会直接返回，粗找循环不会重新从入口读频率再试。
  • 旧精找循环保护不返回错误：未识别测量方式的 SearchOilPrecise() 兜底中，loopTime > 100 后跳出循环并返回 NO_ERROR。
  • 频率等于阈值的入口边界：SearchOilLevel() 的方式 0/1/4 粗找入口对 current_frequency == oilLevelFrequency 没有明确分支。
  • 主找液命令没有高层 3 次重试：CMD_FIND_OIL 的主路径是 CMD_MeasureAndFollowOilLevel()，不同于 SearchAndFollowOilLevel() 的高层重试封装。

  SearchOilLevel()

  if position source is encoder and auto switch enabled:
      MotorCtrl_SwitchPositionSourceToMotor()
      device_state = STATE_FINDOIL
      SearchOilLevel()

  device_state = STATE_FLOWOIL
  FollowOilLevel()

SearchOilLevel:
  ret, direct_handled = OilLevel_TryRunDirectSearchMethod()
  if direct_handled:
      return ret

  OilLevel_ResetSearchRuntimeState()
  OilLevel_EnableLevelModeWithRetry()
  OilLevel_RunFrequencyCoarseSearch()
  OilLevel_ResolveSearchTargetFrequency()

  ret, result_recorded = OilLevel_RunResolvedSearchMethod()
  if result_recorded:
      return ret

  OilLevel_RecordSearchResult()

OilLevel_TryRunDirectSearchMethod:
  if method == 2: DensityLevel_RunClosedLoop(search)
  if method == 3: return PARAM_ERROR
  if method == 5:
      reset runtime state
      validate oilLevelFrequency in 1..6500 Hz
      FrequencyLevel_RunFixedClosedLoop(search)

OilLevel_RunFrequencyCoarseSearch:
  read current average level frequency, up to 3 attempts
  if current_frequency < oilLevelFrequency:
      ensure probe fully in oil
      read oil_frequency with retry
      SearchAir()
  else if current_frequency > oilLevelFrequency:
      SearchOil()

OilLevel_RunResolvedSearchMethod:
  if method == 4:
      FrequencyLevel_RunClosedLoop(search)
      result_recorded = true
  else:
      SearchOilPrecise(100)
      result_recorded = false
