# 罐底测量下行保护改动说明

## 背景

罐底测量粗找阶段原逻辑依赖扭力或陀螺仪识别罐底，未使用已有参数 `maxDownDistance` 作为最大下行边界。如果传感器持续下行且罐底状态始终未触发，流程可能一直下探，只能依赖丢步、驱动故障或人工命令切换等外部保护退出。

## 修改目标

1. 罐底测量最大尺带长度限制为 `tankHeight + maxDownDistance`。
2. 超过最大允许位置仍未识别到罐底时，立即停机并返回测量失败。
3. 传感器位置低于 1m 时，将罐底下行速度限制到 0.50m/min。
4. 降速触发时必须打印明确日志，现场可以直接确认限速原因和实际速度。

## 代码改动

修改文件：

- `LTD_MAIN_CPU2/Application/Src/measure_tank_height.c`

新增罐底保护辅助函数：

- `Bottom_GetMaxCableLength01mm()`：计算最大允许尺带长度，单位 0.1mm。
- `Bottom_CheckMaxCableLength()`：判断当前尺带长度是否超过 `tankHeight + maxDownDistance`。
- `Bottom_ApplyNearSensorSpeedLimit()`：传感器位置低于 1m 且原速度高于 0.50m/min 时，返回 0.50m/min。

保护接入位置：

- `SearchBottomRough()`：每轮粗找下行前检查最大尺带长度，再根据传感器位置决定下行速度。
- `SearchBottomPrecise()`：每轮精找下行前检查最大尺带长度，并在原有分段降速基础上继续套用 1m 内限速。

## 报错行为

当当前尺带长度大于 `g_deviceParams.tankHeight + g_deviceParams.maxDownDistance`，且罐底仍未识别时：

- 先执行 `MotorCtrl_QuickStop()`。
- 返回 `MEASUREMENT_WEIGHT_DOWN_FAIL`。
- 最终通过现有错误出口进入测量失败处理。

现场日志示例：

```text
罐底测量    超过最大下行位置仍未识别到罐底 | 尺带=20350.0mm | 上限=20300.0mm | 罐高=20000.0mm | 最大下行=300.0mm
```

## 降速日志

当传感器位置低于 1m 且原速度高于 0.50m/min 时，打印：

```text
罐底测量    传感器位置低于1m，降速到0.50m/min | 传感器位置=950.0mm | 原速度=1.00m/min
```

粗找过程日志同步包含实际下发速度：

```text
罐底测量    长距离寻找罐底    {传感器位置}950.0 ... {扭力值}1234    速度(0.01m/min)50
```

精找过程沿用原有速度日志，限速后打印的速度会显示为 `50`。

## 兼容性

- 不新增参数。
- 不改变 `maxDownDistance` 的寄存器地址和单位。
- 不改变 CPU2/CPU3 共享协议版本。
- 不影响非罐底测量流程。

## 验证建议

1. 设置 `tankHeight=200000`、`maxDownDistance=3000`，模拟罐底状态一直为 `NORMAL`，确认尺带超过 203000 后返回 `MEASUREMENT_WEIGHT_DOWN_FAIL`。
2. 在传感器位置高于 1m 时执行罐底粗找，确认速度使用默认速度。
3. 在传感器位置低于 1m 时执行罐底粗找，确认打印降速日志且实际速度为 `50`。
4. 在精找阶段确认原有 10、40、100 分段速度仍保留；当分段速度高于 50 且位置低于 1m 时被压到 50。
5. 运行 CPU2 构建，确认新增保护逻辑可编译通过。
