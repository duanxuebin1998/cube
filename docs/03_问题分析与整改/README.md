## 维护规则

- 问题分析文档应包含现象、影响范围、根因、整改方案、验证方法、未验证风险和后续动作。
- 如果同一问题已经进入版本发布，文档中应引用对应的版本改动与测试方案。
- 保留历史 PDF 作为阅读导出，不把 PDF 当作唯一可维护正文。
- 本目录的 HTML 主要作为流程化阅读或历史分析页保留；后续需要长期维护的问题结论应补 Markdown 或在 README 中标明对应维护源。
- 当前目录暂不做批量移动；等暂存区清理后，再按 `问题专题索引.md` 的建议小批量拆分专题目录。
