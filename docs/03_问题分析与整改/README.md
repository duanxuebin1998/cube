# 问题分析与整改文档索引

更新日期：2026-06-11

本目录用于保存已经暴露的问题、现场现象、代码原因分析、整改方案、风险说明和后续复查记录。这里的资料强调“发生了什么、根因是什么、怎么改、怎么验证”。

## 文件分类

| 分类 | 文档 | 用途 |
| --- | --- | --- |
| 启动和电机安全 | `重启后电机继续运行导致丢步问题分析与解决方案.md`、`电机24V断电与命令切换改动整理.md` | 启动后运动、断电、命令切换和电机安全边界分析 |

| 水位和故障恢复 | `水位跟随流程梳理.md`、`故障重试日志整理.md` | 水位跟随、故障重试、日志和恢复流程分析 |
| 显示和编码 | `电机长度显示乱码问题分析.md`、`CPU3屏幕驱动与刷新问题分析及整改方案.md` | 中文显示、编码、OLED 驱动刷新、静电花屏恢复和显示健康诊断 |

## 与其他目录的边界

| 情况 | 放置位置 |
| --- | --- |
| 还只是需求或计划 | `../02_需求与计划/` |
| 已完成版本升级并需要交付测试方案 | `../00_构建与版本/版本改动与测试/` |
| 属于现场测试原始记录、串口日志、docx 测试记录 | `../05_测试记录/` |
| 涉及协议地址、寄存器或兼容性 | 同步更新 `../01_协议与寄存器/` |
| 涉及功能安全、SIL、编码规范或安全模块分级 | 同步更新 `../06_SIL功能安全认证/` |

## 维护规则

- 问题分析文档应包含现象、影响范围、根因、整改方案、验证方法、未验证风险和后续动作。
- 如果同一问题已经进入版本发布，文档中应引用对应的版本改动与测试方案。
- 保留历史 PDF 作为阅读导出，不把 PDF 当作唯一可维护正文。
