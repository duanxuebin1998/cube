# 无线滑环设备端匹配开发计划与执行记录

日期：2026-05-22

最终整理日期：2026-05-23

## 目标范围

一期只实现 CPU2 维护调试入口，由 CPU2 接管 UART6 配置本机 CH9141K 主机模块的默认连接从机 MAC。从机模块仍按出厂或工装保持从机模式与一致密码。

当前状态：已按方案 4（RSSI 近距离匹配）和方案 5（名称筛选后连接）新增 CPU2 串口调试入口，并补充当前连接状态读取命令；最终与 CPU3 正式命令、运行态 MAC 发布和屏幕显示合并为一个版本提交。

## 执行计划

1. 新增 `ch9141_at.c/.h`。
   - 停止 UART6 DMA，清理 UART6 残留数据和错误标志。
   - 使用软件 AT 方式进入 CH9141K 配置状态。
   - 每条 AT 指令追加 `\r\n`，等待 `OK`、`ERR`、`LINK OK`、`PAIR ERR`、`SCAN END` 或 RSSI 上报后再发送下一条。
   - 打印指令、等待条件、超时时间、返回码、响应长度、关键标志和失败原始响应；连接密码字段脱敏。

2. 新增 `wireless_pairing.c/.h`。
   - 确认 CH9141K 主机模式，必要时设置 `AT+BLEMODE=1` 并复位。
   - 支持 `AT+SCAN=ON` 自动扫描和候选解析。
   - 支持 RSSI 近距离匹配：最强 RSSI 不低于 `-55 dB`，多候选时领先第二名不少于 `8 dB`。
   - 扫描候选 MAC 统一转大写；多候选缺少可比较的第二 RSSI 时拒绝自动匹配。
   - 支持名称筛选匹配：只接受扫描输出中显式 `NAME:` / `NAME=` / `PNAME:` / `PNAME=` 字段。
   - 目标 `LINK OK` 后写入 `AT+CONADD=<MAC>,000000` 保存默认连接。
   - 保存后复位模块，恢复 UART6 透传，并调用 `WIRELESS_ProbeNode(1)`、`WIRELESS_ProbeNode(2)` 确认主机和从机透传链路。
   - 缓存最近一次成功匹配的从机 MAC 和名称，供后续状态查询补充打印。
   - 支持只读查询当前连接状态：读取 `BLEMODE`、`BLESTA`、`CCADD`；RSSI 按协议先 ACK 后异步上报处理，不扫描、不断开、不保存默认连接。
   - AT 控制字只按独立行或分隔符识别，避免候选名称/数据内容触发 `OK`、`ERR`、`LINK OK` 等误判。
   - 正常路径默认隐藏逐条 AT 收发明细，只保留业务摘要；失败时自动打印 AT 结果和原始响应。
   - RSSI 异步上报必须等到数值才算完成，避免只收到 `RSSI` 标题就进入解析失败。
   - 每条 AT 命令发送前短暂清理 UART6 残留；`BLEMODE` / `BLESTA` 只接受协议合法枚举值，避免 RSSI 异步尾包污染状态查询。
   - 打印扫描解析统计、候选原始行、RSSI/名称选择原因、连接保存阶段和复位后主/从节点探测结果。

3. 接入 CPU2 调试串口命令。
   - `SPS`：扫描并打印候选，不保存默认连接。
   - `SPR`：按 RSSI 近距离规则自动选择并保存默认连接。
   - `SPN=<name>`：按扫描结果中的蓝牙名称选择并保存默认连接，例如 `SPN=SENSOR001`。
   - `SPC`：读取当前连接状态；已连接时打印从机名称缓存、MAC 和 RSSI。
   - 入口放在 `MeasureStart()` 前，配对动作不额外初始化电机。

4. 版本与文档。
   - 本记录属于 CPU2 无线滑环本地调试能力的阶段性开发记录。
   - 阶段性开发曾按 `V1.8.0.0` 规划；最终不单独发布该版本，而是与 CPU3 正式命令和 MAC 显示合并提交。
   - 最终合并到 MAIN 的版本口径：CPU2 `V1.8.1.0 -> V1.9.0.0`，CPU3 `V1.6.0.0 -> V1.7.0.0`，`DEVICE_PROTOCOL_VERSION` 升级为 `5u`。
   - 已补充 CHANGELOG、协议变更记录和合并后的版本改动测试方案。

5. 验证。
   - 静态检查：确认新增符号引用、命令入口和 UART6 调用边界。
   - 编译验证：运行 CPU2 CMake 配置和构建。
   - 台架验证建议：已知 MAC、单从机扫描、多从机冲突、密码错误、断电重启、匹配后传感器通信。

## 关键约束

- 一期默认密码为 `000000`，后续若现场确认密码不同，应改为编译期常量或进入二期参数化。
- 设备端只能配置本机主机模块，不能直接配置滑环另一端从机模块。
- `SPN=<name>` 依赖 `AT+SCAN=ON` 的实际输出里带名称字段；如果当前 CH9141K 固件只输出 MAC/RSSI，则该命令会拒绝匹配。
- `SPC` 不能从 CH9141K 直接反查当前已连接远端名称；名称只来自 CPU2 本次运行期最近一次成功 `SPR`/`SPN` 缓存，缓存未命中时会打印未知。`AT+RSSI=ON,<周期>` 不是直接返回 RSSI，必须先等待 `OK`，再等待后续异步 RSSI 上报。
- 多候选时不会静默选择，除非 RSSI 满足近距离安全条件。
- CPU3 菜单、匹配中/完成状态和 MAC 显示已在最终合并版本中实现；后续如果要显示扫描候选、RSSI 明细或手动选择候选，需要再次评估协议字段和显示交互。
