# CPU2 串口调试指令与打印信息梳理

本文按当前 CPU2 源码梳理 `process_command()` 支持的 ASCII 串口指令、执行路径、CPU3 显示状态和主要串口打印。来源以 `LTD_MAIN_CPU2/Application/Src/measure.c`、`LTD_MAIN_CPU2/Application/Src/test.c`、无线滑环匹配和电机位置模型相关源码为准。

## 总体入口

通用入口打印：

```text
串口命令	收到处理请求
```

空命令打印：

```text
串口命令	空命令，忽略
```

指令分三类处理：

| 类别 | 指令 | 执行方式 | CPU3 显示状态 |
| --- | --- | --- | --- |
| 正式业务命令 | `I/G/K/R/W/O/P/Q` | 转成 `CommandType`，写入 `g_deviceParams.command`，由主循环执行 | 显示对应业务状态 |
| 特殊前置调试命令 | `SC`、`SP*`、`B/BE` | 在通用 `MeasureStart()` 前拦截执行 | `SC`、`B/BE` 显示调试模式；`SP*` 保持无线滑环流程状态 |
| 普通串口调试命令 | `A/C/D/E/L/M/N/T*/Y*` | 先执行 `MeasureStart()`，再直接执行调试动作 | 执行期间显示调试模式 |

不显示调试模式的特例：
- `F/H/J` 调用正常测量过程，保留罐底、零点、液位测量和液位跟随等业务状态。
- `X` 是单点测量展示演示，主动刷新展示用业务状态。
- 未识别命令当前没有统一“未知指令”打印；只会看到入口打印和可能的 `MeasureStart()` 打印。

## 正式业务命令

这类命令不直接在串口入口执行业务函数，只转交主循环，保证 `current_command`、命令切换和故障恢复路径一致。

转交打印：

```text
串口正式命令	已转主循环执行	命令=%lu
```

| 串口指令 | 转换命令 | 主循环首条业务打印 | 说明 |
| --- | --- | --- | --- |
| `I` | `CMD_BACK_ZERO` | `执行回零点指令` | 单次回零点 |
| `G` | `CMD_FIND_BOTTOM` | `执行罐底测量指令` | 单次罐底测量 |
| `K` | `CMD_FIND_OIL` | `执行寻找液位指令` | 单次液位测量并跟随 |
| `R` | `CMD_MEASURE_DISTRIBUTED` | `执行分布测量指令` | 密度分布测量 |
| `W` | `CMD_FIND_WATER` | `执行寻找水位指令` | 单次寻找水位 |
| `O` | `CMD_SET_EMPTY_WEIGHT` | `执行设置空载称重指令` | 记录空载称重 |
| `P` | `CMD_SET_FULL_WEIGHT` | `执行设置满载称重指令` | 记录满载称重 |
| `Q` | `CMD_RESTORE_FACTORY` | `执行恢复出厂设置指令` | 恢复出厂参数 |

## 传感器与无线通信命令

### `SC`

用途：综合测试无线主机、无线从机和传感器通信，不驱动电机。

入口打印：

```text
串口调试	执行传感器与无线通信综合测试指令
```

过程打印：

```text
===== 传感器与无线通信测试开始 =====
[正常] 无线主机链路探测
[异常] 无线主机链路探测	错误码=0x...
识别结果: sensorType=%lu sensorID=%lu
DSM一代密度数据: 频率=%.3f Hz 密度=%.3f 温度=%.3f
LTD/V2密度: %.3f
===== 通信测试结束，成功=%lu 失败=%lu =====
```

显示状态：执行期间显示“调试模式中”，结束后恢复进入前状态。

### `SP*`

用途：无线滑环 CH9141K 扫描、匹配和连接状态查询。该组命令保留无线滑环自身状态，不强行套用调试模式显示。

| 指令 | 用途 | 入口/关键打印 |
| --- | --- | --- |
| `SPS` | 扫描候选从机 | `===== 无线滑环扫描调试开始 =====`、`无线滑环扫描调试	命令=SPS	动作=扫描候选，会临时断开当前连接，不保存默认连接` |
| `SPR` | 按 RSSI 近距离规则匹配 | `===== 无线滑环RSSI匹配开始 =====`、`无线滑环RSSI匹配	命令=SPR	最强RSSI阈值=%d dB	多候选差值=%d dB` |
| `SPN=<名称>` | 按蓝牙名称完全匹配 | `===== 无线滑环名称匹配开始：%s =====`、`无线滑环名称匹配	命令=SPN	目标名称=%s	匹配方式=显式名称字段完全匹配` |
| `SPC` | 查询当前连接状态 | `===== 无线滑环连接状态查询开始 =====`、`无线滑环连接状态	命令=SPC	动作=只读查询，不扫描、不断开、不保存默认连接` |

错误或用法打印：

```text
SP调试命令	用法：SPS=扫描，SPR=按RSSI匹配，SPN=<名称>=按蓝牙名称匹配，SPC=读取连接状态
无线滑环匹配	名称参数无效，格式：SPN=<name>，长度小于18字节
无线滑环匹配	RSSI选择失败	...
无线滑环匹配	最终结果	结果=失败	错误码=0x...
```

## B/BE 往返诊断命令

### 格式

| 指令 | 用途 | 参数 |
| --- | --- | --- |
| `B<mm>` | 按电机记步模型做下行/上行往返测试 | `<mm>` 为距离，单位 mm |
| `BE<mm>` | 按编码轮读数做下行/上行往返测试 | `<mm>` 为距离，单位 mm |
| `B<mm>S` / `BE<mm>S` | 每个下行/上行阶段后加一次传感器通信检查 | `S` 开启通信检查 |
| `B<mm>,1` / `BE<mm>,1` | 与 `S` 后缀等价 | `,1` 开启通信检查 |

显示状态：进入时切到“调试模式中”；退出时恢复进入前 `device_state` 和 `error_code`。诊断过程清除临时错误时仍保持调试模式显示。

### 入口打印

参数无效：

```text
B电机测试	距离参数无效	距离=%dmm
BE编码器测试	距离参数无效	距离=%dmm
```

参数有效：

```text
串口B指令	命令参数	模式=B电机	距离=%dmm	传感器通信=%u
串口B指令	命令参数	模式=BE编码器	距离=%dmm	传感器通信=%u
```

### B 过程打印

```text
B电机测试	开始	距离=%.2fmm	传感器通信=%u
[第%lu轮]	B下行	开始
[第%lu轮]	B下行	完成
[传感器] B下行后 类型=...
[第%lu轮]	B上行回零	开始
[第%lu轮]	B上行回零	完成
[传感器] B上行后 类型=...
[第%lu轮]	B电机测试	往返完成
```

### BE 过程打印

```text
BE编码器测试	开始	距离=%.2fmm	原点=%ld(0.00mm)	下行目标=%ld(%.2fmm)	编码增量=%ld(%.2fmm)	保护距离=%.2fmm	传感器通信=%u
[第%lu轮]	BE下行	开始	当前=%ld(%.2fmm)	原点=%ld(0.00mm)	目标=%ld(%.2fmm)
BE下行	保护行程已下发	保护距离=%.2fmm
BE下行	编码器到位触发	触发位置=%ld(%.2fmm)	目标=%ld(%.2fmm)	触发偏差=%.2fmm
BE下行	停稳结果	停稳位置=%ld(%.2fmm)	目标=%ld(%.2fmm)	停稳偏差=%.2fmm
[第%lu轮]	BE下行	完成	上行起点=%ld(%.2fmm)	固定原点=%ld(0.00mm)	固定下行目标=%ld(%.2fmm)
[第%lu轮]	BE上行	开始	上行起点=%ld(%.2fmm)	目标原点=%ld(0.00mm)	固定下行目标=%ld(%.2fmm)
[第%lu轮]	BE编码器测试	往返完成	当前=%ld(%.2fmm)
串口B指令	BE已返回	距离=%dmm	待执行命令=%lu	当前命令=%lu	新串口命令=%u
```

命令切换退出：

```text
B/BE检测到命令切换请求，停止当前串口测试
检测到命令切换请求，停止当前串口命令
```

## 电机和测试类调试命令

这些命令先执行 `MeasureStart()`。如果启动失败，打印：

```text
串口命令	启动失败	电机初始化错误码=0x%08lX\r\n
```

| 指令 | 用途 | 显示状态 | 主要打印 |
| --- | --- | --- | --- |
| `A0` | 慢停电机 | 调试模式 | 仅入口打印和底层停止相关打印 |
| `A+<mm>` | 上行指定距离 | 调试模式 | `串口上行	距离=%dmm\r\n`；失败时 `串口上行	下发失败	错误码=0x%08lX\r\n` |
| `A-<mm>` | 下行指定距离 | 调试模式 | `串口下行	距离=%dmm\r\n`；失败时 `串口下行	下发失败	错误码=0x%08lX\r\n` |
| `C` | 电机 4 步进分辨率测试 | 调试模式 | `串口调试	电机4步进分辨率测试开始`，内部还有 `motor STEP text start`、重量/编码器打印 |
| `D` | 电机 4 步进下行触底测试 | 调试模式 | `串口调试	电机4步进下行触底测试开始`，内部打印下行和重量 |
| `E` | 电机 4 步进上行碰零点测试 | 调试模式 | `串口调试	电机4步进上行碰零点测试开始`，内部打印多档步进下行/上行和重量 |
| `L` | 编码值清零 | 调试模式 | `串口调试	编码值清零` |
| `M` | 电机高温循环测试 | 调试模式 | `串口调试	电机高温循环测试开始` |
| `N` | 300mm 下行/上行循环测试 | 调试模式 | `串口调试	电机300mm往返测试开始`、`电机往返测试	下行开始`、`电机往返测试	上行回零开始` |

失败告警口径：

```text
串口上行	下发失败	错误码=0x%08lX\r\n
串口下行	下发失败	错误码=0x%08lX\r\n
```

同时会通过错误日志记录模块 `ERROR_LOG_MODULE_COMM`，处理口径为“仅记录”，不在串口入口直接设置最终故障态。

## 正常测量流程重复性入口

这些命令虽然由串口触发，但执行的是正常测量函数，不切调试模式。

| 指令 | 用途 | 入口打印 | 退出条件 |
| --- | --- | --- | --- |
| `F` | 罐底测量重复性测试 | `串口调试	罐底测量重复性测试开始` | 收到有效新命令或底层返回 `STATE_SWITCH` |
| `H` | 零点/罐底重复性测试 | `串口调试	零点/罐底测量重复性测试开始` | 收到有效新命令或底层返回 `STATE_SWITCH` |
| `J` | 液位测量重复性测试 | `串口调试	液位测量重复性测试开始` | 收到有效新命令时慢停并退出 |

这些命令内部会继续打印对应业务流程日志，例如找罐底、回零点、液位测量、液位跟随等日志。CPU3 状态也按这些业务流程显示，不显示“调试模式中”。

## 单点展示命令

### `X`

用途：不读真实传感器、不驱动电机，只刷新单点测量显示字段，用于 CPU3 显示链路演示。

入口打印：

```text
串口调试	执行单点测量展示指令
===== 单点测量展示模式开始 =====
展示说明: 不读真实传感器、不驱动电机，只刷新单点测量显示字段
停止方式: 下发任意新命令即可退出展示
```

过程打印：

```text
单点展示	运行到测量点 [%lu/6] 位置=%.1fmm
单点展示	已到达展示点，开始刷新虚拟温度/密度
单点展示	状态=固定点测量中 位置=%.1fmm 温度=%.2fC 密度=%.1f 标密=%.1f VCF20=%lu 重量密度=%.1f
```

退出打印：

```text
单点展示检测到新命令，退出当前演示
```

显示状态：按演示流程显示 `运行到点`、`固定点测量中` 等业务状态，不显示调试模式。

## 现场使用建议

- 想确认 CPU3 是否不再停留旧业务状态，优先用 `B100`、`BE100`、`SC`、`A+10`、`TS`、`YC` 验证，应显示“调试模式中”。
- 想验证正式业务状态不要被调试模式覆盖，用 `F/H/J/I/G/K/W/R` 验证，应显示对应测量状态。
- `B/BE` 是持续循环诊断，退出方式是发送任意有效新命令；如果出现 `BE已返回`，说明命令切换、编码目标未达或底层异常已经让测试函数退出。
- `SP*` 会操作 CH9141K AT/扫描/连接状态，`SPS` 会临时断开当前连接；现场执行前要确认无线链路允许被打断。
- 当前未识别普通串口命令缺少统一提示，后续建议在 `process_command()` 末尾增加 `串口命令	未识别	原始=%s` 这类打印，便于现场排查输入错误。
