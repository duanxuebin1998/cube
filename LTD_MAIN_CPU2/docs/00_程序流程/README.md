# CPU2 程序流程文档

更新日期：2026-06-13

本文件夹只保留一套 CPU2 当前程序流程文档，不再把“代码梳理”和“测量指令”拆成两个目录。

- [CPU2程序流程总览.html](CPU2程序流程总览.html)：唯一入口，集中查看主业务闭环、文档分层、命令参数测量上报关系和页面导航。
- [问题点总表.html](问题点总表.html)：集中查看具体问题点，支持按风险等级和关键词筛选，并可跳回对应页面。
- [01_启动主循环与中断.html](01_启动主循环与中断.html) ~ [16_其它项目代码.html](16_其它项目代码.html)：按功能域展开，每页同时包含整理范围、详细业务级 SVG 流程图、源码证据、问题点与优化建议、关键源码索引。
- [函数详细清单.json](函数详细清单.json)：源码扫描依据，覆盖 106 个 C/H 文件、865 个函数。
- [正式指令清单.json](正式指令清单.json)：正式指令与功能域页面、页面锚点的映射依据，覆盖 34 条正式指令。

阅读顺序建议：先打开总览理解全局业务闭环，再按功能域进入 01~16 页面；每个页面先看详细业务级 SVG 流程图，再对照源码证据和问题点确认具体实现细节。
