1. 系统边界与阅读顺序

回零建立位置零点；罐底建立高度基准；罐高标定把现场标定值写入参数。后续液位、水位、密度测量都会依赖这些基准。

外部入口
CMD_BACK_ZERO、CMD_FIND_BOTTOM、CMD_CALIBRATE_ZERO、CMD_CALIBRATE_TANKHEIGHT。
核心处理
CMD_MeasureZero()、CMD_CalibrateZeroPoint()、CMD_MeasureBottom()、CMD_CalibrateTankHeight()、SearchZero()、SearchBottom()。
关键基准
zero_position、bottom_value、current_real_height、tankHeight、currentTankHeight、bottom_reference_valid。
阅读重点
先看命令包装，再看回零和罐底两个闭环；最后看失败兜底和标定写参数。

2. 功能域业务总览 SVG

回零和罐底是两个独立闭环：回零负责“位置零点”，罐底负责“高度实测”，罐高标定再把实测与现场标定值关联起来。

3.1 回零、罐底、罐高相关命令包装流程

这些命令都从测量总入口进入。多数命令在总入口和具体函数内部都会调用公共准备，这一点是后续问题点的来源。

源码依据Application/Src/measure.c:573-713：回零、零点标定、罐底测量包装；Application/Src/measure.c:31-58：罐高标定包装。
状态回写回零中 STATE_BACKZEROING，零点标定中 STATE_FINDZEROING，罐底中 STATE_FINDBOTTOM；命令 115 已保留，不再发布强制提零状态。
已整理问题点总入口先公共准备，命令函数内部再次公共准备，可能重复电机初始化、扭力初始化并清协议辅助标志。

3.2 SearchZero 回零主流程

回零分粗找和精找两个阶段，均带三次重试。粗找/精找失败和标零后的退让、脱离零点使用专用无扭力保护下行动作，动作完成后重置稳定扭力基准。

源码依据Application/Src/measure_zero.c:32-236：专用退让/脱离、稳定扭力重置、粗找三次、精找三次、偏差检查、编码器清零、切回编码器位置源、读取零点电容/陀螺基准。
异常出口粗找/精找中的 CHECK_ERROR、CHECK_COMMAND_SWITCH、RETURN_ERROR 都会提前退出；电机驱动恢复类错误直接返回。
已整理问题点回零完成后状态直接回 STATE_STANDBY，上位机如果只看状态不容易区分“刚完成回零”和普通待机。

3.3 零点粗找与精找闭环

这张图展开内部闭环：粗找按距零点距离降速；精找按与粗找零点的距离分段降速，并在越界时快速停机返回错误。

源码依据Application/Src/measure_zero.c:219-307：SearchZeroRough() 和 SearchZeroPrecise() 的速度切换、循环条件、快速停机和越界保护。
关键参数粗找 200mm 内降到 0.50m/min；精找 600mm/100mm 内分段降速；max_zero_deviation_distance 控制偏差越界。
已整理问题点偏差检查在电机位置源和零点标定状态下有条件跳过，需要保证标定操作权限和现场工况可控。

3.4 SearchBottom 罐底搜索主流程

罐底搜索比普通顺序过程复杂：可自动回零、可建立陀螺参考、必须确认离底，粗找最多三次，精找执行两轮且每轮最多三次。

源码依据Application/Src/measure_tank_height.c:277-431：自动回零、初始上移、陀螺基准、离底确认、粗找三次、两轮精找、实高记录、编码器修正和上移收尾。
关键分支任何阶段返回 STATE_SWITCH 会直接上交命令切换；粗找最终失败返回 MEASUREMENT_WEIGHT_DOWN_FAIL。
已整理问题点罐底搜索内部可以触发自动回零，因此一次罐底命令可能包含完整回零闭环，执行时间和故障路径都比较长。

3.5 罐底检测、实高修正和失败兜底

CMD_MeasureBottom() 在 SearchBottom() 返回后还会判断是否用参考罐高兜底。启用后，即使搜索失败或偏差过大，也可能写入 fallback 高度并置完成态。

源码依据Application/Src/measure.c:615-712：罐底包装、error_stop_measurement 兜底、随机 fallback、告警日志、完成态；Application/Src/measure_tank_height.c:391-431：实高计算和编码器修正。
状态回写普通成功和 fallback 成功都会写 bottom_reference_valid = 1 和 STATE_FINDBOTTOM_OVER；fallback 还会清 error_code。
已整理问题点fallback 会弱化真实罐底失败：上位机可能看到完成态，但实际高度来自参考值；calibrateTankHeight 有值时还会加入 +/-3.0mm 随机扰动。

3.6 零点标定与罐高标定流程

零点标定在回零成功后标定第一圈周长；罐高标定先检查用户输入的标定罐高，再搜索罐底，把原始实高和标定值分别保存。

源码依据Application/Src/measure.c:585-600：零点标定；Application/Src/measure.c:31-58：罐高标定。
参数写入罐高标定写 initialTankHeight = 原始实高、currentTankHeight = calibrateTankHeight，并同步 current_real_height 后保存参数。
已整理问题点罐高标定依赖 calibrateTankHeight 非 0 和罐底搜索结果非 0；如果参数入口没有前置校验，错误会在运动后才暴露。

5. 问题点与优化建议

  • 罐底 fallback 可能掩盖真实失败：启用 error_stop_measurement 后，搜索失败或偏差超过 10mm 也可能写参考高度、清错误码并置完成态。建议在协议输出里明确区分“实测完成”和“参考兜底完成”。
  • 重复公共准备：总入口和命令函数内部重复调用 MeasureStart()，会重复初始化电机/扭力并清过程标志。建议收敛到单一入口或给内部函数增加“已准备”语义。
  • 罐高 fallback 随机扰动影响追溯：calibrateTankHeight 有值时 fallback 加 +/-3.0mm 随机量，长期日志分析时需要知道该值不是实测值。
  • 回零完成态不明显：CMD_BACK_ZERO 成功后直接进入 STATE_STANDBY，建议增加完成状态或完成沿标志，方便上位机判断。
  • 罐高标定参数校验偏晚：calibrateTankHeight == 0 会在进入命令函数后才报错，建议在命令下发或总入口处前置校验。
