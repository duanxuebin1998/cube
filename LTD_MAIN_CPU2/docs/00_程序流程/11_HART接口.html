1. 整理范围

HART 当前实现是从 USART2 中断直接进入协议解析，解析成功后根据命令号生成响应；响应以长地址结构为基础，短帧请求再转换为短地址响应。

帧类型

短帧使用轮询地址匹配，长帧使用厂家、设备类型和 3 字节设备 ID 匹配。

支持命令

支持 0 读唯一标识、1 读主变量、2 读电流、3 读动态变量、6 写轮询地址。

输出硬件

AD5421 初始化、诊断和写电流由 AoOutput_Init()/AoOutput_Update() 管理；HART 命令只读取当前 AO 电流和百分比。

3. 源码证据

初始化Services/Hart/hart.c:52-60 仅设置 HART_RTS 为接收方向并初始化 HART 参数；AD5421 初始化已移到 AoOutput 服务。

USART2 中断Core/Src/stm32f4xx_it.c:382-415 在 IDLE 中断停止 DMA，调用 HartCommunicationProcess，有响应则切 RTS 发送。

发送完成Core/Src/usart.c:70-80 发送完成后等待 TC、延时、RTS 回接收并重启 RX DMA。

解析入口Services/Hart/hart.c:82-176 解析成功后按命令号分派，短帧响应再转换，最后计算 BCC 和前导码。

长帧校验Services/Hart/hart.c:215-228 长帧命令在 data[6]，校验 MANUFACTURER_ID、DEVICE_TYPE 和 DEVICE_ID。

BCC 校验Services/Hart/hart.c:234-246 对定界符到数据区逐字节异或，与帧尾 BCC 比较。

命令 0Services/Hart/hart.c:307-333 填写唯一标识、版本、设备 ID、前导码等固定身份信息。

命令 1/2/3Services/Hart/hart.c:342-421 命令 1 读取液位，命令 2 读取 AoOutput 电流/百分比，命令 3 返回电流、液位、温度和平均密度。

4. 问题点与优化建议

1. HART 解析与组包在 USART2 中断链路内执行

解析、打印、响应数据填充、BCC 和前导码添加都在中断入口调用；发送完成回调还有等待 TC 和大循环延时，实时性风险较高。

Core/Src/stm32f4xx_it.c:382-415, Core/Src/usart.c:70-80
2. HART 变量依赖 AO/测量缓存的新鲜度

命令 1/2/3 已绑定液位、AO 电流、温度和密度，但 HART 中断直接读取当前缓存；如果 AO 服务或测量结果未及时刷新，返回值会滞后。

Services/Hart/hart.c:342-421, Services/AoOutput/ao_output.c:488-508
3. 不支持命令没有标准错误响应

default 分支仅打印不支持命令，Sendlen 可能保留为 0 或旧值风险，建议明确清零并返回 HART 状态码。

Services/Hart/hart.c:167-170
4. 解析按固定偏移访问，缺少接收长度边界保护

AnalyseRcvPackage 根据 BytesCount 计算 datalen 并访问 data[datalen]，但未直接使用 USART2_RX_LEN 做边界约束。

Services/Hart/hart.c:192-246
5. 命令 6 只改 RAM 轮询地址

HartParameters.PollingAddress 被更新后没有持久化路径，重启后会丢失。

Services/Hart/hart.c:410-421
6. 短地址响应转换依赖原长响应布局

ConvertToShortAddressResponsePacket 通过覆盖 data 数组删除 4 字节，结构体布局变化时容易引入错位。

Services/Hart/hart.c:430-440
7. HART 和 AO 输出链路职责已分离

HartInit 不再初始化 AD5421，HART 命令只读取 AoOutput 运行态；排查无电流输出时应先看 AO 使能、AoOutput_Update 和 AD5421 诊断。

Services/Hart/hart.c:52-60, Services/AoOutput/ao_output.c:354-470
8. float 字节序转换通过指针重解释实现

SetFloatData 对 float 地址按 u32 指针重解释，在严格别名或不同编译配置下可读性和可移植性较弱。

Services/Hart/hart.c:259-267
