1. 总体结论

本次改动从“电机运动函数简化”开始，最终形成两类结果：第一类是 motor_ctrl_motion_api.c 内部结构收敛，减少重复速度恢复、ticks 等待和 Jog 位置检查逻辑；第二类是台架复测暴露出的安全修复，即绝对目标越界在运动下发前被拒绝，并且参数类确定性错误不再进入自动恢复重跑。

注意：本 HTML 是第一轮历史清单，不代表当前 motor-motion-structure worktree 的完整 diff。当前分支新增的 MotorMotionTargetPlan、等待循环 helper、第三轮策略评估和计划完成审计，以《电机运动函数简化优化计划.md》《电机点动与位置模式分层优化方案.md》《电机运动第三轮策略评估记录.md》《电机运动当前计划完成审计.md》为准。

结构简化

新增 MotorMotionSpeedScope、ticks 起步/到位等待 helper、Jog 位置刷新检查 helper，删除 MotorCtrl_MoveAndWait() 中误导性的不可达重试框架。

安全修复

新增 MotorMotion_CheckAbsoluteTargetRange()，在正式距离、正式绝对位置、Jog 相对和 Jog 绝对入口下发运动前检查目标范围。

恢复策略

新增 FaultRecovery_IsNonRecoverableError()，过滤 PARAM_RANGE_ERROR 等确定性参数错误，避免自动恢复反复执行无效目标。

4. 故障恢复改动

函数当前行号本次改动原因
FaultRecovery_IsNonRecoverableError() fault_recovery.c:62 新增确定性配置/边界错误分类，当前过滤 PARAM_RANGE_ERROR、PARAM_ADDRESS_OVERFLOW、PARAM_ERROR。 这些错误不会通过重新初始化或重读部件参数恢复，自动重跑只会重复失败。
FaultRecovery_Start() fault_recovery.c:226 在检查 retry limit 和命令白名单前，先排除不可恢复错误。 T05 复测曾暴露越界目标会被 CMD_RUN_TO_POSITION 自动恢复重跑 3 次。
FaultRecovery_IsRecoverableCommand() fault_recovery.c:98 注释更新为“先排除确定性配置/边界错误，再按命令白名单恢复”。 让维护说明与代码行为一致。

本次最终没有过滤所有 MEASUREMENT_POSITION_ERROR。早期方案曾考虑直接把位置错误列为不可恢复，但复核后认为范围过大，可能影响其它位置异常路径；最终改为目标越界返回 PARAM_RANGE_ERROR，自动恢复只过滤参数类确定性错误。

5. 行为变化和兼容性

项目变化前变化后影响
绝对目标越界 部分路径只验证当前位置快照，未在运动下发前可靠拒绝目标本身越界。 目标小于 0 或大于罐高时，在下发运动前返回 PARAM_RANGE_ERROR。 CPU2 运行行为变化；提交/发布前应升 CPU2 patch 版本。
越界错误码 曾在复测中返回 MEASUREMENT_POSITION_ERROR。 最终返回 PARAM_RANGE_ERROR = 0x00110003。 错误归因更准确；未新增错误码，未改变 CPU2/CPU3 共享协议枚举。
自动恢复 CMD_RUN_TO_POSITION 属于可恢复命令，越界目标失败后会进入自动重跑。 参数类确定性错误不进入自动恢复。 避免无效目标重复执行；硬件通信、驱动等非参数类错误仍按原白名单恢复。
运动策略 正式绝对运动和 Jog 运动保持各自策略。 仍保持各自策略；本次未把 MoveToPosition 替换为 Jog 反馈策略。 不改变默认运动算法，只补目标前置拒绝和内部结构整理。
台架下限 现场要求传感器位置不低于 200mm。 固件目标范围仍按 0~tankHeight 判断；本文档只记录 200mm 是台架限位。 是否固化 200mm 下限仍需产品/现场决策。
