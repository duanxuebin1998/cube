1. 总体结论

电机程序的核心分层比较清晰：业务命令和测量流程调用 MotorCtrl_* 上层接口；MotorControl 内部再分为运动 API、驱动参数/健康检查、位置模型、丢步检测和尺带拟合；最底层由 TMC5130.c 负责 SPI 寄存器访问和步进驱动器控制，AS5145.c 与 encoder.c 负责外部编码轮采集与位置换算。

2026-06-11 当前 codex/motor-simplify worktree 已完成第一轮结构优化：临时速度恢复由 MotorMotionSpeedScope 统一收口，MotorCtrl_MoveAndWait() 保留单次正式运动主线，ticks 运动拆成起步确认和到位确认两个内部 helper，Jog 到目标流程复用统一的位置刷新检查。台架验证仍以《电机运动函数台架验证记录.md》为准，本文不宣称实物验证已经完成。

正常业务运动

CMD_MoveUp()、CMD_MoveDown()、液位/密度/罐底等测量流程主要走 MotorCtrl_MoveAndWait() 或 MotorCtrl_MoveToPosition()，默认带驱动健康检查、有效位置刷新、命令切换打断、慢停和保护检测；临时速度由 MotorMotionSpeedScope 统一恢复。

调试和强制运动

A、B、BE、BJ/BJP、C/D/E/M/N 等串口调试路径会部分绕开正式测量初始化或保护检测。MotorCtrl_MoveBlockingNoDetectForceDebug() 只绕过编码器首帧门控；BJ/BJP 调用 Jog 接口验证主动位置反馈和提前减速方案。

位置源

系统支持编码轮记步和电机记步两套位置源。编码轮模式由 encoder_get_cable_length_01mm() 换算尺带长度；电机记步模式由 TMC5130_XACTUAL、卷筒模型和切换基准推算业务位置。

关键安全边界

运动前统一经过 MotorDriver_CheckMotionReady() 和 MotorDriver_CheckHealth()；运行中持续调用 MotorDriver_SyncPositionOrCheckHealth()、MotorCtrl_PollRuntimePosition()、MotorCtrl_CheckLostStepAutoTiming() 等接口。Jog 路径还会通过当前有效位置源判断剩余距离、减速距离和越界风险。

2. 文件和职责地图

文件 角色 主要职责
LTD_MAIN_CPU2/Services/MotorControl/motor_ctrl.h 对外接口 定义业务层可调用的电机接口、方向宏、卷筒状态结构和单位约定。业务代码应优先调用这里声明的 MotorCtrl_* 函数。
motor_ctrl.c 全局状态 定义 velocity、s_motor_driver、s_motor_position 等 MotorControl 跨文件共享状态。
motor_ctrl_internal.h 内部契约 集中内部宏、常量、运行态结构、FRAM 持久化结构、TFIT 结构和 MotorDriver_*/MotorPosition_* 跨文件内部接口。
motor_ctrl_motion_api.c 运动 API 实现按距离、按 ticks、绝对位置、连续上/下行、急停/慢停、无检测运动、等待停止和命令切换打断。
motor_ctrl_driver_param.c 驱动参数 负责 TMC5130 初始化、速度/电流换算、VMAX 刷新、驱动健康检查、功率级检查、显示状态推断和临时速度恢复。
motor_ctrl_position_model.c 位置模型 维护编码轮/电机记步位置源，基于 XACTUAL 和卷筒模型换算尺带长度，处理 FRAM 位置持久化和 XACTUAL 异常读数过滤。
motor_ctrl_lost_step_detect.c 保护检测 通过位置窗口和时间窗口判断运行中是否疑似丢步；无检测运动下只做运行日志，不参与保护。
motor_ctrl_tape_fit.c 卷筒拟合 实现 TFIT 自动/手动采样、全局或局部求解、首圈周长和尺带厚度应用。
BSP/Peripherals/src/TMC5130.c 底层驱动 封装 TMC5130 SPI 收发、寄存器读写、位置模式运动、停止、使能、电流、速度、等待到位和驱动状态解析。
BSP/Peripherals/src/AS5145.c 编码器采集 通过 SPI/SSI 定时采集 AS5145 角度帧，校验奇偶、OCF/COF/LIN/MagINC/MagDEC 状态，维护首帧有效门控和最近错误码。
Services/Encoder/encoder.c 编码轮位置 累计编码轮跨零点计数，持久化 A/B 槽，按编码轮周长换算尺带长度和传感器位置。
Application/Src/measure.c 业务命令 串口调试命令和正式测量命令入口；调用电机接口完成手动上/下行、强制运动、B/BE 测试、位置源切换、TFIT 和测量流程。

5. 对外函数清单

5.1 初始化、停止和状态

函数位置作用主要注意点
MotorCtrl_Init(void)motor_ctrl_driver_param.c初始化 TMC5130、设置速度/电流/斜坡参数、恢复持久化位置和位置源状态。测量开始前会再次调用；非首次初始化用于恢复掉电/复位后的驱动配置。
MotorCtrl_BootSafeStop(void)motor_ctrl_driver_param.c上电早期安全停机，清理驱动残留运动目标。用于避免重启后电机沿旧目标继续运行。
MotorCtrl_InvalidateDriverInit(void)motor_ctrl_driver_param.c在 TMC 通信、复位、配置丢失或功率级异常后标记驱动初始化失效。后续运动入口会尝试重新初始化。
MotorCtrl_IsDriverInitValid(void)motor_ctrl_driver_param.c查询驱动初始化和上电安全停机状态是否有效。故障恢复和 App 空闲错误处理会使用。
MotorCtrl_QuickStop(void)motor_ctrl_motion_api.c快速停止，停止后短暂关闭再重新使能驱动，并恢复默认速度。用于需要更强制停止的场景。
MotorCtrl_SlowStop(void)motor_ctrl_motion_api.c按 TMC 斜坡减速停止，等待停止完成，并恢复默认速度。命令切换、故障处理、自动恢复常用。
MotorCtrl_GetDisplayState(void)motor_ctrl_motion_api.c返回显示/协议用电机状态：0 停止、1 上行、2 下行。会结合缓存状态和 TMC 实际运动状态推断。

MotorCtrl_MoveNoWait(float move_mm, int dir, uint32_t speed_x100)motor_ctrl_motion_api.c按距离换算 ticks 并下发运动目标，不等待到位。B 指令、连续运动、部分调试循环。

MotorCtrl_MoveDown(uint32_t speed_x100)motor_ctrl_motion_api.c连续下行放带，内部调用 MotorCtrl_MoveNoWait(200, DOWN)。液位查找中的连续下行。

MotorCtrl_MoveBlockingNoDetectForceDebug(...)motor_ctrl_motion_api.c强制调试无检测运动，只绕过编码器首帧门控。CMD_ForceMoveUp()、CMD_ForceMoveDown()、CMD_ForceLiftZero()。

11. 保护、恢复和易错点

电机相关改动最容易出问题的地方不是单个函数，而是绕开了已有边界：运动前门控、命令切换打断、TMC5130 掉电/复位恢复、编码器首帧有效门控、位置源切换回滚和 FRAM 持久化。

风险点涉及函数检查建议
未初始化或 24V 功率级未建立时下发运动MotorDriver_CheckMotionReady()、MotorDriver_CheckHealth()、stpr_checkDriverPowerReady()新增运动入口必须经过 MotorControl 上层门控，除非明确是受控低检测测试。
命令切换时电机未停稳CHECK_COMMAND_SWITCH_AND_STOP、MotorDriver_StopIfCommandSwitchRequested()、MotorDriver_StopAndMarkStopped()长循环和等待循环要持续检查命令切换，返回 STATE_SWITCH 前先停机。
异常返回时临时速度未恢复MotorMotionSpeedScope、MotorMotion_ReturnWithSpeedScope()、MotorMotion_CheckErrorWithSpeedScope()新增带临时速度的运动路径必须通过 scope 收尾；若提前调用故障处理，也要先恢复默认速度。
编码轮未首帧有效导致位置盲区Encoder_IsReady()、AS5145_HasValidSample()、MotorDriver_CheckMotionReady()普通运动不能绕过首帧门控；强制调试路径要在文档和日志中明确。
主动位置反馈使用了错误位置源MotorCtrl_RefreshPositionFromActiveSource()、MotorCtrl_SnapshotSensorPositionMm()、MotorMotion_RefreshActivePositionMm()Jog、绝对位置和密度流程都应按当前记步源刷新位置；切换位置源后要重新确认快照来源。
Jog 速度模式接近目标时过冲MotorMotion_CalcJogSlowdownDistanceMm()、MotorMotion_CalcJogStopDistanceMm()、MotorMotion_StopJogAndRestore()调整速度、加减速或卷筒模型后，必须复核减速距离、最终停机距离和越界阈值。
TMC5130 单帧异常 XACTUAL 污染位置MotorPosition_FilterXactualGlitch()、MotorPosition_TryUpdateDrumStateFromXactual()读取异常时二次确认，不要直接更新缓存和 FRAM。
位置源切换失败留下半更新状态MotorCtrl_SwitchPositionSourceToMotor()、MotorPosition_RollbackPositionSourceSwitch()切换失败必须回滚旧模式、旧局部周长、基准和错误码。
调试无检测运动误用于正式流程MotorCtrl_MoveBlockingNoDetect()、MotorCtrl_MoveBlockingNoDetectForceDebug()正式测量流程优先使用 MotorCtrl_MoveAndWait() 或 MotorCtrl_MoveToPosition()。

12. 错误来源和处理路径

错误来源 典型错误码/状态 主要产生位置 处理路径
TMC5130 SPI 通信 MOTOR_TMC_COMM_ERROR stpr_writeInt()、stpr_tryReadInt()、stpr_moveBy()、stpr_stop() 上层通常调用 MotorCtrl_SlowStop() 或返回错误；部分路径会调用 MotorCtrl_InvalidateDriverInit()，等待下一次运动前重新初始化。
TMC5130 复位/欠压/配置丢失 MOTOR_DISABLED、MOTOR_TMC_COMM_ERROR 或驱动状态错误 stpr_checkDriverStatus()、MotorDriver_CheckHealth()、MotorDriver_CheckMotionReady() 标记驱动初始化失效；运动入口尝试 MotorCtrl_Init() 恢复，恢复失败则阻止运动。
绝对目标超出罐高 PARAM_RANGE_ERROR MotorMotion_CheckAbsoluteTargetRange() 在下发运动前返回错误；故障恢复过滤该确定性错误，避免自动重跑无效目标。
TMC5130 过温/短路/开路/StallGuard MOTOR_OVERTEMPERATURE、MOTOR_ALARM_TRIGGERED tmc5130_decodeDrvStatus()、stpr_checkDriverStatus() 返回统一错误码，上层停止当前运动并进入故障处理或自动恢复流程。
24V 功率级未建立 MOTOR_DISABLED 或功率级检查失败 stpr_checkDriverPowerReady()、MotorDriver_CheckInitPowerReadyWithRetry() 初始化期等待实际电流建立；超时后按电机不可用处理，不允许继续下发正式运动。
编码器 SSI 采集 ENCODER_TIMEOUT、ENCODER_PARITY_ERROR、ENCODER_OCF_INCOMPLETE、ENCODER_CORDIC_OVERFLOW、ENCODER_LINEARITY_WARNING AS5145.c 的 Get_SSI_Error_Code()、Handle_SSI_Error()、AS5145_GetLastError() 编码轮位置源下会写入全局错误码并阻止普通运动；电机记步模式对编码器错误有特殊分支，避免误拦截。
编码器首帧未就绪 ENCODER_TIMEOUT、ENCODER_POWERON_FAIL Initialize_Encoder()、Encoder_WaitReady()、MotorDriver_CheckMotionReady() 普通运动入口阻止运动；强制调试运动可显式绕过该门控。
丢步/编码轮未跟随 ENCODER_LOST_STEP MotorCtrl_CheckLostStepAutoTiming() 正式搜索/跟随流程检测到后停止当前运动并上报错误；无检测运动只记录运行日志。
命令切换 STATE_SWITCH CHECK_COMMAND_SWITCH_AND_STOP、MotorDriver_StopIfCommandSwitchRequested() 先停机，再把返回值交给上层流程退出，不应继续执行原命令剩余动作。
位置源切换失败 运动错误、参数错误、保存失败或编码器采样异常 MotorCtrl_SwitchPositionSourceToMotor()、MotorPosition_RollbackPositionSourceSwitch() 回滚旧记步模式、旧局部周长、旧电机基准和旧错误码，避免半切换状态残留。
运行超时/停机超时 MOTOR_RUN_TIMEOUT MotorMotion_WaitStopAbortable()、MotorMotion_WaitUntilStopWithTarget()、MotorDriver_StopAndMarkStopped() 停止运动并返回错误，交给业务流程记录或上报。
